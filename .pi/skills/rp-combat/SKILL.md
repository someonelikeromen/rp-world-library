# RP Combat

多世界战斗判定与战斗日志维护。

## 多世界战斗框架加载

- 渐进式入口：`framework/README.md`
- 路径解析规则：`framework/README.md` 必须相对本 skill 目录解析，实际位置为 `.pi/skills/rp-combat/framework/README.md`；不得按项目根目录解析为 `framework/README.md`。
- 如果读取渐进式入口失败，先检查是否发生了相对路径解析错误，不要据此判定模块化框架不存在。
- 完整母版：`docs/world-combat-framework.md`
- 战斗判定时优先读取 `framework/README.md`，再按场景需要读取对应模块；不要默认一次性加载完整母版。
- 涉及任何 N 级评估时，必须先读取 `framework/02-rating/02-evaluation-method.md`，再读取 `framework/02-rating/03-rating-system.md`；不得只读取 N0–N24 等级表后直接定级。
- 模块正文是母版的无损切分，不摘要、不精简、不改写；需要完整语义时按索引顺序读取多个模块。


## 触发条件

- RP 中发生战斗/冲突对抗
- 用户要求战斗判定

## 1. 评级面板

为每个战斗对象建立统一评级面板，区分维度：

| 维度 | 说明 |
|------|------|
| 综合 | 整体战斗力 |
| 攻击 | 输出能力、穿透、破防 |
| 防御 | 承受力、格挡、护甲 |
| 耐久 | 体力、续航、恢复 |
| 反应 | 速度、先手、闪避 |
| 机动 | 移动、追击、脱离 |
| 控制 | 限制、禁锢、debuff |
| 感知 | 侦查、预判、直觉 |
| 精神 | 意志、抗性、精神力 |
| 特殊机制 | 独有能力、规则级效果 |
| 抗性 | 各类型伤害减免 |
| 资源 | 魔力/气/体力/弹药 等 |

## 2. 流程

1. 确认交战对象、战斗目标（击败/击杀/拖延/逃跑/捕获）。
2. 为每个战斗对象建立评级面板。
3. 确认可用能力、资源状态、环境、地图位置。
4. 检查能力消耗、蓄力时间、标准出手窗口、外在表现。
5. 比较词条、能力等级、抗性等级。
6. 同级机制碰撞时比较对应驱动属性。
7. 需要随机因素时调用 `rp-dice` skill。
8. 判定结果：伤害、状态变化、资源变化、位置变化。
9. 写入记忆文件。

## 3. 判定原则

- 用维度细分做比较，**禁止只用"综合"硬碰**。
- 评级必须先按评价方式拆证据，再对照评级体系；禁止直接按角色名、称号、稀有度、剧情地位或 N0–N24 表拍板。
- 长蓄力大招不算常态评级。
- 不凭称号或同名词自动拔高。
- 没有明确证据不升到规则/概念/高维。
- 同级能力碰撞时，比较对应驱动属性和环境加成。

## 4. 输出

战斗结束后更新：

- `memory/project.md`：战斗结果、NPC 伤亡、局势变化
- `memory/user.md`：角色状态变化、资源消耗、新伤/新能力
