## 12. 环境与场地优势

不默认世界压制外来能力，但具体环境会影响能力发挥。

记录项：

```json
{
  "environment": {
    "terrain": "城市雨夜",
    "energyDensity": [],
    "visibility": "low",
    "cover": "high",
    "publicExposureRisk": "medium",
    "fieldEffects": [
      {
        "tag": "water-rich",
        "effect": "水系能力控制难度下降，雷电扩散风险上升。"
      }
    ],
    "factionRules": []
  }
}
```

环境可影响：

- 能量恢复。
- 技能发动条件。
- 弹道与命中。
- 隐蔽与侦查。
- 公众暴露风险。
- 势力介入。
- 战后后果。
