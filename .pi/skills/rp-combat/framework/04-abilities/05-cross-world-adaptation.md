## 5. 跨世界能力适配规划

根据当前需求重写：不默认有世界压制。能力能否使用主要看能力自身依赖与当前世界是否提供对应条件。

### 5.1 保留规则

跨世界时：

- 身体层面可完全保留。
- 精神层面可完全保留。
- 灵魂层面可完全保留。
- 天赋可完全兼容。
- 基于自身本质的能力可保留。
- 需要外界交互、外界能量、世界法则支持的能力，视当前世界情况而定。
- 特殊能力可突破常规限制，但必须记录原理、条件和代价。

### 5.2 适配判断不等于压制

进入新世界时，不进行默认压制，而进行条件检查：

```text
1. 能力依赖什么？
2. 当前世界是否存在该资源或等价资源？
3. 使用者是否能感知、吸收、转化、调用该资源？
4. 能力原理是否需要某种世界规则承认？
5. 如果没有原资源，是否可由自身能量、道具、天赋、替代能源补足？
6. 如果世界明确存在排斥机制，才计算压制或反噬。
```

### 5.3 适配结果

```text
Full        完全可用
Equivalent 通过等价资源可用
Partial     部分可用，效果变化
SelfOnly    仅自身部分可用
Unavailable 条件缺失，无法发动
Rejected    被世界规则/环境明确排斥
```

示例：

```json
{
  "abilityId": "shadow-devour",
  "adaptation": "Partial",
  "reason": "当前世界存在阴影与负能量，但不存在原体系的暗影源海。可使用自身储备发动，恢复速度下降。",
  "changes": [
    "最大输出降低",
    "持续时间缩短",
    "侵蚀词条保留",
    "对灵效果保留"
  ]
}
```
