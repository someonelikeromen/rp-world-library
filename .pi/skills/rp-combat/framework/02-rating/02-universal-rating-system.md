## 2. 通用战力评级体系（兼容入口）

本文件保留为旧路径兼容入口。当前框架已经将“评价方式”和“评级体系”拆分，避免只读取 N0–N24 表而跳过多世界评价方法。

## 强制读取顺序

任何角色、能力、道具、形态、世界力量体系、成就奖励、兑换项的 N 级评估，必须按以下顺序读取：

1. `02-rating/02-evaluation-method.md` —— 评价方式：如何扒皮、如何拆证据、如何区分常态/爆发/条件/仪式/外力、如何排除称号水分。
2. `02-rating/03-rating-system.md` —— 评级体系：N0–N24 等级表、分数区间、表现力标注、子级和高等级结构说明。

禁止只读取 `03-rating-system.md` 或只引用 N0–N24 表后直接定级。

## 模块职责

| 模块 | 职责 |
|---|---|
| `02-evaluation-method.md` | 评价方式 / 评估方法 / 扒皮流程 / 输出格式 / 兑换项估价要求 |
| `03-rating-system.md` | 通用评级体系 / N0–N24 等级表 / 数值段 / 表现力标注 |

## 最小合规流程

```text
需要定级
→ 读取 02-evaluation-method.md
→ 按评价方式拆证据
→ 区分常态/强化/爆发/透支/蓄力/仪式/外部支援
→ 排除称号、吹词、同名不同义和借力水分
→ 读取 03-rating-system.md
→ 对照 N0–N24 等级与数值区间
→ 输出 baseRating / peakRating / conditionalRating / disputes
```
