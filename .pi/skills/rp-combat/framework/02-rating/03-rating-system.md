## 2B. 通用评级体系

本模块只回答“评级表是什么”。它提供项目内汪吧风格 N0–N24 等级、分数区间、表现力标注和高等级结构说明。

任何实际定级必须先读取 `02-evaluation-method.md`，按评价方式拆证据后，再使用本模块对照等级。不得只读取本模块后直接定级。

### 2B.1 通用评分结构

本项目使用“项目内汪吧风格评级表”，不伪称为某个社区的官方原表。设计原则参考战力讨论中的“扒皮”思路：以可验证表现、作用范围、破坏尺度、创造/支配尺度、速度与抗性表现作为证据，禁止只凭称号、设定吹词或角色台词直接定级。

评分结构：

```text
评级名 + 子级 + 数值区间 + 表现力标注 + 证据要求
```

数值使用指数式扩张，不追求现实物理精确换算，只用于跨世界内部一致性。每一级内部保留低/中/高/巅峰四段。

```text
N0  普通人级              0-99
N1  街头级                100-299
N2  墙壁级                300-599
N3  房屋级                600-999
N4  建筑级                1,000-1,999
N5  街区级                2,000-3,999
N6  城镇级                4,000-7,999
N7  城市级                8,000-15,999
N8  山脉/区域级           16,000-31,999
N9  国家/大陆板块级       32,000-63,999
N10 大陆级                64,000-127,999
N11 月球/小行星级         128,000-255,999
N12 行星级                256,000-511,999
N13 大行星/恒星表层级     512,000-1,023,999
N14 恒星级                1,024,000-2,047,999
N15 星系级                2,048,000-4,095,999
N16 星系团级              4,096,000-8,191,999
N17 可观测宇宙级          8,192,000-16,383,999
N18 单体宇宙级            16,384,000-32,767,999
N19 多宇宙级              32,768,000-65,535,999
N20 大型多元宇宙级        65,536,000-131,071,999
N21 无限多元宇宙级        131,072,000-262,143,999
N22 高维多元级            262,144,000-524,287,999
N23 复杂高维结构级        524,288,000-1,048,575,999
N24 外层/超维叙事结构级   1,048,576,000+
```

高维与外层级不只看“能量数字”，必须有明确世界观结构证据：例如支配/创造/毁灭多个独立宇宙、无限宇宙集合、高维轴、超越时空连续体、支配低维叙事结构等。否则不能仅凭“无限”“超越”“全能”等词汇定级。

### 2B.2 表现力标注表

每个等级必须有对应表现力标注，用于 GM / agent 判断。

| 等级 | 表现力标注 | 典型证据 |
|---|---|---|
| N0 普通人级 | 普通成年人、运动员、持械普通人范围 | 打斗、负重、短跑、现实训练表现 |
| N1 街头级 | 可稳定压制多人、破坏轻质物体 | 徒手击倒多人、破坏木门、轻型武器威胁 |
| N2 墙壁级 | 可破坏墙体、承受小规模爆炸/撞击 | 打穿砖墙、硬抗近距离钝击 |
| N3 房屋级 | 可破坏单体房屋或造成同级灾害 | 摧毁小屋、局部塌方 |
| N4 建筑级 | 可破坏大型建筑主体 | 打塌楼层、摧毁大型结构 |
| N5 街区级 | 可影响或破坏街区范围 | 街区级爆炸、范围扫荡 |
| N6 城镇级 | 可毁灭/压制小镇级范围 | 大范围术式、军队级灾害 |
| N7 城市级 | 可毁灭/支配城市范围 | 城市级破坏、覆盖全城结界 |
| N8 山脉/区域级 | 可摧毁山脉、岛屿或大片区域 | 改变区域地形、摧毁大型岛屿 |
| N9 国家/大陆板块级 | 可影响国家级范围或大陆板块结构 | 国家级灾害、板块级地形改变 |
| N10 大陆级 | 可毁灭/重塑大陆尺度 | 大陆破坏、跨大陆天灾 |
| N11 月球/小行星级 | 可摧毁或创造月球、小行星级天体 | 天体级破坏或承受同级攻击 |
| N12 行星级 | 可摧毁、重塑、支配行星 | 爆星、星球级结界、全球环境改写 |
| N13 大行星/恒星表层级 | 介于行星与恒星主体之间 | 巨行星级、恒星表层扰动 |
| N14 恒星级 | 可摧毁、创造、支配恒星 | 恒星毁灭、恒星能量级输出 |
| N15 星系级 | 可影响或毁灭星系尺度 | 星系级打击、支配星系结构 |
| N16 星系团级 | 可影响多个星系组成的大尺度结构 | 星系团范围创造/毁灭/支配 |
| N17 可观测宇宙级 | 可影响可观测宇宙尺度结构 | 宇宙尺度扩散、全宇宙物质层面影响 |
| N18 单体宇宙级 | 可创造、毁灭、重启或支配一个完整宇宙 | 完整宇宙时空、物质、规则层面操作 |
| N19 多宇宙级 | 可影响多个独立宇宙 | 多个宇宙毁灭/创造/支配证据 |
| N20 大型多元宇宙级 | 可影响大量独立宇宙集合 | 大规模宇宙集合管理、吞噬、重启 |
| N21 无限多元宇宙级 | 可影响无限数量独立宇宙 | 明确无限宇宙集合与有效作用证据 |
| N22 高维多元级 | 可作用于高维结构，低维宇宙只是其截面/子集 | 明确高维轴、高维存在、低维压倒性支配 |
| N23 复杂高维结构级 | 支配多层高维、嵌套高维或复杂超时空结构 | 多层维度、无限维阶梯、超宇宙结构证据 |
| N24 外层/超维叙事结构级 | 超越常规维度、时空、宇宙集合定义 | 支配叙事层、设定层、超越维度数量本身 |

### 2B.3 子级与数值段

每一级内部用四段描述：

```text
低段：刚进入该级，表现不稳定或范围偏小
中段：稳定达到该级常规表现
高段：该级中明显强者，可压制中低段
巅峰：接近下一级门槛，但仍未满足下一级证据
```

数值段按区间四等分。例如 N12 行星级 `256,000-511,999`：

```text
N12-Low   256,000-319,999
N12-Mid   320,000-383,999
N12-High  384,000-447,999
N12-Peak  448,000-511,999
```

### 2B.4 高等级特殊说明

从 N18 开始，不能只按破坏力理解。

需要区分：

- 单体宇宙：一个完整时空连续体。
- 多宇宙：多个彼此独立的宇宙。
- 大型多元：大量独立宇宙集合。
- 无限多元：明确无限数量宇宙集合。
- 高维多元：存在比普通宇宙更高维的结构，并能有效作用。
- 复杂高维：多层嵌套、高维阶梯、超越单一高维轴。
- 外层/超维叙事结构：超越维度数量、时空集合或叙事层级。

高等级需要记录“作用对象”而不是只写等级：

```json
{
  "scaleTarget": "infinite-multiverse",
  "structureEvidence": "明确存在无限数量独立宇宙，并被同一能力同时重置。",
  "operationType": "reset",
  "isCombatApplicable": true,
  "conditions": []
}
```
