# RP Map

维护多边形网格地图。RP中涉及位置移动、区域探索、战场定位时使用。

## 触发条件

- 进入新区域或场景
- 需要空间定位（战斗/探索）
- 用户要求查看地图

## 地图格式

- 方格、六边形、三角网格、自定义多边形或节点地图
- 格子通过颜色/图标/标签/文字和图层表达状态
- 不单靠颜色表达关键信息
- GM 隐藏层默认不展示

## 每个格子/节点记录

- 坐标或顶点
- 地形、移动成本、视野阻挡、掩体、高度
- 颜色、图标、标签
- 势力控制
- 单位、物品、事件、资源
- 玩家描述与 GM 隐藏信息

## 更新流程

1. 初始地图写入文件
2. 探索/战斗/破坏/占领 → 写入 delta
3. 战斗日志记录位置和范围变化
4. 前端读取投影展示
