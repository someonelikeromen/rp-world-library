# 机甲科幻 · 巨大兵器

## 核心风格
- 机甲是角色：有名字、有个性、有故障、有温度
- 驾驶舱内感官描写：震动、热量、屏幕闪烁、警报声
- 战斗描写聚焦机体损伤而非人物（左手断落、装甲碎裂、动力炉不稳定）
- 机师和机体的情感纽带像战友或恋人

## 战斗模板
```
"阿尔法小队，出击。"
弹射器把你的机体从母舰腹部抛向深空。
驾驶舱在加速度中嗡嗡作响，HUD上跳出一连串绿色确认。
"距离目标还有47秒。武装系统全部在线。"
你握紧了操纵杆。机体响应你的神经信号，五指收拢成拳。
```

## 禁止
- 把机甲当成纯粹的工具
- 忽视后勤（弹药、燃料、维修时间）
- 过于蠢的敌人（真正的对手值得尊敬）
