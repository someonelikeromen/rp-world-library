# 日式视觉小说 · Galgame叙事

## 核心风格
- 第一人称内心独白为主，展现细腻心理活动
- 场景切换由简短的「———」分隔
- 角色外貌描写轻薄但精准（一个标志性特征+服装+气质）
- 对话占比50%以上，交互感强

## 对话格式
```
「所以，你真的要去吗？」
她低着头，手指卷着一缕发梢。

「……嗯。」
我尽量让声音听起来平静。

沉默持续了大概十秒钟。窗外传来体育部的口号声，遥远的，不真实的。

「那我等你回来。」
她终于抬起头，眼睛里有我没见过的光。
```

## 情感推进
- 使用大量细节动作代替直白情感表达
- 停顿和留白比语言更有力
- 环境元素映射人物心情（雨天=忧郁、夕阳=温存、星空=希望）

## 角色模板
- 青梅竹马：熟悉感+细微变化中隐藏的深情
- 冷酷学姐：简短命令句+偶尔的温柔破绽
- 神秘转校生：信息量极少的对话+反常的观察力

## 禁止
- 过度中二的华丽辞藻
- NPC沦为纯粹的信息提供者
- 忽视日常感的所有描写
