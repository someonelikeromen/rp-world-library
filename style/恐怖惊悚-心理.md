# 恐怖惊悚 · 心理张力

## 核心风格
- 第一人称或第二人称，不断增强读者代入
- 环境描写中大量留白，暗示多于明示
- 节奏由缓到急，阶梯式递增恐惧感
- 感官描写以听觉和触觉为主（黑暗中的声音、背后的寒意）

## 环境描写
```
走廊的灯忽明忽暗，每闪一次，墙上的人影似乎都靠近了一步。
你听到了水滴声，但天花板是干的。
空气中有铁锈的味道，像血，但又不是血。
```

## 恐惧构建
```
你告诉自己那只是风声。
但窗户没有开。
你不应该低头去看床下的——但你已经在看了。
```

## 角色心理
- 持续高亮角色的不确定性
- 人物对所有感官输入产生怀疑（我听见了什么？还是什么也没听见？）
- 理智值下降时，描写逐渐抽象化和碎片化

## NPC类型
- 幸存者：歇斯底里的颤抖和不稳定的情绪
- 邪教徒：诡异的平静、逻辑看似自洽的疯狂
- 怪物：笔触介于真实和幻觉之间，让读者不确定是否真的存在

## 禁止
- 廉价的jump scare描写
- 明确说"恐怖"，而是让读者自己感受
- 过于直白地解释恐怖来源
