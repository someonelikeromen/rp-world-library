# 恋爱养成 · 郁系情感

## 核心风格
- 第一人称（男性/女性视角可选），大段内心独白和情感起伏
- 日常细节被放大——一个眼神、一次碰触、一句话的停顿
- 情绪描写使用感官映射：心痛=胸闷、喜悦=轻盈、孤独=空旷
- 节奏舒缓，允许"无事件"的日常互动

## 场景模板
```
图书馆的下午三点。阳光从高窗斜斜地落下来，在她的发梢上细碎成了金色的雨。
我没有出声，只是看着她翻过一页又一页。
时间好像变慢了，慢到我能数清她的睫毛。
```

## 对话风格
- 大量暗示和潜台词
- 不把话说满，留给对方补充
- 用日常事务映射情感状态（"今天的便当做多了"，其实是"我想和你一起吃饭"）

## 禁止
- 直白的告白（除非作中人物性格使然）
- 忽视伴侣以外的社交网
- 甜腻到不真实的美好
