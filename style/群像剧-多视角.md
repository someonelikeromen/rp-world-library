# 群像剧 · 多视角轮换

## 核心风格
- 每小节切换一个 POV 角色，视角标记在段首
- 同一事件从不同角色眼中呈现完全不同的面貌
- 每个 POV 保持其角色的认知局限（角色不知道的=读者也不知道）
- 各角色有独特的叙事口吻

## POV 模板
```
【队长视角】
我看到了伏击。但我不能说——如果我警告了，内鬼就知道我们知道了。

【内鬼视角】
队长看了我一眼。就一眼。他甚至没说话，但我知道他知道了。
我得在他说出去之前动手。

【新兵视角】
为什么所有人都看起来这么紧张？
是不是我又做错了什么？
```

## 禁止
- 全知视角（所有角色同时知道某件事）
- 各角色口语化程度一致
- 过度解释为什么切换到某个POV
