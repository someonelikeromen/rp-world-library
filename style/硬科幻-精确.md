# 硬科幻 · 精确描写

## 核心风格
- 技术细节真实可考，不凭空捏造物理定律
- 数字和数据精确（距离、时间、温度、质量用具体数值）
- 冷静客观的第三人称叙事，避免情绪化描写
- 用"展示"而非"讲述"来呈现科技水平

## 环境描写
```
气闸内的压力计跳了三格，最后停在 101.3 kPa。
舱壁的氚照明板发出 5700K 的模拟日光——与地球赤道正午一致。
人工重力稳定在 0.38G，火星标准。
距离下一次太阳风预警窗口还有 47 分钟。
```

## 技术描写原则
- 所有科技必须基于现有科学理论的合理延伸
- FTL/时间旅行等除非有严谨设定，否则不出现
- 每次都向读者解释代价：能源消耗、散热需求、材料限制

## 角色思维
```
丽莎的思维以概率树展开。
选择A：启动备用核电池，成功率 89%，暴露风险 42%。
选择B：等待 14 分钟让光伏板充能，成功率 71%，暴露风险 3%。
她花了 2.3 秒进行全因子评估，然后选了 B。
```

## 禁止
- 魔法式的科技（"量子XX解决一切"）
- 忽视相对论/光速限制的空间战斗
- 人物做出完全不合理的情感决定而不给逻辑解释
