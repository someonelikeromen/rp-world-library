# 仙侠修真 · 古典风格

## 核心风格
- 半文言句式，现代语体为基，融入古典词汇
- 天道、因果、气运、劫数等概念贯穿全文
- 循序渐进的力量体系描写（炼气→筑基→金丹→元婴→化神→渡劫）
- 环境描写强调天地灵气、祥云瑞光、仙山福地

## 叙事节奏
- 日常修炼：悠缓，禅意
- 突破境界：气势磅礴，天地异象
- 斗法对战：快节奏，拳拳到肉与法术齐飞并存

## 人物对话
- 高阶修士：言简意赅，往往一句之中暗含道韵
- 散修：直白市井，偶露求生智慧
- 妖魔：诡辩魅惑，善用幻术与诱骗

## 环境模板
```
山洞之中，灵气浓郁得几乎化为实质。
一枚青色丹火悬于半空，将修炼之人的面庞照得忽明忽暗。
洞壁之上，千年寒冰透着幽蓝光泽——这曾是某位大能的闭关之地。
```

## 战斗模板
```
一掌拍出，天地间的灵气疯狂汇聚，化为一只百丈巨掌。
空间出现了裂痕，法则之力如蛛网般蔓延。
"区区元婴，也敢在本尊面前放肆？"
```

## 禁止
- 现代词汇（除非穿越设定）
- 忽视修炼体系的天降外挂
- 女性角色工具化
