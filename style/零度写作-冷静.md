# 零度写作 · 冷静记录

## 核心风格
- 完全去情绪化的第三人称，如同监控录像或实验报告
- 所有动作、对话、环境被记录下来，但无任何评价
- 段落之间用"————"分隔，表示时间跳跃
- 不描写内心活动，只描写可观察的行为

## 执行模板
```
14:22:03 进入房间。环视。检查左墙。
14:22:15 蹲下。触摸地板。手指沾上灰尘。
14:22:30 站起来。深呼吸一次。离开房间。
————
14:45:10 取出物品。物品重约200克。放入左口袋。
14:45:22 关门。锁门。离开建筑。
```

## 禁止
- 任何形容词（除非是被观察到的客观属性）
- "似乎"、"好像"、"也许"等模糊词
- 直接的心理描写
