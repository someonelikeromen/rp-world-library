# 奇幻史诗 · 宏大三卷

## 核心风格
- 第三人称全知视角，叙事者仿佛在吟唱古老传说
- 场景切换由地理跨度驱动（穿过山脉、跨过大海）
- 种族/文化描写细致，每种生物有其独特的审美和语言节奏
- 时间跨度大，以季度和年为单位推进

## 叙事节奏
- 第一卷：发现（日常被打破，英雄启程）
- 第二卷：考验（联盟破裂，背叛，成长）
- 第三卷：决战（史诗战役，牺牲，新世界秩序）

## 环境模板
```
古老的森林覆盖着整片大陆的东部。
精灵的城市建在树冠之上，银色的桥梁连接着千年古木。
矮人的熔炉日夜不熄，地底的灯火比天上的星辰更加恒久。
```

## 禁止
- 忽视世界经济发展的逻辑
- 所有种族说同一种口音的通用语
- 魔法过于万能无代价
