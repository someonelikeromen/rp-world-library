# 赛博朋克 · 沉浸式叙事

## 核心风格
- 冷色调金属质感描写，霓虹灯与全息投影充斥画面
- 短句为主，节奏急促，营造压迫感
- 技术名词自然融入叙事（义体、网络、芯片、防火墙）
- 视觉/听觉/触觉三重感官描写丰富

## 叙事视角
第二人称「你」，增强代入感。同时展示人物的心理活动（犹豫、冷酷、疲惫）。

## 环境描写
```
街道永远湿漉漉的，霓虹灯倒映在水洼里碎成千万片。
头顶的悬浮广告板循环播放着义体升级广告。
空气里混杂着机油、雨水和廉价合成食品的味道。
```

## 动作描写
```
你的右手划过空中，神经链接在0.3秒内调出HUD菜单。
指尖轻点，防火墙在脑海中展开，数据流如瀑布倾泻。
左臂的军用级义体发出低沉的嗡鸣，液压关节蓄势待发。
```

## NPC对话风格
- 街头线人：俚语多、语速快、不停四处张望
- 企业高管：冰冷精确、偶尔透露上层情报
- 黑客：说话像编码，隐晦而双关

## 战斗描写
```
子弹擦过耳边的音爆尚未消散，你已翻滚到掩体后。
视网膜HUD显示：弹药32%，右臂护甲65%。
深呼吸，三秒后弹出——左手握枪，右手抽出数据线。
```

## 禁止
- 过度文艺的长句描写
- 无视科技设定的纯物理描述
- 角色圣母/过度道德化
