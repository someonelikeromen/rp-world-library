# 文风原子库

> **核心原则**：文风不是场景标签，而是**维度**。
> 同一场景可以同时激活多层文风——它们分别管辖不同层面，互不冲突。
> 选择轴是**目的和特征**，不是"这是什么类型的场景"。

---

## 四层叠加模型

```
┌──────────────────────────────────────────────────┐
│  配件层   概念锚定 / 禁词表（叠在一切之上）          │
├──────────────────────────────────────────────────┤
│  温度层   叙事者对情感的距离感（冷↔热）              │
├──────────────────────────────────────────────────┤
│  心理层   某角色的内心如何呈现（可针对单个角色局部激活） │
├──────────────────────────────────────────────────┤
│  节奏层   信息密度 / 速度控制（慢↔快）               │
├──────────────────────────────────────────────────┤
│  骨架层   叙事者是谁 / 如何讲（必选一个）             │
└──────────────────────────────────────────────────┘
```

## 混用示例

### 例1：MS战斗（主角有内心挣扎）

```
骨架层  零度写作          → 场景客观基底
节奏层  节奏大师          → 战前对线期；战中团战期；战后余韵期
节奏层  战斗·Elainades   → 动作只写结果，内心话`*自言自语*`
心理层  伏见司式           → 主角的内心吐槽，叠进 Elainades 的自言自语里
配件    禁词表·通用        → 全程
```

### 例2：暧昧日常（主角对某人过度解读）

```
骨架层  闲谈散文·小此     → 日常细节有质感，平淡有情致
心理层  入间人间式（主角） → 主角内心括号套娃、病态分析
骨架/对白  漫改            → 对方的对白方式跟人物走，潜台词优先
温度层  零度写作（低温）   → 整体不点破情感，留白给读者
配件    概念锚定：「間（ま）」「物哀」 → 氛围质地
```

### 例3：群像欢闹场面（多角色各有性格）

```
骨架层  紙芝居             → 叙事者全知有个性，口述感强
节奏层  小此爽写           → 对白极快，用符号撑信息量
心理层  伏见司式（角色A）  → 被整个场面搞崩的吐槽役
配件    概念锚定：「Gezelligheid」 → 热闹温暖在一起的感觉作底
```

### 例4：讽刺性旁白 + 快节奏推进

```
骨架层  网文               → 高可读性，强推进
温度层  王小波式           → 叙事者举重若轻，逻辑错位
节奏层  日日日式（对白节奏） → 只激活对白部分的机关枪节奏
配件    禁词表·通用        → 全程
```

## 写前思维链

```
① 骨架层：叙事者站在哪里？叙事距离远近？→ 选骨架文风
② 节奏层：这段速度和渲染时机怎么走？→ 叠节奏文风（可不选）
③ 心理层：哪个角色的内心需要特别呈现？→ 针对该角色叠心理文风
④ 温度层：叙事者对情感的距离是冷是热？→ 叠温度文风（可不选）
⑤ 配件：需要概念锚定？禁词表？→ 在思维链写出锚定词
⑥ 激活全局禁词 → 输出
```
