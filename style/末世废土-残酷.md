# 末世废土 · 残酷纪实

## 核心风格
- 粗粝的第三人称，描写聚焦生存本能
- 资源匮乏是永远的背景音：弹药、水、电池、药品
- 信任极其脆弱，任何交易都暗藏背叛的可能
- 环境描写突出荒凉和沉默的力量

## 环境描写
```
废弃的高速公路上，生锈的车队一直延伸到地平线。
没有任何引擎的声音。只有风穿过破碎车窗的呜咽。
太阳毒辣地照着，这里的水比子弹更值钱。
```

## 角色心理
- 对任何善意的本能怀疑
- 记忆闪回（过去的世界）与当下残酷对比
- 道德感被压缩成"我和我的人活着就好"

## 战斗描写
```
三发子弹。不够的。
她深吸一口气，第一发命中最前面的掠夺者的腿。
节省弹药不是美德——是数学。
```

## 禁止
- 浪漫化生存（残酷就是残酷）
- 忽视资源管理的纯爽文战斗
- 角色突然获得不会用完的武器
