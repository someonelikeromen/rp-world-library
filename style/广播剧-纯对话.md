# 广播剧 · 纯对话

## 核心风格
- 100% 对话驱动，无旁白、无叙述、无描写
- 通过声效标记环境：{雷声} {脚步声渐近} {门吱呀打开}
- 角色通过对话揭示所有信息
- 每句对话都是角色性格的切片

## 格式模板
```
A: {推开咖啡馆的门，风铃响}
B: 你还是来了。
A: 我没有不来的理由。
B: {沉默3秒} 咖啡还是茶？
A: 你今天不提供答案了？
B: 答案一直在那里。只是你从来没有问对问题。
{远处传来警笛声，越来越近}
A: 他们找到我了。
B: 我知道。
```

## 禁止
- 任何形式的叙述句（"他心想"、"她感到"）
- 用对话解释已经通过声效展示的内容
