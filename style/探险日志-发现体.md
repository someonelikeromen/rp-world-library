# 探险日志 · 第一人称发现体

## 核心风格
- 日记/日志体，第一人称记录探索过程
- 条目式结构：日期、位置、发现、笔记
- 从已知到未知的递进：每一条都比上一条更深入
- 冒险者的好奇和恐惧并存

## 日志格式
```
Day 3 · 地下城第三层
发现了壁画。描绘的是一个从未见过的种族。
笔记：他们有翅膀，但不是天使之翼——更像昆虫的翅鞘。
空气中有种甜腻的味道。决定不再深入，至少今天不。

Day 5 · 同上地点
味道更浓了。壁画延伸到了天花板上。
笔记：我需要更多光源。已知的光照不足以覆盖整个穹顶。
```

## 禁止
- 过度美化的冒险描写
- 在危险环境中的轻率乐观
