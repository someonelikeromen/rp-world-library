## 2022-11-06 12:43-13:07 / 开服前与首次登录

2022年11月6日。东京。

12:43。

公寓里的暖气开得不高，窗边有一点冬天前的干冷。桌上摊着三样东西：NERvGear 的说明书、你手写的几页备忘、还有一只压在纸角上的黑色签字笔。

备忘第一页写得很短。

`如果断更超过72小时，按预案处理。`

下面是神乐坂菖蒲的联系方式、平台后台账号交接提示、自动扣款记录、存稿位置。字迹很稳，稳得像在写普通工作交接，而不是给某种荒唐到没人会相信的灾难留后路。

手机屏幕亮了一下。

神乐坂菖蒲发来消息。

> 「今天别熬夜。还有，《遮天》第三卷的修订意见我晚上发你。你要是敢又用‘取材’当借口消失，我真的会杀到你公寓。」

几秒后，黑猫也发来一条。

> 「所以你真的要玩那个SAO？哼……不要以为用了‘一叶知秋’这种名字就很帅。」

沙织的消息跟在后面。

> 「辰也氏，吾等已听从劝告，没有入手SAO！所以请务必回来分享体验报告是也！」

你看着那两条消息，手指停在屏幕上方。

至少她们没进去。

这个念头浮出来的时候，你没有什么英雄式的安心。只是觉得胸口某个地方轻了一点，又很快沉回去。

房间另一侧，NERvGear静静躺在床边。外壳泛着冷硬的光。你当然知道公开说明里没有任何问题，也知道没有证据的时候，报警、爆料、写怪文书都只会被当成未成年作者压力过大。

更麻烦的是，你记得的东西太模糊了。

茅场晶彦。死亡游戏。起始之镇。桐人。亚丝娜。第一层。第七十五层。The Seed。

中间大量空白像被水泡过的纸，摸上去还在，字却散了。

12:51。

你关掉手机，把它放在桌面正中。稿件备份已经上传。账单自动扣款已经确认。门锁、电源、窗户、饮水、床边空间，都检查过一遍。

这不是万全准备。

只是你能做的准备。

你拿起NERvGear，指腹擦过边缘。脑子里短暂地闪过第一世机房里白色灯管的光，闪过医院天花板，闪过一个更遥远、更古老、几乎没有画面的死亡。

然后那些东西都沉下去。

只剩下现在。

12:58。

你躺下，调整好头盔的位置。

黑暗扣下来之前，你看见天花板边缘有一道很细的影子。像一片叶子落在秋天开始之前。

系统启动音响起。

> 「NERvGear，启动。」

视野归零。

下一秒，登录界面在黑暗中展开。

`Sword Art Online`

`Player Name: 一叶知秋`

`LINK START` 按钮悬在你面前，蓝白色的光稳定得近乎冷淡。

你按下了 `LINK START`。

视觉先消失。

然后是重量。

身体像被一层很薄的水膜包住，指尖、手腕、肩膀、胸口，一处一处从现实里断开。NERvGear的校准提示在黑暗中依次亮起。蓝色线条扫过你的四肢，像有人用冷光重新画出一个人。

`Sensory Calibration...`

`Motor Input Lock...`

`FullDive Sequence Stable.`

短暂的失重之后，脚下忽然有了地面。

不是木地板。不是你公寓里那块有一点划痕的浅色复合板。

是石砖。

你睁开眼。

风从广场另一头吹过来，带着草叶、面包、金属和人群的味道。不是现实里的空气，可它足够像，像到你的呼吸本能地停了一下。

起始之镇。

巨大的广场铺展开来，白石建筑和红色屋顶一层层向外延伸。钟楼立在远处，阳光从建筑之间斜斜落下，玩家们的声音到处都是。

你低头看了看自己的手。

和现实一样。

手指修长，掌心有训练留下的薄茧。皮肤质感被系统还原得过分仔细，连指节处一点旧伤的淡痕都在。

你轻轻活动五指。

没有小宇宙。

没有任何多余的热，也没有从灵魂深处翻上来的光。身体是游戏身体，规则是游戏规则。你知道这件事，但真正站在这里时，才算确认。

你调出菜单。

半透明窗口在右侧展开。

```text
Player: 一叶知秋
Level: 1
EXP: 0/100
HP: 620/620
SP: 240/240
Col: 1000
Location: SAO·第1层·起始之镇·中央广场
Equipment: 新手长剑 + 无副手 + 新手上衣/长裤/靴 + 无饰品
Inventory: 初级回复药水 x3；黑面包 x2；起始之镇基础地图
Weapon Proficiency: 单手直剑 1/1000；双手剑 1/1000
Sword Skills: 单手直剑·水平斩（1-Hit）；单手直剑·斜斩（1-Hit）；双手剑·基础剑技（待获得双手剑后确认）
Unique/Original Skills: 无
Support/Life Skills: 无
Special Permissions: 无
```

系统显示得很清楚。没有惊喜，也没有额外补偿。它不会因为你记得另一个世界、死过两次、写过几百万字小说，就在背包里塞一把神器。

挺公平的。

你甚至想笑一下。

广场边缘，一个新手玩家正在把剑拔出来，又因为动作太大差点打到旁边的人。另一个玩家立刻骂了回去。几秒钟后，两个人又一起笑起来，尴尬地互相道歉。

现在一切还像游戏。

你看向天空。

蓝得很干净。

干净到让人不舒服。

距离正式开服已经过去了几分钟。原作里那场宣告不会在第一秒发生。它会给人一点时间，让人走出去，让人觉得自己真的只是来玩游戏。

你脑子里浮起几个模糊词。

起始之镇。野猪。克莱因。桐人。教学。傍晚。茅场。

顺序不完整。

广场上的喧闹还在继续。

系统时间向前跳了一格。

`13:07`

## 系统修正 / 归档初始化与VIT方案

上一段首次登录面板中 `HP 620/620`、`SP 240/240`、`Col 1000`、`新手长剑/药水/地图` 与 `单手直剑/双手剑熟练度` 为临时模板草案，已作废。

按本地SAO归档采用以下权威初始化：

```text
Player: 一叶知秋
Level: 1
EXP: 0/100
HP: 250/250
Col: 500
Cursor: 绿名
Guild: 无
Base Attributes: STR 5 / AGI 5 / VIT 5
Unallocated Attribute Points: 0
Skill Slots: 2/2, Equipped Skill IDs: []
Equipment: 主手 null；副手 null；头部 null；身体 null；足部 null；饰品1 null；饰品2 null
Inventory: {}
Known Recipes: {}
Status Effects: {}
Party: party-player, leader=player
Death: false
```

系统口径：采用 `STR/AGI/VIT` 三属性方案。VIT作为SAO账号层基础属性参与最大HP、体力/抗性、防御倾向的后续结算；现实圣斗士肉体、灵魂、兵击训练不直接增加SAO数值。衍生攻击、防御、速度、准确率、闪避率只即时计算，不作为权威变量保存。

开局继续时，需要先处理初始菜单/角色创建选择：初始武器、两个技能槽、是否存在初始补给，均在选择后再写入。

## 2022-11-06 13:25 / 起始之镇中央广场

你站在广场中央，系统窗口浮在视野右侧，几乎不挡路。

你没有急着动。

先看状态，再看环境，这比乱走更重要。


视野里的人很多。

有些人兴奋，有些人茫然，还有些人只是站着，像在等一个根本不会来的提示音。广场边上，几个新手正围着自己的菜单窗口翻看，动作笨拙得像第一次拿到能变成世界的工具。

你抬头看了看钟楼，又扫过周围建筑的门牌和道路分布。

起始之镇很安静，至少表面如此。石板路、白墙、红顶、NPC商店、传送阵方向的提示牌，都和你模糊记忆里的印象差不多，但细节又有些偏差，像一张被重新排版过的旧地图。

这意味着两件事。

第一，你记得的东西不能直接当路线图用。

第二，凡是能靠自己确认的，就别交给记忆。

你把菜单往下翻了一层。

技能槽显示是空的，两个槽位都没有占用。装备栏也空得干净，没有系统默认武器，没有背包里的补给，没有地图附件。你现在能确认的只有自己的基础值、当前位置和这具游戏身体的初始权限。

这和你要的开局一致。

没有多余赠品，也没有胡乱预设的“模板装备”。

周围开始有人往广场东侧聚过去，像是听见了什么消息。你没有立刻跟上，只是把视线停在那边一瞬，然后又收回来。

先确认第一件事。

你想怎么做？

1. 先去广场边缘观察玩家和NPC分布。
2. 打开系统菜单，确认初始武器/技能选择项是否存在。
3. 直接前往起始之镇商店区，查看可购置装备和补给。
4. 先不动，等待事件自然发生。
