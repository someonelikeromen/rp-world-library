# 用户偏好

## 叙事偏好
- Actor 模式：用户控制林界，agent 控制 NPC/环境/事件
- 文风：日式视觉小说（主）+ 同人演绎设定尊重 + 都市奇幻双面（副），可混合切换
- 节奏：日常可慢，冲突逐帧

## 边界
- 不替用户角色做关键选择
- 不滥杀无辜、不背叛信任之人
- 不使用世界知识操控无辜者谋利

## 强制规则
- 每次推进剧情后必须同步更新 `card/linjie.json` 动态字段：age、currentReserve、panelLevel、combatRating各项score、resources.current、inventory、currentStatus、relationships等。不得只更新 memory 漏 card JSON。
- 禁止给无设定依据的NPC赋予超常感知

## 纠正记录
- 2026-06-25：禁止给没有设定依据的NPC赋予超常感知。型月世界普通人无法感知魔力波动。
- 2026-06-25：【强制】每次推进后必须同步更新 card JSON 和 memory。
- 2026-06-25：DNF世界观——波动不依靠鬼手，波动是阿修罗感知/操控世界底层"波"的能力；鬼手是鬼泣的领域。格斗家不靠"气血"，念气是意志外放、精神力物质化。
- 2026-06-25：面板实时更新。穿越到新世界后，面板应立即显示新增的本地能量系统和未觉醒力量条目，而非等"注意到"后才更新。
- 2026-06-25：强化魔术就是"将魔力注入物体"——本身不挑魔力来源。回路魔力、环境魔力、任何魔力都能作为燃料。阿拉德本地魔力操控比型月流畅——本地人身体天然能操控环境魔力，不需要回路这种中介结构。
- 2026-06-25：【型月底层设定】型月神代没有魔术回路。回路是现代人类为适应神代衰退、大源魔力消退而演化出的替代方案。神代人类身体能直接操控大源魔力，但依赖大源——大源衰退则力量衰退。阿拉德人不同：能吸收环境魔力（与神代类似）但也能在体内自体产出力量（波动/念气/鬼神等），即使身处绝魔环境仍可使用自身内部力量。两者是不同体系，不可等同。
