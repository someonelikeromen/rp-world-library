# 反馈记忆

## 当前 RP 模式偏好

- 模式：Actor。用户控制主角；AI 只控制 NPC、环境、事件，不替用户做关键选择。
- 玩法：类跑团 / 安科 / 安价混合。
- 行动裁定：用户行为需先判断可行性、角色一致性、信息条件、能力条件与现实阻力；不合理行动不直接放行，可改为不可做、高难度、劣势、需要前置条件或产生长期后果。
- 世界：漫威电影宇宙。
- 开局时间线：托尼·斯塔克在阿富汗失踪前一个月。
- 主角：顾遥 / Yao Gu，男，24 岁，普通人穿越者，纽约市立大学布鲁克林学院计算机科学本科生。
- 主角性格：平常低欲望、低存在感；压力越大越专注；战斗时会释放压抑的狂气。
- 文风：混合文风，根据场景切换；同一场景可混用多种文风。

## 骰池系统偏好

- 使用类似《黑暗世界 / World of Darkness》的 d10 骰池系统，而非单一 d20。
- 基础检定：投掷多个 d10，每个骰子结果达到 8 及以上记为 1 个成功。
- 默认规则：10-again；掷出 10 时追加骰。
- 能力/特质可提供强化规则，例如 9-again、8-again、重骰、保底成功、降低失败代价、额外效果等。
- 复杂行动可使用多种鉴定混合：属性、技能、方法、装备、资源、情境、成就标签共同决定骰池。
- 掷骰前需要公开骰池构成、成功阈值、again 规则、难度/所需成功数、失败后果。
- 掷骰结果是公开信息，不伪造、不暗改、不因结果不理想而重掷，除非已有能力或规则允许。

## 成就与奖励系统偏好（v0.3）

- 详细规则见 `rules/rp-system-v03.md`，该文件优先于旧记忆。
- 成就等级使用 F / E / D / C / B / A / S / SS / EX。
- 每次成就奖励先生成 10 个不重复候选，再随机展示 3 个，用户三选一。
- 成就奖励需要用户明确领取后才实际获得；触发成就只生成待领取奖励，未领取奖励不生效。
- 奖励必须是原作中明确存在的完整对象：完整流派、明确术式/招式/技能、明确物品、明确血统/体质/体系基础、明确角色能力传承。
- 禁止风格化原创奖励，禁止普通技能换皮，禁止“某某雏形 / 某某式直觉 / 某某感”等非原作对象。
- 有流派的能力必须给完整流派传承，如水之呼吸、飞天御剑流；不得拆成某个自创雏形或单招替代流派。
- 若奖励需要某个力量体系基础，奖励必须自动补足施展该能力的最低标准，如查克拉、魔术回路、念基础、身体强度等。
- 等级不够时，强奖励不进入候选池；不得把强奖励改造成自创弱化版。
- 奖励来源以项目已有世界观为主，其他世界观为辅，但必须满足原作明确与完整性规则。
