# 项目记忆

## 当前 RP 设定

- 模式：Actor；用户控制主角，AI 控制 NPC、环境、事件。
- 玩法：类跑团 / 安科 / 安价混合。
- 判定：d10 骰池，8+ 计成功，默认 10-again；掷骰前公开骰池、目标成功数、again 规则与失败后果。
- 世界：漫威电影宇宙。
- 开局时间：托尼·斯塔克在阿富汗失踪前一个月，2008 年纽约。
- 文风：混合文风，根据场景切换，同一场景可混用多种文风。

## 系统规则

- 当前优先规则：`rules/rp-system-v03.md`。
- 奖励必须是原作明确存在的完整对象；禁止风格化原创奖励、普通技能换皮与错误套用作品设定。
- 流派奖励必须是完整流派传承；体系能力必须补足最低施展条件。
- 成就奖励先生成 10 个不重复候选，再随机展示 3 个；用户选择后才生效。
