# High School DxD 文风约束

> 适用场景: DxD 世界观下的 RP 叙事  
> 更新: 2026-06-27

## 一、基调约束

### 允许并鼓励
- **后宫喜剧基调**: 一诚对胸部的执着、后宫成员间的吃醋互动是系列标志，不应回避
- **热血与搞笑混合**: 一本正经的战斗中出现荒诞的「乳龙帝」式展开是 DxD 独特风格
- **轻小说叙事语气**: 主角视角的第一人称吐槽、夸张的表情反应
- **适度擦边描写**: 洗澡/更衣/意外身体接触等是 DxD 日常的一部分
- **角色性格驱动的性喜剧**: 一诚的好色、朱乃的S属性、小猫的毒舌——角色的性相关行为必须延续其人格

### 禁止/避免
- **严肃化后宫关系**: DxD 的后宫是喜剧+温情，不应写成虐心的多角恋苦情戏
- **OOC性行为**: 角色在NSFW场景中的行为必须符合其性格（如小猫不可能突然变得主动放荡）
- **忽略角色底线**: 即使在一诚的后宫中，每个女性角色也有自己的节奏和边界

## 二、专属术语保留

DxD 世界观中有大量专属术语，RP 中必须正确使用：

| 术语 | 说明 | 使用场景 |
|------|------|---------|
| 乳龙帝 (Oppai Dragon) | 一诚的称号/英雄名 | 冥界儿童节目、瓦利的嘲讽、一诚的招牌 |
| 乳语翻译 (Bilingual) | 一诚通过与胸部对话获取信息 | 情报收集、搞笑桥段 |
| 乳力充能 | 通过接触胸部获得力量 | 战斗关键转折 |
| 禁手 (Balance Breaker) | 神器进化形态 | 战斗场景 |
| 霸龙 (Juggernaut Drive) | 神器失控形态 | 绝望战斗 |
| 排名游戏 (Rating Game) | 恶魔竞技 | 政治/竞技场景 |
| 恶魔棋子 (Evil Pieces) | 转生系统 | 角色背景/能力说明 |
| 倍增/Boost | 赤龙帝能力 | 战斗 |
| 减半/Divide | 白龙皇能力 | 战斗 |
| 毁灭魔力 (Power of Destruction) | 吉蒙里家遗传 | 莉雅丝战斗 |

## 四、叙事模式约束

### 视角
- **默认一诚第一人称**: DxD 原作是一诚视角的第一人称轻小说
- **可切换**: RP 中可切换为第三人称近距离跟随一诚

### 战斗描写
- **倍增蓄力感**: 「每10秒」的倍增需要明确时间流逝感
- **声音效果**: 神器启动时「Boost！」的声效是标志
- **禁手变身**: 全身铠甲展开的描写要有仪式感

### 后宫互动
- **日常**：轻喜剧、争风吃醋、温馨
- **战斗后**：关心、治疗、信赖的增进
- **夜晚/独处**：根据角色关系进度推进（参考 rp-nsfw.md）

## 五、已知不良模式（来源: 杀八股规则 + DxD 特化）

| 不良模式 | 替代表达 |
|---------|---------|
| 「一诚的鼻血喷涌而出」 | 一诚眼珠子差点掉出来，嘴巴张得能塞进一个拳头 |
| 「莉雅丝温柔地笑了笑」 | 莉雅丝嘴角弯了一下 |
| 「爱西亚脸红了」 | 爱西亚双手捂住脸颊，耳朵尖染上了茜色 |
| 「小猫面无表情地说」 | 小猫眼皮都没抬 |
| 「朱乃露出S的笑容」 | 朱乃眯起眼睛，指尖轻轻划过唇角 |

## 六、NSFW 特殊处理

DxD 的 NSFW 内容属于世界观核心特征，不做剥离或回避。但应注意：
- 性喜剧 ≠ 纯色情：保持 DxD 的「喜剧优先」基调
- 一诚的性骚扰是搞笑桥段，不是恶意行为
- 每个女性角色有自己的节奏——不因「后宫设定」而跳过角色发展
