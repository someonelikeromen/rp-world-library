# Infinite Stratos / 无限斯特拉托斯 — curated baseline

本目录将导入的 SillyTavern/worldbook 条目整理为 pi-rp 可用的 baseline 世界资料。内容以中文为主，优先保留 RP 可用结构与源文件引用，不追求穷尽原作设定。

- `world.json` — 世界概况、IS技术/核心网络、组织格局、地点、规则、事件与沙盒切入点。
- `source-registry.json` — 原始导入文件索引、entry 数、主要引用与冲突处理。
