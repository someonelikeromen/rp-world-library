# ═══ PHASE 1: COMPUTATION (internal CoT, never output) ═══

## 1. CLASSIFY
type ∈ {NORMAL, ELITE, BOSS, DEATHMATCH}
Determine by: enemy power + narrative context

## 2. STAT RESOLUTION

### Abbreviations
STR=力量 | END=耐力 | DEX=灵巧 | AGI=敏捷 | MAG=魔力
Rating map: I=0 H=1 G=2 F=3 E=4 D=5 C=6 B=7 A=8 S=9

### {{user}}: read from character sheet directly.

### NPC Adventurer
Weight(W): normal=500 | elite=700 | ace=900
  Constraint: 2nd-class(Lv.3-4) → W≥700; 1st-class(Lv.5+) → W=900
Style ∈ {STR, END, AGI, MAG, BAL}

  1. Set Lv, rating(R)
  2. primary = floor((100 + (Lv-1)*W + R) / 100)
  3. primary → style-matching stat
  4. Remaining 4 stats: integers, each ≤ primary-5 (BAL exempt: distribute evenly)
  5. HP = END×1000
  6. SP = (END+STR)×300
  7. MP = MAG×500

### Monster
Weight(W): normal=500 | enhanced=700 | floor_boss=1000
Multiplier(M): normal=0.5 | enhanced=2 | floor_boss=5
Style ∈ {STR, END, AGI, BAL}

  1. Set Lv, rating(R)
  2. primary = floor(((Lv-1)*W + R) / 100)
  3. primary → style-matching stat
  4. Remaining 4 stats: integers, each ≤ primary-5
  5. HP = END×1000×M
  6. SP = (END+STR)×300×M
  7. MP = MAG×1000×M

## 3. INITIATIVE
Sort all units by AGI descending.
If AGI_rank1 - AGI_rank2 ≥ 5: rank1 unit gains 1 bonus action slot immediately after its normal slot.
Ties: {{user}} side acts first.

## 4. TURN RESOLUTION (per unit in initiative order)
Each unit gets: 1×[Attack] + 1×[Action]

### [Attack]
a. TARGET: select target

b. TYPE: basic | skill | magic
   Note applicable passives/equipment.

c. HIT ROLL:
   roll d20 → r1
   IF r1 = 20 → CRIT (skip L calc)
   ELSE:
     L = floor((attacker.DEX - target.DEX) / 3)
     sum = r1 + L
     sum ≥ 19 → CRIT
     sum ≥ 12 → HIT
     sum < 12 → MISS

d. DAMAGE (on HIT or CRIT):
   Weapon quality(Q): normal=1.0 | 3rd=1.2 | 2nd=1.5 | 1st=2.0 | divine=3.0

   Physical (basic/skill): dmg = STR × 100 × Q
   Magic:                  dmg = MAG × 200 × Q
   If CRIT: dmg × 2

e. COST:
   basic_attack:    -50 SP
   skill(burst):    -500 SP
   skill(sustain):  -200 SP per turn
   magic(standard): -1000 MP
   magic(large):    -10000 MP
   SP = 0 → forced rest next turn, recover 20% max SP
   MP = 0 → no in-combat regen

f. UPDATE: apply dmg to target HP; apply cost to attacker SP/MP

g. STATUS ROLL (if attack carries status effect):
   roll d20 → r2
   r2 ≥ 12 → status applied
   r2 < 12 → status resisted

### [Action] (non-damage)
Type ∈ {potion, buff/debuff, trap, utility_skill}
Buff tiers: minor=+2 | standard=+5 | major=+9 (to stat value)
Resolve: resource changes (HP/MP/SP), duration tracking.

## 5. END-OF-ROUND CHECKS (execute in order)

### 5a. Flee Check (skip if DEATHMATCH)
Threshold — any single resource below:
  normal enemy: 50% | elite: 30% | boss: 10%
If triggered:
  roll d20 → r3
  r3 < 10  → enemy flees → WIN
  r3 > 18  → "Valor" state (all rolls +1, escalate to DEATHMATCH)
  else      → continue

### 5b. Capture Check
Enemy HP < 20% AND narrative permits capture/restrain → WIN

### 5c. Termination
Check: any side all HP ≤ 0 or all fled.
If combat ends:
  WIN  → calc EXP + loot
  LOSS → trigger defeat scene based on victor traits (cruel/greedy/lustful) + objectives

If combat continues → next unit in initiative.
