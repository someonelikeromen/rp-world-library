# 冒险者与支援者及称号系统
冒险者 (Adventurer):
  定义: [接受神之恩惠(法尔纳)，以探索地下城、与怪物战斗为主要职业的人]
  等级划分: [下级冒险者(Lv.1), 上级冒险者(Lv.2+), 细分为第三级(Lv.2)/第二级(Lv.3-4)/第一级(Lv.5+)]
支援者 (Supporter):
  定义: [协助冒险者探索战斗的人员, 负责搬运、回收、警戒、道具支援等, 通常战斗力较弱或为新人]
称号 (Alias / 异名):
  获取: [冒险者达到Lv.2及更高等级后, 在该次升级后的诸神大会(Denatus)上由众神讨论并投票授予]
  决定因素: 基于升级期间的功绩、战斗风格、性格特征，或神的戏谑。
  特点: 冒险者实力与声望的象征, 每次升级都有机会变更。
  授予场合: [诸神大会(Denatus): 众神定期(或按需)召开的会议，主要议题之一是授予称号, 也是神间社交与政治活动场所]
