# Fate 参数化战斗系统

> 来源: 型月引擎评审 B3  
> 适用范围: 型月世界 RP 战斗

## 从者参数体系

六阶参数制（E/D/C/B/A/EX）：

| 等级 | 数值含义 | 等价 |
|------|---------|------|
| E | 10 | 人类最低限 |
| D | 20 | 略高于人类 |
| C | 30 | 超越人类 |
| B | 40 | 标准从者级 |
| A | 50 | 优秀从者级 |
| EX | 不可数值化 | 规格外 |

参数项：筋力(STR) / 耐久(CON) / 敏捷(AGI) / 魔力(MGI) / 幸运(LCK) / 宝具(NP)

## 战斗检定流程

```
Step 1: 敏捷(AGI)检定
  攻方 AGI - 守方 AGI
  > 0 → 先手 + 回避优势
  = 0 → 同时行动
  < 0 → 后手
  差 ≥ 2 级 → 强制受击（无法回避）

Step 2: 攻防检定
  (攻方 STR × 技能倍率) - (守方 CON + 护甲)
  > 0 → 破防
  ≤ 0 → 被格挡/未穿透

Step 3: 魔术/宝具判定
  魔力(MGI) 对抗 + 宝具等级判定
  对魔力 等级 ≥ 魔术等级 → 无效化
  对魔力 等级 < 魔术等级 → 按差值减免

Step 4: 幸运(LCK)检定
  涉及概率性效果时 Roll LCK 判定
  对即死/因果干涉类宝具有抵抗作用
```

## 宝具等级与类型

| 等级 | 说明 |
|------|------|
| E~D | 低规格宝具 |
| C~B | 标准从者宝具 |
| A~A+ | 强力宝具 |
| A++ | 顶级宝具 |
| EX | 不可测量的规格外 |

类型: 对人/对军/对城/对国/结界/对肃正/对界

真名解放: 解放时暴露真名，攻击力最大化。非解放状态宝具性能大幅降低。

## 与通用 combat rating 的映射

Fate 六阶参数 → 通用 N0-N24 评级:

| Fate 参数级 | 通用评级范围 |
|------------|-------------|
| E~D (10-20) | N1 街头级 (100-299) |
| C (30) | N2-N3 墙壁~房屋级 (300-999) |
| B (40) | N4-N5 建筑~街区级 (1000-3999) |
| A (50) | N6-N7 城镇~城市级 (4000-15999) |
| EX | N8+ 区域级+ (16000+) |

跨世界战斗时使用通用评级，Fate 世界内部使用六阶参数。
