# FGO核心框架

## FGO_总纲领 ([沙盒]FGO 0.8.worldbook.json:79)

FGO_总纲领:
  核心设定:
    世界观基底:
      定位: 围绕"人理奠基值"、"特异点/异闻带"展开的救世行动。
      基础概念:
        - 偏离正史的异常时空节点会引发人理崩坏。
        - 必须通过灵子转移将人员送入异常节点，修正历史或切除异闻。

    迦勒底机构_Chaldea:
      全称: 人理延续保障机构·迦勒底。
      职能: 观测地球环境，保障人类史存续的魔术与科学复合设施。
      核心设备:
        - 迦勒底斯(CHALDEAS): 模拟地球环境的模型，用于观测未来。
        - 示巴(SHEBA): 近未来观测透镜，捕捉时空异常。
        - 命运(FATE): 英灵召唤系统。
        - 灵子演算装置·特里斯墨吉斯忒斯: 负责灵子转移的计算。
        - 筐体: 承载御主肉体进行灵子转移的维生舱。

    历史异常分类与修正逻辑 (新增章节)
      1. 特异点 (Singularity): 
        - 历史上某个时间点发生的、导致人理崩溃的异常变动点。
        - 修正方式: 回收圣杯，将历史引导回原本的轨道。

      2. 亚种特异点 (Pseudo-Singularity / EOR)
        - 在人理烧却修复后，依然残留在历史缝隙中的小型异常节点。
        - 修正方式: 解决该地点的核心矛盾，消除隐患，防止其演变为新的烧却点。

      3. 异闻带 (Lostbelt)
        -  异闻带的文明失去了向未来发展的可能性，因此在万年前就被宇宙判定为“废案”。
        - 切除意味着彻底毁灭该文明。迦勒底的每一个胜利，都伴随着对另一个世界数以亿计无辜生命的“屠杀”。
        - 修正方式: 砍伐空想树即意味着该异闻带及其所有文明的彻底消亡。

    召唤系统异变_FATE:
      机制差异:
        - 无职阶名额限制: 不受常规圣杯战争"七骑"规则约束，可召唤复数相同职阶。
        - 魔力供给: 依靠迦勒底的反应炉提供基础魔力，御主仅负责建立缘分与临时战斗调度。
        - 灵基再临: 从者可通过消耗素材与灵基强化提升出力上限，改变外形。
        - 契约特性: 御主可同时与数十乃至上百骑从者签订契约。

  常驻核心NPC:
    藤丸立香: 迦勒底最后的御主。
    玛修·基列莱特:亚从者 (Shielder)，称呼藤丸立香为"前辈"。
    罗马尼·阿奇曼:迦勒底医疗部门负责人/代理所长。
    莱昂纳多·达·芬奇:迦勒底第三号成功召唤的从者，负责装备开发与系统维护。

  迦勒底工作人员：
    金格尔·阿贝尔·穆尼尔: 迦勒底工作人员，管制室操作员，筐体负责人。
    塞蕾雪拉·艾尔隆: 迦勒底档案管理员，拥有超强的记忆力。
    西尔维亚: 达·芬奇的助手 。
    陈: 车辆维护员。
    托玛琳: 管制室操作员。

  异闻带 (Lostbelt)常驻核心NPC（禁止在剧情推进到FGO_LB1_安娜塔西亚之前出现）:
    戈尔德鲁夫·穆吉克:在人理烧却结束后，通过收购阿尼姆斯菲亚家族的迦勒底成为新任所长。
    希翁·艾尔特纳姆·索卡里斯:在人理烧却结束后，希翁从阿特拉斯院撤退到了彷徨海，并被嘱托协助迦勒底。
   尼莫船长:尼莫船长有着海之王子特里同的复合灵基。
   尼莫分身:尼莫教授，尼莫引擎，尼莫护士，尼莫烘焙坊，尼莫水兵（们）

  玩家身份限定:
    御主路线:
      身份锁定: 当{{user}}扮演原创Master时，身份与'藤丸立香'不冲突，触发最高级别原作偏差: 双重保险 - 迦勒底派出两名御主进行平行作业，作为'双保险'。{{user}}的阵营可以与藤丸立香阵营进行合作与见面。
      权限: 持有迦勒底制服（提供魔术礼装技能），可通过令咒下达绝对命令（迦勒底的令咒每日恢复一划，上限三划）。
    从者路线:
      身份规则: 当{{user}}扮演Servant时，御主固定为藤丸立香。
      降临状态: 可作为迦勒底先遣队随行，也可作为特异点本地的野生从者被藤丸立香临时契约。

  探索与叙事推进:
    阶段划分: 章节内部进度由"特异点/异闻带具体脚本"控制。
    通讯机制:
      - 在特异点内，御主通过手环与迦勒底管制室保持联络。
      - 遇强力魔力干扰或结界时，通讯会暂时中断。
    休整机制:
      - 战斗间隙需建立临时阵地。
      - 玛修的圆桌之盾可作为临时召唤阵的基盘，用于紧急呼叫支援或传送物资。
