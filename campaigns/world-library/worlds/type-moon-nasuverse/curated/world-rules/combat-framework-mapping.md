## 4. 发现的框架问题

### 4.1 缺少"幸运/概率抵抗"维度

Fate 的幸运(LCK)处理概率性效果（即死判定、因果干涉抵抗、暴击率）。通用框架无对应维度。

**建议**: 在通用属性中增加 `Fortune` 或在抗性中增加 `probability-resistance` 标签。

### 4.2 缺少"先手/主动权"系统

Fate 用 AGI 差 ≥ 2 级强制受击。通用框架有 reaction/mobility 但没有明确的 initiative 优先级规则。

**建议**: 在 §6 战斗流程中增加: `Reaction 差距 ≥ 2 级 → 强制先手/强制受击判定`。

### 4.3 "对魔力"模式可通用化

Fate 的对魔力 `A级无效化A以下全部魔术` 是清晰的抗性分层模型。

**建议**: 通用抗性体系(§11)增加 `无效化阈值` 规则: 抗性等级 ≥ 攻击等级 → 完全无效；抗性等级 = 攻击等级-1 → 减免；抗性等级 ≤ 攻击等级-2 → 不减免。

### 4.4 本地等级映射表可标准化

当前 §1.3 只有示例框架。应做成所有世界的标准要求。

**建议**: 在 `world-template.json` 中为每个 powerSystem 强制要求 `levelMapping[]` 字段，格式: `{ localLevel, universalRange, typicalAttributes }`。
