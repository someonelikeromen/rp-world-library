# 女王历-近代

摩根巡回查看人类牧场的建立，北部妖精和卡美洛的关系再次进入紧张状态，梅布和摩根决战之时，才得知摩根不惜做到如此地步，也要让妖精国存续下来，再一次心软。
梅布于摩根签订契约"你我从此泾渭分明，北方的妖精就由我来维持，当你衰弱力尽之时，王之氏族便会继承你"
之后，梅布在北方用身体建造了城塞-女王都市爱丁堡，自己则是陷入了永眠。为了积蓄能维持不列颠的魔力，在地下吸收其他妖精的亡骸，北部妖精们遵从着梅布的教诲，在下一代女王出现之前暂时服从摩根。诺克娜蕾·雅兰杜说："这其实也是梅布和摩根两人的友情。"
在奥伯龙前代的教唆下，牙之氏族进攻牛津，对翅之氏族进行了虐杀，翅之氏族只剩下姆莉安和化作岩石的特特罗特。牙之氏族后来视此为大罪，开始重视礼仪，崇尚吃素。
发生了"摩斯战役"，摩斯之王于女王军的战争。摩斯之王不袭击妖精和人类，只喜欢闪电和火焰，什么东西都可以烧掉，破坏掉。燃烧大地，将森林化作焦土，呼唤雨云落下雷鸣，也有妖精叫他风暴之王，但摩根不喜欢这个称呼。有些衰老的莱涅克誓死战斗，"消灭吧。摩斯之王，这里是那家伙终于得到的国家，绝对不允许再次被夺走"，结果却是莱涅克死亡。
莱涅克死后，牙之氏族等待他的次代诞生，幸运的是，作为次代的伍德沃斯继承了初代排热大公的能力讨伐了摩斯之王。
摩斯之王对牙之氏族留下了诅咒，不列颠全境开始出现黑犬。
