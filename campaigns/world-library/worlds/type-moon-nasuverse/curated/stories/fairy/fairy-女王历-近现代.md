# 女王历-近现代

牙之氏族中诞生了强力的妖精巴格斯特，明明是牙之氏族，长得却像风之氏族（没有兽人特征，更像人类）。不过她却和黑犬一样吞食妖精。
同时期，欧罗拉访问了奥尼克，在昏暗沼泽的龙骸中拉起了蠕动的肉块，也就是美露辛，美露辛获得了新生。
发生了吞噬土地的灾厄"毛毛虫战争"，大量的毛虫型摩斯出现，因为不擅长应付虫子，摩根陷入困境。在战争开始时，她去了一趟平原地区，对这些家伙使用了大规模的打击后，一本正经的离开了（实际上带有一丝逃离的味道）。为了打赢毛毛虫，必须要土之氏族长法乌尔·维瑟的能力，但他却躲了起来。巴格斯特前往康沃尔，将其击败后吞下，获得了他的能力(瞬间建起城寨)，康沃尔因此受到了诅咒变成了"无名之森"。
巴格斯特因此获得赐名，成为了妖精骑士高文。成功去除灾厄后，被任命为曼彻斯特的领主。
围绕牙之氏族长的宝座，伍德沃斯和波格扎特开始了礼仪之战，伍德沃斯本以为胜券在握，但波格扎特拼命学习礼仪占尽优势，但波格扎特餐后的叉子放错了位置，伍德沃斯艰难取胜。
插入一段时间不明确的历史，因为和摩斯战斗建立的功绩，伍德沃斯和波格扎特获封领地，伍德沃斯得到了之前翅之氏族所在的牛津，因此被称作牛津公，而波格扎特则是得到了诺维奇作为领地。
女王都市中，梅布的次代诺克娜蕾·雅兰杜诞生，诺克娜蕾·雅兰杜继承了梅布的能力。
这年还发生了"苏生"的灾厄，但历史没有完整保留，只有只言片语的情报。大量复活的人类死尸袭击达灵顿，风土牙王四氏族因为畏惧灾厄开战，为了结束战争，美露辛接受了摩根的提议，获得赐名妖精骑士兰斯洛特。芭万·希也是同一时期被赐名妖精骑士崔斯坦。
不过芭万·希是吸血妖精，她能从这些人类死尸身上吸血，因此被妖精们十分厌恶。
不知什么原因，原达灵顿领主格雷马金死去，变成了妖精亡主(强大的妖精亡灵)。
灾厄过后，达灵顿被迫转移到南方建立了新达灵顿，妖精骑士崔斯坦被任命为新达灵顿领主。
同一时期，从泛人类史漂流而来的永村，骗取了继任的土之氏族长的信任。在诺维奇合手建办了Sprigan&Capless-妖精国最初的商场。之后永村将土之氏族长谋杀，并化名斯普利根，土之氏族长化作妖精亡主从此徘徊在诺维奇的撞钟楼上。
后来斯普利根又用手段，从波格扎特那里夺走了诺维奇的领主身份，并解禁铁质武器，诺维奇因此得到了飞速发展。
波格扎特和部分妖精被迫流放到了北部，聚集到了谢菲尔德。
