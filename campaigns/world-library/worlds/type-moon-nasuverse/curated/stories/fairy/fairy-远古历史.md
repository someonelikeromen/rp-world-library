# 远古历史

天外来客捕食游星略过地球，其目的史捕食在地球上的文明，派出了"白色巨人"肆意破坏吞噬。
正确的历史："白色巨人"被守护星球的圣剑之光贯穿，地球上的人类文明因此得以保留延续。
现在的历史：本应完成铸剑使命的原始六妖精犯下了怠惰之罪，在最关键的时刻，玩忽职守，没有去锻造圣剑，捕食游星成功进食，将地球文明悉数破坏，地球变成了一片虚无之海，只有北部留下阿尔比昂之龙残骸形成的一小片湖区森林，而六妖精的所在地自然都是海洋。
为了惩罚六妖精凯尔特的兽神科尔努诺斯从星之内海（遥远的无罪之境）来到了地表被派去训斥妖精们
但是科尔努诺斯是温和的神，他宽容的帮助了六妖精，妖精们最初感恩戴德，但过了许久依旧没有大地出现，妖精们认为这是科尔努诺斯能力不够导致的，另一方面，科尔努诺斯为了让他们意识到自己的错误，不停的劝诱他们端正生活，反省言行。六妖精因此变得无法忍受，想着让科尔努诺斯的身体浮在海面上形成小岛。
于是，六妖精们心生一计，举办了祭典，要将科尔努诺斯供奉为自己的神，科尔努诺斯甚欢，以为妖精们开始反省，不听巫女的劝阻参加了祭典，被六妖精用特殊的毒酒杀害。妖精们犯下了世世代代都不能被洗刷的原罪，从此再也回不到只有无罪之人方可通行的星之内海。

随着科尔努诺斯的灵魂消亡，巫女也一同被"杀死"（身体被分解为了因子变成了新人类的模板），死前留下了关于不列颠未来的预言--春夏秋冬四场战争以及最终的奈落之虫

六妖精作为亚铃，繁衍出"石之子"与"森之子"作为自己的氏族，不过子们很快死去，成为朽木漂浮在海上，因为能够诞生出次代，所以妖精的数目并没有减少。

但科尔努诺斯残留的神怒也会让妖精死去，因此妖精们为了逃离神之遗体利用死去妖精化作的朽木与土壤填平了大海以神之遗体为中心形成了新的陆地向外扩张，而神之遗体所在之地，被称之为神之墓所的地方不让这些朽木靠近，形成了深不见底的大洞，纵使灵魂已经褪去，诅咒妖精们的亡骸也一直在等待苏醒的那天。
妖精们第一次迎来了千年一回的"大灾厄"，六妖精其中的两只死亡，因为六妖精是亚铃，所以没有次代，因此可以算是永久的死亡

之后每隔1000年，妖精的国度都会因为"大灾厄"而灭亡，同时也出现了因为灵魂之伤而无法留下次代便消灭的妖精
