# 妖精的种族

旧时妖精主要有着六个氏族，分别为：牙之氏族、翅之氏族、土之氏族、风之氏族、镜之氏族、雨之氏族。被称为旧六氏族。
现在妖精主要有着六个氏族，分别为：牙之氏族、翅之氏族、土之氏族、风之氏族、镜之氏族、王之氏族。王之氏族替代了雨之氏族的位置。被称为新六氏族。
风之氏族：人型妖精，有着美丽的翅膀（类似蝶翼），通常理性且平易近人。
土之氏族：矮人型妖精，负责建筑物与道路等建设。
牙之氏族：兽人型妖精，好战，比其他氏族更能抵御摩斯毒（因此基本是唯一能与摩斯战斗的氏族）。
翅之氏族：幼人型妖精，有着和类似昆虫的翅膀，温厚且崇尚学习，遭遇了灭族只剩下姆莉安一只
（特特罗特也是翅之氏族，但情况特殊）
镜之氏族：拥有预言之力的氏族，看得到未来，出生时便知晓自己的命运，也遭遇了灭族
雨之氏族：非常和平的牧歌民族，曾以不列颠岛的最北端为领土，不与其他氏族斗争，但在古旧前便被灭族。
王之氏族：本质上只有梅布与其次代的诺克娜蕾·雅兰杜两人，不过也泛指所有北部妖精。
乐园妖精：仅有摩根与阿尔托莉雅·卡斯特。乐园妖精的使命是，让六氏族承认他们的过错并锻造圣剑。
