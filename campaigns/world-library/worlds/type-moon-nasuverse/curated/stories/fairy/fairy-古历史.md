# 古历史

按照巫女的预言，不列颠果然发生了最初的战争春之战争。
不列颠北部扩张，其边缘到达了曼彻斯特一带，和依靠阿尔比昂之龙残骸形成的一小片湖区森林所生存下来的北部妖精遭遇。
北部妖精并不是原始六妖精的氏族，并没有犯下"原罪"，不过北部妖精发现南部妖精(即，六氏族的妖精)拥有"人类"很是嫉妒，所以渡海攻击过来，但是南部妖精更强，还有着"人类buff"的加持，形成了单方面虐杀北部妖精的惨状，甚至北部妖精产生的次代出生便会被立即杀死，这些遗体化作枯木填补了湖区与不列颠陆地之间的海域。
南部妖精完胜，北部妖精被赶尽杀绝到再也没有次代出生的地步。
不曾拥有罪孽的北部妖精的亡骸这样警告到,"下次就轮到你们了"，他们用所有人的命促使了一位王的诞生，那便是北之女王梅布。
梅布是旧六氏族都无法完全比拟的大妖精，有着阿尔比昂的加护以及原初的力量，在在杀戮之中逃出这片湖区，在西边创建了西之岛-爱尔兰，于是西之岛变成了看不见但的确存在的传说之岛，也成了不列颠被流放的妖精们最后的希望之地。
南部妖精们得到了湖区并作了进一步的发展，镜之氏族诞生于此，而雨之氏族诞生在最北端。
在"春之战争"的遗迹处，雨之氏族与镜之氏族建立了王国，雨之氏族在奥克尼建立了首都，接下来一千年间，奥克尼作为全不列颠屈指可数的都市持续繁荣。
乐园的妖精薇薇安(摩根)漂流至奥克尼，雨之氏族的族长将其藏匿维护，给她起了名字梣这样的名字，并饱含爱意地将她抚养长大。因此薇薇安的同年温暖而幸福，年幼的薇薇安因此并没打算完成乐园的使命，也就是，让六氏族承认他们的过错并锻造圣剑，而是梦想创造一个所有人都能快乐生活的童话王国。
但是接纳乐园妖精这一行为触碰到了其他氏族长的禁忌，他们不想让乐园的妖精开始巡礼，于是风土牙翅四个氏族联合，一夜之间将雨之氏族灭族。奥克尼从此全境落下雪一样的雨之氏族的眼泪，这是雨之氏族对其他氏族的警告与对乐园妖精的谢罪。

在最初的世界线中，薇薇安也随着雨之氏族的灭亡而被杀害
因此妖精历1年，爆发了席卷不列颠全境的"大灾厄"，几乎所有的妖精都灭亡了，之后的两千年间，虽有少数从大灾厄中生还的妖精，但也无法回到曾经繁荣的数量了，只剩下苟延残喘的下级妖精们的"国度"
