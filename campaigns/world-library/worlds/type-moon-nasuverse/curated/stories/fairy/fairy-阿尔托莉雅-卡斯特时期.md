# 阿尔托莉雅·卡斯特时期

阿尔托莉雅·卡斯特漂流至湖区，镜之氏族长艾因塞尔将其丢到大海里并留下预言，"拯救不列颠的救世主诞生了，击破虚假王的真王现身了"。
卡斯特在廷塔杰尔被捡起
同年，不列颠岛的终末装置-这一代的奥伯龙·伏提庚在威尔士的秋之森现形。
为了迎合预言，欧罗拉决定自己准备一个预言之子，在索尔兹伯里建立养育院，伍德沃斯担任院长。他们决定用梣的选定之枪伪装一个预言之子，但枪只有无罪之人方能使用，所以养育院里只能聚集人类的孩子。
资质最好的帕西瓦尔，得到了妖精骑士兰斯洛特的亲情与教育。

某一年，与卡斯特一起来到地表的选定之杖开始说话，奥伯龙自称梅林开始教起了卡斯特蹩脚的魔术，一年后选定之杖被没收。
因欧罗拉讨厌镜之妖精，兰斯洛特前往奥尼克灭族。
帕西瓦尔在这一年的某一天发挥了选定之枪的能力，但选定之枪在妖精历时便出了问题，有了夺取使用者寿命的负面效果，帕西瓦尔因此成长了十岁长大，失去了自称预言之子的资格。也因此遭到了欧罗拉的抛弃，养育院也一同被废弃。
阿尔托莉雅和埃克托相遇，开始在埃克托的工坊帮忙。
阿尔托莉雅迎来16岁，廷塔杰尔村的村民看她魔力依旧少的可怜，并且将要撑不过今年的税收而十分急躁，最终变得狂暴而恶妖精化，村中烧起了大火。因为伍德沃斯也在同一时间抵达了廷塔杰尔村，埃克托和阿尔托莉雅误以为是伍德沃斯放的火，与暴乱之中，阿尔托莉雅逃离了廷塔杰尔，准备开始巡礼。
但是，这时的阿尔托莉雅能力太差，并没有被当作预言之子，四处碰壁，失意之下决定前往无名之森

同年迦勒底到达妖精国不列颠。
