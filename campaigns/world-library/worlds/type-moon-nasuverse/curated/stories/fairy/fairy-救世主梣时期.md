# 救世主梣时期

摩根正式化名梣开始活动，屡次镇填灾厄，但因为在灾厄后依旧存活，所以被妖精们讨厌，于是选择救世之后救在棺中沉睡，直到下一次灾厄的产生。她不断进行着这样的循环。
因为摩根的幼年是幸福的，也因为她幼时的理想，她多次选择原谅不列颠的妖精们
妖精历4000年时，贤人格里姆被梣召唤，附身一位14岁左右样貌的妖精，并成为梣的魔术老师。 
妖精历3000年左右，不死身的黑骑士埃克托也加入了队伍中。
不知何年，梣和翅之氏族的"暴徒妖精"特特罗特单挑，梣取胜后，特特罗特作为初代妖精骑士加入了梣的队伍。

妖精历6000年的春之战争后，梅布在爱尔兰岛蛰伏了4000年，这些年间，梅布和新北部妖精（被流放等的妖精们，后直接称北部妖精）把人类当作了伙伴，共同建立了文明。
于是，夏之战争爆发。
女王梅布率领北部妖精和铁武装的人类（铁武器能够伤害到妖精）与南部妖精作战。
虽然南部妖精有着数量上的优势，但这次的战力是北部妖精方面更强，南部妖精进入绝境，救世主梣从中调停，争取时间。
就在梅布离成功仅有一步之遥时，梅布的左右手，也就是梅布的人类丈夫先一步衰弱死去，但被外界流传是人类背叛了她，趁着梅布痛苦万分的时机梣对其"穷追猛打"让其加入氏族，并发誓不再攻击不列颠。
梅布提出停战条约，原本雨之氏族的空位，被梅布以王之氏族继承，不列颠北部变回自己的领土。
纷争解决后，梣再次被南部妖精们排斥，进入棺中沉睡，被埋葬在奥克尼。
牙之氏族诞生了返祖亚铃"星之排热器官之子"勇者莱涅克，被称为排热大公
梣与排热大公莱涅克战斗后取胜，两人成为友人。莱涅克出于牙之氏族的立场，并没有和梣一同旅行，但背地里却为梣鞠躬尽瘁。
莱涅克对此解释道："虽然和乐园妖精的使命不相容，但我很欣赏梣的强大"，不过埃克托看穿了这一切，莱涅克不过是傲娇暗恋梣。
秋之战争爆发
梣联合翅之氏族与人类-乌瑟的联合军一起，打败了风土牙镜四大氏族，并于梅布平手。
乌瑟被指名成为不列颠第一任统一王，原定梅布与乌瑟联姻，彻底解决不列颠的纷争问题(不过乌瑟喜欢的是梣，对梅布无感)。
伦蒂尼恩戴冠式的前日举办了调停式，出席的有乌瑟，梣，埃克托，贤人格里姆，初代妖精骑士与各个氏族的代表。莱涅克因为不喜欢乌瑟（因为发现乌瑟也喜欢梣），所以没有出席。嘴上说着要讨伐摩斯而前往西海岸，心里想着："虽然代理去了，但是牙之族长不去还是有问题吧。"于是在戴冠式的早上，决定前往伦蒂尼恩。
别扭的到达伦蒂尼恩时，一切都已经结束了。
乌瑟在戴冠式上被妖精（极有可能是欧罗拉）在酒里下了毒，暴乱与内乱发生，圆桌据点-伦蒂尼恩灭亡，贤人格里姆"逃跑"，梣在混乱中与埃克托走散，由于埃克托是不死身，于是被破坏了双耳后丢入了海里。梣将出卖圆桌的女人变成她的样子，假的救世主梣被迫承担暴动的责任，在索尔兹伯里得到了处刑。
特特罗特知道做什么都没有意义了，所以和梣的棺一同前往了奥克尼。
莱涅克作为氏族长，立场上不能帮助梣，但他内心十分后悔，"要是我在的话能改变什么吗，不，什么都改变不了吧，身为不列颠的妖精的我是无法拯救梣的"一直到女王历，莱涅克都在为这个选择所苦。
