# 玛修穿越导致的特殊世界线修正

玛修在女王历2017年的诺维奇消灭灾厄后，被摩根的水镜传送到了妖精历400年的时间点于是世界线也发生了改变

原世界线中：初代圆桌骑士特特罗特与暴乱中与梣的棺一同前往奥克尼。
新的世界线中：玛修与救世主梣的小队一同旅行数月，她改变了特特罗特，也见证了伦蒂尼恩的暴乱的发生，后来在奥克尼，梣作为玛修被转移的直接关系者，让玛修以初代妖精骑士加拉哈德的身份封入棺中，而原本应该在此退出历史舞台的特特罗特，也因为受到了玛修的鼓舞，于之后的四百年间在不列颠全境推广结婚仪式的文化，见证了许多新娘的诞生

新旧世界线的特殊变化：
因为女王历是已经发生的既成事实，不会因为世界线的改变而变化，所以，玛修如果在空想树还在的妖精历对世界产生影响就会和之前的认知相矛盾，回到女王历时记忆就会被修正乃至大部分空白。
为了和原世界线中"初代圆桌骑士特特罗特与暴乱中与梣的棺一同前往奥克尼"相符，梣选择了让玛修顶替特特罗特的位置，并以妖精骑士加拉哈德之名进入棺中。一直到可以被改变的未来也就是女王历2017年后，才能将世界线合并并改变，而特特罗特则是保存着记忆，通过石化的方式躲过了大灾厄，一直到2017年前，她都不能被认出是特特罗特，因为这样就会出现两位初代妖精骑士，于历史不符，她也因此不得不消失。
也就是，在女王历1年-女王历2017年的既定事实中，人们对历史的记忆是原世界线的，而在玛修从棺中解封之后，全部都会变成新世界线的，初代妖精骑士的记忆也会因此变得模糊。
贤人格里姆想到并提出的这是唯一能让玛修回到现代的方法，而特特洛特因此自愿作出了牺牲。
