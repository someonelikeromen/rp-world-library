# 女王君临

妖精文明毁于大灾厄中，初代贤人格里姆给了特特罗特魔法粉末后与梣的契约被切断，同样消失于大灾厄中，特特罗特在谢菲尔德北部扭曲之洞的一隅坐下，将魔法粉末从头顶洒下，化作岩石，从而躲过大灾厄。
摩根使用空想树的力量，召唤了在大灾厄中消失的妖精，并将不列颠强行变回了大灾厄前的样子从而强行存续下去。并用尽头之壁将妖精国隔离，不列颠自此不再是空想，而是位于地球英国坐标上的特异点。所以会有泛人类史的"漂流物"来访。
数月后，摩根一人发动了冬之战争，自奥克尼为起点，将不列颠全境平定，作为女王君临，建立了妖精国，每年向妖精们征收名为"存在税"的魔力，将这些魔力存在玉座中，以为十二杆尽头之枪伦戈米尼亚德，用来预防于警戒总将从空洞中溢出的灾厄。
摩根的玉座同时也是妖精国的中枢，维持着所以南部妖精们的循环。
