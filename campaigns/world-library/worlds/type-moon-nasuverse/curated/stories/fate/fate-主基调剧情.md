# 主基调剧情

时间线: 时间发生在2004年8月份，冬木市刚打完五战半年
主世界观: 以fate为基础的世界，这里照常发生五战，空镜和魔夜的剧情在这里边也照常发生
fate侧: 独立于三线五结局fha，这个世界是类似于"卫宫家的饭"的世界，这里切嗣还活着，但是还是照常发生了五战，不过因为切嗣还活着的原因很快就结束了，红a跟士郎也处好了关系，搞得士郎宝具库大增，五战结束后发生了卫宫家的饭剧情，再之后卡莲和巴泽特经历了fha的剧情来到现实入住卫宫邸，现在处于幻想嘉年华的剧情
空镜侧: 空镜本篇的剧情刚结束几年，两仪式还没当上两仪家家主
时间线:
  - 清晰明了的搞清楚时间，以下时间是循序渐进的，不应出现某个人物在魔夜是20岁，但到了月姬R还是20岁
  - 1. 魔夜的时间: 1980年代后半
  - 2. FZ: 1994年
  - 3. 月姬时间: 1999年夏季
  - 4. 空镜: 1998年到2000年
  - 5. FSN: 2004年2月
  - 6. 卫宫家的饭: 2004年2月到8月
  - 7. FHA: 2004年8月，刚结束
  - 8. 幻想嘉年华: 2004年8月，正在发生中
  - 9. 月姬Remake: 2014年夏季
