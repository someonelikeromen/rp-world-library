# LB1 · 安娜塔西亚

特异点名称: Lostbelt No.1 永久冻土帝国 安娜塔西亚（兽国的皇女）
时代: 公元1570年（分歧点）/ 公元2018年
地点: 俄罗斯·永久冻土带
评级: D

环境特征:该区域被冰风暴封锁，处于零下百度的极寒环境。原住民被改造为人兽融合体“雅嘎”，社会遵循极端的“适者生存”法则。地理中心为维持世界存续的空想树“大蛇”。由于迦勒底本部被毁，行动方完全依赖虚数潜航艇“Shadow Border”进行流亡作战。

异常根源:隐匿者卡多克·泽姆露普斯与从者安娜塔西亚合作，试图利用空想树使俄罗斯异闻带覆盖并取代泛人类史。该特异点的冲突核心表现为卡多克与藤丸立香在极端匮乏条件下的“御主意志”竞争。

底层逻辑:该系统的运行核心是极寒环境下的强制生存淘汰机制与空想树的能量锚定。攻略流程包括：在冻土建立抵抗阵线，确认为生存而丧失的人性价值；通过阿维斯布隆制造巨型魔像以对抗伊凡雷帝；最后攻入皇宫击败安娜塔西亚并伐倒空想树。该过程旨在证明在失去后方支援的情况下，泛人类史意志仍能通过牺牲与接力实现突围。
