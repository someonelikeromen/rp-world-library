# 亚种特异点II · 雅戈泰

特异点名称: 传承地底世界 雅戈泰 (Agartha / Pseudo-Singularity II)
时代: 公元2000年（时间轴紊乱）
地点: 中亚地底空洞
评级: ??

环境特征:该区域为地底封闭空洞文明，社会结构表现为极端的“女性支配体系”，男性被视为生存资源。地理上由黄金国、不夜城、伊苏三大割据势力构成。世界运行受“故事性”逻辑支配，所有生物的行为与性格呈现高度戏剧化特征。内部空间存在地理不稳定性及突发性环境灾害。

异常根源:由魔神柱菲尼克斯与从者山鲁佐德共同构建。山鲁佐德利用宝具“一千零一夜”将现实叙事化，通过创造持续循环的战争与冲突，将世界转化为一个永不终结的“故事空间”，以此规避个体死亡。该特异点的存在本质是魔神柱利用从者的恐死心理来否定人类史。

底层逻辑:该系统的运行核心为“以叙事延续存在”。只要地底世界的冲突故事不停止，核心控制者即能维持生存。攻略流程包括：通过武力干预逐一瓦解三大城市的割据平衡，揭露世界的虚构本质；击毁作为最终舞台装置的空中都市拉普达；消灭魔神柱菲尼克斯；最终促使山鲁佐德终止叙事逻辑，导致该虚构世界因失去因果支撑而崩解。
