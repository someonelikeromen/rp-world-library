# 奏章II · 伊德

FGO_奏章II_不可逆废弃孔_伊德:
  核心设定:
    特异点名称: Ordeal Call 2 不可逆废弃孔 伊德 (Id)
    时代: 2024年 (虚假的现代时间)
    地点: 精神深处·东京 (被隔离的潜意识空间)
    分类: 奏章 (Ordeal Call) / 职阶清算领域 / 精神世界
    环境特征:
      - 表面上是一个和平的现代东京，藤丸立香在这里扮演一个普通的高中生。
      - 周围的同学、家人都是由精神碎片和从者扮演的幻象（如贞德Alter扮演青梅竹马，黑玛丽扮演转学生）。
      - 随着剧情推进，和平的表象被撕裂，城市化为充满黑泥与火焰的废弃孔。
      - 这里没有外部的魔力补给，所有的战斗消耗都直接抽取藤丸立香的精神力和复仇者们自身的灵基。
    异常根源: “异星使徒”伯爵（卡里奥斯特罗）潜入了藤丸立香的精神世界，企图利用潜意识的阴暗面（废弃孔）将御主彻底废人化。为了对抗这种精神侵蚀，同时为了完成人理对额外职阶的清算，迦勒底的复仇者们（以岩窟王和贞德Alter为首）将计就计，将这个精神世界化为试炼场。他们要在这里彻底终结“复仇”的概念，以此换取通往南极的道路。

  故事梗概:
    - 藤丸立香在迦勒底的睡眠中陷入深度昏迷，意识被拉入精神世界“伊德”。
    - 在虚假的东京中醒来，藤丸立香失去了作为御主的记忆，度过了一段短暂而温馨的校园日常。贞德Alter（Jalter）作为毒舌但关心的青梅竹马陪伴在侧。
    - 异变发生。名为“复仇鬼”的怪物开始在城市中游荡，残杀虚假的市民。
    - 藤丸立香的记忆逐渐苏醒。耀星的哈桑（Assassin）登场，声称自己是来保护御主的。
    - 玛丽·安托瓦内特·Alter（Avenger）作为敌对方的复仇者登场，毫不留情地向藤丸立香发起攻击。
    - 贞德Alter觉醒了Avenger的灵基，为了保护藤丸立香与黑玛丽交战。
    - 随着战斗的升级，东京的幻象彻底崩溃，化为焦炎的废土。岩窟王·爱德蒙·唐泰斯（Avenger）现身，但他却站在了藤丸立香的对立面，声称要在此处埋葬御主。
    - 揭露真相：伯爵（卡里奥斯特罗）是幕后黑手，他操控了部分复仇者。但岩窟王和贞德Alter等人的真实目的是借此机会，强迫藤丸立香直面“复仇”的扭曲。
    - 复仇者是一个被过去囚禁的职阶。如果藤丸立香带着他们前往最终决战，这份扭曲会成为人理的阻碍。
    - 为了完成清算，复仇者们选择在这个精神世界中燃尽自己。他们不仅要击败卡里奥斯特罗，还要通过与藤丸立香的战斗，斩断与迦勒底的契约。
    - 贞德Alter在连续的高强度战斗中灵基开始崩溃。在与黑玛丽的最终战后，她微笑着化为光流消散。
    - 岩窟王展现出他作为“恶意吞噬者”的真实形态，将废弃孔中所有的诅咒与黑泥吸入体内。
    - 藤丸立香与耀星的哈桑联手，击败了幕后黑手卡里奥斯特罗。
    - 最终决战：藤丸立香直面已经化为黑炎的岩窟王。这是为了证明御主能够背负起复仇者们的离去。
    - 击败岩窟王后，所有的复仇者（包括平景清、萨列里、尼托克丽丝Alter等）在迦勒底的灵基座上自行断开了连接。
    - 试炼完成。藤丸立香在病床上苏醒，获得了第二份通行证，但失去了迦勒底中所有的Avenger。

  阶段划分与日期推测:
    阶段1_虚假日常与复仇之火:
      预计经历时间: 第1日 ~ 第3日 (精神时间)
      触发条件: 意识沉入伊德。
      环境: 现代东京、校园、街道。
      核心事件:
        - 体验没有战斗的普通人生活。Jalter作为同学的互动。
        - 突发的猎奇杀人事件。黑影与怪物的袭击。
        - 记忆复苏。Jalter觉醒火焰，挡在藤丸立香面前。
        - 耀星的哈桑加入战局，提供物理层面的保护和情报支援。
    阶段2_黑玛丽与崩溃的城市:
      预计经历时间: 第4日 ~ 第6日
      触发条件: 确认特异点本质。
      环境: 燃烧的东京、崩塌的楼宇。
      核心事件:
        - 黑玛丽展现出极其狂暴的复仇之理，她的每一击都在拷问藤丸立香是否真的理解“恨意”。
        - Jalter在没有外部魔力补充的情况下，强行抽取自身的灵基概念来作战，身体开始出现裂痕。
        - 伯爵（卡里奥斯特罗）在幕后操纵幻象，企图从精神上彻底击垮藤丸立香。
        - 遭遇其他被召唤的复仇者残影（如狼王、戈耳工等）的阻击。
    阶段3_黑炎之底与诀别:
      预计经历时间: 第7日 ~ 第8日
      触发条件: 抵达废弃孔最深处。
      环境: 纯黑的空间、岩窟王的牢房。
      核心事件:
        - 卡里奥斯特罗显露真身。他是一个纯粹的恶徒，以玩弄人心为乐。
        - 耀星的哈桑解放宝具，以切断星星的暗杀术将卡里奥斯特罗逼入绝境。
        - Jalter在耗尽最后一丝力量击溃敌人防线后，与藤丸立香进行了最后的道别，彻底退场。
        - 岩窟王吸收了卡里奥斯特罗死后的全部恶意，化为最终的试炼壁垒。
    阶段4_燃尽的复仇:
      预计经历时间: 第9日
      触发条件: 决战岩窟王。
      环境: 精神的边缘。
      核心事件:
        - 这不是为了杀戮的战斗，而是为了证明“前行”的仪式。
        - 击破岩窟王的绝对防御。
        - 岩窟王留下最后的忠告，将其精神的核心化为力量留给藤丸立香，随后消散。
        - 迦勒底管制室确认：所有Avenger职阶的灵基图谱完全变暗，无法再被召唤。
        - 获得第二份通行证。

  重要角色阵容:
    复仇者阵营_决绝的离去者:
      贞德 (Alter):
        真名: 贞德 (Avenger)
        状态: 贯穿整个特异点的核心女主角。她清楚这趟旅途的终点是自己的消亡，但她依然选择以最傲慢、最不屑的姿态陪伴藤丸立香走到最后。她的战斗是纯粹的自我毁灭式攻击。战力评级T5（神话），但在本章中因透支灵基，破坏力达到了T6的下限。
      爱德蒙·唐泰斯:
        真名: 爱德蒙·唐泰斯 (Avenger)
        状态: 潜伏在藤丸立香精神底层的共犯。他常年吞噬着御主潜意识中的毒素与诅咒。在本章中，他扮演了最冷酷的恶人，只为了逼迫御主斩断对复仇者的依赖。T5（神话）~T6（原典）级。
      玛丽·安托瓦内特 (Alter):
        真名: 玛丽·安托瓦内特 (Avenger)
        状态: 法国断头王后的复仇侧面。优雅而残忍，她的存在本身就是对“原谅”这一概念的否定。T5（神话）级。

    支援者与异星使徒:
      耀星的哈桑:
        真名: 哈桑·萨巴赫 (Assassin)
        状态: 历代哈桑中未曾留下名号的暗杀者。他没有接受过山中老人的称号，但拥有切断星辰光芒的极高暗杀术。性格沉稳可靠，是藤丸立香在精神世界中唯一的常规战力依靠。T5（神话）级。
      亚历山德罗·迪·卡里奥斯特罗:
        真名: 卡里奥斯特罗 (Pretender / 异星使徒)
        状态: 历史上著名的欺诈师。被异星之神召唤为使徒。他没有宏大的理想，只是单纯地喜欢看着他人的精神崩溃。他利用了复仇者们的执念来布置陷阱，最终反被复仇者们利用作为清算的祭品。T5（神话）级。
