# 断章 · 平安京

FGO_断章_地狱界曼荼罗_平安京:
  核心设定:
    特异点名称: 亜種特異点IV 地狱界曼荼罗 平安京 (轰雷一闪)
    时代: 公元1008年前后 (平安时代中期)
    地点: 日本·平安京（京都）
    分类: 亚种特异点（非正式异闻带编号，位于LB5.5）
    环境特征:
      - 平安京的街道被扭曲为现世与地狱的重叠空间。白日尚有人烟，入夜后地狱的门打开，鬼种与怨灵横行。
      - 大地的灵脉被道满改写，形成了巨大的"曼荼罗"阵式。整个平安京本身就是一个仪式场。
      - 罗城门、朱雀大路、内 的宫殿群——这些平安京的标志性建筑在地狱化的过程中逐渐变异，最终化为魔界的入口。
      - 空气中弥漫着硫磺与香灰混合的气味，天空在夜间呈现出血红色。
    异常根源: 异星之神的使徒·蘆屋道满（Limbo）以平安京为舞台，企图实施一场大规模的仪式。他利用平安京地下沉睡的强大存在——伊吹童子（八岐大蛇的神灵化身）——作为仪式的核心引擎，将这片土地彻底转化为"地狱界"。道满的目的并非单纯的破坏，而是收集数据与验证术式，为异星之神的最终计划做准备。

  故事梗概:
    - 迦勒底在LB5奥林波斯战役结束后的休整期间，探测到平安时代日本出现了无法忽视的时空异常信号。
    - 藤丸立香与玛修搭乘Shadow Border前往调查。降落后发现平安京处于一种诡异的"半崩坏"状态——白天是正常的贵族社会，入夜后整座城市堕入地狱。
    - 结识了紫式部，她作为宫廷女官对当前的异常有着敏锐的感知，成为了藤丸立香在平安京中的导航者。
    - 遭遇平安京四天王之一的渡辺纲，他正在独自讨伐横行的鬼种，但发现鬼的数量远超常理。
    - 发现酒吞童子与茨木童子等鬼种并非此次异变的元凶，反而也受到了道满的操纵与利用。酒吞童子对道满这种"借他人之手行事"的做法极度厌恶。
    - 源赖光作为讨鬼的核心战力登场，但她体内牛头天王（丑御前）的血统在地狱化的平安京中被强烈激发，精神状态极不稳定——讨鬼之念与自身的鬼性在她体内剧烈冲突。
    - 坂田金时作为泛人类史的从者现界，与源赖光重逢。金时是唯一能在赖光暴走边缘将她拉回来的人。
    - 道满现身，揭露了仪式的核心：唤醒沉睡在平安京地脉深处的伊吹童子。伊吹童子是八岐大蛇的神灵化身，其存在本身就是一柄"神剑"的对立面——与草薙剑互为表里的灾厄。
    - 源赖光在与自身鬼性的最终对峙中做出了选择，以讨鬼者的意志压制了体内的天王之血，全力出击。
    - 伊吹童子以巨大的神灵形态降临，藤丸立香联合赖光、金时、酒吞等人展开殊死战斗。
    - 击溃伊吹童子，道满的仪式被中断。但道满本人并未被消灭——他以分身或替身的方式逃脱，宣告自己将在下一个舞台继续行动。
    - 平安京的地狱化被解除，时空异常消弭。

  阶段划分与日期推测:
    阶段1_昼之京与夜之狱:
      预计经历时间: 第1日 ~ 第3日
      触发条件: 降落平安京。
      环境: 平安京市街、贵族宅邸。
      核心事件:
        - 白天抵达平安京，一切看似正常。贵族们照常举办歌会，牛车在朱雀大路上缓慢行驶。
        - 结识紫式部。她注意到最近宫中怪异事件频发，贵族们在夜间失踪、宫女口中念叨着听不懂的经文。
        - 第一个夜晚降临。平安京的街道在日落后开始变形——地面裂开，涌出硫磺色的瘴气；建筑物的影子开始自行移动；远处传来不属于人类的嚎叫。
        - 遭遇低级鬼种的袭击。玛修以奥特瑙斯进行防御，但发现鬼种的数量远超正常的特异点规模。
        - 遇到正在巡逻斩鬼的渡辺纲。他对藤丸立香等"异邦人"保持警惕，但在确认双方目标一致后选择合作。
    阶段2_鬼种与讨鬼者:
      预计经历时间: 第4日 ~ 第6日
      触发条件: 深入调查鬼种异常增殖的原因。
      环境: 大江山方向、荒废的寺院。
      核心事件:
        - 追踪鬼种的源头，遭遇酒吞童子。酒吞并未立刻开战，而是以一种玩味的姿态告知藤丸立香——他和茨木同样被某个"恶趣味的术师"摆了一道，被强行拉入这个地狱化的棋盘。
        - 茨木童子对渡辺纲的出现产生极其激烈的反应（被斩断手臂的因缘），差点引发混战。酒吞出面制止。
        - 源赖光出现。她以压倒性的武力瞬间镇压了周围的鬼种，但藤丸立香注意到她的精神状态异常——她的眼中时而闪过金色的光芒，身上散发着与鬼种相似的灵压。
        - 坂田金时随后赶到，紧紧跟在赖光身边。金时私下告诉藤丸立香：赖光的体内封印着牛头天王（丑御前）的血脉，在地狱化的环境下，这道封印正在被侵蚀。
    阶段3_道满显现与大蛇之胎:
      预计经历时间: 第7日 ~ 第9日
      触发条件: 追踪到仪式的核心区域。
      环境: 平安京地脉深处、变异的内裏。
      核心事件:
        - 蘆屋道满以宫廷阴阳师的伪装现身，随后揭露真面目。他的言行举止极度癫狂却又精密——每一句话都像在念经，每一个动作都是仪式的一部分。
        - 道满展示了仪式的进度：平安京地下的灵脉已经被他改写为巨大的曼荼罗阵，而阵的中心沉睡着伊吹童子——八岐大蛇以少女形态凝结的神灵本体。
        - 道满激活仪式的下一阶段，整个平安京的地狱化急剧加速。白天也不再安全，鬼种从地面涌出，贵族与平民开始大规模死亡或变异。
        - 源赖光体内的天王之血对伊吹童子的灵压产生了共鸣，她陷入半暴走状态。金时拼死抑制赖光，但他自己也被赖光的暴走误伤。
        - 酒吞童子在这个阶段展现出与平时截然不同的姿态——面对道满这种"利用鬼种作棋子"的行为，他作为鬼之头目的尊严被践踏，主动向藤丸立香提出临时同盟。
    阶段4_讨鬼绝刀与大蛇降临:
      预计经历时间: 第10日 ~ 第12日
      触发条件: 伊吹童子被道满强制唤醒。
      环境: 崩坏的平安京全域。
      核心事件:
        - 道满完成仪式的最终阶段。伊吹童子以神灵形态降临——她并非凶恶的怪物形象，而是一名持有酒壶的少女，但她身后展开的八条蛇影投射出的灵压足以碾碎一切低阶从者的灵基。
        - 伊吹童子的存在本身就是对"草薙剑"这一概念的否定。她是剑所斩杀的"蛇"的具现，持有与草薙剑对等的神代权能。战力评级T6（原典），在日本土地上享有极大的知名度加成。
        - 源赖光在金时的呼唤下恢复了意识。她做出了最终的抉择——不是压制体内的鬼血，而是将讨鬼的意志与鬼的力量同时点燃。她短暂地达到了超越自身极限的状态，以丑御前的力量强化自身的讨鬼武艺。
        - 酒吞童子与茨木童子从侧面压制伊吹童子的蛇影，金时正面承受伊吹童子的攻击为赖光创造空隙。
        - 赖光以最后一击贯穿伊吹童子的核心。伊吹童子的神灵形态崩溃。
        - 道满在仪式被中断后，面无恼色，甚至拍手称赞。他表示此次实验已经获得了足够的数据，随后以术式遁走，留下一句意味深长的话：他将在更盛大的舞台上再次登场。
        - 平安京的地狱化随着伊吹童子的消散而解除。紫式部在送别时表示，她会将这段经历写入自己的物语中。

  重要角色阵容:
    异星使徒_狂乱的术师:
      蘆屋道满 (Limbo):
        真名: 蘆屋道满 (Alter Ego / 异星之神使徒)
        状态: 异星之神的使徒之一，与"言峰"（拉斯普京外壳）并列。平安时代的阴阳师，安倍晴明的宿敌。性格极度癫狂、戏剧化，将一切视为"法悦"（至高的狂喜）。他的行为逻辑不是"完成任务"，而是"在完成任务的过程中获得最大的快感"。他在平安京制造地狱并非出于仇恨，纯粹是因为他觉得这样"美"。
        战力: 本体战力约T5（神话）级。但他极少正面作战，更擅长操纵术式、傀儡、结界，以及利用他人作为棋子。即使被"击杀"也能以分身或替身逃脱。
        核心威胁: 他不是靠武力碾压，而是靠布局和仪式。整个平安京就是他的"作品"。

    平安京的鬼与人:
      源赖光:
        真名: 源赖光 (Berserker)
        状态: 平安时代最强的讨鬼武者之一。表面上是完美的女武将，但体内流淌着牛头天王（丑御前）的鬼血。她的讨鬼之念异常偏执——不仅是职责，更是对自身鬼性的否定与恐惧。在地狱化的平安京中，这份矛盾被推到了极限。T5（神话）级，短暂超限时接近T6。
      坂田金时:
        真名: 坂田金时 (Berserker / Rider)
        状态: 源赖光四天王之首。粗犷、率直、重情义。他是唯一能触及赖光真实内心的人。在赖光暴走时，金时不是用武力压制，而是用言语和存在本身将她拉回。T4（史诗）~T5（神话）级。
      酒吞童子:
        真名: 酒吞童子 (Assassin)
        状态: 大江山之鬼王。表面上是个嬉皮笑脸、只爱喝酒的混混，但实际拥有极高的鬼种位格。他对道满将鬼种当作"仪式材料"的做法极度愤怒——不是因为道德，而是因为尊严。作为鬼的头领，他的部下只能由他来处置。T5（神话）级。
      茨木童子:
        真名: 茨木童子 (Berserker)
        状态: 酒吞童子的挚友，罗生门之鬼。对渡辺纲有着刻骨铭心的执念（曾被其斩断手臂）。性格比酒吞更加直率和暴烈。在这个断章中，她是酒吞的左右手，但也是最容易失控的变量。T4（史诗）~T5（神话）级。
      渡辺纲:
        真名: 渡辺纲 (Saber)
        状态: 源赖光四天王之一，斩鬼之武士。冷静、寡言、对鬼种抱有绝对的敌意。他的刀法干净利落，没有多余的动作。与茨木童子之间存在宿命的因缘。T4（史诗）级。
      伊吹童子:
        真名: 伊吹童子 (Saber / 神灵)
        状态: 八岐大蛇的神灵化身，以少女的姿态凝结的灾厄核心。她并非主动为恶——她是被道满从沉睡中强制唤醒的存在。持有与草薙剑对等的神代权能。T6（原典）级，在日本土地上因知名度加成可能触及更高。

    泛人类史与迦勒底:
      紫式部:
        真名: 紫式部 (Caster)
        状态: 平安时代的宫廷女官，《源氏物语》的作者。在这个断章中充当导航与情报支援角色。她对"物语（故事）"有着超越常人的感知力，能通过阅读灵脉的"文脉"来判断仪式的进度。战斗能力不高（T3决战级），但情报价值极大。
      玛修·基列莱特 (奥特瑙斯):
        真名: 玛修 (Shielder)
        状态: 继续使用奥特瑙斯系统作战。在平安京的鬼种大军面前承受了持续的防御压力。
