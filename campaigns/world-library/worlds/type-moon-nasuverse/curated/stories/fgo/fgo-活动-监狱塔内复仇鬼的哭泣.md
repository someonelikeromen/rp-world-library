# 活动 · 监狱塔内复仇鬼的哭泣

特异点名称: 监狱塔·伊夫（深夜之罪人 / Prison Tower）
时代: 公元2016年3月16日
地点: 法国近海·伊夫城（灵魂牢狱）
评级: ？

环境特征:该区域为封闭式精神监狱，地理结构由对应七宗罪的“七重门”构成。空间环境随支配者意志扭曲，攻击方式表现为针对意识的人格污染与灵魂折磨。受试者（御主）处于意识被囚禁、现实肉身灵基濒危的脱离状态。
异常根源:由魔术王盖提亚在伦敦特异点留下的诅咒干涉引发。核心变量为盖提亚的残留恶意与从者爱德蒙·唐泰斯（岩窟王）的介入。前者试图通过七重审判摧毁受试者精神，后者则将该空间转化为针对御主的生存适应性考验。
底层逻辑:该系统的运行机制是以罪业试炼为手段，系统性拆解受试者的精神支柱。攻略流程为：受试者在岩窟王引导下，以现实身份为锚点，依次通过嫉妒、色欲、傲慢等七层精神关卡。破局关键在于利用生存意志对抗精神审判，最终通过否定绝望逻辑使灵魂脱离监狱塔束缚，回归现实。

迦勒底： 藤丸立香(御主/被囚者)、玛修·基列莱特(亚从者/现实侧守护)
复仇者： 岩窟王[爱德蒙·唐泰斯](复仇者/引路人/最终支配者)
审判支配者_七罪： 剧院魅影(第一支配者/嫉妒)、弗格斯(第二支配者/色欲)、吉尔·德·雷_Caster(第三支配者/怠惰)、吉尔·德·雷_Saber(第四支配者/愤怒)、卡利古拉(第五支配者/暴食)、天草四郎(第六支配者/救赎试炼)、梅尔塞苔丝(第七支配者/傲慢)
干涉者： 贞德(劝解/拦截)、吉尔伽美什_Caster(现实侧观测)
幕后诅咒源： 魔术王所罗门(诅咒发动者)
-事件A: 第一重门·黑发鬼 (2016年3月16日 深夜)[触发:立香灵魂被拉入监狱塔伊夫|完成:与Avenger契约并击碎魅影]: 立香灵魂被拉入"监狱塔伊夫"。Avenger宣告立香被囚，须闯过七重审判。第一支配者魅影因"嫉妒"欲夺取立香性命。立香与Avenger契约并击碎魅影。魅影临终前警告复仇者未必是善类。
【剧院魅影】："在这扭曲的伊夫城，能守护你的只有一人。而此人，未必是善人。"
【Avenger】："等待。并心怀希望吧。"

-事件B: 第二重门·炼狱的恶魔 (2016年3月17日 深夜)[触发:第一重门突破|完成:击败弗格斯，玛修发现立香状态转危]: Avenger说明灵魂腐朽将导致肉体死亡。立香救下失忆女性并赐名梅尔塞苔丝。支配者弗格斯以"色欲"为由索要女性，遭立香拒绝后开战。两人击败弗格斯。现实中，玛修发现立香状态转为危险。
【弗格斯】："心中没有个一两股兽欲怎配称得上勇士或英雄！把那个女人交出来！！"
【Avenger】："若感到绝望，若已不想战斗，就立刻说。不用等七日到来，我就会杀了你。"

-事件C: 第三重门·螺湮城之怪 (2016年3月18日 深夜)[触发:第二重门突破|完成:以魔术回路为锚斩断吉尔(术)]: 现实中立香深度昏迷，吉尔伽美什在侧守护。监狱塔内，Avenger质问立香是否"怠惰"。第三支配者吉尔（术）代表堕落极致，试图折磨灵魂。立香以现实身为锚点引导魔力，与Avenger合力将其斩断。
【Avenger】："如果你不愿意被我抛下，就拼死追上来吧。将注意力放在魔术回路的存在上，你不过是人类，只能通过道理来引导力量。"
【吉尔·德·雷（术）】："灵魂也有痛觉。只要折断灵魂的手指、撕裂灵魂的腹部……你就会向绝望滑落！其速度甚至能超越划过夜空的流星！"

-事件D: 第四重门·神明不语 (2016年3月19日 深夜)[触发:第三重门突破|完成:岩窟王击败贞德与吉尔(剑)，真身被揭示]: 审判主题为"愤怒"。第四支配者吉尔（剑）与贞德现身。贞德试图劝解Avenger，遭其断然拒绝。贞德揭示Avenger真身为基督山伯爵。岩窟王击败圣女与骑士，宣告继续迈向恩仇彼方。
【贞德】："抛弃了人心中所有善良的部分，选择复仇之人。他正是，全世界最有名的复仇者。"
【Avenger】："既然如此，那我就这样做！顺从人类的请求，对世界复仇！连主也无法拯救我的灵魂！"

-事件E: 第五重门·月光无情 (2016年3月20日 深夜)[触发:第四重门突破|完成:卡利古拉以爱的思念完成对命运的抵抗后消逝]: 第五支配者卡利古拉在深渊中获得短暂清醒，将"暴食"定义为填补空虚的贪婪。随后其受月神诅咒重陷狂乱并袭击立香。战后重归理性的卡利古拉宣告，凭借对爱的思念完成了对命运的抵抗。
【卡利古拉】："余在疯狂的呐喊中怀着仅存的思念。尽管如此渺小……但这正是……余对被诅咒命运的抵抗。"
【梅尔塞苔丝】："无论是愤怒还是嫉妒，全都不过是正常的精神活动。若说这些是罪，那除主之外还有谁能审判呢？"

-事件F: 第六重门·复仇是—— (2016年3月21日 深夜)[触发:第五重门突破|完成:立香支持岩窟王击碎天草四郎与贞德的救赎]: 贞德再次拦截。Avenger正式自号"岩窟王"。第六支配者天草四郎现身，联手贞德试图救赎复仇者。立香选择支持岩窟王，凭借求生意志击碎圣者的理想。岩窟王对两人的高尚表示致敬。
【岩窟王】："我乃岩窟王！基督山伯爵！烙印于人类历史上的恶鬼阴影，永恒的复仇者！别对我谈论恩仇，女人！"
【天草四郎】："既是知晓人间地狱为何之人，想必也知道何谓真正宝贵之物。"

-事件G: 第七重门·岩窟王 (2016年3月22日 深夜)[触发:第六重门突破|完成:岩窟王揭示诅咒真相并将立香从灵魂牢狱中解放]: 岩窟王述说传说终局。梅尔塞苔丝揭露自己本是"傲慢"支配者，因被救而丧失职责并消失。岩窟王作为最后支配者挑战立香，战后揭晓真相：此乃魔术王诅咒，岩窟王因不屈的意志救下立香并送上最后祝福。
【梅尔塞苔丝/第七支配者】："他的话语中充斥着大量欺瞒，但只有那句话能留在心中：'等待。并心怀希望吧'。"
【岩窟王】："真遗憾啊，魔术王！你区区一次冲动，区区一次姑息的陷阱，在此彻底破产了！前进吧！从灵魂的牢狱中解放——你！总有一天，会拯救世界吧！"
