# LB7 · 纳维米克特兰

FGO_异闻带VII_黄金树海纪行_纳维_米克特兰:
  核心设定:
    特特异点名称: Lostbelt No.7 黄金树海纪行 纳维·米克特兰 (受体头领 / 戴冠式)
    时代: 公元前6600万年 (泛人类史分歧点) / 实际时间为2018年
    地点: 南美大陆·米克特兰（地下世界）
    异闻深度: A++
    环境特征:
      - 整个异闻带位于地下，分为九层地底世界。天空是岩壁，太阳是由特殊机制（库库尔坎）人造的。
      - 生态系统极其繁茂，充满了黄金树海和各种史前植物。
      - 这里的统治物种是“迪诺斯”（恐龙进化而成的人型或半人型生物）。他们天生拥有极高的物理能力，不吃肉，不需要劳动，没有领地意识，没有争斗心，完美地与自然共融。
      - 地下最深处（第九层）沉睡着游星尖兵——ORT。
    异常根源: 6600万年前陨石撞击地球，但在这条世界线中，地表生物（恐龙）为了生存逃入了地下空洞，并在玛雅神明（其实是来自外星的真体机神）的干涉下进化为迪诺斯。同时，原本应该在公元前一万两千年降临的ORT，在这个世界线于6600万年前与陨石一同降落并陷入沉睡。隐匿者戴比特·泽姆·沃伊德企图唤醒ORT，以终结异星之神的阴谋，哪怕这意味着星球的解体。

  故事梗概:
    - 【前篇】Shadow Border在降落南美时遭遇不明攻击，几乎全毁。藤丸立香与玛修等人失散，独自在树海中醒来。
    - 藤丸立香遇到了失忆的“异星之神”——U-奥尔加玛丽。她不仅失去了记忆，还变得意外的通情达理且充满保护欲。两人结成奇妙的同盟。
    - 在探索中结识了当地的迪诺斯，以及泛人类史的从者特拉洛克（其实是特诺奇蒂特兰的拟人化）和特斯卡特利波卡（烟雾镜）。
    - 了解到这个异闻带的奇特规则：迪诺斯们活在绝对的和平中，但他们知道自己的世界将在一年后毁灭（因为戴比特的计划），却平静地接受了这一点。
    - 藤丸立香与尼莫船长、玛修等人重新汇合。迦勒底的目的是阻止戴比特唤醒ORT，并切除异闻带。
    - 遭遇“勇者王”卡玛佐兹。他曾是泛人类史（或者是某个被剪定的世界线）中唯一存活的生命，为了保护人类杀死了Beast，自己也变成了怪物。
    - 【后篇】戴比特的计划揭晓：他发现异星之神（马里斯比利·阿尼姆斯菲亚的计划产物）的真正目的是利用全地球的资源进行某种宇宙级的扩张。为了阻止这个比毁灭更糟糕的结局，戴比特决定用ORT来摧毁地球。
    - 库库尔坎（异闻带之王）显露真身——她其实是ORT的心脏结合了神灵概念诞生的存在。她深爱着迪诺斯，却又受制于自身的本质。
    - 戴比特成功献祭了自己的心脏和从者，唤醒了ORT。
    - ORT苏醒，开始向地表移动，沿途吞噬一切（包括从者、空间、概念）。迦勒底所有的从者进行接力式的自杀式阻击（ORT总力战）。
    - U-奥尔加玛丽恢复记忆，但在面对ORT的绝境中，她选择与迦勒底站在一起，燃烧自己将其重创。
    - 库库尔坎放弃了自身作为“太阳”的使命，化为陨石对ORT发动致命一击。
    - 最终，ORT的本体被摧毁。但ORT甚至超越了死亡的概念，它在死前的一瞬吞噬了泛人类史的英灵召唤系统，将“自己”作为从者召唤出来（冠位降级版的ORT·希巴尔巴）。
    - 藤丸立香与卡多克、戴比特（濒死状态下倒戈协助）联手，彻底击碎了ORT的残影。
    - 迪诺斯们在灾难中安然迎来了灭绝。南美异闻带消失。

  阶段划分与日期推测:
    阶段1_坠落与失忆的神 (前篇):
      预计经历时间: 第1日 ~ 第7日
      触发条件: 降落南美。
      环境: 第一层至第三层树海、奇琴伊察。
      核心事件:
        - 战舰被击毁，队伍失散。藤丸立香与失忆的U-奥尔加玛丽同行。
        - 结识迪诺斯“帝王花”（被卡玛佐兹改造的从者）和当地向导。
        - 在奇琴伊察见识到迪诺斯文明的和平与奇异（踢球决定祭品等）。
        - 遭遇特斯卡特利波卡，他作为戴比特的从者，对藤丸立香进行试探。
    阶段2_冥界的勇者与重逢 (前篇):
      预计经历时间: 第8日 ~ 第14日
      触发条件: 寻找失散的同伴。
      环境: 第四层至第六层、卡玛佐兹的领地。
      核心事件:
        - 与玛修、尼莫等人汇合。
        - 深入卡玛佐兹的领地。了解到卡玛佐兹那悲惨的过去：为了拯救没有希望的世界，他把自己变成了吸血鬼，杀死了所有的神，但最终还是只剩下他一个人。
        - 卡玛佐兹对迦勒底发起考验。击败他后，他释怀退场。
    阶段3_戴比特的真相与心脏 (后篇):
      预计经历时间: 第15日 ~ 第20日
      触发条件: 抵达第九层入口。
      环境: 玛雅遗迹、祭坛。
      核心事件:
        - 戴比特揭露真相：迦勒底（马里斯比利）才是真正威胁宇宙平衡的元凶，异闻带只是掩护。他必须唤醒ORT来重置一切。
        - 库库尔坎的身份曝光。作为ORT的心脏，她面临着“保护迪诺斯”还是“回归ORT”的矛盾。
        - 特斯卡特利波卡展现冠位Assassin的实力，但他并不绝对忠于戴比特，而是遵循“战士的法则”行事。
        - 戴比特献祭自身，打破封印。
    阶段4_ORT总力战 (后篇终局):
      预计经历时间: 第21日 ~ 第23日
      触发条件: ORT苏醒。
      环境: 崩溃的地下世界、ORT移动路径。
      核心事件:
        - ORT展现出绝对的规格外力量。它不仅免疫大部分攻击，还能将被击败的从者直接“水晶化”并吸收其灵基（被击败的从者在本次作战中永久不可再次使用）。
        - 迦勒底投入所有记录在案的从者，进行无休止的车轮战。这是纯粹的数值与生命力的填补。
        - U-奥尔加玛丽恢复记忆，意识到自己曾是异星之神。但在最后关头，她选择为了藤丸立香和地球燃烧自己的灵基，重创ORT。
        - 库库尔坎耗尽一切，将ORT的本体击碎。
    阶段5_大平原的落日与灭绝:
      预计经历时间: 第24日
      触发条件: ORT本体死亡。
      环境: 最深处大平原。
      核心事件:
        - ORT的尸骸中诞生了“从者·ORT”。
        - 戴比特在最后时刻认可了迦勒底的决心，利用特斯卡特利波卡的权能提供支援。
        - 彻底粉碎ORT。
        - 迪诺斯们没有恐慌，没有逃跑。他们静静地看着天空的毁灭，认为“我们度过了没有遗憾的一生”。带着这份平静，迪诺斯文明迎来了灭绝。南美异闻带切除。

  重要角色阵容:
    隐匿者与神明:
      戴比特·泽姆·沃伊德:
        真名: 戴比特 (Crypter / 御主)
        状态: A队中最神秘、最强的人。他没有常人的情感和共情能力，但拥有绝对理性的判断。他不仅能在南美的极端环境中生存，甚至能以人类之躯肉搏从者。他的目的不是生存，而是作为“地球的白细胞”去消灭马里斯比利造成的病灶（迦勒底系统）。
      特斯卡特利波卡:
        真名: 特斯卡特利波卡 (Assassin / 冠位候补)
        状态: 阿兹特克的全能之神，烟雾镜。现代社会适应良好，喜欢枪械和黑帮做派。性格随性但绝对公平，掌管战争与献祭。战力评级T7（冠位）。
      库库尔坎:
        真名: 库库尔坎 (Foreigner / 异闻带之王)
        状态: 表面上是风与太阳之神，实际上是ORT的心脏（能量核心）结合了当地信仰诞生的独立意识。她深爱着南美和迪诺斯，性格开朗、强大且有些天然。T7（原典/星之触角）级。

    异星之神与特异存在:
      U-奥尔加玛丽:
        真名: 奥尔加玛丽 (Beast / 异星之神)
        状态: 因不明原因坠落南美并失去记忆。保留了傲娇和容易慌张的性格底色，但展现出了极强的责任感和对藤丸立香的保护欲。战力评级T7。
      卡玛佐兹:
        真名: 卡玛佐兹 (Alter Ego / Beast I 候补)
        状态: 蝙蝠神，勇者王。为了拯救自己世界的人类，杀死了所有的神和威胁，自己变成了不死的怪物，但人类依然灭绝了。他在地下世界游荡，渴望被真正击败以获得解脱。T6~T7级。
      特拉洛克 (特诺奇蒂特兰):
        真名: 特诺奇蒂特兰 (Pretender)
        状态: 表面上是雨神特拉洛克，实际上是阿兹特克首都“特诺奇蒂特兰”这座城市的拟人化。极度兄控（崇拜特斯卡特利波卡）。

    终极灾厄:
      ORT (奥尔特):
        真名: ORT (游星尖兵 / 蜘蛛)
        状态: 沉睡在南美地下的外星生命体。不具备地球的概念，免疫地球上的法则。其移动本身就会改变周围的物理法则（水晶溪谷）。没有善恶之分，只是一台吞噬一切的机器。战力评级超出常规体系，绝对的T7+（不可测度）。在后篇中被击败后，甚至利用了泛人类史的召唤系统将自己召唤出来。

    泛人类史阵营:
      尼莫船长与玛修:
        状态: 在本章中承担了极大的后勤与突击压力。
      卡多克·泽姆露普斯:
        状态: 作为副御主继续支援藤丸立香。
