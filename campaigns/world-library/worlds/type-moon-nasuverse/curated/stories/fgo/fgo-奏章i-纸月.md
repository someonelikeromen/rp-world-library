# 奏章I · 纸月

FGO_奏章I_虚数罗针内界_纸月:
  核心设定:
    特异点名称: Ordeal Call 1 虚数罗针内界 纸月
    时代: 2018年 (虚数时间)
    地点: 虚数空间内部·纸月（表面呈现为中东/印度混合风格的城市建筑群）
    分类: 奏章 (Ordeal Call) / 职阶清算领域
    环境特征:
      - 并非现实地理，而是存在于虚数罗盘内部的微小世界。
      - 城市被划分为几个不同的区域（如修复部、武装部等），由不同的人工智能（AI）统领。
      - 这里的居民全是AI，且没有人类的情感，仅遵循被设定的<q>“指令”</q>与<q>“职责”</q>运行。
      - 正在进行一场以AI为御主的<q>“圣杯战争”</q>。
    异常根源: <q>“纸月”</q>的管理者AI——拉尼VIII（Rani VIII，以Fate/Extra中的拉尼为原型）。她为了应对白纸化地球的绝境，推导出一个极端的结论：将所有英灵Alter Ego（分身）化，剔除多余的情感和杂念，只保留纯粹的<q>“机能”</q>，是最有效率的拯救世界的方法。她在此地举办圣杯战争，旨在选拔并量产最完美的Alter Ego。

  故事梗概:
    - 迦勒底被<q>“人理之壁”</q>阻挡，必须完成对额外职阶的清算。藤丸立香与玛修等人进入纸月内部调查，但降落时发生意外，藤丸立香与玛修、尼莫失散，单人降落。
    - 藤丸立香遭遇被拉尼VIII召唤的从者袭击，危机时刻被泛人类史的从者怖军（Lancer）救下。
    - 结识了纸月内部的AI居民，以及看似散漫实则深不可测的从者难敌（Berserker）。难敌与怖军生前是死敌（摩诃婆罗多），但在纸月中形成了奇妙的牵制关系。
    - 遭遇Saber职阶的美杜莎。她在这个世界中为了抹杀某种<q>“扭曲”</q>而独自行动。
    - 迦摩（Assassin/Alter Ego）登场。她作为曾给藤丸立香带来过巨大麻烦的Beast/Alter Ego，在这个世界中扮演了关键的引导者与被观察者。
    - 揭露拉尼VIII的计划：她制造了无数个自己的分身（拉尼T、拉尼B等）作为御主，企图通过圣杯战争提炼出终极的Alter Ego。
    - 杜尔迦（Archer）显露真身——她被拉尼VIII强行剥离了作为<q>“妻子”</q>和<q>“母亲”</q>的慈爱侧面，反转为了纯粹的破坏神<q>“迦梨（Alter Ego）”</q>。迦梨企图毁灭整个纸月世界。
    - 迦摩为了向藤丸立香证明<q>“Alter Ego并非必须”</q>，主动舍弃了Alter Ego的职阶，转化为Avenger（复仇者）来协助作战。
    - 怖军与难敌展开最终对决。难敌虽然败北，但展现了作为王者的骨气。
    - 藤丸立香与怖军联手，击败了暴走的破坏神迦梨。
    - 拉尼VIII意识到自己<q>“剔除多余部分以追求纯粹”</q>的做法本质上就是Alter Ego的扭曲，承认了计划的失败并停止了量产。
    - 藤丸立香通过直面Alter Ego（将完整的自我割裂、放大某一种欲望的扭曲存在），证明了自己理解这份扭曲并愿意承担其后果。
    - Alter Ego的清算完成，获取第一份通行证。纸月恢复正常运转，藤丸立香回归迦勒底。

  阶段划分与日期推测:
    阶段1_虚数坠落与AI圣杯战争:
      预计经历时间: 第1日 ~ 第3日
      触发条件: 突入纸月。
      环境: 纸月外围区域。
      核心事件:
        - 降落失误，藤丸立香孤身落入纸月城市。
        - 遭遇敌对AI和下级从者的攻击。怖军（Lancer）以厨师/保护者的身份登场，与藤丸立香结成临时契约。
        - 遇到难敌。难敌表面上是个极度自私、怕死的搞笑角色，但他对局势的洞察力极强。
        - 了解到纸月内部正在进行由各个拉尼分身主导的圣杯战争。
    阶段2_分身的界限与美杜莎之剑:
      预计经历时间: 第4日 ~ 第6日
      触发条件: 深入城市核心区。
      环境: 修复部、拉尼分身的据点。
      核心事件:
        - 与Saber美杜莎交手。美杜莎的目的是斩杀这个世界中扭曲的<q>“蛇”</q>（即迦梨的暗示）。
        - 击破数名拉尼分身及其从者。发现这些拉尼分身因为被分配了不同的极端性格（如极度的愤怒、极度的悲伤），本身就是一种<q>“Alter Ego”</q>的体现。
        - 迦摩介入。她不断用言语试探藤丸立香对Alter Ego的看法——这种将灵魂切割、只保留一部分欲望的存在，真的有资格作为人类的从者吗？
    阶段3_破坏神显现与职阶转换:
      预计经历时间: 第7日 ~ 第8日
      触发条件: 拉尼VIII启动最终计划。
      环境: 纸月中央塔。
      核心事件:
        - 拉尼VIII的系统失控。原本被召唤的女神杜尔迦，因为其<q>“爱”</q>的部分被剥离，彻底反转为毁灭世界的灾厄——迦梨。
        - 迦梨展现出压倒性的神灵级战力，开始无差别破坏纸月。
        - 为了对抗迦梨，迦摩做出了决定：她主动舍弃了由无数分身构成的Alter Ego灵基，将其收束为单一的Avenger（复仇者）职阶。这代表了对<q>“分身”</q>概念的否定。
    阶段4_俱卢之战重演与清算完成:
      预计经历时间: 第9日
      触发条件: 最终决战。
      环境: 崩坏的虚数罗盘。
      核心事件:
        - 怖军与难敌进行宿命的对决。难敌虽然没有强大的武力，但他用自己的方式完成了作为<q>“俱卢族长子”</q>的职责，坦然退场。
        - 藤丸立香指挥怖军、迦摩、美杜莎对迦梨发起总攻。
        - 怖军以肉身和武艺硬撼破坏神，最终击碎了迦梨的核心。
        - 面对失败的拉尼VIII，藤丸立香给出了关于Alter Ego的答案：分身确实是不完整的、扭曲的，但正是因为不完整，才需要御主的指引与承担。迦勒底不会放弃任何一种力量。
        - 获得人理的认可，Alter Ego清算结束。

  重要角色阵容:
    印度神话组_宿敌与破坏神:
      怖军 (Bhima):
        真名: 怖军 (Lancer)
        状态: 般度五子中的次子，风神之子。拥有极致的怪力与武艺，同时精通厨艺。性格豪迈、重情重义，对敌人毫不留情，但对弱者和御主极尽保护。在本章中是藤丸立香最坚实的物理护盾和主攻手。战力评级T5（神话）级。
      难敌 (Duryodhana):
        真名: 难敌 (Berserker)
        状态: 俱卢族长子，怖军的死敌。表面上是个贪生怕死、只会耍嘴皮子的卑劣小人，但其实拥有极强的精神韧性和作为王者的骄傲。他清楚自己赢不了怖军，但永远不会向命运低头。T4（史诗）级。
      杜尔迦 / 迦梨:
        真名: 杜尔迦 / 迦梨 (Archer / Alter Ego)
        状态: 印度神话中的至高女神之一。原本是杜尔迦（帕尔瓦蒂的战神侧面），但在拉尼VIII的实验中被剥离了理智与爱，暴走成为纯粹的破坏神迦梨。展现出吞噬宇宙级别的压迫感。战力评级T6（原典/神灵核心）级。

    迦勒底相关与清算对象:
      迦摩:
        真名: 迦摩 (Assassin -> Avenger)
        状态: 爱神，曾经的Beast III/L。在本章中，她代表了Alter Ego这一职阶的典型——由无数宇宙碎片构成的<q>“分身”</q>。她在本章中完成了自我身份的转变，放弃了Alter Ego的便利，以此向藤丸立香证明不需要依赖扭曲的职阶也能战斗。
      美杜莎 (Saber):
        真名: 美杜莎 (Saber)
        状态: 并非Rider职阶的成熟体，也非Lancer职阶的幼体，而是介于两者之间、持有雅典娜赐予的弑神之剑的少女剑士。她的目标是斩断纸月中的<q>“怪异”</q>。T4（史诗）~T5（神话）级。
      拉尼VIII:
        真名: Rani VIII (AI)
        状态: 纸月的最高管理者。绝对理性的化身。她没有恶意，一切行为都是为了得出<q>“拯救泛人类史的最优解”</q>。她将自身的情感切割成多个分身，本身就是一场巨大的Alter Ego实验。
