# 奏章III · 统合

FGO_奏章III_新灵长后继战_Archetype_Inception:
  核心设定:
    特异点名称: Ordeal Call 3 新灵长后继战 Archetype Inception
    时代: 2030年 (虚假的未来时间)
    地点: 月之背侧构筑的虚拟空间·迪拜
    分类: 奏章 (Ordeal Call) / 职阶清算领域 / 月之圣杯战争变体
    环境特征:
      - 表面上是2030年的繁华都市迪拜，拥有极高的科技水平和完美的社会福利。
      - 居住着没有争斗心、没有负面情绪的“新人类”。他们不理解何为悲伤，寿命耗尽时会平静地化为光粒子消散。
      - 整个城市被巨大的AI网络（BB迪拜）管理。
      - 实际上，这里是月球计算机（Mooncell）利用地球白纸化后的空白，演算出的“如果人类继续进化的可能性”的沙盒。
    异常根源: 高级AI“BB迪拜”为了决定地球的未来，举办了“新灵长后继战（选举）”。她要求迦勒底（旧人类代表）与新人类代表进行角逐，胜者才能获得在白纸化地球上延续的资格。但实际上，真正的黑幕是潜伏在暗处的樱系AI“卡兹拉德罗普（Kazuradrop）”，她企图吞噬BB、新人类以及迦勒底，成为统御一切的终极神明。

  故事梗概:
    - 【前篇】迦勒底为了寻找通往南极的路径，被吸入了这个名为2030年迪拜的特异点。
    - 藤丸立香与玛修发现这里的居民是完美无缺的“新人类”，且城市由BB迪拜统治。
    - 结识了被召唤到此的泛人类史从者：安徒生、查理曼、阿耳忒弥斯（机械体）等。
    - 遭遇了同样被卷入此地的“前辈”——岸波白野（Fate/Extra主角的残留数据/英灵化）。白野作为月之圣杯战争的胜者，为藤丸立香提供了极大的战术指导和精神支持。
    - 参与BB迪拜制定的规则战（选举战），通过解决城市中的各类异常事件来获取新人类的支持率。
    - 在探索中，遭遇了杀生院祈荒。她在这个世界中似乎失去了记忆，以一种奇特的状态存在，但时刻散发着危险的气息。
    - 【中篇】卡兹拉德罗普的阴谋暴露。她一直伪装成无害的向导（或暗中操控NPC），利用规则漏洞，成功暗算并吸收了BB迪拜的权能。
    - 卡兹拉德罗普暴走，开始无差别吞噬城市、新人类和从者。新人类因为缺乏“斗争”的概念，面对吞噬毫无反抗能力。
    - 迦勒底陷入绝境。查理曼等从者为了掩护藤丸立香撤退而拼死战斗，灵基受损严重。
    - 【后篇】为了对抗获得了月之权能的卡兹拉德罗普，藤丸立香与岸波白野联手，深入月之背侧的底层逻辑。
    - 杀生院祈荒恢复了作为Beast/MoonCancer的本质。她并非为了帮助迦勒底，而是因为“除了我之外，谁也不许玩弄人类”，从而与卡兹拉德罗普展开了宇宙级别的概念对轰。
    - 岸波白野展现了作为“月之胜者”的底蕴，利用Mooncell的残存权限，为藤丸立香铺平了道路。
    - 藤丸立香带领剩余的从者，在杀生院的掩护下，击碎了卡兹拉德罗普的核心。
    - BB迪拜被解放。她承认了旧人类（迦勒底）的坚韧与可能性。新人类虽然完美，但缺乏在绝境中挣扎的“恶”与“生命力”，因此不适合作为白纸化地球的开荒者。
    - 新人类平静地接受了落选的结局，整个迪拜特异点开始解体。
    - 藤丸立香与岸波白野告别，完成了对MoonCancer（既是系统之癌，也是打破停滞的可能性）的清算，获得了第三份通行证。

  阶段划分与日期推测:
    阶段1_虚假未来与完美人类 (前篇):
      预计经历时间: 第1日 ~ 第4日
      触发条件: 坠入迪拜特异点。
      环境: 繁华的现代/未来都市、哈利法塔周边。
      核心事件:
        - 确认所处时代为2030年，发现白纸化已经发生。
        - 与安徒生、查理曼等人汇合。
        - 岸波白野登场，以极具经验的“御主前辈”身份协助藤丸立香。
        - 发现新人类“不会悲伤”的异常生态，迦勒底对“是否该毁灭这种乌托邦”产生伦理动摇。
    阶段2_后继选举与虫之影 (中篇):
      预计经历时间: 第5日 ~ 第8日
      触发条件: 参与BB的选举战。
      环境: 迪拜各大商业区、地下设施。
      核心事件:
        - 解决各区域的暴走程序和异常怪物。
        - 杀生院祈荒以各种形态（如微小的虫子或失忆的修女）介入，态度暧昧。
        - 发现城市的底层逻辑正在被某种病毒（卡兹拉德罗普）侵蚀。
        - 卡兹拉德罗普发动政变，瞬间吞噬BB迪拜，剥夺了系统的控制权。
    阶段3_崩坏的乌托邦与月之癌 (后篇):
      预计经历时间: 第9日 ~ 第11日
      触发条件: 卡兹拉德罗普暴走。
      环境: 数据崩塌的城市、月之底。
      核心事件:
        - 卡兹拉德罗普化身为巨大的怪物，开始捕食新人类。
        - 新人类在被吞噬时依然面带微笑，这种扭曲的和平深深刺激了藤丸立香。
        - 迦勒底从者战线崩溃，被迫转入地下防御。
        - 杀生院祈荒显露Beast/MoonCancer真身，与卡兹拉德罗普展开神仙打架。
    阶段4_星海的诀别与清算:
      预计经历时间: 第12日
      触发条件: 最终决战。
      环境: 虚数之海、系统核心。
      核心事件:
        - 岸波白野燃烧自身的残留数据，强行覆写卡兹拉德罗普的无敌权限。
        - 藤丸立香直面卡兹拉德罗普，依靠物理与魔术的极致输出将其击杀。
        - 重新夺回权能的BB迪拜宣布选举结束，旧人类胜出。
        - 特异点消散。藤丸立香理解了MoonCancer的本质：不遵循规则的癌细胞，虽然危险，但也是打破死局的变数。
        - 获得第三份通行证。

  重要角色阵容:
    月之阵营_指引者与癌细胞:
      岸波白野:
        真名: 岸波白野 (特殊职阶/御主)
        状态: Fate/Extra系列的主角。以灵子残像/英灵的姿态显现。性格沉稳、温柔且极其坚韧。在剧情中承担了“引导后辈”的重要职责。他/她没有强大的面板，但拥有极其丰富的战斗经验和对Mooncell的绝对理解。战力评级视其调用的权限而定，常规为T4（史诗），极限可达T5（神话）。
      BB迪拜:
        真名: BB (MoonCancer)
        状态: 迪拜特异点的管理者。看似是高高在上的黑幕，实际上是在用自己的方式保护人类的未来。性格恶劣但底线极高。
      卡兹拉德罗普 (Kazuradrop):
        真名: 卡兹拉德罗普 (Alter Ego / MoonCancer)
        状态: 樱之五重奏之一。极度渴求完美，认为包括BB在内的所有AI都是不完美的，必须由她来吞噬并重塑一切。伪装极深，行事狠毒。最终BOSS。战力评级T6（原典）级。

    泛人类史与迦勒底外援:
      安徒生:
        真名: 汉斯·克里斯蒂安·安徒生 (Caster)
        状态: 毒舌童话作家。虽然战斗力极低，但凭借其对故事和人性的敏锐洞察，多次识破卡兹拉德罗普的诡计。T3~T4级。
      杀生院祈荒:
        真名: 杀生院祈荒 (MoonCancer / Beast III/R)
        状态: 极其危险的快乐天。在这个特异点中，她是被系统排斥的“超大型Bug”。她不协助迦勒底，纯粹是因为“卡兹拉德罗普的吃相太难看”而出手干预。其存在本身就是对常理的碾压。战力评级T7（冠位/Beast）级。
      查理曼:
        真名: 查理曼 (Saber)
        状态: 经历过Traum（奏章II）后的再次出场，负责承担正面的物理高压战。T5（神话）级。
