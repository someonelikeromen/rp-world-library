# 型月文风约束与禁词表

> 来源: 型月引擎评审 B2  
> 用途: RP 中保持型月世界的独特文风，避免串味到其他世界观

## 核心约束

型月世界的文风特征：
- **残酷美学**: 不回避血腥、痛苦、代价，但不猎奇
- **感官描写**: 魔力/杀意/死线的视觉化、质感化
- **魔术逻辑**: 一切超自然现象必须有"魔术体系内的解释"
- **限知视角**: 严格按当前角色感知能力叙事

## 禁词替换表

| 禁止使用 | 原因 | 替换为 |
|---------|------|--------|
| 内力 | 武侠概念，型月无此设定 | 魔力 |
| 真气/斗气 | 修仙/武侠概念 | 魔力/魔力放出 |
| 杀气 | 通用但偏武侠化 | 杀意/敌意/魔力波动 |
| 法力 | 通用泛西方奇幻 | 魔力/术式 |
| 灵力 | 通用泛东方奇幻 | 魔力（型月无独立灵力体系） |
| 元神/元婴 | 修仙概念 | 灵魂/魔术回路核心 |
| 天道/大道 | 修仙概念 | 根源（对应）或不用 |
| 仙人/飞升 | 修仙概念 | 魔法使（对应）或不用 |
| 爆种/开挂 | 网文化描述 | 魔力过载/灵基突破（需说明代价） |
| 领域 | 通用但型月有特定词 | 固有结界/结界/术式场 |
| 次元 | 不作技术概念使用时禁用 | 平行世界/世界线/空间 |

## 型月特有术语规范

| 术语 | 规范用法 |
|------|---------|
| 魔术 vs 魔法 | 可复现技术=魔术，不可复现奇迹=魔法。严格区分 |
| 魔力 vs 魔力(Od/Mana) | 需要区分时标注：小源(Od)/大源(Mana) |
| 英灵 vs 从者 | 英灵=本体(在英灵座)，从者=分身(被召唤的) |
| 宝具 | 需真名解放，描述时标注等级(E~EX)和类型 |
| 职阶 | 基础七职阶 + 额外职阶，必须大写 English: Saber/Archer... |
| 令咒 | 三划/御主/绝对命令权 |
| 魔术回路 | 灵魂器官，先天决定数量和质 |
| 魔术刻印 | 家族传承，移植产生排异 |
| 根源 | 大写或加粗，不用"天道"替代 |
| 抑止力 | 盖亚(地球) vs 阿赖耶(人类) |

## 禁止的叙事模式

- ❌ 唯心爆种: 没有魔力代价的突然变强
- ❌ 好感度绑架: NPC 因好感度无视底线
- ❌ 全知视角: 角色知道不可能知道的信息
- ❌ 跨世界串味: 用其他世界的术语/体系解释型月现象
