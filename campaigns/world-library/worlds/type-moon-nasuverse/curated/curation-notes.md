## agent_team 经验

1. **角色域阈值**: ~75-90条/agent 安全上限。~150+ 导致 context overflow
2. **mechanics 域**: 规则原文是角色条目的 2-3 倍，需 ~35条/agent
3. **原文嵌入**: agent 不应复制原文（上下文不够），应由脚本 post-process 完成
4. **分批写入**: "每10条 write" 策略有效，terminated 也能保留大量输出
5. **after 依赖**: merge 步骤用 after 不阻塞
