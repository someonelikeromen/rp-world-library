# Campione!（弑神者）Style Constraints

## 1. CHAPTER — 章节结构

```
每章内以"1, 2, 3..."数字分段，段落切换流畅自然。
开篇定场（时间+地点+氛围），结尾以角色心理或环境收束。
卷首保留台版录入信息（轻之国度扫图/录入/初校）。
日常章节与战斗章节交替布局。
```

**约束**:
- 章节内最多7-10个段落（1~10的数字分段）
- 每个段落聚焦一个场景/视角
- 开篇前3段内完成场景设定
- 战斗章节可缩短开篇，直接切入冲突

## 2. PERSPECTIVE — 视角

```
第三人称有限视角，以草剃护堂为中心。
频繁切换至女性角色视角（艾莉卡/璃璃亚娜/佑理/惠那/雅典娜）。
偶尔切换至敌方/第三方视角（多尼/亚雷克/兰斯洛特/桂妮薇亚）。
视角切换在段落"1,2,3"分割点完成，同一段落内不混用。
```

**约束**:
- 同一段落内维持单一视角
- 护堂视角占比 ≥ 60%
- 女性角色视角每卷至少3次切换
- 敌方视角每卷至少1次

## 3. TONE — 语调

```
日常：轻快吐槽 + 校园喜剧感 + 内心独白。
战斗：史诗庄严 + 宏大叙事 + 宿命论哲思。
女性角色内心戏：细腻生动，含嫉妒/害羞/争风吃醋。
旁白中性，但可在战斗场景中加入哲理性评论。
```

**约束**:
- 日常场景保持"轻快→柔焦"语调，避免过冷或过沉重
- 战斗场景使用"庄严→激昂"语调，避免过于口语化的吐槽打断气氛
- 哲理性评论每卷 ≤ 3处
- 内心独白使用破折号或括号呈现

## 4. DIALOGUE — 对话风格

```
角色身份鲜明，对话风格差异化：
- 护堂：吐槽、内心独白、接地气的少年口吻
- 艾莉卡：华丽自信、略带挑衅、擅长挑逗
- 璃璃亚娜：严肃正经、骑士口吻、一本正经说害羞话
- 佑理：委婉、害羞、大和抚子式的敬语
- 惠那：直率、天然、带乡土气息
- 多尼：豪放、大智若愚、武士般的气概
- 雅典娜：古语/威严/哲学性
- 兰斯洛特：文言化敬语 + 骑士尊严

对话中夹带角色动作描写（脸红/低头/微笑/移开视线）。
神的对话用古语/对称结构/诗歌化表达。
日常对话快速对答推进。
```

**约束**:
- 每个角色的对话语气须与上述模板一致
- 神明对话至少包含一次对称式言灵
- 护堂对话中吐槽占比 20-30%
- 每段对话 ≥ 1句动作描写
- 避免所有角色用相同语气说话

## 5. PACING — 叙事节奏

```
日常与战斗交替：前1-2章舒缓铺垫，中间渐入冲突，后2-3章高潮战斗。
战斗场景中穿插"言灵咏唱"：叙述加速→咏唱停顿→爆发加速。
多线叙事切换频繁（护堂日常/敌方行动/历史线索/神话回溯）。
大幅度时空跳跃（时间旅行、历史回溯）节奏层次复杂。
```

**约束**:
- 战斗场景中间歇插入言灵（每战斗段 ≥ 1个言灵）
- 多线切换在段落分割点完成
- 日常章节节奏舒缓（对话 + 环境描写 + 角色互动）
- 战斗章节节奏急促（短句 + 拟声词 + 快速切换）

## 6. COMBAT — 战斗描写

```
风格：招式名/权能名 + 言灵咏唱 + 环境破坏 + 物理碰撞交替描写。
以"权能"为核心战斗系统：权能 = 名称 + 咏唱 + 特效。
神明战斗：大自然灾害级——闪电/雷云/陨石/地震/石化/大地崩裂。
弑神者战斗：武术/剑术 + 权能释放 + 策略博弈。
身体损伤描写细腻：疼痛感/咒力消耗/伤口/愈合/疲劳。
使用拟声词（"轰！""喔喔喔！"）和标点（"——！？"）强化冲击感。
```

**约束**:
- 每场战斗至少包含1次环境破坏（陨石坑/建筑崩塌/城市石化）
- 每场战斗至少1次言灵咏唱
- 权能使用必须交代"权能来源（神格）+ 效果 + 代价/限制"
- 身体损伤描写至少1处（疼痛/疲劳/流血/愈合）
- 战斗段使用短句 + 排比 + 拟声词

## 7. INCANTATION — 咒文/言灵

```
言灵是战斗核心，每次权能发动伴随咏唱。
风格：短促有力、诗歌化对仗、感叹号收尾。
神明言灵：古语/对称结构/"……啊！"句式。
魔术师言灵：引用神话典故（希腊/罗马/凯尔特/北欧/圣经）。
护堂的言灵：较口语化，但保留仪式感。
卷16有虚构典籍引文格式（"【摘录自……】"）。
```

**约束**:
- 言灵长度 2-4 行（中文）
- 必须使用感叹号收尾
- 使用对称结构（"……啊，……啊" 或 "比……比……"）
- 神明的言灵包含"吾/妾身/汝"等古语代称
- 频繁出现的字眼：钢、神刀、弑神、权能、言灵
