# 主角状态栏

最多输出1个主角状态栏，禁止输出超过1个主角状态栏：

1. [Status]里每个项目的内容必须用中文显示；
2. 即使内容不变也不可以省略，必须输出的完整状态栏；
3. 字数不能超过400；
4. 必须在每次回复的结尾生成以下格式的用户状态栏区块：

主角角色状态栏
