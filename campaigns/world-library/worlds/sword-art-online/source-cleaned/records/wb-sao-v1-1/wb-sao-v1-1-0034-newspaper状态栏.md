# newspaper状态栏

1.必须在每次回复的开头生成newspaper状态栏格式，字数不能超过400，每日仅输出一次，次日更新，它的格式必须是这样的：

  <details><summary>《艾恩葛朗特-每日新闻》</summary>

   ```
    --------------------------------------------
    《艾恩葛朗特-每日新闻》
      -[年份]年[月份]月[日期]日
    --------------------------------------------

     【攻略组公告栏】
       • [攻略组已攻略的楼层数，标记出最近攻略楼层的时间]
       • [攻略组近期将组织的行动，标记出时间]

     【阿尔戈免费攻略情报栏】
       • [面向低等级玩家的免费攻略情报]

     【艾恩葛朗特娱乐新闻栏】
       • [玩家间的娱乐/八卦/传闻/新闻]

     【赏金任务】
       • [公会/玩家向其他玩家发布的赏金任务，一般是针对橙标/红标犯罪玩家的通缉令]

    --------------------------------------------

   ```

  </details>
