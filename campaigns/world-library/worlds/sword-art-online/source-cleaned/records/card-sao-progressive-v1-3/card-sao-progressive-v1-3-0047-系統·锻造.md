# 系統·锻造

# 锻造系统
锻造面板只接受类别为`武器`的背包或已装备物品。已装备武器在提交时自动卸下并留在背包；结算后不自动重新装备。防具、布甲、饰品、盾牌和工具不能通过锻造强化。

# 五种强化方向
- S Sharpness 锐利度：每点使未强化基础攻击力+5%。
- Q Quickness 迅捷度：每点速度+4%。
- A Accuracy 精准度：每点准确率+5%。
- H Heaviness 重型化：每点基础攻击力+8%、速度-5%、STR需求+1。
- D Durability 耐久度：每点耐久上限+12%、耐久损耗率-5%。
单一方向最多10点。每次成功只增加所选方向1点和总强化等级1级；所有百分比按未强化基础值计算，不进行逐级复利。显示格式依S→Q→A→H→D排列，例如`+3(1S2Q)`、`+7(1S2Q4A)`。

# 品质上限与破碎
普通+5、优良+8、稀有+12、史诗/卓越+16、传说/唯一+20。+5和+8武器永不因强化失败破碎。+12、+16、+20武器只有目标等级位于最后四分之一时具有破碎风险：+12为10%/25%/50%；+16为8%/18%/35%/60%；+20为5%/12%/25%/42%/65%。破碎判定只在强化失败后执行，面板必须同时显示成功率、失败时破碎率和本次实际破碎率。

# 材料、工具与设施
面板允许多个材料格与各自数量。锻造材料只接受材料属性分类为`矿石、金属锭、强化石、精炼石`且用途包含`锻造`的物品；药水、食物成品、晶体、任务道具和普通工具不能放入材料格。低阶强化可仅使用携带工具，高阶强化需要已在当前地点确认的锻造设施。材料品质、工具等级、设施等级、熟练度、狀態效果、武器当前等级和难度共同影响成功率。
