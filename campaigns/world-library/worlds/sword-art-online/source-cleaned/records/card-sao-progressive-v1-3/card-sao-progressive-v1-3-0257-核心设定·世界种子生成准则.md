# 机制·异常状态·燃燒

# 触发与输入
火焰攻击、燃烧地形、爆炸、道具或机关命中。异常不能凭旁白突然出现，必须有攻击命中、道具使用、环境暴露、机关或任务脚本。
`{操作:"添加|更新",角色ID:"player|character-*",狀態名稱:"燃燒",發生時機:"立即|本輪結束",狀態效果:{來源,效果,強度,開始時間:"",剩餘時間,解除條件,描述,圖示:"burn"}}`
语意为"最后、结束时、离开前、战斗末尾"时使用`本輪結束`；核心按实际发生时刻写入开始时间。

# 保存与强度
`狀態效果.燃燒 = {ID,名稱,來源,效果說明,強度,強度等級,開始時間,剩餘秒數,剩餘分鐘,有限持續時間,結算累積秒數,解除條件,描述,圖示,機器規則}`
持续时间输入单位为秒；正数必须显示倒数。1级／微弱；2级／一般；3级／强；4级／严重；5级／致命。来源强度必须与等级相称。

# 固定机器效果
效果：每5秒结算一次，单次HP变化为-(强度等级×2)。
机器规则：`{類型:"週期HP",間隔秒數:5,每次HP變化:-2×強度等級}`。LLM不能改动倍率、间隔或类型。
正文约束：正文必须表现持续灼烧与灭火需求；HP由核心随时间结算。
状态栏、正文判定与`SAO_BATTLE`必须读取`有效衍生屬性`；不得继续使用未修正的基础数值。

# 时间与解除
新状态建立当轮不倒扣此前经过时间。之后每次时间推进由核心结算周期HP、扣减剩余秒数并在归零时移除。解除：灭火、离开燃烧区并完成解除、对应道具或剩余秒数归零。
同名状态再次命中使用更新；强度最高5级，禁止无因无限叠加。
