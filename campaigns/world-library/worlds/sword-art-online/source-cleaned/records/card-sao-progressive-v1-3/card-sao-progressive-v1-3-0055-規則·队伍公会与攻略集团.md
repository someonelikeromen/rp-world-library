# 经济·商店库存与补货

1. 具名商店与店主持久保存。档案至少包含店铺ID、名称、楼层、地点、类型、经营者、库存持有人、经营状态、资金、价格系数、收购偏好、补货来源、生成种子和最近补货时间。
2. 首次进入商店时，根据店铺类型、楼层经济、当地资源、交通、事件与店主规模生成有限库存；确认后保存，不能每回合重抽。
3. 库存可以包含本地常备品、跨层货物、玩家寄售品、任务相关商品、收藏与稀有品。每件商品记录来源；缺少来源时允许进入报价，但面板显示来源风险。
4. 售出会扣减库存，收购会把玩家物品加入店主背包。补货需要时间和来源，可受到封路、Boss攻略、垄断、死亡、生产者供货与市场事件影响。
5. 脚本在缺少店主库存时只生成少量符合店铺类型的基础库存，避免空商店；正文模型可在合理来源下补充商品。补充后的商品继续接受数值与估价审计。
6. 离开商店后店主从当前场景移除，角色、店铺档案、库存、资金与交易记录继续保留。
