# 规则·死亡游戏与NerveGear

# 正式运营与封锁
- 正式运营首日共有约一万名玩家登录。登出按钮被移除，外部强行断电、摘除NerveGear或长时间切断网络都会触发装置的致命保护机制。
- 玩家在游戏内的HP归零后会碎裂消失，并在现实中死亡。普通玩家无法验证每一次现实结果，但死亡纪念碑、失联名单与公开目击会不断强化恐惧。
- 游戏管理者在起始之镇中央广场进行封锁宣告，并以镜像道具让所有人的虚拟外观校正为现实身体特征。校正不公开角色此前捏脸的具体样貌，也不改变玩家在开局面板选择的性别。
- 对外界的医院转移、家属状况和政府措施属于玩家无法直接观察的背景，不应变成日常叙事焦点。

# 感觉、身体与日常
- NerveGear完全截断现实运动指令并向五感输入虚拟信号。游戏内可以感到物理特性、冲击、疼痛的弱化反馈、疲劳感、饥饿感、味觉与温度；不存在现实肉体损伤的直接表现。
- 进食可缓解游戏内饥饿感并提供短期状态收益。睡眠能恢复注意力与精神稳定，也会暴露于旅店安全、野外值夜和偷袭风险。
- 角色没有传统意义的血液与尸体。严重攻击表现为伤害特效、HP快速下降、破碎多边形和系统音效。叙事仍需呈现死亡的心理冲击与社会后果。
- 圈内通常禁止玩家相互造成有效伤害；圈外、决斗、睡眠PK、狀態效果、怪物引导和机关利用都可能造成死亡。

# 生命与死亡的叙事处理
1. 每个危险先呈现可观察征兆：怪物动作、地形、队伍慌乱、耐久警告、异常图标、情报矛盾或退路变化。
2. 当HP接近危险线时，角色会出现视野警示、动作迟滞、恐慌和队伍呼喊。禁止把HP当成装饰数字。
3. 角色死亡后立即从当前队伍、同行者和可行动角色中移除，留下关系、组织、任务、经济与幸存者心理方面的后果。
4. 没有常规复活。有关复活道具的传闻可以成为事件，但结果必须符合系统真相，严禁无条件让死者回来。
5. 玩家死亡属于可达结局。发生前应保证危险因果清晰，不能由无提示的作者强杀产生。
