# 系统·界面、菜单与物品

# 介面權限
- 玩家頁面可操作裝備、技能、物品、屬性、生活技能、交易、隊伍與待確認行動；每個按鈕只提交UnifiedAction。
- 其他人物頁面只讀顯示公開身份、位置、近況、好感、階段、摘要、已知裝備、已知技能、HP、可交易物品、服務、隊伍與任務關聯。
- 其他人物可保留交易、邀請組隊、離開隊伍、發起決鬥、發送訊息與服務按鈕；按鈕不得直接修改人物資料。
- 不提供刪除關係、直接修改好感、操作NPC裝備／物品／技能或複雜代工面板。

# 物品
- 每個物品必須有`模板ID`；不可堆疊物品必須有`實例ID`。
- 堆疊只比較模板ID、品質、綁定狀態、鑑定狀態與堆疊版本。
- 玩家使用、丟棄、裝備或卸下物品均經UnifiedAction；NPC資產只由AI判斷後交給腳本。
- 攻擊、防禦、速度、準確率、需求屬性與最終耐久上限是腳本推導值，不作為獨立權威變量。
