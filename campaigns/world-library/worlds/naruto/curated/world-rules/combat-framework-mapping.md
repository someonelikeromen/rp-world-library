# 火影忍者战斗框架映射（初版）

> 来源：本地 Naruto worldbook 归档。此文件为 RP 多世界战斗框架的初步映射，需在后续精修中按 feats/剧情证据细化。

| 本地层级 | 描述 | 建议 N 级范围 |
|---|---|---|
| 普通人/学生 | 未系统掌握查克拉或忍者基础训练不足 | N0-N1 |
| 下忍/中忍 | 基础忍术、体术、任务战斗能力 | N1-N3 |
| 上忍/精英上忍 | 多属性忍术、战术和高阶体术 | N3-N5 |
| 影级/晓核心 | 大规模忍术、血继限界、尾兽级对抗 | N5-N8 |
| 尾兽/人柱力完全体 | 大范围破坏与超常恢复/查克拉量 | N7-N10 |
| 六道级/大筒木级 | 求道玉、轮回眼、神树/十尾级现象 | N10+ |

## 注意

- 具体角色评级必须在战斗发生或兑换/成就评估时重新按多世界战斗框架核定。
- 状态栏/变量/输出规则不参与战力定级。
