## Phase 1 — 角色全息档案

**目标**：为 Phase 0 发现的每一个角色建立全息档案。每角色1 agent。

### 输出格式

同 saijaku PLAN 的 Phase 1 格式（=====CHARACTER===== 分隔）。

**规则**：
- 每项有原文 sourceRef（vol-XX/ch-YY）
- 原文找不到填 NO_EVIDENCE
- 能力的战绩标注对手和章节
- 地错特有的升级/能力值/技能系统必须详细记录
- 角色版本跟随等级变化（Lv.1→Lv.2→Lv.3→Lv.4→Lv.5→Lv.6）

### 校验门禁

```

不通过 → 为缺失角色补跑 agent
```
