# 系统·队伍、公会与攻略集团

# 隊伍
- `/玩家/隊伍`是唯一隊伍資料，單隊最多六人。不存在玩家同行者或人物自己的隊伍副本。
- `/世界/當前場景角色ID`只表示在場人物，不代表隊伍成員。
- 邀請、加入、離隊、踢出、隊長和戰利品規則變更使用`隊伍`UnifiedAction。對方尚未明確接受時不得加入。
- 隊伍頁與人物頁只讀顯示隊友資料；UI按鈕只提交行動。

# 聯合部隊與公會
- Boss聯合部隊最多八支六人隊伍，需明確情報、職責、替補、消耗、撤退與掉落規則。
- 第三層公會系統解鎖前，只允許固定隊、攻略派系與鬆散團體。
- 組織以固定ID寫入`/世界/組織/<組織ID>`，保存形態、登記、權限、成立樓層、活動樓層、據點、成員與近況。
