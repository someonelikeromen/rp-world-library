# 运行·全局时代阶段与内容解锁

**条目类型：** 预处理（preprocessing），常量条目，始终启用
**注入位置：** 角色描述之后（after_char）
**分类：** factions / locations / events / systems / runtime-prompts / abilities / bosses / quests / mixed

---

## 内容

预处理条目，根据当前世界状态动态计算并输出 SAO 时代阶段与解锁能力。

### 计算逻辑

读取世界状态数据：
- 当前楼层与已解锁楼层列表，确定攻略前线
- 事件旗标（`/世界/事件`），提取首层 Boss 讨伐状态与第三层公会任务/公会登记解锁状态
- 统计各楼层档案中已确认地点数量
- 统计活跃组织数量（不含解散、覆灭、合并、消失的组织）

### 时代阶段判定

- 首层 Boss 未讨伐 → **开服混乱期**
- 公会登记未解锁 → **攻略协作形成期**
- 攻略前线 < 10 层 → **公会制度初成期**
- 攻略前线 < 25 层 → **中层拓展期**
- 攻略前线 < 50 层 → **组织重整期**
- 攻略前线 ≥ 50 层 → **高层攻略期**

### 输出时代能力对象

| 能力字段 | 判定条件 |
|----------|----------|
| 阶段名称 | 上述阶段判定结果 |
| 攻略前线 | 当前最高已解锁楼层 |
| 正式公会登记 | 第三层公会任务完成或公会登记旗标解锁 |
| 攻略集团公开活动 | 首层 Boss 已讨伐 |
| 跨聚落稳定市场 | 前线 ≥ 2 层且已确认地点 ≥ 4 |
| 广域情报网络 | 前线 ≥ 5 层且已确认地点 ≥ 10 |
| 高层内容公开 | 前线 ≥ 10 层 |
| 判定依据 | 已确认地点数与活动组织数 |

### 规则说明

- 正式公会登记只由第三层公会任务或明确开局旗标解锁。
- 原作组织、制度、市场、情报与任务密度必须满足各自门槛。
- 静态条目被注入不代表已成立、已发生、已被玩家得知或已接取。
- 所有成立事件写入 `/世界/事件`，组织写入 `/世界/组织`。
