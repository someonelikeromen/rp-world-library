# 任务·共用生成与运行规则

任务与世界事件分开保存。任务使用固定 ID 写入 `/任务/<任务ID>`；类型限系统任务、支线任务、讨伐任务、护送任务、调查任务、技能任务、生产任务、战争任务、交付任务、私人请求、私人约定、承诺与组织事项。

系统任务、支线任务、讨伐、护送、调查、技能、生产、战争与交付任务的发起者必须是已建立于 `/角色/<固定角色ID>` 且 `类型:NPC` 的人物。原作玩家、原创玩家、传闻、系统旁白与主角不能发出系统委托；他们只能提出私人请求、约定、承诺或组织事项。

任务必须有发起者 ID、参与者 ID、状态、楼层、地点、阶段、描述、目标、线索、条件、关键物品、失败条件、奖励预览、分支、结果与时间。人物内只保存关联任务 ID。叙事栏位可直接更新；经验、Col 与物品奖励只由 `任务奖励` UnifiedAction 结算。
