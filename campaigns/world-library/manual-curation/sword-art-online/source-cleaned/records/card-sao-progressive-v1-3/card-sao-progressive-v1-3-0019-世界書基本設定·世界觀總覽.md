# 物品生成准则

# 固定身份
每個物品必須有`模板ID、模板版本、物品ID、顯示名稱、類別、子類、品質、堆疊版本、可堆疊、數量、綁定狀態、鑑定狀態、可交易、可掉落、基礎資料、耐久、強化、來源`。
可堆疊物品的實例ID為null；裝備、唯一物品、未鑑定物品或有獨立耐久者使用固定實例ID且不可堆疊。

# 堆疊規則
同一堆疊只比較模板ID、品質、綁定狀態、鑑定狀態與堆疊版本。描述、來源、取得時間、自由文字說明與交易對象不參與。

# 入庫
掉落、交易、任務獎勵、製作與服務產出只能建立`物品取得`、`交易`、`任務獎勵`、`生活技能`或`NPC服務`UnifiedAction。禁止直接修改背包。
