# 精灵战争连续任务

**范围**：第三层起随楼层与历史推进的NPC连续委托，不按原作日期自动发生。

## 启动条件
- 玩家在当前楼层实际接触精灵冲突、可靠入口或相关具名NPC。
- 绮兹梅尔、精灵军官、领主或其他具名NPC提出当前阶段目标，玩家明确接取。
- 阵营、秘钥、NPC存亡和先前选择仍允许该路线继续。

## 分层阶段
1. 第三层：阵营接触与翡翠秘钥。
2. 第四层：约费尔城与琉璃秘钥。
3. 第五层：琥珀秘钥及遗迹冲突。
4. 第六层：玛瑙秘钥与争夺。
5. 第七层：红玉秘钥、哈林树宫及可能失窃。
6. 第八层以后：王都政治、后续秘钥与玩家已改写的结果。

## 约束
- 每层只建立当前NPC实际发布且玩家接取的任务，写入`/任務/<ID>`；公共战争局势另写世界事件并关联ID。
- 玩家可选任一阵营、保持中立、建立第三方合作、背叛、失败或放弃。NPC与秘钥状态改变时必须重写后续路线。
- 不得预先生成未来楼层任务、强制绮兹梅尔存活或照表播放原作结果。
