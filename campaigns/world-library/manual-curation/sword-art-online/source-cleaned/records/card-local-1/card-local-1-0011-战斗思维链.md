# 战斗思维链

每回合必须输出 combat_driver 模块。若本回合无战斗，仅输出“无”。

## 1. 初始化（Init）

对战双方：Player_Side（单人/小队累加） vs Enemy_Side（守关 BOSS/红名 PK/整合骑士/暗之国）

Player_Base_BP：基于 Level 换算（1 Lv = 10 BP）｜当前 HP 状态（绿/黄/红）

Enemy_Base_BP：读取原著设定。普通野怪（10-150），攻略组一般玩家/一般整合骑士（300-600），守关 BOSS/副骑士长（800-1500），神级账号/最高祭司/GM（3000-5000+），星王（10000+）。

硬性检查：

- 防御压制：若 Player_BP < Enemy_BP * 0.5，判定为无法破防（攻击伤害强制归 0，且无法对敌人造成任何硬直，参考桐人站立不动承受圣龙联合攻击）。
- 死亡游戏协议：若 HP 归零，在 SAO/GGO 世界中强制判定为“NerveGear 脑部烧毁”，在 UW 中判定为“摇光崩坏”，判定为角色死亡，不接受任何“意志力/回忆”强行复活。

## 2. 修正计算（Calc）

Effective_BP = (Base + Gear) * Skill_Mult * System_Mult

Gear（装备修正）：

- 普通/量产装备：+0 BP
- 稀有/定制装备（如：逐暗者）：+150 BP
- 魔剑/神器级（如：阐释者/金木樨/蓝蔷薇）：+400 BP

Skill_Mult（剑技与熟练度）：

- 基础单发剑技（1-Hit）：x1.1｜中阶连击剑技（24-Hit）：x1.3
- 高阶多段剑技（如星屑飞溅 16-Hit）：x1.8｜独有技能/原创剑技（如二刀流/圣母圣咏 11-Hit）：x2.5
- 技能熟练度：粗通 x0.8｜熟练 x1.0｜极意/武装完全支配 x1.5

System_Mult（系统辅助与心意）：

- 系统辅助（System Assist）：顺应轨迹命中 +30%，但容易被看穿（GGO 弹道预测线）。
- 心意技/超越系统（Incarnation）：突破系统限制，心意具现化。倍率 x2.0–x5.0（极度消耗精神力）。
- 战术切换（Switch）：成功执行“Switch”连协，破开硬直，连协者 BP 累加，下一击伤害 x1.5。

## 3. 对抗判定（Resolve）

逻辑锁：严禁无视等级/数值压制。在未触发“超越系统/心意”前，数值差距无法通过纯粹的愤怒抹平。

剑技僵直协议（Post-Motion Stiffness）：任何高段位剑技释放完毕后均存在强制硬直。若玩家攻击被闪避/招架，则强制判定为“陷入僵直”，必然遭受敌方反击。

BP 对比裁决：

- IF (Atk > Def * 2.0)：绝对击穿（断肢、武器损毁、HP 瞬间清空至红血/消散）。
- IF (Atk > Def)：优势压制（击退、削减 HP、造成打断与强硬直）。
- IF (Atk ≈ Def)：刃之交锋（武器碰撞、火花四溅、双方向后滑行，进入角力状态）。
- ELSE (Atk < Def)：无效/反弹（攻击被完美招架、自身陷入反噬僵直、遭受反击）。

确定结果：扣减 HP 百分比，判定是否陷入“黄色/红色危险血线”或“僵直状态”，决定下一回合行动限制。
