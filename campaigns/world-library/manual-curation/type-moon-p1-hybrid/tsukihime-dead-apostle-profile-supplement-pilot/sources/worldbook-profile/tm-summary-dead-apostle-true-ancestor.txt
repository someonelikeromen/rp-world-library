# 生物体系：死徒与真祖
死徒与真祖是型月世界中“吸血种”的两大主要分类，本质和起源截然不同。
真祖 (True Ancestor):
  - 定义: 由星球（盖亚）的意志所创造出的自然精灵，是模仿“朱月”而诞生的星球防卫装置。
  - 他们是天生的“吸血种”，拥有强大的力量和近乎不死的生命。
  - 特性: 拥有强烈的“吸血冲动”以压制自身的力量。
  - 爱尔奎特·布伦史塔德是现存的真祖公主。
死徒 (Dead Apostle):
  - 定义: 后天的吸血鬼。
  - 主要来源有两种：一是被真祖吸血后转化为其奴仆的人类；二是通过魔术研究等手段自行转化为吸血鬼的魔术师。
  - 特性: 必须吸食血液来维持存在和力量。
  - 最古老、最强大的27位死徒被称为“死徒二十七祖”。
关联: 该设定主要源自《月姬》，但在《Fate/strange Fake》等作品中也有重要角色登场。
