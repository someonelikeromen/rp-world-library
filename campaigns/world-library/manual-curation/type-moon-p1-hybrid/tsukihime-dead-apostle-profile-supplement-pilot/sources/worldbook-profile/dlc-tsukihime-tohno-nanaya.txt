# 四大退魔家族 / 七夜 / 远野 context
退魔组织由巫净、两仪、浅神、七夜四个以退魔为使命的家族组成，所有家族都拥有超能力。
退魔组织的主要对手是鬼种的混血后裔，其中部分包括远野家族。
七夜家族以暗杀术著称，血脉传承退魔冲动，因遭远野一族灭族而消亡。
远野家族是一个拥有浓厚恶魔血统的混血。
远野家族成员体内承袭着类似吸血鬼的魔族血液，导致世代存在寿命短暂与非正常死亡现象。
远野家的祖先是当地的地主，同时也是恶魔混血。
远野家族成员的血液中混杂着鬼种的血液，潜在力量和能力远超常人。
当这种血液变得太强时，远野家的成员开始逐渐失去理智，其中一些人的外貌会发生变化。
大多数失去理智的远野家成员会变成以人肉为食的恶魔，因此远野家主的责任就是惩罚这些偏离者。

# 七夜黄理 profile signals
七夜黄理是远野志贵的生父，七夜家族的末代家主。
七夜黄理是一个杀手，以暗杀为业，是这一族中最强大的人。
直到该家族在远野槙久的策划下被毁灭，他本人也死于轧间红摩之手。
七夜黄理拥有“净眼”，能看到人的内侧，无需交谈便能知晓对方的想法。

# 同人版远野志贵 profile signals
同人版远野志贵: 月姬的男主角，因为以前的事件而拥有可以看到“死”并可杀死万物的“直死之魔眼”。
为避免带给脑部过大的负担，平常戴着魔眼杀的眼镜来抑止。
真实身份是退魔者七夜一族的末裔；七夜家被远野家灭族后被远野槙久发现。
因与远野家长子四季名字同音而被收养并用催眠窜改记忆，当成自己的儿子收养。
原名七夜志贵，退魔家族“七夜”的唯一幸存者，随身带着的短刀“七夜”正是其祖传物品。
外貌: 远野志贵被描绘为一个体格健壮的年轻人。
外貌: 他有一头不羁的黑发，部分遮住额头，几缕发丝垂在眼镜边缘，眼镜有简单矩形框架。
外貌: 他穿着传统日本校服，由扣整齐、立领的深蓝色学兰上衣和颜色相配的裤子组成。
月姬前: 七夜一族作为拥有超能力的退魔家族，曾受远野槙久邀请剿灭斋木家。
月姬前: 七夜黄理展现出的非人战力令槙久感到威胁，槙久随后联合分家将七夜一族灭门。
月姬前: 八年前，受远野家血统特有的“反转冲动”影响，四季发狂变成怪物袭击秋叶。
月姬前: 志贵挺身而出，以自己的生命为代价替秋叶挡下致命一击，胸口因此留下巨大伤疤，并陷入濒死。
月姬前: 志贵苏醒后遗忘反转冲动真相，但因濒死体验觉醒了“直死之魔眼”。
月姬初期: 志贵因贫血早退时偶遇金发白衣女性，体内退魔之血觉醒导致杀人冲动失控。
月姬初期: 他尾随该女子至公寓，利用直死之魔眼与短刀将其分割成17块。

# 同人版七夜志贵 profile signals
同人版七夜志贵: 七夜志贵是远野志贵改姓远野前的本名。
在月姬各作中可以指幼年的志贵、七夜退魔之血躁动下的志贵、志贵想象中自己杀人鬼的一面，或杀人鬼被TATARI具现化后的相对独立个体。
以“七夜”自居的另一个志贵。有杀人癖（恶鬼治退）。
原始版中，它是由于志贵对自己反转冲动的畏惧和不安被瓦拉齐亚之夜映照出来，而作为TATARI登场。
从发言中推测七夜也能使用“直死之魔眼”，但原作者后来提及他并没有直死之魔眼。

# 重制版远野志贵 profile signals
重制版远野志贵: 姓名包括远野志贵与七夜志贵(真名)。
重制版远野志贵种族标为人类(退魔者)、灵能者，以及希耶尔线 Extra End 限定的半吸血鬼(死徒)。
重制版远野志贵年龄17，身高173cm，体重57kg，生日1997年10月15日，血型AB型，出生地区七夜家。
重制版活动范围为总耶市，所属团体包括远野家，圣堂教会仅限重制版夜之虹结局。
重制版介绍: 居住在总耶的远野家的成员，月姬男主角，因为以前事件拥有可看到“死”并杀死万物的直死之魔眼。
重制版介绍: 平常戴着魔眼杀眼镜来抑止，以避免脑部过大负担。
重制版介绍: 真实身份是退魔者七夜一族末裔，七夜家被远野家灭族后被远野槙久发现。
