# 三咲町 / location source signals
三咲町是位于日本东京郊区的一个城镇。
这里是《月姬》、《歌月十夜》、《月姬格斗 (Melty Blood)》系列以及《魔法使之夜》故事发生的地方，该城镇也出现在《空之境界》中。
在《月姬 -A piece of blue glass moon- (重制版)》系列中，三咲町被总耶所取代。
该镇位于群山环绕之中，旧称为三咲市三咲町。
从江户时代起，这里作为宿场町（驿站城镇）而繁荣，并在1980年代迅速推进现代化。
数百年来，该镇一直处于苍崎家族的控制之下。
这片土地虽然远离魔术协会的势力范围，但作为最后仅存的魔法基盘，也成为其他魔术师觊觎的目标。
远野家本邸位于坡道顶端的西式豪宅，占地面积巨大，本馆后方连接和风别馆与广阔杂木林。
远野家地下王国是远野家族的秘密之一，拥有地下室、地牢与研究实验室等可疑区域。
住宅区是通往学校的必经之路；希耶尔的公寓位于此区域。
学校是志贵称为私立二流升学学校的本地高中，实际是一所正规升学名校。
公园面向办公区，广场日间喧闹，夜间却空无一人；志贵偏爱此处长椅。
爱尔奎特的公寓是爱尔奎特用魔眼洗脑管理员后租下的公寓。
希耶尔的公寓位于住宅区，壁橱内堆满从工厂直接拿货的速食咖喱。
梅西安是三咲町的一家咖喱店，是希耶尔最喜欢的店。
三咲市立高中是《月姬》故事发生的当地高中，已知学生包括乾有彦、希耶尔、山濑舞子、有间都古、弓冢五月、远野志贵。
私立浅上女子学园是秋叶就读的全寄宿制贵族女子学校。
祭祀摩天楼是《月姬格斗 (Melty Blood)》事件开始的地方，远野志贵在这里结识紫苑·艾尔特纳姆·阿特拉西亚。
后巷是奇异空间，常发生杀人事件却未被封锁；弓冢五月和紫苑被迫生活在后巷中，组成“后巷同盟”。
