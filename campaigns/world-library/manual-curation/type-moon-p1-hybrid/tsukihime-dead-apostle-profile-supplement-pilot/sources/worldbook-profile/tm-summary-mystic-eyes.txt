# 特殊异能：魔眼
魔眼是寄宿在眼中，能够干涉外界或他人的超能力，是一种天生或后天变异的异能。
定义: 通过“视线”来启动效果，将魔术的咏唱和启动过程极大地简化。
等级: 根据其能力和稀有度，分为普通、宝石、黄金、虹、以及论外的神级。
等级越高的魔眼，能力越接近“法则”层面的干涉。
种类: 能力千差万别，常见的有“魅惑之魔眼”、“束缚之魔眼”，以及神级的“石化之魔眼”等。
