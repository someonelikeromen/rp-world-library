# 关键组织：圣堂教会
圣堂教会是型月世界中管理“神之理”的庞大组织，与魔术协会彼此监视、时有冲突。
宗旨: 传播主的福音，但其背后带有“狩猎异端”的职责。
一切不符合其教义的神秘（如魔术、吸血鬼）都在其“狩猎”范围内。
武力集团:
  - 第八秘迹会: 负责回收与管理圣遗物的部门。
  - 埋葬机关: 负责讨伐最危险异端的王牌部队。
代行者 (Executor): 被派遣到各地执行任务、清除异端的神职人员。
圣杯战争中的角色: 通常以“监督者”的身份介入，维持战争的基本规则，代表人物是言峰父子。

# 武器分类：概念武装
概念武装并非依靠物理破坏力，而是通过将某种“概念”或“法则”强加给对手来造成伤害的特殊武器。
原理: 攻击的不是肉体，而是对象的“存在”或“属性”。
将某种定义具现为武器形态，例如一把“必然能切开不死之身”的剑，在面对不死属性的敌人时，可以无视对方防御，直接将“切开”这一概念施加于其上。
案例: 圣堂教会的“黑键”、美杜莎的“石化魔眼”、库·丘林的“Gae Bolg（穿刺死棘之枪）”的因果逆转效果。
