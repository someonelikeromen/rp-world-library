# 特殊异能：直死之魔眼
直死之魔眼是所有魔眼中最稀有、最顶级的异能之一，能让持有者“看到万物的死”。
定义: 并非“杀害”能力，而是“理解并连接死亡”这一概念本身的能力，与“根源”直接相关。
视觉表现:
  - 死之线: 在持有者眼中，万物上遍布的黑色裂纹。
  - 用利器沿线切割，可以无视对象的物理强度和防御，直接将其“杀死”。
  - 死之点: 物体“存在”的起点与终点。
  - 用利器刺中，会直接抹消该物体的“存在”本身，是更高阶的应用。
持有者: 获得此魔眼需要经历特殊的濒死体验，极其稀有。
已知的持有者仅有《空之境界》的两仪式与《月姬》的远野志贵。
