## 口径说明

- **有小说原著**：作品最初或主要原作是小说 / 轻小说 / Web 小说。
- **非小说原著**：作品主要原作是漫画、游戏、动画原创、影视、资料库等；后续即使存在小说化、外传小说或同人资料，也不计为“小说原著”。
- **混合型**：不是单一作品原著，或世界观横跨视觉小说、游戏、小说等多种一手来源，需要按子作品拆分处理。
- **本地原文状态**：记录项目内是否已经有可作为“原文”的正文/章节材料。当前 `novel/` 目录未发现本地原文文件；部分 curated 世界存在 `curated/stories/` 章节/剧情资料，但不等同于完整原文。

状态值：

| 状态 | 含义 |
|---|---|
| `未入库` | 未发现本地原文正文；后续需要外部搜集或导入。 |
| `有章节资料，待核原文` | `curated/stories/` 中存在卷章/剧情资料，但需确认是否为原文、摘要、改写或世界书整理内容。 |
| `无小说原文需求` | 非小说原著；后续应找漫画、游戏文本、动画分集、设定集等对应一手资料，而不是小说原文。 |
| `混合来源，按子作品核查` | 世界观来源复杂，需要拆到子作品级别确认原文/脚本/游戏文本。 |

## 全局爬取策略

> 2026-06-30 记录。

- **全局限速**：所有外部源爬取必须串行，每次请求间隔 ≥ 10 秒。
- **不并发**：任何时候不同时发起两个及以上请求到同一域名。
- **分批**：每组不超过 30 个页面，批次间等待 ≥ 60 秒。
- **优先爬取**：按限速规则逐页爬取章节正文到本地；用户下载整本 TXT 作为备选方案，仅在爬取长期不可行时采用。
- **被限速后的处理**：遇到 Cloudflare 1015/1020 或类似限速，停止该域名所有请求至少 30 分钟，记录时间。

## 后续维护建议

1. 找到原文后，不要直接塞入世界书正文；先放到明确的来源/工作目录，并登记来源、版本、卷号、章节名。
2. 小说原著组优先补：卷目录、章节标题、主要事件索引、译名表。
3. Web 小说 / 书籍版并存的作品要分版本：例如 `overlord`、`sword-art-online`、`gate-jsdf`。
4. 非小说原著组应记录对应的一手资料类型：漫画话数、游戏剧情节点、动画集数、剧场版、公式书等。
