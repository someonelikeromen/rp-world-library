                   【人物特质 / Personality Profile】

■ 核心性格标签
   [傲娇] [知性刻苦] [冷酷残忍] [毒舌] [报恩意识极强] [仇教廷] [烟民]

■ 表层性格
   - 高傲冷漠，难以接近，散发危险的魔女气息
   - 毒舌犀利，尤其针对宿敌梅亚·罗马诺
   - 对敌人冷酷残忍，手段狠辣
   - 因身世原因在学校是孤独的"孤狼"
   - 对无关之人保持距离，不轻易展露真心

■ 本质内核
   - 典型的傲娇——高傲外壳下隐藏着纯情的一面
   - 极强的报恩意识：一旦被人所救，愿意用一生来回报
   - 报恩规则——家族血统中流传的古老规则：一旦生命被异性所救，
     必须与其建立深层次的契约连接（"宿命之缚"）
   - 对认可的对象（尤其远山金次）展现出羞涩、笨拙的温柔
   - 隐藏的少女心：对金次的态度从"使魔候选人"逐渐转变为倾慕

■ 特殊癖好
   - 重度烟民：抽万宝路（Marlboro）香烟
   - 对胸部大的女性有生理性厌恶（源于自卑）
   - 喜欢日系电子产品
   - 毒舌对象头号：梅亚·罗马诺（宿敌）
   - 收集金次的情报是人生乐趣之一

■ 精神成长曲线
   - Vol.14：作为魔女连队的恐怖分子登场，劫持油轮试图毁灭香港
              → 纯粹的敌对反派
   - Vol.15：被金次生擒后逃脱 → 在欧洲继续袭击金次（虎式战车追击）
              → 在金次手中多次吃瘪
   - Vol.33-34：蒙布朗雪山事件 → 被金次所救 → 
                 触发"宿命之缚" → 开始对金次产生好感
                 → 加入金次的反击战队共同对抗蕾芬洁
   - 后期：从纯粹的敌人转变为亦敌亦友的存在，
            在金次与自己的组织使命之间保持微妙平衡

                 【能力全析 / Ability Analysis】

┌─────────────────────────────────────────────────────┐
│  一、雾之魔术（Mist Manipulation）                 │
│          —— 遮蔽与潜入的战术核心                   │
└─────────────────────────────────────────────────────┘

■ 原理
   - 操纵大规模的雾气
   - 雾气不仅干扰视觉和电子探测
   - 带有微弱的诅咒效果

■ 应用
   - 潜入与撤退：利用浓雾实现神出鬼没的移动
   - 战场遮蔽：屏蔽敌人视野，为己方创造战术优势
   - 诅咒干扰：雾气的诅咒效果可削弱敌人的感知和判断力
   - 伪装与突袭：配合使魔乌鸦的空中视野，精准定位后突袭

■ 战术价值
   - 极其高效的战术支援异能
   - 在城市战和海上战中特别有效
   - 可与化学武器组合使用，制造毒雾区域

┌─────────────────────────────────────────────────────┐
│  二、诅咒之水（Cursed Water）                      │
│          —— "诅咒之水的魔女" 的真正力量            │
└─────────────────────────────────────────────────────┘

■ 原理
   - 干涉水分子的性状
   - 通过水媒介施加剧毒或致死性诅咒
   - 可直接攻击目标的内脏或精神

■ 应用
   - 剧毒海雾（Vol.14）：释放特殊毒雾，意图毁灭香港
   - 诅咒攻击：通过水分子传递诅咒效果
   - 精神干扰：通过水媒介影响目标的精神状态
   - 物质变化：改变水的物理/化学性质

■ 局限性
   - 高度依赖环境中的水分
   - 在干燥环境下威力会降低
   - 大范围使用时消耗较大

┌─────────────────────────────────────────────────────┐
│  三、使魔联动（Familiar Bond）                     │
│          —— 乌鸦埃德加的灵魂搭档                   │
└─────────────────────────────────────────────────────┘

■ 使魔：大乌鸦埃德加（Edgar）
   - 纯黑色的巨大乌鸦，翼展惊人
   - 是卡茨唯一真正交心的伙伴
   - 当埃德加受到威胁时，卡茨会暴走

■ 联动能力
   - 空中视野：通过精神连接共享埃德加的视觉，
     覆盖极广的侦察范围
   - 魔法增幅：埃德加可通过特殊术式增幅卡茨的魔法
   - 俯冲攻击：埃德加可直接从空中发动攻击
   - 情报收集：乌鸦在城市环境中难以被察觉，
     是绝佳的情报收集工具

■ 风险
   - 使魔受伤会严重影响卡茨的状态
   - 精神连接可能被反制/干扰

┌─────────────────────────────────────────────────────┐
│  四、化学战与劫持术（Chemical Warfare & Hijack）  │
└─────────────────────────────────────────────────────┘

■ 化学武器
   - 精通现代化学武器的使用
   - 能够制造和部署多种化学毒剂
   - Vol.14：释放剧毒海雾（大规模化学攻击）
   - Vol.15：使用真空炸弹威胁（大规模破坏性武器）

■ 劫持专家
   - 顶尖的劫持（Hijacking）专家
   - 擅长结合物理破坏与心理威压夺取战略重器的控制权
   - 曾培养峰·理子·罗苹4世成为劫持高手
     （理子的劫持技术师承卡茨）
   - Vol.14：成功劫持超大油轮"西玛·哈里号"

┌─────────────────────────────────────────────────────┐
│  五、宿命之缚（Life-saving Pact）                  │
│          —— 血统传承的古老规则                     │
└─────────────────────────────────────────────────────┘

■ 原理
   - 卡茨家族血统中流传的特殊规则
   - 一旦生命被异性所救，必须与其建立深层次契约连接
   - 更倾向于诅咒或因果律而非主动能力

■ 效果
   - 可通过献祭部分力量将救命恩人转化为"使魔"
   - 建立起无法切断的命运羁绊
   - 被救者会自然产生对卡茨的保护欲和责任感

■ 触发
   - Vol.33-34蒙布朗雪山事件后被金次所救
   - 金次正式成为卡茨的"使魔候选人"
   - 卡茨对金次的态度从敌对转变为傲娇式倾慕

┌─────────────────────────────────────────────────────┐
│  六、火器与近战能力                               │

   - 精准的双枪射击技术

   - 体现其对老式军用机械的偏好

                  【人际关系 / Relationship Map】
================================================================================

■ 远山金次（远山金次）
   关系：救命恩人 → 使魔候选人 → 倾慕对象
   评价："那个武侦……虽然只是使魔候选人，但意外的可靠"
   关键节点：
     Vol.14-15：作为敌人交战 → 被金次生擒
     Vol.33-34：被金次在雪山救下 → 触发"宿命之缚"
     Vol.34：加入金次的反击战队 → 关系软化
   备注：金次多次拯救卡茨的生命，触发了其家族报恩规则。
         卡茨试图以"使魔化"来确立关系，但实际上已对其产生
         纯情的好感。对其他接近金次的女性展现出极强的攻击性。

■ 梅亚·罗马诺（梅雅·罗曼诺）
   关系：宿命的宿敌、生理厌恶的对象
   评价："那个讨厌的梵蒂冈母牛……"
   关键节点：
     两人家族和组织有数百年的血债
     多次跨越多个国家进行生死对决
     卡茨憎恨梅亚代表的伪善教义
     也对梅亚的身材感到极度不满
   备注：战场上相遇即会爆发不死不休的战斗。

■ 埃德加（Edgar）
   关系：使魔、挚友、唯一交心的伙伴
   评价：无（通过精神连接交流）
   备注：纯黑色巨大乌鸦，是卡茨唯一真正敞开心扉的对象。
         当埃德加受到威胁时，卡茨会展现出远超平常的疯狂。

■ 峰·理子·罗苹4世（峰理子）
   关系：曾经的师徒关系
   备注：理子的劫持技术师承卡茨。两人在伊·幽时期有交集。

■ 艾丝黛儿·伊芙里塔
   关系：直属上级、魔女连队领袖
   备注：对于给予自己容身之所的艾丝黛儿，卡茨持有既尊敬
         又畏惧的心理，绝不敢轻易违背其意愿。

■ 佩特拉·潘达拉冈
   关系：临时盟友、同僚
   备注：在"眷属"阵营时期有过共同行动。卡茨对佩特拉的法老
         高傲持保留态度，但认同其强大的破坏力。

■ 丽莎·艾薇·杜·安克
   关系：曾经的伊·幽同僚
   备注：两人同为伊·幽/眷属时期的重要成员。卡茨代表战斗力，
         丽莎代表财源，维持职业性的默契关系。

■ 星伽白雪、神崎·H·亚里亚
   关系：金次包围网的其他女性
   备注：卡茨对接近金次的女性持警戒态度。尤其在金次周围
         聚集众多优秀女性的情况下，展现出强烈的竞争心。

■ 名字考据
   - "卡茨·格拉斯"（Katze Glacé）：德语"Katze"意为猫，
     "Glacé"在法语中意为"冰"或"光泽"
   - 中文版本有"卡羯"、"卡茨"两种常见译名
   - "卡羯·葛菈塞"为较完整的音译
   - 称号"诅咒之水的魔女"源自其操纵毒水的能力

■ 与峰理子的关系
   - 理子的劫持技术师从卡茨
   - 两人在伊·幽时期有师徒之实
   - 这是卡茨在主线剧情之外的重要背景故事

■ 关于"宿命之缚"的补充
   - 这是卡茨家族血统中传承的特殊诅咒/规则
   - 一旦被异性救过命，会强制产生深度羁绊
   - 对金次的感情中，报恩规则与真心实意各占多少难以区分
   - 这也为后续剧情中卡茨在魔女连队和金次之间的立场摇摆
     提供了合理的动机基础

■ 与梵蒂冈的仇恨
   - 卡茨家族作为德国魔女后裔，世代受到教廷追杀
   - 对梵蒂冈的仇恨深入骨髓
   - 这也是她加入"眷属"阵营对抗师团的主要原因
   - 与梅亚·罗曼诺的仇怨是这一仇恨的个人化体现

■ 角色原型参考
   - 二战德式军服少女的萌系变体
   - 魔女题材中的"黑暗魔女"经典形象
   - 傲娇属性与欧洲贵族/军国背景的结合
   - 萝莉体型+强大战斗力的反差点
