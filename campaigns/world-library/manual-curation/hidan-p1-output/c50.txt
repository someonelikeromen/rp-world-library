================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 冷静干练：作为GⅢ团队的破坏工作/斥候担当，展现出专业的战术素养
   - 沉默寡言：不算健谈，但关键发言一针见血
   - 忠诚可靠：对GⅢ的命令无条件执行，是团队中值得信赖的代理领队
   - 日常中的普通女孩：与九九藻一起上学放学、玩UNO、制作cos服时
     展现出与年龄相符的少女一面

■ 本质内核
   - 战术天才：作为第一世代人工天才，被设计为"战术特化型"——
     与GⅢ（战斗特化）和金天（智力特化）形成能力互补
   - 从敌人到伙伴：最初以敌人身份登场并击溃巴斯克维尔小队，
     在玉藻的"色诱策略"下被拉拢，最终完全融入师团阵营
   - 隐藏的温柔：虽以冷酷的战术家形象示人，但对同伴（尤其金天）
     展现出深沉的关爱和保护欲
   - 坚定的归属感：作为人工制造的生命，找到GⅢ团队和远山家的归属后，
     展现出极强的忠诚和团队意识

■ 作为"人工天才"的自我认知
   - 金女是美军利用远山金叉DNA制造的第一世代人工天才之一
   - 与GⅢ同为第一世代产物（GⅢ战斗特化，金女战术特化）
   - 明知自己是被制造的存在，但并不为此困扰——
     与金天（GⅤ）对自我身份的不安相比，金女更早地接受了自身定位
   - 将GⅢ团队和远山家视为真正的"归宿"，用行动而非言语表达归属感

■ 精神成长曲线
   - Vol.10以前：作为敌对势力成员活动（与巴斯克维尔小队为敌）
   - Vol.10：击溃巴斯克维尔小队 → 被"罗密欧任务"拉拢
   - Vol.11：与白雪+贞德在木工包围战激战 → 和解 → 正式加入师团
   - Vol.11-：作为GⅢ团队核心成员持续活跃 → 建立与远山家兄弟姐妹的羁绊
   - Vol.27：在拯救金天的行动中发挥关键作用（使用佩特拉之钥）
   - Vol.40：参与埃及远征，使用"姐对"爆发模式对战拉斯普丁纳

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、核心能力——战术特化 (Tactical Specialization) │
│          —— 第一世代人工天才的设计方向           │
└─────────────────────────────────────────────────────┘

■ 设计定位
   - 美国军方"第一世代人工天才"计划的战术特化型产物
   - 与GⅢ（纯战斗特化）不同，金女被设计为战场指挥官/战术分析者
   - 能够快速解析战场局势，制定最优战术方案
   - 在GⅢ团队中担任代理领队（GⅢ不在时指挥团队行动）

■ 战术能力表现
   [1] 战场分析
       快速评估敌我战力对比和地形优势
       在混战中保持清晰的战术思维

   [2] 团队指挥
       代理领队职责：GⅢ不在时统率团队行事
       能高效调度队友的特殊能力进行协同作战

   [3] 破坏工作
       擅长潜入、破坏、干扰等战术行动
       在GⅢ团队中专门负责"破坏工作"领域

■ 战斗力评估（金次评价）
   - 战斗力约为九九藻级别（B+〜A-等级）
   - 虽不及GⅢ的顶级战力，但配合战术头脑可匹敌更高等级的对手
   - 曾单枪匹马击溃巴斯克维尔小队全员（Vol.10）

┌─────────────────────────────────────────────────────┐
│  二、"姐对"爆发模式 (Sister HSS / 姐对爆发)     │
│          —— GⅣ特有的HSS变体                    │
└─────────────────────────────────────────────────────┘

■ 概述
   - 金女特有的HSS（Hysteria Savant Syndrome）爆发模式
   - 与金次的"标准爆发"、GⅢ的"王者爆发"不同的变体
   - 以"姐妹"（Sister）为概念核心的战斗状态——保护家族/团队的力量
   - 名称中的"姐对"暗示了她作为远山家四姐的角色定位

■ 效果
   - 身体能力全方位提升（类似标准爆发）
   - 战术思维进一步加速，达到近乎预知级的判断力
   - 在Vol.40埃及苏伊士炮台战中使用此模式配合光影刀对战拉斯普丁纳

■ 与金次的HSS对比
   - 金次：标准爆发（性兴奋/情绪高涨触发），物理能力极速强化
   - 金女："姐对"爆发（保护家族/团队的意志触发），战术分析+物理能力均衡强化
   - GⅢ："王者爆发"（Vol.11觉醒），战斗特化的极致强化
   - 三者同源（远山家色金武术）但呈现不同的分支形式

┌─────────────────────────────────────────────────────┐
│  三、单分子震动刀 (Monomolecular Vibration Blade)│
│          —— 金女的标志性近战武器                │
└─────────────────────────────────────────────────────┘

■ 性质
   - 分子级震荡切割武器
   - 能在分子层面切割目标，破坏力极强
   - 远山家G系列成员使用的特殊武装之一

■ 战斗应用
   - 近战格斗的核心武装
   - 释放震动波进行远程攻击（推测）
   - 结合战术特化的战斗风格，以精确致命为主

■ 弱点
   - 极度温差会导致金属脆化断裂
   - 在"木工包围战"中，白雪（火焰）与贞德（寒冰）的
     冰火联动战术利用温差使金女的单分子震动刀脆化断裂
   - 这一战术突破直接导致金女在该战中败北

┌─────────────────────────────────────────────────────┐
│  四、磁力推进纤维盾 (Magnetic Propulsion Shield) │
│          —— 攻防一体的战术装备                  │
└─────────────────────────────────────────────────────┘

■ 性质
   - GⅢ团队为金女配备的专用装备
   - 以磁力推进纤维构成的防御/机动复合装备
   - 兼具防护、推进、机动性提升等多重功能

■ 功能
   [1] 防御
       以磁力纤维形成防护层
       有效抵挡物理/能量攻击
       对抗超自然攻击的效果视强度而定

   [2] 机动
       磁力推进可实现短距离高速移动
       战场机动性显著提升
       配合斥候/破坏任务的快速进出

   [3] 战术组合
       可与单分子震动刀形成攻防一体的战斗风格
       在GⅢ团队中以"斥候/破坏/代理领队"的定位使用该装备

┌─────────────────────────────────────────────────────┐
│  五、佩特拉之钥 (Petra Key) 持有者              │
└─────────────────────────────────────────────────────┘

■ 性质
   - 具有特殊能力的魔法造物
   - 原由佩特拉（克丽欧佩特拉转世/伊·U成员）持有
   - 金女在后续剧情中获得此物

■ 关键应用
   - Vol.27：金女使用佩特拉之钥成功停止金天（GⅤ）体内的反色金暴走
   - 这是拯救金天生命的关键转折点
   - 佩特拉之钥具有中和/封印人工色金的特殊能力

■ 意义
   - 金女持有佩特拉之钥象征她在远山家族中
     承担"守护妹妹"的责任
   - 也是她从"人工制造的兵器"转变为"守护家族的战士"的标志

┌─────────────────────────────────────────────────────┐
│  六、远山家色金武术（远山五省）                 │
│          —— 不完全传承                         │
└─────────────────────────────────────────────────────┘

■ 概述
   - 作为远山家的G系列成员，金女基因中烙印着色金武术的因子
   - 但与金次（正式传承"镜·空·螺旋·扇·樱花"五省）不同，
     金女作为人工天才的色金武术为不完全传承
   - 更多依赖战术头脑而非纯粹的武术技巧

■ 已知应用
   - 结合单分子震动刀的远山式近战技法
   - "姐对"爆发模式下的色金粒子加速
   - 光影刀（Vol.40使用）——结合光与影的远山系武术变体

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 人工制造的生命 vs 自我选择的家族归属
成长弧光: 敌对势力战斗员 → 被策反的敌人 → 团队核心成员 → 守护家族的战士
象征意象: 单分子震动刀（精确致命的战术美）、佩特拉之钥（守护家族的责任）、
          姐对爆发（姐妹羁绊的力量）

■ 作品定位
   - G之血族的第四代成员，与GⅢ同为第一世代人工天才
   - 远山家四姐——"战术特化型"人工天才
   - 最初作为敌方战力击溃巴斯克维尔小队，后通过"色诱策略"被拉拢
   - 从敌人到战友的典型弧线——与L·华生的角色弧线有异曲同工之妙
   - GⅢ团队中不可或缺的"战术大脑"和代理领队
   - 在拯救金天（GⅤ）的行动中发挥关键作用

■ 与G血族其他成员的差异化
   - GⅠ（加奈）：神秘与伪装 → vs → GⅣ（金女）：战术与直接
   - GⅡ（金次）：对卒+爆发模式核心 → vs → GⅣ：姐对爆发模式变体
   - GⅢ（金三）：艺术性战斗特化 → vs → GⅣ：冷静战术特化
   - GⅤ（金天）：智力特化+超能力 → vs → GⅣ：实战战术特化
   - 金女是G血族中"实战战术"的代表——连接战斗与谋略的桥梁

■ 第一世代人工天才的意义
   - 金女与GⅢ共同代表"第一世代"的两种分支
   - GⅢ = 战斗特化（直接杀伤最大化）
   - GⅣ = 战术特化（战场效率最大化）
   - 两人互补：GⅢ负责"做什么"，金女负责"怎么做"
   - 这是美国军方"人工天才"计划的双轨设计

■ 从"敌人"到"家族守护者"的弧线
   - 金女的角色弧线是绯弹系列最典型的"敌人→伙伴"转化之一
   - 她的转化与L·华生类似但路径不同：
     华生是因被识破女儿身而软化，
     金女则是通过"色诱策略"+木工包围战的以武会武而和解
   - 此后她完全融入了师团和远山家的体系
   - 从击溃巴斯克维尔小队的敌人，到使用佩特拉之钥拯救妹妹的守护者
   - 她的配特拉之钥持有者身份象征着她的"身份转变"——从兵器到家人

■ 关键事实确认
   - 远山金女（GⅣ）是远山金叉的DNA制造的第一世代人工天才（战术特化型）
   - 别名"远山要"在部分资料中出现（c0.txt、c128.txt）
   - 初登场于Vol.10《禁忌的双极》，以"击溃巴斯克维尔小队的强敌"形象亮相
   - 在木工包围战中被白雪+贞德的冰火联动击败，随后和解
   - 通过玉藻策反的"罗密欧任务"被正式拉拢为师团成员
   - 在GⅢ团队中担任破坏工作/斥候/代理领队
   - 拥有独特的"姐对"爆发模式（HSS变体）
   - 持有佩特拉之钥并在Vol.27拯救金天时发挥关键作用
   - 与九九藻关系亲密，同上学、同玩闹
   - 武器为单分子震动刀、磁力推进纤维盾，后期使用光影刀
   - 战斗力被评为约等于九九藻级别（B+），但战术头脑加分显著

■ 关于"远山要"的名称
   - c0.txt（金次档案）列出侄子/女：远山要、远山奏
   - c128.txt（金天档案）列出"远山金女 (GIV / 远山要 / G-IV)"
   - 推测"远山要"既是金女的本名/别名，也可能是远山家下一代的成员名
   - 考虑到G血族的命名体系（金+"数字/代称"），
     "要"（Kaname）可能是金女在远山家谱中的正式社会名
   - 本档案以"远山金女"为主名，"远山要"为别名

■ 关于"姐对"爆发模式
   - "姐对"（Sister Mode/姉対）是金女的HSS变体
   - 与其他爆发模式的关系：
     · 金次：标准爆发（HSS原型）
     · 金次：狂怒爆发（Frenzy HSS，Vol.8天空树初现）
     · GⅢ：王者爆发（Vol.11觉醒）
     · 金女：姐对爆发（时间点不明，但在Vol.40已完全掌握）
   - "姐对"之名的含义：以"姐姐"的身份和意志驱动爆发模式
     专注于保护妹妹和家族成员
   - 此模式在金女与金天（GⅤ）的姐妹羁绊中具有主题意义

■ 关于单分子震动刀
   - 单分子震动刀（Monomolecular Vibration Blade）是金女的核心武器
   - 在木工包围战中，白雪的色香菖蒲（火焰）与贞德的钻石冰尘（寒冰）
     的急剧温差使刀刃脆化断裂——这是该武器唯一已知的被破坏记录
   - 推测后期已重建或修复此武器
   - 在Vol.40埃及篇中使用"光影刀"——可能是新武器或震动刀的升级版

■ 关于金女在GⅢ团队中的角色定位
   - GⅢ团队核心成员一览：
     · GⅢ（远山金三）—— 总指挥官/最强战力
     · 亚特拉士 —— 前线重装突击手
     · 柯林斯 —— 火力支援/财务管理/翻译
     · 安格斯 —— 驾驶/运输/执事
     · 洛嘉 —— 超能力少女/侦查
     · 九九藻 —— 战斗/色金顾问/护卫
     · 金女 —— 斥候/破坏/代理领队
     · 基思 —— KGB出身重火力
     · 马许 —— 人工天才/网路机械
   - 金女在团队中的独特价值：战术指挥+破坏工作+代理领队
   - 当GⅢ不在时，金女是团队的实质领导者

■ 与白雪+贞德的三角关系
   - 金女与白雪+贞德的"敌人→对手→战友"弧线值得关注
   - Vol.10：金女单方面击溃白雪（巴斯克维尔全员）
