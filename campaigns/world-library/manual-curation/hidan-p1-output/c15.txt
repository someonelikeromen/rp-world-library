                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 伊·U（伊·幽 / Eo?）首领，通称"教授"
   - 神崎·H·亚莉亚的曾祖父（直系血亲）
   - 福尔摩斯家族始祖·第一代福尔摩斯
   - 史上最伟大的侦探之一（在该世界观中）
   - 国际犯罪组织"伊·U"的创建者与最高支配者
   - 与莫里亚蒂教授百年来持续对抗的宿敌
   - 约翰·H·华生一世的最佳搭档与挚友

■ 家族
   - 福尔摩斯家族：一个庞大的武侦/侦探家族网络
   - 曾孙女：神崎·H·亚莉亚（Kanzaki Holmes Aria，福尔摩斯四世）
   - 后裔：梅露爱特·福尔摩斯（Holmes IV，伦敦的福尔摩斯）
   - 后裔：华生四世（John H. Watson IV，作为搭档家族的传承）
   - 福尔摩斯家族历代出产天才侦探和强袭武侦

■ 外貌特征
   - 老年男性
   - 双目完全失明（依赖听觉、推理和第六感感知世界）
   - 标志性的深邃面容，带有历经百年的智者气质
   - 通常身着正装/绅士装束
   - 虽为盲人，但举手投足间展现出超越常人的从容与威严
   - 存在感极强，即使不视物也能准确"注视"对方

■ 年龄
   - 实际年龄不明，但活跃已超过百年
   - 至少98年前已与华生一世搭档
   - 通过某种手段（卡邦克鲁的第二条生命）维持寿命

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 极具威压感的存在：作为伊·U首领，一言一行都透露着绝对的自信与支配力
   - 智者的从容：对一切局势了然于心的沉着
   - 戏剧性：偏好在大场面中揭示真相，将战斗与推理视为一种"演出"
   - 威严的长者：对后辈（尤其是亚莉亚、金次）既有考验也有期许

■ 本质内核
   - 究极的理性主义者：依赖推理和数据而非直觉
   - 深谋远虑的战略家：计划跨度可达数十年甚至百年
   - 对"真相"的执着追求：即便双目失明，仍以推理"看见"世界
   - 对搭档（华生）的绝对信任：百年来唯一完全信赖的人
   - 传承者：寻找接班人、完成"绯色研究"课程，为福尔摩斯血脉留下传承

■ 黑暗面
   - 不择手段：为达目的（如对抗莫里亚蒂、保护世界），不惜利用亲近之人
   - 操控者：将亚莉亚卷入伊·U继承计划，用历镜植入绯弹改变其人生
   - 曾击杀远山加奈（亚莉亚的盟友/金次的大哥）以测试亚莉亚和展示力量
   - 从卡邦克鲁处抢夺第二条生命的手法带有掠夺性
   - 在"正义"与"操作"之间的灰色地带行事

■ 精神特质
   - "条理预知"式思维：通过搜集信息推演出未来走向，以此布局
   - 百年的寂寞：拥有漫长的生命，看着一代代亲人老去
   - 对"不可能犯罪"的痴迷：与化不可能为可能的金次形成镜像关系
   - 面对极限时的豁达：在ICBM发射库中被金次击败时，展现出对后继者的认可

■ 实际战斗能力描述有限（因角色主要以智谋/首领身份行动）
   - 能够单手击穿远山加奈（GⅠ）的心脏 —— 展示出基础战斗能力
   - 在ICBM发射库中与金次和亚莉亚对峙时，使用幻影分身
   - 拥有翼龙作为坐骑/救援单位（在深潜救援金次时使用）

   - 由麾下的伊·U精英成员执行直接战斗任务

■ 已知战斗技/手段
   - "幻影"（幻影分身）：在ICBM发射库中使用的分身能力
   - 翼龙骑乘：具有大型飞行生物的操控能力
   - 全面战指挥：核潜艇战术、导弹发射、鱼雷战的卓越指挥能力

┌─────────────────────────────────────────────────────┐
│  四、历镜（时空透镜/Rei镜）                       │
└─────────────────────────────────────────────────────┘

■ 性质
   - 能够穿越时间与空间的装置
   - 与绯绯色金（绯弹）的起源密切相关
   - 使用时可能对使用者产生代价（夏洛克双目失明可能与此相关）

■ 已知使用记录
   - Vol.5: 射中三年前的亚莉亚背部，将绯弹（绯绯色金）植入其体内
   - 该操作使亚莉亚头发变粉金色、瞳色变红紫色、身体成长停滞
   - 夏洛克以此完成"绯色研究"课程，授予亚莉亚"绯弹的亚莉亚"称号

■ 风险
   - 时间干涉可能产生不可预知的蝴蝶效应
   - 使用历镜的代价是使用者逐渐失去感官（夏洛克双目失明的可能原因）

                  【人际关系 / Relationship Map】
================================================================================

■ 神崎·H·亚莉亚（Kanzaki Holmes Aria）
   关系：曾孙女 · 继承者 · 被考验者
   评价："她体内流着福尔摩斯的血……但要比我更热血、更冲动"
   关键节点：在伊·U号上带走亚莉亚 → 揭示绯弹真相 → 授予"绯弹的亚莉亚"称号
   备注：夏洛克对亚莉亚的感情复杂——既是血脉至亲，又是"作品"和继承者。
         他用极其残酷的方式（击杀加奈、植入绯弹、改变人生）来考验和培养她。

■ 远山金次（Tohyama Kinji）
   关系：击败者 · 被认可的对手 · 后辈
   评价："那个远山家的孩子……化不可能为可能的少年"
   关键节点：ICBM发射库对决 → 被金次用樱花+头锤击败 → 后续多次协助金次
   备注：夏洛克对金次的态度从"需要清除的障碍"逐渐转变为"值得投资的后辈"。
         在后续剧情中，夏洛克持续为金次提供资源和情报支援。

■ 约翰·H·华生一世（John H. Watson I）
   关系：最佳搭档 · 百年的朋友 · 生命容器
   评价："华生，你一直都知道该怎么让我走出来。"
   关键节点：百年前搭档 → 分离98年 → Vol.37在印度再会
   备注：华生一世是夏洛克人生中唯一完全信赖的人。98年来华生以村医身份隐居印度，
         体内存放着夏洛克从卡邦克鲁处抢来的第二条生命。两人的重逢是全系列最
         感人的场景之一。

■ 莫里亚蒂教授（Professor Moriarty / 詹姆斯·莫里亚蒂）
   关系：宿敌 · 一百年的对手 · 镜像
   评价："莫里亚蒂……那个用数学毁灭世界的人"
   关键节点：莱辛巴赫瀑布对决（背景）→ 百年对抗 → 鄂霍次克海海战
   备注：莫里亚蒂是夏洛克存在的"阴影面"——如果说夏洛克代表推理与秩序，
         莫里亚蒂代表混沌与毁灭。莫里亚蒂拥有七条生命（来自七位列库忒亚女神），
         试图引发"第三次接轨"。

■ 梅露爱特·福尔摩斯（Mellate Holmes / 福尔摩斯四世）
   关系：后裔 · 伦敦的福尔摩斯
   备注：梅露爱特是福尔摩斯家族的另一支后裔，与亚莉亚同为福尔摩斯四世。
         她主要活跃在伦敦，在Vol.37加入夺还小队。

■ 远山加奈 / 远山金一（Tohyama Kana / Tohyama Kinichi）
   关系：前对手 · 被击杀者
   备注：夏洛克在Vol.5击杀加奈，这是为了测试亚莉亚并清理伊·U继承的障碍。
         加奈的死推动了金次后续的成长。

■ 卡邦克鲁（Carbuncle / 大地女神）
   关系：被掠夺者 · 间接同盟
   备注：夏洛克98年前从卡邦克鲁处抢走第二条生命，导致卡邦克鲁与夏洛克有
         长达近一世纪的敌对。卡邦克鲁施咒使夏洛克无法靠近其生命容器。

■ N组织成员
   关系：敌对势力
   备注：包括尼莫（提督）、伊藤茉斩、路西菲莉亚·莫里亚蒂四世等，

                  【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 理性 vs 混沌 / 秩序 vs 破坏 / 百年对抗
成长弧光: 不适用（夏洛克本身已处于"完成态"，他的角色弧在于传承与和解）
象征意象: 核潜艇（百年的力量）、历镜（穿越时间代价）、盲眼（看透真相）

■ 角色定位
   - 《绯弹的亚里亚》世界观的顶层支配者之一
   - 作为"传承的象征"——代表福尔摩斯家族的源头与宿命
   - 作为"考验者"——为年轻一代（金次、亚莉亚）提供试炼
   - 作为"信息核心"——揭示绯弹、色金、历镜世界观的关键人物
   - 与莫里亚蒂构成"善恶双壁"的平衡结构

■ 与历史原型的差异
   - 《绯弹的亚里亚》中的夏洛克·福尔摩斯比原作更加"超人类"
   - 拥有核潜艇、ICBM、历镜等军事/科幻级资源
   - 双目失明但感知力远超常人
   - 寿命远超常人（通过盗取第二生命）
   - 不仅是被崇拜的名侦探，更是实际支配国际组织的"教父"

■ 在作品中的叙事功能
   - 世界观揭示者：绯弹、历镜、伊·U、色金秘密的解说者
   - 试炼者：为金次和亚莉亚的成长提供决定性考验
   - 最终战的伏笔：与莫里亚蒂教授的百年对决是系列终极主线之一
   - 传承链的起点：从夏洛克到亚莉亚，福尔摩斯血脉的传承

================================================================================
                 【档案补遗 / Archive Notes】
================================================================================

■ 关于"夏洛克·福尔摩斯"在该世界观中的定位
   绯弹的亚里亚将夏洛克·福尔摩斯重新诠释为一个跨越百年的"活传奇"。
   他不是普通的老人，而是掌握国际组织、拥有超常寿命、能操纵时空的
   "非人"级存在。同时，他保留了原著中名侦探的核心——推理与观察。

■ 关于双目失明的设定
   夏洛克的失明在该系列中是一个重要设定：
   1. 强化了"推理而非视觉"的侦探本质
   2. 暗示了使用历镜的代价
   3. 使角色更具神秘感和威严
   4. 让"盲人比明眼人看得更清楚"这个主题更加突出

■ 关于伊·U（伊·幽）的解读
   "伊·U"的片假名表记为「イ・ユ」，常见解读为"Eo?"，
   是夏洛克·福尔摩斯创建的跨国组织。
   该组织的成员多为历史伟人的后代/转世，如：
   - 神崎·H·亚莉亚（福尔摩斯四世）
   - 峰·理子·罗苹4世（亚森·罗苹后裔）
   - 贞德·达鲁克30世（圣女贞德后裔）
   - 等等

■ 关于"教授"称号
   夏洛克在该系列中常被称为"教授"（Professor），
   这个称呼对应了原著中莫里亚蒂的称号——"犯罪界的拿破仑"，
   在绯弹世界观中，夏洛克成为了"教授"，而莫里亚蒂则隐于幕后。

■ 与华生一世的关系
   夏洛克与华生一世的关系是系列中最深厚的情感线之一。
   华生一世以村医身份隐居印度98年，体内保存着夏洛克所需的第二条生命。
   即使分离近一世纪，两人重逢的第一刻就恢复了当年的默契。
   这种横跨百年的信任与羁绊是夏洛克角色中最为"人性化"的一面。

■ 与莫里亚蒂的百年对抗
   莫里亚蒂教授是该系列中夏洛克的终极对手。
   莫里亚蒂拥有七条生命（来自七位列库忒亚女神），
   试图引发"第三次接轨"——将列库忒亚世界与地球融合。
   夏洛克为阻止莫里亚蒂，不惜一切手段，包括：
   - 抢夺卡邦克鲁的生命
   - 培养亚莉亚作为继承者
   - 联合金次等新一代武侦
   - 与华生一世重组最强搭档

■ 已知后续剧情线索
   - 夏洛克与华生一世的最强搭档组合将在后续发挥关键作用
   - 与莫里亚蒂的最终决战尚未到来
   - 夏洛克持有的历镜和绯弹的真相可能还有更深层的秘密

■ 角色原型考
   绯弹版夏洛克·福尔摩斯融合了以下要素：
   - 柯南·道尔原著的经典夏洛克形象（推理、烟斗、小提琴的象征虽被淡化）
   - 詹姆斯·邦德式的国际阴谋操纵者（核潜艇、全球组织）
   - 奇幻作品中"活过百年"的老智者（第二生命、历镜）
   - 日式ACG中的"考验主角的强大长者"（如猎人会长尼特罗等角色原型）
