                        【基础情报 / Basic Info】

■ 身份
   - 前日本公安零课 代号"四（4式）"（四 / Shi / 死）
   - 国际恐怖组织"Nautilus（N）"核心战斗力 / 执行者
   - "带灰色/黑色指环之人"
   - 伊藤家族长女
   - 远山金次名义上的"杀父仇人"
   - 远山金叉的"恋人"（以杀死对方为表达方式）

■ 家族
   - 伊藤家：世代产出"多重脑连结（Multi-Brain Access）"超能力者的特异家族
   - 弟弟：伊藤可鹉韦（前公安零课成员 · 为讨伐姊姊而加入公安）
   - 族人将其视为"活神明"，从小供奉在类似神社的设施中
   - "可鹉韦"之名意为"神"——弟弟被起此名作为替身/诱饵，以保护真正的神（茉斩）

■ 年龄: 约25岁（初登场时）
■ 身高: 约170cm（高挑身材）
■ 体重: 未公开（精悍的战术体格）
■ 三围: 未公开（但金次描述为"身材很好的大姊姊"）
■ 发色: 初期如夜幕般漆黑的长直发（垂至腰际）→ 后期因能力过度使用/心理转变转为银白色
■ 瞳色: 深邃的褐色/深褐色
■ 喜欢: 远山金叉（唯一爱慕的对象）、弟弟可鹉韦（作为血脉羁绊）、追求强者的决斗、学校制服（从未穿过而产生兴趣）
■ 厌恶: 弱者的纠缠、家族污点、谎言、现代社交中的虚伪辞令
■ 惯用手: 右（但矢指/箭指以右手食指为武器）
■ 服装: 标志性黑色防弹长风衣 + 战术服 + 黑色长靴

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 极度冷静、寡言、面无表情
   - 看起来像"名工匠制作的人偶般端正"——金次初印象
   - 眼神恍惚无神，没有聚焦在任何一点
   - "感受不到任何身为一个人的温度"——比蕾姬或LOO还要无机
   - 战斗状态下情感几乎为零

■ 本质内核
   - 孤独的狼：一生贯彻独来独往
   - 情感逻辑极端扭曲：将"杀戮"等同于"爱"的终极表达方式
   - 重情重义（以自己扭曲的方式）：对金叉的执着跨越生死
   - 拥有家族荣誉感，但已走上无法回头的黑暗道路
   - 内心深处依然保留对弟弟可鹉韦的一丝柔软

■ "爱=杀"的哲学
   - 唯一爱慕的对象是远山金叉
   - 认为"只有死亡能让两颗心彻底融合"
   - 追求与强者（尤其金叉）的生死对决，视为"浪漫"的最高形式
   - 认为被杀是"被爱"的终极证据
   - 对金次评价："你之前不是也保护过我吗？"——在金次挺身保护她时流露出罕见的困惑

■ 社交障碍
   - 自幼被当做"活神明"隔离在神社中
   - 13岁被公安零课带走，彻底脱离正常社会生活
   - 长期在战斗中度过，完全缺乏普通的人际交往经验
   - 对话简短、破碎，对日常事物缺乏常识
   - 但偶尔表现出对人类"普通"事物的好奇心（如对学校制服）

■ 精神成长曲线
   - 幼年期：被当作活神明供奉的少女 → 被零课带走
   - 公安零课期：作为"四式"（死神般的存在）执行无数暗杀任务 → 击败远山金叉（1999年）
   - N组织期：加入N，成为核心执行者 → 劫持春雾舰时期（最危险的状态）
   - 与金次同盟期：暂时合作寻找金叉 → 逐渐暴露内心的矛盾
   - 最终决战期：与金叉的死斗 → 重伤坠谷，生死不明 → 找到某种"解脱"

================================================================================
                 【能力全析 / Ability Analysis】
================================================================================

┌──────────────────────────────────────────────────────┐
│  一、多重脑连结（Multi-Brain Access / 多重脑接続） │
│          —— 伊藤家世代传承的神经系超能力          │
└──────────────────────────────────────────────────────┘

■ 核心原理
   - 伊藤家在极低机率下会产出天生拥有"多个脑"的人物
   - 能够同时使用多个脑区进行并列运算处理
   - 正常人类使用1-2个脑区（1-2档），伊藤家族成员可达更高档位
   - 茉斩和可鹉韦姐弟是家族中最极端的案例

■ 逐级提升系统（Access System / 接入）
   - 通过分级解锁大脑的限制器，实现神经信号传导的几何倍率加速
   - 每提升一档，身体机能、反应速度、动态视觉呈指数级提升
   - 代价：大脑中负责语言表达的部分受阻碍→说话变得破碎、断续、像机器人
   - 最高可达6档以上（可鹉韦最高5档，茉斩远超过此水平）

■ 已确认的能力档位及其表现

   [1-2档 · 常人级别]
       与人无异的日常状态
       对话流畅，情感表现正常
       战斗能力接近一般特工
       初登场时即以此状态面对金次和妖刕——仍展现出压倒性气场

   [3-4档 · 精英战斗状态]
       身体机能大幅提升
       可用肉眼捕捉手枪子弹的轨迹
       可用指尖弹开飞行中的子弹（矢指初级）
       判断力与反应速度远超常人
       出现轻微言语障碍

   [5-6档 · 极限战斗状态]
       身体机能提升至非人境界
       可同时用不可知子弹压制两名以上高手
       动态视觉达到可"看清所有子弹轨迹"的程度
       言语基本消失 → 仅剩破碎的单词
       金次评价："她的眼睛看到的整个世界都和我不一样"

■ 能力缺陷
   - 无法长时间维持高档位（大脑过载）
   - 高档位下几乎丧失沟通能力
   - 长期过度使用导致大脑损伤/发色变化
   - 随能力提升，情感表达越来越淡薄
   - 与远山家的HSS有本质不同：HSS依赖性兴奋驱动，Access依赖大脑解禁

┌──────────────────────────────────────────────────────┐
│  二、矢指/箭指（Arrow Finger / 矢指 / 不可知子弹） │
│     —— 窃取自远山金叉并异化发展的杀人技           │
└──────────────────────────────────────────────────────┘

■ 原理
   - 将全身力量瞬间汇聚于右手食指尖端
   - 通过极高速弹击产生压缩空气的动能冲击波
   - 能够正面弹开飞行中的子弹（如同以指尖"击弹"）
   - 可在瞬间贯穿钢板或人体
   - 被称为"不可知子弹"（Unknowable Bullet / 不可知の弾丸）
     因为发射动作极小，肉眼几乎不可见

■ 应用场景
   [1] 弹开子弹
       以指尖弹击发射空气弹 → 正面击飞手枪子弹
       春雾舰上以此技能轻松化解金次与可鹉韦的六发子弹夹击

   [2] 远程狙击
       发射看不见的空气冲击波
       威力可击碎石板、切断钢缆
       射程约数十米

   [3] 操控弹道
       精妙到可干涉他人子弹的轨迹
       使金次和可鹉韦互相射击/互殴
       "如同看不见的手在操控棋盘"——金次评价

   [4] 复合矢指
       同时射出多发不可知子弹
       对多名敌人形成压制性火力

■ 与远山金叉的关联
   - 此技源自远山金叉的传授或"战斗中的观察窃取"
   - 茉斩在该技能上的造诣可能已经反超原创者
   - 金叉的"樱花一击"与茉斩的"矢指"有对战记录（1999年）
   - 金次在罗马斗兽场战中，曾试图狙击中茉斩的右手食指（阻止矢指使用）

┌──────────────────────────────────────────────────────┐
│  三、特工战术全精通                               │
└──────────────────────────────────────────────────────┘

■ 潜入能力
   - 公安零课出身，顶级渗透/潜伏技巧
   - 可在人群中毫无痕迹地出现与消失（金次称其"神出鬼没"）
   - 多次在完全不被发现的情况下接近目标

■ 战斗技巧
   - 徒手格斗：顶级水平，配合Access锁定时堪比超人类
   - 枪械精通：熟悉各类枪械，但主要依赖矢指
   - 战术判断：可在复杂混战中先发制人，以一敌多
   - 环境利用：将周围环境化为致命陷阱

■ 装备操控
   - 重型装备：能操控护卫舰级别的军事装备
   - 在春雾舰事件中独自完成舰只劫持与核鱼雷（NDD）发射准备

■ 防御能力
   - 黑色防弹风衣：可有效抵挡手枪子弹（金次近距离射击被衣襬弹开）
   - 反应速度极快：可在枪口指向自己的瞬间做出闪避/反击

┌──────────────────────────────────────────────────────┐
│  四、病态直觉（Morbid Intuition）                  │
└──────────────────────────────────────────────────────┘

■ 基于扭曲情感逻辑的危险感知
   - 对杀气与恶意有如同野兽般的敏锐感应
   - 能在复杂混战中先发制人
   - 甚至连妖刕静刃的"预知眼"都无法看穿茉斩的死期

■ 战斗中的表现
   - 即使背对敌人——仍然"毫无破绽"
   - 金次、妖刕、可鹉韦三人围剿却无法发动攻击
   - "不知道为什么——我们就是知道自己已经踏进那女人的攻击范围内了"
     "不是透过五感，而是类似直觉的东西"

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 作为"活神明"被隔离的宿命 vs 渴望真实连接的扭曲表达
本质悲剧: 一个从未被教会"正常去爱"的女人，只能以杀戮作为爱的语言
核心象征: 断裂的语言（无法表达内心）→ 只能用矢指（纯粹的暴力）来沟通

■ 存在主义主题
   - "活神明"——被封印在人类社会中找不到位置的异类
   - 被崇拜而不是被理解——孤立的一生
   - N组织提供了同类聚集的空间（与尼莫、古兰督卡等超能力者）
   - 但即使是N内部，茉斩也因极端个人化的动机而格格不入

■ "爱=杀"的畸形美学
   - 极可能是童年隔离导致的对"连接"的病态理解
   - 唯一被允许的"亲密"经验来自战斗/刺杀
   - 对金叉的爱是唯一的人类情感——却只能用杀死对方来表达
   - 茉斩的悲剧性在于：她的爱是真诚的——只不过表现形式被扭曲

■ 镜像关系
   - 伊藤茉斩 / 远山金叉 —— 互相欣赏的最强敌人/扭曲恋人
   - 伊藤茉斩 / 伊藤可鹉韦 —— 姐弟的对抗 = 家族宿命的传承与反抗
   - 伊藤茉斩 / 远山金次 —— "杀父仇人"与儿子的宿命对决
     （但与传统的复仇叙事不同——金叉实际上没死，使"杀父仇人"身份成为讽刺）

■ 与远山金叉的符号学
   - 金叉: 远山家色金武术的顶点 → 使用"樱花""绝闩"等守护型招式
   - 茉斩: 窃取/异化金叉的技艺 → 将"矢指"发展为纯粹的杀伐兵器
   - 两人的关系 = 守护本能 vs 毁灭本能的镜像碰撞

■ 银发的象征（后期）
   - 过度使用Access导致发色由黑转银白
   - 象征能力的极限透支 → 生命的燃烧
   - 银白 = 接近"非人"的神性/死性

              【档案备注 / Archive Notes】
================================================================================

■ 关键事实确认
   - 伊藤茉斩 ≠ 远山金叉的"真正凶手"
     金叉未死于茉斩之手 → 而是以假死转入地下作为"砦派"特务
     因此"杀父仇人"这个称呼在故事后期被证实是误传
   - 茉斩的金叉情结是绯弹后期最重要的情感线之一
   - 伊藤家族的多重脑能力与远山家的HSS是两条平行的超常血统
   - 茉斩坠谷后的生死状态在卷31后未被明确交代

■ N组织内的地位变化
   - 灰色指环（第23卷春雾舰时期）→ 黑色指环（第25卷罗马时期）
   - 推测降级原因可能与春雾舰任务的失败有关
   - 但茉斩本人似乎对组织内地位不甚在意（更关心金叉的行踪）

■ 关于"可鹉韦"名字的真相
   - "可鹉韦"（カムイ / Kamui）在阿伊努语中意为"神"或"精灵"
   - 家族制度：真正拥有能力的孩子称为"神"（活神明）
   - 其兄弟被命名为"可鹉韦"作为替身/诱饵——保护真正的神
   - 因此可鹉韦的存在自始至终都是为了"替茉斩去死"
   - 但可鹉韦选择反过来"杀掉神"——这种反转本身就很有戏剧性

■ 人物定位总结
   - 绯弹系列中期登场的"最强级别"对手
   - 少数能让金次在爆发模式下仍被完全压制的存在
   - 既是反派也是悲剧性角色
   - 是连接"金叉线"（远山家的过去）和"N组织线"（当前威胁）的关键人物
   - 代表"爱的另一种可能性"——病态的、扭曲的、但仍真诚的爱

■ 与其他角色的战斗数据参考
   - 金次（爆发模式）+ 可鹉韦（5档）+ 妖刕（潜能解放）→ 三人联手无法触碰到茉斩
   - 这是系列中少数主角方以"等级压制"方式完全失败的战斗
   - 说明茉斩在当时点（第23卷）的战斗力远高于金次认知的任何对手
   - 后期随金次成长，差距逐渐缩小
