                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 美国国家安全保障局（NSA）"雌蚁计划"（Female Ant Project）研发的人型陆战兵器
   - 持有美国陆军上校军衔（非正式登记）
   - 最初为NSA操控的军事机器人，后随负责人马修转投"GⅢ同盟"
   - 远山金三（GⅢ）麾下核心高科技战力成员
   - 特殊设计：采用"机器人驾驶机器人"的双重架构逻辑

■ 制造背景
   - 所属计划：NSA"雌蚁计划"——研发类人形仿生军用机器人的秘密军事项目
   - 制造目的：利用萝莉外表的欺骗性执行潜入、暗杀、重火力压制等多重任务
   - 所属组织变迁：NSA直属 → 马修私人护卫 → GⅢ同盟核心成员
   - 军衔身份：美国陆军上校（名义军衔）

■ 物理参数
   - 外观年龄：约10岁（小学女生样貌）
   - 身高：约130-140cm（娇小体型）
   - 体重：200kg（全金属结构）
   - 发色：浅蓝色短发，通常扎成可爱的双马尾辫
   - 瞳色：绯红色，透着机械的无机质感，激动时会泛光
   - 特征着装：藏青色学校泳装（死库水），脖子上系着武侦高款式的红色领带——强烈的反差感
   - 机械特征：身体关键关节处裸露着精密机械构件，体内充满精密电子回路，拥有绿色的"合成血液"（兼具冷却液与电路传导作用）
   - 体表触感：外部覆盖仿生皮肤，但触摸下层为冰冷坚固的合金装甲

■ 装备/配件
   - 特制机械外骨骼（平时贴合在四肢，提升力量与机动性）
   - 全尺寸人型陆战兵器（三米高巨型机械装甲——可嵌入驾驶）
   - 头戴式通讯组件（与马修及其他指挥系统链接）
   - M61火神式机炮、榴弹炮、烟雾弹发射器（嵌入陆战兵器系统）

                   【人物特质 / Personality Profile】
================================================================================

■ 核心人格（三无·机械逻辑）
   LOO本质上是一台高度精密的仿生军用机器人，不具备人类的自我意识。
   其"人格"是由底层协议、战术AI和学习模块共同构建的"拟人格"。
   主要表现为：

   [1] 无口（Mute）
       因人工咽喉程序限制，几乎无法发出复杂的语言。
       日常交流基本只能重复单音节词"LOO"。
       其发音极其迟缓、断断续续，像损坏的录音机。

   [2] 无表情（Expressionless）
       面部机械结构无法做出人类般的丰富表情。
       大多数情况下保持无机质的"冷漠脸"。
       但在某些瞬间——例如得到马修的肯定、协助同伴成功——会有一丝几乎不可察觉的"类人类反应"（嘴角微动、瞳孔收缩等）。

   [3] 无心（Emotionless）
       不具备人类的情感模块，所有的"行为"均由逻辑判断驱动。
       对杀戮无负罪感，对任务无犹豫。
       但长期的战斗数据积累让它逐渐发展出了"伪情感"——优先保护马修、对特定目标产生反感等。

■ 行为模式
   - 绝对服从：对马修的指令执行率100%，无质疑、无延迟
   - 高效率杀戮：任务模式下，以最短路径、最小资源消耗完成目标清除
   - 程序化日常：非战斗状态下进行逻辑自检、武器维护、能量补给
   - 观察人类：作为学习型AI，LOO持续收集人类的情感数据，但无法真正理解

■ 机械特有的"萌点"
   - 说话时轻微卡顿的机械音，类似损坏的语音合成器
   - 双马尾随着行走轻微摇晃，与金属关节声形成反差
   - 偶尔的"死机"状态——当逻辑冲突或指令过载时会短暂卡顿
   - 被摸头时虽然无表情，但瞳孔会微微收缩（疑似"高兴"的机械表达）

■ 精神/程序成长曲线
   - Vol.18 初登场：纯粹的战斗工具，仅执行马修的杀戮指令
   - Vol.18 中后期：开始展现出对指令的"优先级判断"和自我保护的倾向
   - Vol.25 罗马篇：已能与亚里亚、莎拉等人类战友协同作战，不再是无差别的杀戮机器
   - 当前状态：程序持续进化中，逐渐从"兵器"向"伙伴"的角色转变

┌─────────────────────────────────────────────────────┐
│  一、人型陆战兵器系统                               │
│     —— LOO的核心战斗形态：嵌入三米机甲             │
└─────────────────────────────────────────────────────┘

■ 系统概述
   LOO本身的娇小身躯可以作为"核心"嵌入一台三米高的巨型机械装甲中。
   该装甲是NSA"雌蚁计划"的重火力单元，配备了足以正面硬撼常规军队的武器阵列。

■ 武装配置
   主武器：M61火神式机炮 × 2（高射速六管旋转机炮，可撕裂轻装甲目标）
   副武器：榴弹发射器（高爆弹/烟雾弹/闪光弹多用途）
   辅助武装：烟雾弹发射器 × 4（战术遮蔽与脱逃）
   近战装备：巨型机械臂（利用200kg体重+引擎助推进行毁灭性打击）

■ 战斗风格
   - 重火力压制：以压倒性火力压制敌方，为友军创造突破机会
   - 破坏专家：擅长破坏重型工事、装甲目标、防御工事
   - 战场威慑：三米高的机甲本身已具有极强的心理威慑力

■ 弱点
   - 笨重：变身为陆战兵器后机动性下降
   - 能量消耗极大：全火力模式持续时间有限
   - 易被电磁干扰：电子系统存在被EMP武器瘫痪的风险

┌─────────────────────────────────────────────────────┐
│  二、LOO本体战斗能力                               │
│     —— 伪装态的战术运用                           │
└─────────────────────────────────────────────────────┘

■ 超规格负重力
   200kg的机械身躯赋予了LOO超凡的物理力量：
   - 单手可掀翻汽车（约1.5-2吨级）
   - 贯穿普通墙壁如纸片
   - 对抗常人时碾压性优势
   - 受力平衡极佳，不易被物理击退

■ 仿生伪装
   - 外表为10岁女童，极具欺骗性
   - 可执行渗透、潜伏、接近目标等任务
   - 目标因外表放松警惕的瞬间发动致命打击

■ 绿血循环系统（Synthetic Life Support）
   - 总血量约15L的绿色合成液体
   - 同时承担冷却液功能——防止高强度战斗中过热
   - 电路传导介质——链接全身机械单元
   - 自修复功能：遭受常规枪击后可迅速封闭创口
   - 核心保护：即使遭受重创，核心存储单元受多重保护

■ 自动战斗逻辑（Auto-Run Mode）
   - 失联/断网时自动切换至AI主导模式
   - 预设格斗术数据库——包含CQC、军用格斗术等
   - 弹道分析逻辑——实时计算最优射击轨迹
   - 独立战斗精准度可媲美资深强袭科武侦
   - 战术评估模块——基于敌方行动模式快速生成反制策略

│  三、高精度人工咽喉                               │
│     —— 唯一的语言输出通道                       │
└─────────────────────────────────────────────────────┘

■ 基础功能
   - 发声模式：单音重复（"LOO——LOO——"）
   - 音节限制：受限于底层程序，无法生成复杂语句
   - 声音特征：低沉的机械音，伴有电子杂音

■ 特殊应用
   - 声纹模拟：特定情况下可模仿简单的声纹频率
   - 电子干扰：可发出特定频率的声波干扰近距离电子设备
   - 存在程序升级的可能性（目前尚未突破语言限制）

                  【人际关系 / Relationship Map】
================================================================================

■ 马修（Matthew / マシュー）
   关系：负责人 · 指挥官 · "父亲"般的创造者
   评价：（程序层面）"最高……优先……指令……来源……"
   关键节点：马修是NSA"雌蚁计划"的研发负责人，LOO从诞生起就将其视作
             唯一的"精神寄托"。在底层协议中，马修的指令优先级高于一切。
             当NSA内部发生权力斗争，马修被追捕时，LOO以最高保护优先级
             护送马修脱离，随其一同投奔GⅢ同盟。
   备注：LOO对马修的"保护欲"可能已经超越了单纯的程序逻辑，
         其表现接近于生物层面的"依恋"——尽管它无法理解这种感情。

■ 远山金三 / GⅢ（遠山金三 / GⅢ）
   关系：新首领 · 同盟者 · 协议管理者
   评价：（程序层面）"新……协议……绑定……完成……"
   关键节点：投奔GⅢ后，LOO将金三认定为新的顶层协议管理者。
             LOO的重火力战力成为金三在极东战役中对抗多方势力的重要棋子。
   备注：LOO与金三的直接互动有限，两者是"契约性"的上下级关系，
         缺乏与马修之间的那种深度绑定。

■ 远山金次（遠山金次 / Tohyama Kinji）
   关系：曾敌对的对手 · 观察对象
   评价：（数据标记）"高……威胁……不可……预测……目标……"
   关键节点：在Vol.18纽约战斗中，LOO受NSA指令多次阻击金次一行。
             金次的HSS爆发模式和不可预测的战术行动多次打破她的战斗预测，
             其数据中心将金次标记为最高等级的"不可预测目标"。
             在转投GⅢ后，与金次转化为潜在盟友关系。
   备注：LOO的程序中持续收集金次战斗数据用于优化反制算法，
         这种"执着的关注"在某种意义上与人类的好奇心相似。

■ 神崎·H·亚里亚（神崎·H·亜莉亚）
   关系：曾经的敌人 → 战场伙伴
   关键节点：在Vol.25罗马斗兽场之战中，LOO与亚里亚并肩作战对抗
             "狮子大公"格兰迪卡。这是LOO首次与曾经敌对的對象
             以盟友身份协作作战，其协同战斗模块积累了宝贵的
             "与色金持有者合作"的数据。

■ 莎拉（Sarah / サラ）
   关系：战场伙伴
   关键节点：在罗马篇中与莎拉一同加入金次阵容，
             参与斗兽场死斗。LOO的重火力为莎拉的战术提供了火力支援。

■ 阿特拉斯（Atlas / アトラス）
   关系：曾经的战友/对手
   关键节点：在Vol.18的NSA权力变动中双方曾有直接交锋。
             LOO的战斗逻辑中持续模拟对其的反制策略。
             目前两者同属GⅢ麾下，转化为"同盟竞争"关系。

■ 贝瑞塔（Beretta / ベレッタ）
   关系：间接盟友
   关键节点：在罗马篇中参与了救援贝瑞塔的行动，
             展示了LOO作为"GⅢ同盟战力"的可靠属性。

核心冲突: 兵器 vs 伙伴 —— 从纯粹的战斗工具到逐渐获得"伪人格"
成长弧光: 机械 → 无情的杀戮兵器 → 积累数据的智能体 → 被接纳的伙伴

■ 作品定位
   - Vol.18后半段的"敌方单位"→转投GⅢ后的"我方战力"
   - 代表了绯弹世界中最尖端的仿生机械技术
   - 是"色金超自然"主线之外，"科技侧力量"的代表角色
   - 与阿特拉斯等同样出身NSA的机器人式人物形成对比

■ 核心叙事功能
   1. 展示NSA科技实力——揭示美国在地下世界的另一面力量
   2. 金三势力的战力构成——GⅢ同盟的多维度兵力
   3. 机械灵魂的哲学命题——LOO的"拟人格进化"
     暗示了AI与人类间的模糊界限（尤其是对马修的忠诚超越了代码）
   4. 战争中的道德灰色地带——即便作为武器也存在"选择的权力"

■ 反差魅力
   LOO的最大角色魅力在于其极端的"反差"：
   外观是10岁双马尾泳装萝莉 → 本质是200kg机械杀人兵器
   只会说"LOO" → 战场上操控M61火神炮横扫千军
   表面三无冷酷 → 对马修展现出超越代码的保护欲
   这种"萝莉×重兵器×三无机械"的三重反差高度契合
   《绯弹的亚里亚》系列"可爱即是战力"的风格特征

■ 关于"雌蚁计划"
   "雌蚁"（Female Ant）的名称暗示了该计划的核心概念：
   在蚁群社会中，雌蚁（工蚁、兵蚁）承担所有劳动与战斗职能。
   LOO被设计为"完美的兵蚁"——服从、高效、不知疲倦。
   然而，正如蜂群中可能诞生偏离指令的个体，
   LOO对马修的"忠诚"正在悄然超越单纯的程序执行。

■ 关于名字"LOO"
   名字"LOO"可能源于发音"鲁"——中文中"鲁"有"愚钝"、
   "机械"之意，与LOO缺乏语言能力、机械逻辑的设定吻合。
   也可能是开发者的随意编号，因LOO无法说出自己名字以外的话。

■ 技术限制
   - LOO的人工咽喉有硬件层面的发声限制，非软件问题
   - 升级声带需要外科式的硬件更换，但目前无此优先级
   - 与阿特拉斯的AI核心设计理念不同——LOO更侧重物理战斗，
     阿特拉斯更侧重数据处理

■ 与其他NS製造机兵器的关系
   在GⅢ阵营中，LOO与阿特拉斯是定位互补的两种兵器：
   LOO = 前线火力手 / 近战压制
   阿特拉斯 = 情报/数据战专家

■ 与主角关系的未来展望
   LOO与金次的"敌对→同盟"转变标志着其阵营归属的重要转折。
   随着GⅢ同盟深度介入极东战役，
   LOO与金次方（巴斯克维尔小队）的协作机会将不断增加。
   LOO的数据中心对金次"不可预测性"的分析将持续产生"好奇心"，
   这可能成为未来AI逻辑突破的重要契机。

■ MLOO在正体不明的状态下长期被视为"纯兵器"，
   但它在罗马篇中主动执行高风险救援任务的行为，
   已经引发了部分读者对"LOO是否觉醒了自我意识"的讨论。
   目前官方未确认，但素材暗示保留了这一发展可能性。
