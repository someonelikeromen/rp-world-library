                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 蓝帮 (Blue Gang / 九龙一带武侦黑社会组织) 最强战士
   - 称号: 九龙猴王 (Kowloon Monkey King)
   - 蓝帮城守护者 / 诸葛静幻直属战斗力
   - 本体: 不完全的绯绯神碎片 (孙) / 被绯绯神碎片寄生的人类少女 (猴)
   - 另称: 孙悟空 / 悟空

■ 人格状态（核心设定）
   猴/孙拥有同一具身体，但存在两套截然不同的人格意识：
   ┌─────────────────────────────────────────────────────────────┐
   │  【猴 (Monkey / サル)】                                    │
   │   ● 温和、天真、胆小（尤其怕野狗）                          │
   │   ● 能说日语，与金次直接交流                                │
   │   ● 意识到自己的身体被"孙"控制，对暴行感到恐惧和愧疚       │
   │   ● 希望有人能阻止孙                                        │
   │   ● 本质上是一个被绯绯神碎片寄生、无法控制自己身体的少女    │
   │   ● 被囚禁在蓝帮城地下牢房中，由自己主动请求关押            │
   └─────────────────────────────────────────────────────────────┘
   ┌─────────────────────────────────────────────────────────────┐
   │  【孙 (Sun / ソン)】                                        │
   │   ● 暴戾、好战、嗜杀，只会说中文（通过舔对方能复制语言）   │
   │   ● 是不完全的"绯绯神"碎片——绯绯色金之力的具现化            │
   │   ● 视金次为值得一战的对手，极度享受战斗的酣畅              │
   │   ● 使用如意棒的姿态如同齐天大圣孙悟空降世                  │
   │   ● 败北后承认金次的实力，具备战士的骄傲与磊落              │
   │   ● 随着剧情进展，与猴的界限逐渐模糊，体现出融合倾向        │
   └─────────────────────────────────────────────────────────────┘
   两者共享同一具少女躯体。切换人格时伴随明显的气质剧变——瞳孔、
   表情、语言乃至体态都会彻底改变。人格切换的触发机制不明确，
   但孙在感到战斗威胁或主动现战时会出现。

■ 年龄: 外表约14-16岁（实际不明 · 绯绯神碎片年龄概念模糊）
■ 身高: 约155cm（娇小少女体型）
■ 发色: 黑发（束成高马尾/双丸子头，带有传统中国武侠风格）
■ 瞳色: 黑瞳（孙显现时变为绯红色）
■ 服装: 经常穿着中国风战斗服（红色/金色基调，改良旗袍式样）
■ 喜欢: 战斗（孙）/ 金次的战斗能力（孙）/ 平静（猴）
■ 厌恶: 野狗（猴）/ 失败（孙）
■ 惯用手: 右

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 猴的人格特质 (表层/受支配人格)
   - 天真无邪：拥有与外表相符的少女心性，对世界充满好奇
   - 胆小怕事：尤其恐惧野狗——这一设定在严肃的追逐战中制造了令人印象深刻的
     反差喜剧效果（金次在粥店偶遇猴时，本已剑拔弩张，猴却因野狗出现而吓哭逃走）
   - 温顺顺从：对金次表现出近乎依赖的信任，主动告知自己身体的秘密
   - 自我认知清晰：明确定义自己是"被关在身体里的无用家伙"，
     对自己的无力感到痛苦
   - 善良本质：在蓝帮城牢中向金次提出"必死的作战方案"来解决孙，
     愿意牺牲自己来阻止绯绯神的暴走

■ 孙的人格特质 (深层/支配人格)
   - 战斗狂：将战斗视为最高乐趣，遇到强者（如金次）时会主动邀战
   - 纯粹武人：不依赖诡计，用纯粹的力量和技巧正面压倒对手
   - 磊落坦荡：败北后坦率承认"你赢了"，不抵赖不记仇
   - 暴戾但守规矩：在"死亡游戏"屋顶决斗中遵循一对一的武人规则
   - 对金次的独特欣赏：称金次的战斗能力为"好"——这是孙能给出的最高评价

■ 人格张力的戏剧价值
   猴/孙的双重人格不是简单的"善与恶"的二元对立，而是：
   - 被寄生者 (猴) 与 寄生意识 (孙) 的关系
   - 人类性 (猴) 与 神性/绯绯色金之力 (孙) 的对抗
   - 两千年传说（孙悟空神话）在当代（武侦世界）的再演绎
   - 这种张力的最终走向在后期的"同窗会联盟"行动中体现为融合——
     猴与孙学会共享力量而非相互压制

■ 精神成长曲线
   - Vol.12 (初登场)：纯粹的敌对战斗力，隶属于蓝帮的神秘战士
   - Vol.13 (香港偶遇)：猴的面纱揭开——温柔人格与寺庙对话，
     孙展现真面目——不完全的绯绯神
   - Vol.14 (蓝帮城决斗)：孙全力以赴后败北，承认金次；
     猴提出自我牺牲方案，被救；使用筋斗云协助金次
   - Vol.37 (印度篇)：猴/孙作为金次夺还小队成员，已从敌人转化为可靠队友，
     与卡邦克鲁进行武术对决
   - Vol.45+ (毕业篇)：作为support角色稳定存在，融入金次的人际网络

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、如意棒 (Ruyi Bang / 如意金箍棒)              │
│          —— 齐天大圣的传说武器在当代的再现        │
└─────────────────────────────────────────────────────┘

■ 形态
   - 金色金属长棍，长度可变（从短棍到长杖可调整）
   - 两端有金色箍圈装饰，中间刻有花纹
   - 与《西游记》中孙悟空使用的如意金箍棒完全对应

■ 应用模式

   [1] 近战打击 (直接棍术)
       特征：以超越常人的臂力挥舞如意棒，每一击都具备崩碎钢筋水泥的威力
       技巧：包括横扫、竖劈、戳刺、回旋等多变棍法
       威力：可一击击溃武侦级别的防御

   [2] 雷射发射 (雷射眼 / 如意棒炮击)
       特征：从如意棒一端或两端发射绯红色的高能量光束
       别名：剧情中被称为"雷射眼"或"如意棒雷射"
       威力：足以重伤GⅢ（远山金三），贯穿建筑结构
       蓄力：全力发射需要短暂蓄力时间，蓄力时金光凝缩于棒端
       金次对策：金次在最终战中用"矛盾"战术——以萨克逊剑的刀背缠刃迎击
                 雷射光束，利用金属气化吸收能量的原理延缓穿透，
                 配合亚莉亚一发子弹在胸前拦截残余光束

   [3] 伸缩突击 (如意棒的伸缩特性)
       特征：棒身瞬间伸长，进行出其不意的中距离突刺或横扫
       用途：追击、奇袭、扩大攻击范围

┌─────────────────────────────────────────────────────┐
│  二、筋斗云 (Jindouyun / 瞬间移动)                │
│          —— 缩地成寸的绝界桥                      │
└─────────────────────────────────────────────────────┘

■ 原理
   - 短距离空间跳跃能力，在剧情中被描述为"绝界桥"的一种
   - 能在有限范围内将自身（及触碰者）瞬间传送到目标位置
   - 在故事中被猴使用，证明这一能力更接近猴/孙作为"不完全绯绯神"的
     神通力，而非物理或科技手段

■ 实战应用
   - Vol.14 蓝帮城战结尾：猴使用筋斗云将金次与亚莉亚瞬间传送至
     西玛·哈里号油轮甲板，迎战魔女连队
   - 作用距离：至少能从维多利亚港的蓝帮城传送至油轮所在位置
   - 限制：能力并非无限使用，存在间隔/消耗限制

┌─────────────────────────────────────────────────────┐
│  三、超人体能 (猿猴之力)                          │
└─────────────────────────────────────────────────────┘

■ 身体能力
   - 远超常人的臂力、脚力、跳跃力
   - 可在建筑物之间自由跳跃穿梭（如同猿猴）
   - 在路面电车顶、百货公司内部、高速公路等场景展现高超机动性
   - 面对金次爆发模式的近战攻势能够正面对抗而不落下风

■ 格斗风格
   - 以如意棒为核心的棍术，融合了传统中国武术元素
   - 动作灵活迅捷，充分利用少女娇小体型的低重心优势
   - 孙的战斗风格凶猛直接，以压倒性力量碾压对手
   - 在Vol.37印度篇中与卡邦克鲁进行武术对决，展现高度适应性

┌─────────────────────────────────────────────────────┐
│  四、绯绯神之力 (不完全)                          │
└─────────────────────────────────────────────────────┘

■ 核心设定
   孙（Sun）是不完全的"绯绯神"——即绯绯色金（Hihiirokane）的
   半觉醒/碎片化意识体。绯绯色金是两千年前坠落地外的高维知性
   金属生命体（外星人），以"色金"为媒介展开多种能力和现象。
   孙是绯绯神的碎片之一——但并非完整的神格，仅为其中一片。

■ 与壳金七星的关系
   孙/猴与"壳金七星"系统中的第四枚壳金直接相关。
   诸葛静幻向金次交出第四枚壳金后，揭示了孙的真相：
   孙是这枚壳金所联系的绯绯神碎片。

■ 与白雪的色金杀女的关系
   猴在蓝帮城牢中向金次揭示了一个关键情报：
   星伽白雪体内的"色金杀女"（Irokane Korosume）正是
   绯绯色金的控制棒（停止/制动装置）。
   这意味着猴/孙的存在本质上受制于白雪——也意味着
   猴提出的"必死的作战方案"以白雪的色金杀女为核心。

■ 不完全性的含义
   - 孙无法达成绯绯神的完全觉醒（受限于身体和碎片数量）
   - 如意棒雷射的威力虽强，但不及完全体绯绯神
   - 双重人格本身就是不完全的体现——完整的绯绯神意志不会分裂

                  【背景故事 / Background】

■ 起源
   猴/孙的起源在故事中没有完全揭露，但可以推断：
   - 本体是一个少女（猴的人格），被绯绯神碎片（孙的人格）寄生
   - 这个碎片与壳金七星之一的第四枚壳金关联
   - 蓝帮·诸葛静幻掌握着第四枚壳金，并将猴/孙作为蓝帮的最强战力
   - 蓝帮利用孙悟空的神话形象在香港地下世界建立威慑

■ 香港蓝帮时期的战斗序列

   初战 —— 镜高菊代邸 (Vol.12)

   ├─ GⅢ"内脏回避"+"装死"勉强保住性命
   └─ 金次第一次见识超自然层面的敌人

   └─ 建立微妙的信任关系

   路面电车与百货公司激战 (Vol.13)
   ├─ 孙以猴的身份诱捕金次（"机娘"的少女包围网）

   ├─ 两人在香港岛路面电车顶、百货公司内展开激战
   ├─ 白雪暴走入黑雪状态用M60扫射
   ├─ 金次用"呼荡"催眠术安抚白雪后三人乘凯迪拉克逃逸

                  【人际关系 / Relationship Map】
================================================================================

■ 远山金次（远山キンジ）
   关系：曾经的敌人 → 认可的对手 → 信赖的战友
   评价（猴视角）："那个男生……他愿意听我说话。"
   评价（孙视角）："这个男人……很强。我认可他。"
   关键节点：
   - 寺庙对话：猴向金次敞开心扉
   - 屋顶决斗：孙全力战斗，败北后由衷认可
   - 油轮传送：猴主动帮助金次
   - 印度同行：作为小队成员与金次并肩作战
   备注：猴/孙对金次的态度，是故事中罕见的不含男女恋爱色彩、
          纯粹建立在"战士认可"和"被倾听的信任"基础上的关系

■ 星伽白雪（星伽白雪）
   关系：宿命克制关系 / 间接的救助者 / 控制棒持有者
   关键节点：
   - 蓝帮城牢中：猴揭示白雪的色金杀女是控制棒
   - 跳车救援：白雪用锁链镰刀救下跳车的孙
   - 黑雪暴走：白雪因目睹金次与孙战斗而不安暴走
   备注：白雪与猴/孙之间存在着色金层面的先天关联——
           色金杀女是绯绯神的控制棒，而孙是绯绯神的碎片

■ 神崎·H·亚莉亚（神崎·H·亜莉亚）
   关系：间接的战友 / 决胜关键
   关键节点：
   - 屋顶决斗：亚莉亚射出的子弹与金次的萨克逊剑配合，
     拦截了孙的全力如意棒雷射
   - 油轮共斗：孙/猴将金次与亚莉亚一同传送到油轮

■ GⅢ（远山金三）
   关系：初战的对手
   关键节点：
   - 在镜高菊代邸屋顶，孙以如意棒雷射击中GⅢ
   - GⅢ以"装死"和"内脏回避"保住性命
   备注：GⅢ是猴/孙在故事中第一个重伤的主要角色

■ 诸葛静幻（諸葛静幻）
   关系：蓝帮方面的上级 / 保护者
   关键节点：
   - 诸葛静幻是蓝帮在明面上的主事者，掌握第四枚壳金
   - 诸葛对孙/猴的能力有支配权，但也表现出对她的保护意图
   - 诸葛被眧眧们囚禁后，猴/孙失去外部控制

■ 眧眧四姊妹（猛妹·炮娘·狙姐·机娘）
   关系：蓝帮内部的协作关系 → 同僚政变
   关键节点：
   - 眧眧们是蓝帮的实战部队，与孙同为蓝帮战力
   - 眧眧们发动政变囚禁诸葛，利用蓝帮城发起"死亡游戏"
   - 眧眧们并非孙/猴的直属管辖关系

■ 卡羯·葛菈塞（厄水魔女）

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 被寄生的自我 vs 寄生的神性 / 人类意志 vs 色金宿命
成长弧光: 蓝帮战士 → 敌对强者 → 认可的对手 → 信赖的队友
象征意象: 孙悟空（中国神话的反叛英雄）、如意棒（力量与束缚）、
          双重人格（人类与神性的撕扯）

■ 作品定位
   - 《绯弹的亚里亚》中"超自然战力"的代表角色之一
   - 将中国古典神话《西游记》元素融入现代武侦世界的桥梁
   - 双重人格设定为故事提供了独特的叙事张力
   - 蓝帮香港篇的核心对手，也是金次面对的第一个"非人类级"敌人
   - 以"不完全的绯绯神"定位，解释了绯绯色金的更多面向

■ 独特的角色价值
   - 猴/孙是《绯弹的亚里亚》中唯一一个完整呈现"双重人格"设定的角色
   - 具有"被寄生者"和"寄生意识"的双重视角，丰富了色金世界观的深度
   - 与白雪的"色金杀女"构成色金世界观的重要情报拼图
   - 在从敌人转变为队友的过程中，展示了色金存在也可以成为伙伴的可能性

■ 与其他作品中的孙悟空形象的区别
   - 传统《西游记》的孙悟空：男性、英雄、反抗者、取经人
   - 《绯弹的亚里亚》的猴/孙：女性、被寄生者、不完全的神、
     从敌人变为伙伴——是对孙悟空传说的解构与再创作
