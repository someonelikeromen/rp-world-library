================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 阴沉寡言，不擅社交，总是试图避开麻烦
   - 口头禅：最想要的是"平稳的日常生活"
   - 看似冷淡、小物臭（胆小怕事），实则关键时刻绝不退缩
   - 有强烈的"平凡愿望"——不断申请转学到普通高中

■ 本质内核
   - 极度重感情，对伙伴（尤其亚莉亚、巴斯克维尔成员）有不可动摇的责任感
   - 自我牺牲倾向：多次独自承担危险，不愿牵连他人
   - 面对绝境时展现出超乎常人的冷静判断力与战术头脑
   - 内心温柔：对蕾姬、理子、阳菜等战妹有兄长般的守护
   - 矛盾体：既想逃避命运又无法坐视他人受苦

■ 对卒（女性恐惧症 / Gynophobia）
   - 远山家遗传的"色金武术"副作用——见到女性内衣、亲密接触或性相关刺激时会极度恐慌
   - 严重时可导致昏睡、流鼻血、言语不能
   - 爆发模式正是建立在这一体质的基础上
   - 随着故事进展，对特定女性（亚莉亚、蕾姬）的症状逐渐减轻

■ 精神成长曲线
   - Vol.1-4：被迫卷入事件的被动者 → 为亚莉亚第一次主动战斗
   - Vol.5-7：接受巴斯克维尔队长身份 → 建立团队意识
   - Vol.8-：主动面对大哥加奈、承担家族宿命
   - 毕业篇：从逃避命运的学生成长为守护他人的真正武侦

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、爆发模式（HSS: Hysteria Savant Syndrome）    │
│          —— 远山家代代相传的超常战斗状态          │
└─────────────────────────────────────────────────────┘

■ 原理
   - 通过性兴奋/情绪高涨触发肾上腺素+神经传导的极端加速状态
   - 远山家称为"色金武术"的核心 —— 与"绯绯色金"共鸣的遗传适应
   - 大脑进入超高速处理模式，身体能力飞跃性提升

■ 已确认的子模式

   [1] 标准爆发（Normal HSS / 通常爆发）
       触发条件：性兴奋（看到内衣、亲密接触等）
       效果：全能力×数倍，反射神经超加速，战术思考明晰
       特征：瞳孔放大，体表温度上升，战斗持续力有限
       弱点：时间短（约3-5分钟），过后极度疲劳

   [2] 狂怒爆发（Frenzy HSS / 狂怒爆发）
       触发条件：极度愤怒，保护重要之人的执念
       效果：战力约标准爆发×1.7倍
       特征：攻击性极强，容易失去冷静判断，但力量压倒性
       初现：Vol.8 天空树对华生之战

   [3] 垂死爆发（Deathbed HSS / 濒死爆发）
       触发条件：濒死重伤的极限状态下
       效果：超越常规限制的最终爆发
       特征：无视伤痛，仅靠意志驱动身体

   [4] 幻梦爆发（Visionary HSS / 幻梦爆发）
       触发条件：非性刺激，而是对未来的强烈意志/幻觉
       特征：更高维度的战斗直觉

   [5] 母性爆发（Materno HSS / 母性爆发）
       触发条件：将他人认知为"保护对象"（尤其母子关系）
       金次本人未觉醒此模式，由远山雪花觉醒
       相关：HSS的多样化分支

■ 代价与风险
   - 每次爆发后严重疲劳，深度睡眠数小时
   - 长期使用加速色金粒子对身体的侵蚀
   - 爆发中过度依赖可能缩短寿命（参照大哥加奈的早衰）
   - 对卒症状随HSS使用频率可能加重

┌─────────────────────────────────────────────────────┐
│  二、远山家秘传武术 · 色金武术体系               │
└─────────────────────────────────────────────────────┘

■ 远山五省（五件/五省/ごせい）
   远山家世代相传的五种战斗心法，核心为"色即是空"的武学哲学

   [1] 镜（镜 / Mirror）
       原理：将自身化为镜面，反射对方的攻击和战术
       应用：镜击（对方攻击瞬间以最小动作反射→衍生为以拳对拳的打击技）
       进阶：镜拳（双手组合反射式打击）、镜里（能力倍增术）

   [2] 空（空 / Void）
       原理：在绝境中创造空隙，以"无"破"有"
       应用：空手夺白刃、空手偏弹（徒手改变子弹轨道）

   [3] 螺旋（螺旋 / Spiral）
       原理：利用旋转/离心力产生不可预测的弹道变化
       应用：空手偏弹·螺旋版（改变子弹轨迹使其绕过障碍物）

   [4] 扇（扇 / Fan）
       原理：广范围散射攻击，一撃多方向覆盖
       应用：扇贯（穿透性广域攻击）

   [5] 樱花（樱 / Sakura）
       原理：牺牲右臂防御，将全部力量集中于超音速一击
       应用：樱花一击（右臂超音速直拳，代价为右臂暂时/永久损伤）
       初现：Vol.5 对夏洛克·福尔摩斯

■ 进阶奥义
   - 天拋 · 绯绯星伽神（天抛 · 绯绯星伽神）:
     远山家最高位的奥义之一，结合爆发模式的极秘技
   - 秋花/秋草/秋水:
     远山雪花使用的别系远山术，与金次的"镜"系互补

┌─────────────────────────────────────────────────────┐
│  三、其他战斗能力                                 │
└─────────────────────────────────────────────────────┘

■ 火器使用
   - 强袭科出身，枪械操作基础扎实
   - 通常携带：
     · 自动手枪（型号随剧情变化）
     · 近战武器（必要时使用）

■ 战术指挥
   - 巴斯克维尔小队的实际队长
   - 擅于利用队友特性进行"王车易位"式战术配置
   - 在紧急情况下展示优秀的临场指挥能力
     （例：Vol.1 飞机迫降指挥、Vol.7 新干线劫持的五人联合作战）

■ 体能
   - 强袭科S级实力底子，基础体能远超普通高中生
   - 爆发模式下可攀爬101大楼外墙（Vol.45 台北101）
   - 长跑耐力优秀（Vol.45 羽田→东大22公里跑步）

■ 弱点
   - 对卒严重影响日常战斗（特定条件下完全失去战斗力）
   - 爆发模式有严格时间限制
   - 近战纯体力逊于纯近战型对手（依赖HSS补正）

   - 亚莉亚是金次最重要的搭档和恋人，但最终未结婚
   - 远山家的"G编号"对应色金武术的世代序数
   - 对卒虽名为"病"，实为色金武术过度适应的副作用

■ 关于"对卒"的补充
   - 严格名称：色金粒子过敏症（色金粒子過敏症）
   - 不仅是单纯女性恐惧症，更是身体对色金能量的应激反应
   - 爆发模式是利用这种应激反应反向驱动

■ 远山家名称体系
   - 远山家的男性以"金"+"数字/代称"命名
   - 金次 = GⅡ（第二子）← 但父亲是金叉（GⅡ同名冲突）
   - 金一 = GⅠ
   - GⅢ = 远山金三
   - GⅣ = 远山金女
   - GⅤ = 远山金天
   - G零式 = 远山铁（祖父）
