================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 聪慧早熟：因人工天才的教育背景，展现出远超年龄的知识水平
   - 天真烂漫：本质上仍是10岁的小女孩，保有儿童的纯真
   - 乖巧懂事：作为最小的妹妹，努力不给哥哥姐姐添麻烦
   - 好学好问：在松丘馆与金次一起补习时认真投入

■ 本质内核
   - 对家族的深爱：尽管是被制造出来的"人工天才"，但对自己的兄弟姐妹
     有着真挚的依赖与爱。被救出后第一次真正体验了"家族"的温暖
   - 孤独的恐惧：作为实验体长期被隔离在高尾基地，内心深处渴求亲情
   - 坚韧意志：被追捕时不哭不闹，展现出远超年龄的冷静
   - 巨大的适应力：从实验体到普通小学生的身份转换中表现出惊人的柔韧性

■ 特殊体质——反色金（Anti-Ryūryū Color Gold / 反琉琉色金）
   - 体内寄宿着人工制造的琉琉色金（反色金）
   - 这是美国军方"第二世代人工天才"计划的核心成果
   - 反色金具有中和/对抗天然色金（绯绯色金等）的潜力
   - 也是尼莫（列库忒亚女神）能够附身金天的媒介

■ 精神成长曲线
   - Vol.27以前：作为实验体被隔离在高尾基地，缺乏家庭温暖
   - Vol.27：被远山五兄妹联合救出，首次体验兄弟姐妹的爱
   - Vol.27-28：适应普通生活，进入松丘馆与金次一同学习
   - Vol.28-：作为远山家最小的妹妹被整个家族守护与疼爱

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、超能力：血缘感知 (Bloodline Sense)          │
│          —— 感知血缘者位置与状态的天赋能力       │
└─────────────────────────────────────────────────────┘

■ 原理
   - 与生俱来的超感知能力
   - 可感知具有相同血脉（远山家血统）者的位置和大致状态
   - 感知精度随血缘亲密度而变化

■ 能力表现
   [1] 位置感知
       范围：远距离（具体范围未设定上限）
       精度：可定位到大致区域/方向
       案例：在金次与远山五兄妹行动中提供关键定位情报

   [2] 状态感知
       可感知血缘者的健康状况、精神状态、战斗状态
       可能感知到加奈（金一）的早衰程度（文献暗示）

   [3] 局限性
       对"人工色金"（反色金属于人工琉琉色金）的感知不完全
       无法区分过于强大的超自然干扰（如被尼莫附身时自身感知中断）

┌─────────────────────────────────────────────────────┐
│  二、反色金 / 琉琉色金（Anti-Ryūryū Color Gold）│
│          —— 人工制造的色金对抗素               │
└─────────────────────────────────────────────────────┘

■ 来源
   - 美国军方"第二世代人工天才"计划制造
   - 远山金叉从美国带回的"秘密武器"
   - 属于人工合成琉琉色金，与天然绯绯色金（星伽家守护）性质相反

■ 特性
   [1] 对抗性
       可以中和或抑制天然色金的力量
       这使金天成为"色金对抗者"——唯一能在色金体系中保持免疫的存在

   [2] 附身媒介
       反色金同时也是超自然力量的传导媒介
       列库忒亚七女神之一的尼莫可通过反色金附身金天
       （Vol.27 尼莫附身金天，操纵云雾隧道，派出飞龙）

   [3] 能量波动
       反色金的存在会产生独特的能量波动
       可以被特定的感知者（如ZⅡ、星伽白雪等）追踪

┌─────────────────────────────────────────────────────┐
│  三、天才智力                                 │
│          —— 人工天才的教育成果               │
└─────────────────────────────────────────────────────┘

■ 学术能力
   - 作为第二世代人工天才，接受了远超年龄的教育
   - 在松丘馆与金次一同补习时展现了优秀的学习能力
   - 茶常老师评价：学习态度端正，理解力超群
   - 虽然是小学生却能跟上高中备考生的学习节奏

■ 实践能力
   - 可能接受了基础的自保训练
   - 在危机时刻能保持冷静，不胡乱哭闹
   - 善于观察和理解周围状况

■ 弱点
   - 反色金可能对身体健康有未知影响
   - 易被超自然存在（如尼莫）附身利用
   - 年龄过小，物理战斗力近乎零

   - 金天的登场（Vol.27）标志着远山家"第二代人工天才"线的正式展开
   - 别名"奏"（Sō / Kanade）在部分资料中出现
   - 金天与蕾姬之间没有直接互动记录

■ 关于"第二世代"的补充
   - 第一世代：GⅢ、GⅣ（直接使用金叉DNA制造）
   - 第二世代：GV（金天）、ZⅡ等（在第一世代基础上改良）
   - 第二世代的特点：增加了超能力要素（而非仅限色金武术）
   - 反色金是第二世代的核心创新——从"利用色金"转向"中和色金"

■ 远山家名称体系
   - G零式 = 远山铁（祖父）
   - GⅠ   = 远山金一 / 加奈
   - GⅡ   = 远山金叉（父亲）+ 远山金次（次子，同名冲突）
   - GⅢ   = 远山金三（三子，人工天才）
   - GⅣ   = 远山金女（四女，人工天才）
   - GⅤ   = 远山金天（五女，第二世代人工天才）

■ 金天在作品中的功能
   - 叙事功能：为远山五兄妹的集结提供契机
   - 世界观功能：展示"反色金"这一色金体系的对立要素
   - 角色功能：让金次展示"兄长"一面（不同于对亚莉亚等同辈的态度）
   - 超自然功能：作为尼莫附身的媒介，连接列库忒亚世界
