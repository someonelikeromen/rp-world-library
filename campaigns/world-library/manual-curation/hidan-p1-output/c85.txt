                   【人物特质 / Personality Profile】

■ 双重人格结构

   [1] 远山金一（男体 / 基础人格）
       特征：沉默寡言、严肃、正义感极强
       日常状态：不太说话，举止沉稳，对家人极度保护
       战斗状态：被称为"寂静之鬼"——冷静、专注、毫不留情
       外形：男性状态时穿着便服或战斗装，不使用女装
       初现：vol-04（从休眠醒来，未变装为加奈时）

   [2] 加奈（女体 / HSS变装人格）
       特征：绝世美女，温柔优雅，声音甜美，举止高贵
       核心信念："以义为生，讨伐巨恶"——远山家的天命
       战斗风格：华丽而致命，使用大镰刀蝎尾、不可视子弹
       独特现象：化身加奈时完全认为自己就是"加奈"，不承认是远山金一
       sourceRef: vol-04（"当大哥彻底化身成绝世美女·加奈时，他会不知道'大哥'就是在指他自己"）

       备注：金次评价——"变装成绝世美女的手法姑且不论，这位加奈能够将远山家代代相传的
       爆发模式发挥得淋漓尽致，我总是憧憬着她的高洁和强韧"（vol-04）

■ 人格切换机制
   - 通过女装变装 + HSS爆发模式触发双重切换
   - 加奈状态 = 爆发模式常驻状态
   - 解除爆发模式 = 回到金一状态
   - 加奈有部分记忆与金一共享，但很多"加奈"经历的事情她并不当做自己的记忆
   - sourceRef: vol-27（"但因为是'加奈'这个人格是后来才诞生，所以有很多事情她并没有认识为是自己的记忆"）

■ 表层性格（作为加奈）
   - 温柔优雅，如圣母般的慈爱
   - 说话爱引用圣经章节（"出埃及记三十二章二十七节"等）
   - 不会向贫困者收取报酬，甚至会自掏腰包帮助
   - 有海外医师执照，在贫困地区建医院
   - 对家人（尤其弟弟们）极端保护
   - 战斗中绝不杀害对手（零死亡原则）
   - 每次任务从不失手，与加奈共同奋战的武侦从无人阵亡
   sourceRef: vol-04（"与加奈共同奋战的武侦，从来没有人阵亡过"）

■ 本质内核
   - 至高的正义感：不惜以假死、卧底、自我牺牲来实现正义
   - 深沉的家族爱：是所有弟妹的守护者，尤其对金次
   - 完美主义的负担：追求零伤亡、零失败，承受巨大压力
   - 牺牲精神：假装死亡、潜入伊·U、甚至故意被夏洛克狙击濒死
   - 孤独的英雄：独自承担黑暗，不让弟弟们卷入

■ 精神成长曲线
   - 幼年：学习色金武术，继承远山家正义理念
   - 武侦时代：成为传奇特命武侦，零死亡、零失败
   - 假死期（vol-1前）：假装海难死亡，潜入伊·U
   - Vol.3-5：以加奈身份回归，与金次对立 → 被夏洛克狙击濒死 → 垂死爆发
   - Vol.7-18：极东战役中立 → 协助对抗绯绯神
   - Vol.30-45：与佩特拉结婚 → 成为父亲 → 保护家庭

                 【能力全析 / Ability Analysis】

┌─────────────────────────────────────────────────────┐
│  一、爆发模式（HSS: Hysteria Savant Syndrome）    │
│        —— 远山家首屈一指的爆发模式掌控者        │
└─────────────────────────────────────────────────────┘

■ 原理
   - 与远山金次相同的HSS遗传，但掌控程度远高于金次
   - 加奈状态下可"常驻爆发模式"——这是远山家史上罕见的 feat
   - sourceRef: vol-04（"加奈能够一直处于爆发模式"）

■ 确认的子模式

   [1] 常驻爆发（加奈模式）
       触发条件：变装为女性人格"加奈"
       效果：长期维持爆发状态，全能力×数倍
       特征：这是加奈最独特的能力——别人只有几分钟的爆发，她能维持数天
       弱点：爆发结束后需要长达十天左右的"睡眠期"来恢复
       sourceRef: vol-04（"大哥进入爆发模式时会完全变成加奈的人格" / "维持爆发模式下……事后必须藉由超长时间的睡眠来统一进行恢复"）

   [2] 垂死爆发（Agonizante HSS）
       触发条件：濒死重伤时
       效果：在心脏中弹、生命垂危的状态下仍能继续战斗
       特征：无视致命伤，以意志力驱动身体完成目标
       初现：vol-05（被夏洛克·福尔摩斯的A-TNK弹击中心脏后）
       sourceRef: vol-15（"加奈，也就是金一曾经展现过、濒临死亡的时候会发作的'垂死爆发'"）

■ 代价与风险
   - 每次加奈模式后需要"为期十天左右的睡眠期"（vol-04）
   - 长期维持HSS对神经的过载，可能与远山家的"对卒"有关
   - 战斗中寿命损耗的风险（金次多次担忧加奈的寿命）

┌─────────────────────────────────────────────────────┐
│  二、加奈专属战斗体系                             │
└─────────────────────────────────────────────────────┘

■ 武器：大镰刀·蝎尾（Scorpio / 蝎尾）
   类型：铬合金蛇腹式大镰刀
   收纳：藏于加奈的麻花辫之中（25块零件组合）
   结构：包含握柄在内的25块零件宛如蛇腹剑般组合
   攻击范围：177.7cm（自加奈为中心的有效攻击距离）
   特征：
     - 平时分解藏在辫子中（vol-18: "从她那长长的麻花辫中，出现了许多暗夜蓝色的金属片"）
     - 瞬间组合成完整大镰刀
     - 可单手挥舞或以手指微操驱动高速旋转
     - 可以像跳绳二回旋的速度在周身划出球形防卫网（vol-04: "大镰刀则用比跳绳的二回旋还要更快的速度，
       在加奈身旁划出了轨道。弯刀方向不定，时而直横斜，时而前后上下，化身成了球形保护罩"）
     - 可用镰刀摩擦地面，让沙石像子弹一样射出（vol-04: "加奈立刻用镰刀摩擦地面发出声响，
       让些许飞起的沙金像子弹一样射向佩特拉"）
   sourceRef: vol-04, vol-10, vol-18, vol-26, vol-39

■ 武装：熏银色柯尔特·和平制造者（Colt Single Action Army）
   类型：单动式左轮手枪
   外观：熏银色处理，经典西部风格
   相关：加奈的招牌枪械，曾在vol-04展示超高速换弹技巧"空中装弹"
   sourceRef: vol-04（"落地的加奈手中，拿着一把熏银色的柯尔特·和平制造者"）

■ 不可视子弹（不可視の弾丸）
   原理：超高速拔枪射击，快到肉眼无法捕捉拔枪、瞄准、击发的整个过程
   特征：只能看到枪口焰和听到枪声，看不到子弹轨迹和出枪动作
   效果：对手无法反应、无法防御、无法反击
   应用：加奈用这招击败过无数凶恶罪犯，也曾在武侦高中强袭科用此招压制亚莉亚
   sourceRef: vol-04（"加奈用这招打倒过许多凶恶的罪犯，现在她也对我这个弟弟，使出了同样的招式" / "没人看见加奈的攻击……加奈所做的，仅是晃动长长的麻花辫，转头一望罢了"）

■ 樱吹雪（全方位大镰技）
   原理：以超音速向四面八方挥动大镰刀，将四周所有东西都破坏掉的全方位攻击
   特征：极其华丽的广域歼灭技，破坏力惊人
   备注：金次评价——这招带有很强的攻击性，与加奈温和的个性形成对比
   sourceRef: vol-40（"个性明明很温和的加奈，之所以都使用像'不可视子弹'或'樱吹雪'……"）

■ 大镰刀球形防卫网
   原理：以大镰刀超高速围绕自身旋转，形成全方位防御球幕
   应用：对佩特拉战时展示，防御所有接近的攻击
   sourceRef: vol-04, vol-26（"基于这点，对于加奈和佩特拉交手时把大镰刀在自身周围挥甩所产生的球形防卫网"）

■ 空中装弹
   原理：在空中完成左轮手枪的装弹动作，即使在跳跃或后空翻中也能完成
   特征：如魔术般的技巧
   条件：只有在爆发模式下才使得出来
   sourceRef: vol-04（"空中装弹。大哥是如此称呼这招有如魔术般的技巧，只有在爆发模式下才使得出来"）

■ 条理预知（不完全）
   原理：基于超高速推理达成类似于预知未来的分析能力
   特征：不完全但极强，类似于夏洛克·福尔摩斯的"条理预知"
   应用：能够预判对手的行动模式
   sourceRef: vol-11（"加奈，你的条理预知还真了不起啊" / "我的能力并不完全，只能算是推理的范围罢了"）

■ 罗刹（必杀技）
   原理：击打敌人胸口，使其心脏震荡当场死亡
   特征：远山家凶残招式之一
   警告：加奈/金一通常不使用此招（因零死亡原则），但知道使用方法
   sourceRef: vol-40（"有一招击打敌人胸口，使其心脏震荡当场死亡的叫'罗刹'的必杀技"）

┌─────────────────────────────────────────────────────┐
│  三、远山家秘传武术 · 色金武术体系               │
└─────────────────────────────────────────────────────┘

   作为远山家GⅠ（长子），加奈/金一掌握全部远山五省。
   但加奈的武术风格具有强烈的个人特征——由于她的招式源自金一时代（尚未学会加奈变身时）
   学到的格斗技，因此具有更强的攻击性。

■ 远山五省继承情况：
   加奈/金一为远山家中将五省掌握最全面的成员之一
   - 镜：以拳对拳的反射式打击（金次在台北101对赵云的"镜拳"即继承自加奈教导）
   - 空：空手夺白刃/偏弹
   - 螺旋：子弹轨道变化
   - 扇：广范围散射
   - 樱花：超音速一击（加奈可能懂得比金次更多的樱花变体）

   金次曾表示："加奈是我见过最强的武侦。"

      不愧是我老婆，这体力真是惊人。"

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 光与影 — 以黑暗手段（卧底/欺骗/假装死亡）来维护光明（正义/家族）
成长弧光: 孤独的正义使者 → 家族的一员（结婚生子）
象征意象: 蝎尾（致命而美丽）、圣经（信仰与正义）、麻花辫（隐藏的致命武器）

■ 作品定位
   - 远山家战斗力天花板（与金叉并列为"寂静之鬼"级别）
   - 伊·U篇的核心推动者（假死卧底的布局者）
   - 金次的精神导师与最终超越的目标
   - 全作最复杂的双重人格角色（加奈/金一）

■ 在作品主题中的位置
   - 代表"正义的极限"——愿意为正义牺牲到什么程度
   - 金次成长的关键参照系：从追随大哥到超越大哥
   - "色金"传承的活体教科书——远山五省的最佳诠释者

■ 加奈的美学
   - 穿着女装但不显得滑稽——赤松中学用"绝世美女"来定义
   - 战斗风格优雅而致命——大镰刀与左轮手枪的结合
   - 圣经引用赋予角色圣洁感——像一位战斗修女/圣母
   - 麻花辫成为最具识别度的角色特征

              【档案备注 / Archive Notes】
================================================================================

■ 关键事实确认
   - 远山金一与加奈是同一人物的双重人格，"金一"是男体本名，"加奈"是HSS驱动下的女性变装人格
   - 加奈的人格是基于母亲的外貌和性格为蓝本创造的（vol-27）
   - 加奈与佩特拉结婚，育有一女远山塞特（vol-45）
   - 金次在vol-11中提到："至今为止我从来没有赢过'加奈'。就算现在跟她打，我也一点都没有可以获胜的自信"
   - 加奈在罗马武侦高中留学过，结识了梅雅·罗曼诺

■ 关于加奈/金一的命名
   - 金一（Kin-ichi）= GⅠ = 远山家第一子
   - "金"字训读为Kana，"加奈"即为Kana的对应汉字
   - 加奈的读音Kana是"金"的训读（vol-10有对应说明）

■ 关于G编号体系
   - GⅠ = 远山金一（加奈）
   - GⅡ = 远山金次（主角） + 远山金叉（父亲，同名冲突）
   - GⅢ = 远山金三（美军武侦）
   - GⅣ = 远山金女
   - GⅤ = 远山金天

■ "阎"的别名
   - vol-45提及加奈/金一别名"阎"（En），与众多强敌并列在金次回忆中
   - "阎"可能源自阎魔（死神），呼应加奈使用大镰刀的处刑人形象
   - 但也可能在后期剧情中有其他含义

■ AA外传中的表现
   - 加奈/远山金一在AA外传中未有直接登场记录

■ 关于加奈武侦时代的装备
   - 武侦高中女生制服（vol-04首次正式登场时穿）
   - 防弹长外套+绑带半统靴（vol-07极东战役）
   - 札幌武侦高中红色水手服（vol-34家族旧物）
   - 战斗状态会佩戴麻花辫发饰，辫子末端藏蝎尾镰刀
