                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 高阶九尾狐（高次元妖怪 / 高位灵格持有者）
   - 星伽神社的协助者 / 巫女导师级存在
   - 「师团」（Regiment / 极东战役正义侧联盟）的核心情报与战略顾问
   - 天狐评议的执掌者——拥有超常的情报搜集与分析能力
   - 与星伽家拥有跨越数百年的渊源

■ 所属
   - 星伽神社（京都星伽分社 / 星伽本家）
   - 师团（Regiment）——极东战役（FEW）正义方联盟
   - 非武侦系统成员——属于超自然侧的高位存在

■ 种族: 九尾狐（九尾の狐 / Nine-tailed Fox）
   - 极高位的妖兽/精灵存在
   - 拥有数百年的寿命与阅历
   - 在日本神怪体系中与稻荷信仰有深层关联
   - 灵力/妖力远超普通妖怪

■ 年龄: 不明（推测数百岁以上——与星伽家的渊源跨越数代）
■ 身高: 未公开（推测中等身材，成熟女性体型）
■ 发色: 未明确定义（但暗示为狐属性的传统发色——银白或淡金）
■ 瞳色: 未明确定义（推测为狐系的金色或琥珀色）
■ 外貌特征:
   - 九尾狐本体形态：拥有九条尾巴的巨大妖狐
   - 人形态：穿着巫女装束或和服的知性美女
   - 常与星伽神社的巫女们一同出现
   - 具有非人的威压感和神秘气质
   - 尾巴数量（九尾）是力量等级的象征
■ 特长:
   - 天狐评议（超常情报搜集与占卜/预知能力）
   - 高精度战略分析
   - 色金相关知识（对色金体系有极深理解）
   - 灵力/妖术（结界、净化、附魔等）
   - 巫术指导（指导星伽白雪等巫女运用灵力）
■ 喜欢: 维护人妖平衡、指点后辈、平静的观测
■ 厌恶: 恶意破坏平衡者（如N组织/眷属）、色金的滥用
■ 惯用手: 不明

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层形象：沉静的神秘智者
   - 从不主动参与前线战斗，却始终在幕后运筹帷幄
   - 说话方式沉稳、含蓄，偶尔带有居高临下的长者语气
   - 对重要信息只选择性透露，保持一定的神秘感
   - 在师团会议中提出关键策略时语气平淡但分量极重
   - 与人类保持一定的距离感，但内心对人类（尤其是星伽家）极为关切

■ 本质内核：数百年阅历的守护者
   - 作为九尾狐，她的生命跨越了数个世代
   - 亲眼见证过无数次人类的战争与和平
   - 星伽家是她少数愿意倾力守护的存在
   - 对色金体系的理解远超普通人类武侦
   - 在极东战役中，她选择站在「师团」一方，
     并非因为对人类命运的同情，而是出于对更大平衡的维护
   - 深知绯绯色金、琉琉色金、璃璃色金三姐妹的本质
   - 对亚莉亚的绯绯神化发出最终警告，展现了她
     对色金威胁的深刻洞察力

■ 性格特征
   - 智者风范：不直接战斗，而是在关键节点给出致命一击的建议
   - 含蓄深沉：从不轻易展现全部实力——她的真实能力仍是谜
   - 守护者姿态：对星伽家的巫女们有类似母亲或老师的情感
   - 战略眼光：在师团会议中提出拉拢GⅢ/GⅣ的策略，
     展现了对全局的精准把控
   - 天狐的威严：虽平时沉稳，但涉及关键原则时
     会展现出不容置疑的威压感
   - 隐世立场：她更像一个观察者和引导者，
     而非直接参与者——符合九尾狐的传统形象

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、天狐能力体系                                │
└─────────────────────────────────────────────────────┘

■ 天狐评议（SSS级——绯弹世界观顶级情报能力）
   - 玉藻的核心能力：通过天狐特有的神通力
     搜集和分析全世界的超自然情报
   - 在Vol.13（反击的九龙）中，金次正是基于
     玉藻的天狐评议情报，决定主动出击香港蓝帮
   - 评议内容涵盖香港蓝帮的势力分布、
     孙悟空（猴/孙）的所在位置、
     蓝帮与N组织的关联等
   - 情报精度远超高天原佑彩等人类的情报系统
   - 推测能够跨越地域甚至次元的限制获取信息
   - 天狐评议的情报来源是玉藻特有的神通，
     不属于任何武侦技术体系

■ 色金相关知识（SSS级）
   - 对绯绯色金、琉琉色金、璃璃色金三姐妹
     的本质和相互关系有深刻理解
   - 比大多数人类更早预见到亚莉亚的绯绯神化
   - 在Vol.17中，亚莉亚长出犄角后，
     玉藻是第一个给出明确警告的人——
     「亚莉亚即将绯绯神化，期限至3月31日」
   - 知道色金杀女（反相位兵器）的原理和作用
   - 理解琉琉色金和璃璃色金之间的制衡关系
   - 对金色金（绯绯色金之母）的存在也有认知
   - 对「接轨」（Engage）现象和列库忒亚
     异世界的存在有一定了解

■ 灵力/妖术（SS级）
   - 高次元妖怪的天然灵力储备
   - 能够施展结界术、净化术
   - 在Vol.33中帮助远山雪花度过「杀刻」
     （存在劣化症候群）的高烧危机——
     与白雪、伏见等巫女一同以灵力稳定雪花的存在
   - 拥有跨越数百年的灵力修行和积累
   - 对日本神道教的咒术体系极为熟悉

┌─────────────────────────────────────────────────────┐
│  二、战略指导能力                                │
└─────────────────────────────────────────────────────┘

■ 师团战略参谋（S级）
   - 在Vol.10（禁忌的双极）的师团会议上，
     玉藻提出将GⅢ和GⅣ拉拢为师团成员的策略
   - 这一策略直接导致金次被指派「罗密欧任务」
     ——色诱GⅣ（远山金女）
   - 该策略最终成功地将GⅣ从敌对阵营转化为
     巴斯克维尔小队的盟友
   - 展现了她在复杂多方博弈中的精准判断力
   - 她知道何时该主动出击、何时该静观其变

■ 巫女指导（A+级）
   - 对星伽白雪有直接的灵力指导
   - 白雪的色金杀女运用正是在玉藻的指点下
     获得突破性成长
   - 与星伽风雪、星伽粉雪、星伽华雪等
     星伽家巫女也有交集
   - 推测对其他星伽分社的巫女也有教导关系

┌─────────────────────────────────────────────────────┐
│  三、战斗能力（推测）                            │
└─────────────────────────────────────────────────────┘

■ 本体战斗力
   - 九尾狐本体被认为拥有极高的战斗力
   - 但作品中从未展现玉藻直接参战的场景
   - 符合「军师不临前阵」的传统定位
   - 推测其真实战斗力至少等同于甚至超过
     大多数人类S级武侦

■ 妖术战斗
   - 推测擅长狐火、幻术、结界等传统狐妖法术
   - 能够以灵力干涉实体的程度不明
   - 在极东战役中，她的价值在于头脑而非肉体战斗力

■ 事件一：师团会议的策略提案（Vol.10 禁忌的双极）
   角色：战略参谋 / 军师
   内容：
   - 巴斯克维尔小队全员被GⅣ击溃，重伤入院
   - 金次和华生救出众人后，召开师团会议
   - 玉藻提出将GⅢ和GⅣ拉拢为师团成员的策略
   - 金次被指派「罗密欧任务」——通过色诱GⅣ
     将其转化为己方阵营
   - 这一策略最终成功，GⅣ（金女）从一个敌人
     变成了巴斯克维尔小队的重要盟友
   意义：
   - 这是玉藻作为战略参谋能力的首次核心展示
   - 证明了她对复杂局势的精准判断力
   - 「拉拢而非消灭」的策略体现了她的智慧
     ——不浪费战力而是转化战力
   - 这一策略改变了全系列的力量格局

■ 事件二：天狐评议情报提供（Vol.13 反击的九龙）
   角色：情报提供者 / 天狐评议执掌者
   内容：
   - 金次为应对蓝帮威胁，寻找孙悟空（猴/孙）
   - 玉藻的天狐评议提供了关键情报：
     ① 蓝帮在香港的势力分布
     ② 孙悟空（猴/孙）的具体位置
     ③ 蓝帮与N组织的关联信息
     ④ 诸葛静幻的实际立场
   - 基于这些情报，金次决定利用校外教学
     作为掩护前往香港
   - 香港编的整个作战路线基于玉藻的情报
   意义：
   - 天狐评议展现了超越人类情报网的信息获取能力
   - 玉藻的情报直接决定了主要角色们的行动方向
   - 这是她「天狐」能力最具象化的展示
   - 证明了她在不直接参战的情况下
     对局势的掌控力

■ 事件三：绯绯神化警告——3月31日的最终期限（Vol.17 绯弹的宣叙曲）
   角色：命运预言者 / 色金体系的洞察者
   内容：
   - 亚莉亚在武侦战友会的宴席上突然晕倒
   - 身体开始出现异变——长出鬼族的犄角
   - 金次救出被软禁的亚莉亚后，二人在温室重逢
   - 亚莉亚向金次展示犄角，二人重新立约
   - 此时玉藻出现，以极其严肃的口吻警告：
     「亚莉亚即将绯绯神化，期限至3月31日」
   - 这一警告直接推动了后续金次与亚莉亚
     的仓促行动
   - 理子随后承担假扮亚莉亚的掩护任务
   - 金次带亚莉亚回老家见祖父母、拜访大哥
   - 最终在乃木坂的公寓中绯绯神觉醒
   意义：
   - 这是玉藻对色金威胁最直接的一次表达
   - 「3月31日」的期限设定改变了故事的节奏
   - 她对绯绯神化的理解和预判远超常人
   - 展示了玉藻作为「观察者」角色的另一面
     ——必要时会站出来直接警告
   - 她对亚莉亚没有敌意，而是站在更高维度
     进行命运干预

■ 事件四：灵力协助远山雪花度过杀刻（Vol.33 花冠的归国兵）
   角色：灵力协助者 / 星伽体系的一员
   内容：
   - 远山雪花从异世界列库忒亚归来后
   - 遭遇「杀刻」（存在劣化症候群）高烧危机
   - 玉藻与白雪、伏见等巫女共同协力
   - 以灵力帮助雪花稳定因时空穿越而动摇的存在
   - 三人（玉藻、白雪、伏见）作为巫女组
     成功使雪花度过杀刻
   - 雪花随后逐步接受了日本战败的现代世界
   意义：
   - 这是玉藻灵力能力的稀有展示
   - 与白雪、伏见合作，展现了巫女体系的协作性
   - 帮助雪花度过危机为她后续的活跃奠定了基础
   - 展现了玉藻在人类需要时伸出援手的姿态

                  【角色定位 / Character Positioning】
================================================================================

■ 在系列中的功能定位
   - 超自然侧的智慧化身：九尾狐是日本传统妖怪中
     最顶级的智慧存在，玉藻完美承载了这一意象
   - 师团的大脑：在极东战役中，玉藻提供的不只是
     情报，更是战略层面的决策支持
   - 色金体系的阐释者：她对绯绯色金三姐妹的认知
     比人类角色更深——她是色金真相的钥匙之一
   - 星伽家的守护者：跨越数百年的渊源使她成为
     星伽家最可靠的盟友和指导者
   - 命运的观测者：她不直接改变命运，而是在
     关键的节点给出不得不听的警告

■ 作为「非人智者」的典型性
   玉藻是绯弹系列中少数非人类的高位存在之一。
   与人类角色不同，她拥有数百年的寿命积累的智慧，
   对色金、接轨、异世界等超自然现象的理解远超普通武侦。
   她的存在提醒读者：绯弹的世界观不仅有武侦和人类科技，
   还有古老的妖怪、神明和超自然力量。

■ 关于九九藻的关系推测
   九九藻（登场较早，年龄较小的狐系角色）
   与玉藻共享「藻」字，暗示两者同属狐族体系。
   推测九九藻是玉藻的直系后辈、弟子或同族，
   但实力和位阶远低于玉藻的九尾。

■ 与日本传统玉藻前的关系
   角色名「玉藻」直接致敬了日本三大妖怪之一的
   「玉藻前」（九尾狐的传说化身）。
   绯弹系列中的玉藻同样拥有九尾和超常智慧，
   但被赋予了更现代的「天狐评议」「师团参谋」
   等角色功能，是传统与现代的融合。

                【主题关键词 / Thematic Keywords】
================================================================================

核心定位: 高阶九尾狐 / 师团智囊 / 星伽家指导者
角色象征: 古老的智慧 / 平衡的守护者 / 命运观测者
主题意象: 九尾的白狐 / 星伽神社的黄昏 / 天狐评议的灵光

■ 作品定位
   - 绯弹的亚里亚中最具代表性的超自然智慧型角色
   - 「旁观者清」——她不直接卷入战斗，却看得最透彻
   - 代表了日本传统妖怪在现代武侦世界中的生态位
   - 从第八卷的师团会议到第十七卷的绯绯神警告，
     她的每次登场都在关键的决策时刻

■ 与白雪的关系定位
   - 白雪是星伽家的当代巫女代表
   - 玉藻是她背后跨越数百年的指导者体系
   - 这种关系暗示了星伽家并不仅仅是一个现代神社，
     而是一个拥有古老传承和超自然盟友的庞大体系
   - 玉藻对白雪的影响是含蓄而深远的
     ——她不直接教招数，而是指点方向

■ 角色存在意义总结
   玉藻是《绯弹的亚里亚》中最为神秘且地位最高的非人类角色之一。
   她以九尾狐之姿，跨越数百年，作为星伽家最可靠的盟友和师团最
   敏锐的大脑活跃在极东战役的幕后。她的天狐评议提供了几乎
   等同于上帝视角的情报能力，她的战略判断多次改变了故事走向，
   她对绯绯神化的警告是全系列最具震撼力的预言之一。
   她不需要出手战斗——单凭智慧和知识，就足以在关键节点
   改变整个战局。她的存在丰富了绯弹世界观的层次感，
   提醒读者：在武侦手枪和爆发模式的背后，
   还有一个由古老妖怪和神秘力量构成的更深层世界。

                【档案备注 / Archive Notes】
================================================================================

■ 关于角色名的记载
   - 全名「玉藻」（Tamamo）
   - 名字直接致敬日本三大妖怪之一的「玉藻前」
   - 名字中的「藻」（も）字与九九藻等狐系角色共享
   - 罗马音写为「Tamamo」，无姓氏

■ 关于玉藻前传说的关联
   - 日本传说中玉藻前是白面金毛九尾狐的化身
   - 曾化为中国殷商末代君王纣的妃子妲己
   - 后化为印度摩竭陀国斑太子的王妃华阳夫人
   - 在日本平安时代化身为鸟羽天皇的宠妃玉藻前
   - 最终在「杀生石」传说中被击破
   - 绯弹系列的玉藻使用了同名的九尾狐设定，
     但给予了她全新的角色定位——
     不是祸国的妖妃，而是守护平衡的智者
   - 这是作者赤松中学对传统妖怪的现代重新诠释

■ 关于九九藻的关系
   - 九九藻（Kuzumo / 九九藻）
   - 同样带有「藻」字，暗示狐系同族
   - 九九藻登场较早（大约Vol.11前后）
   - 年龄较小，力量等级远低于玉藻
   - 推测为玉藻的弟子、后辈或直系同族
   - 作为狐系角色中的中间代（介于玉藻和未知下位存在之间）

■ 关于玉藻在战斗中的定位
   - 玉藻在整部作品中从未直接参与战斗
   - 这符合九尾狐「不战而屈人之兵」的智者形象
   - 也不排除在系列核心决战中她会以本体参战的可能性
   - 她的战斗力是一个留白，让读者自行想象

■ 关于星伽家的超自然体系
   - 星伽家不仅仅是普通的神社巫女家族
   - 他们拥有色金杀女、绯祓舞等秘术
   - 星伽家的灵力来源可能与玉藻这样的存在有关
   - 玉藻可能是星伽家超自然力量体系的一部分或守护者
   - 星伽风雪、星伽粉雪、星伽华雪等巫女
     都与玉藻有交集

■ 关于她在极东战役中的阵营选择
   - 玉藻选择加入「师团」而非「眷属」
   - 师团主张维持现世平衡
   - 眷属（N组织等）试图通过接轨改变世界
   - 作为数百年寿命的九尾狐，
     她比任何人都清楚打破平衡的代价
   - 她的选择是理性而非感性的

■ 角色成长/信息量总结
   - 初登场（Vol.7-8）：作为星伽体系的背景角色
   - 活跃期（Vol.10-13）：师团参谋、天狐评议情报提供
   - 核心期（Vol.17）：绯绯神化警告——角色定位最高峰
   - 持续支援（Vol.21以降）：灵力协助、星伽体系支撑
   - 玉藻是「揭露型」角色——
     不是她变强了，而是她的能力范围逐步被揭示

■ 与伏见的对比
   - 伏见同样是星伽神社体系的巫女
   - 在Vol.33与玉藻共同协助雪花
   - 伏见的位阶和存在感不及玉藻
   - 两人构成了星伽巫女体系的上下层级
