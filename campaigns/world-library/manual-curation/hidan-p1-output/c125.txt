                   【外貌特征 / Appearance】
================================================================================

■ 基本容姿
   珊蒂与姊姊诺玛拥有完全相同的外貌，如同镜中倒影。使人联想到高级咖啡欧蕾
   的褐色肌肤，五官带有拉丁美洲血统的立体感，大眼睛、挺鼻梁。身材火辣到完全
   不输好莱坞女星的程度：丰满的双峰将制服胸前撑得几乎钮扣要飞开，沿著蜂腰到
   被超迷你紧身裙紧裹的臀部以下，伸展出羚羊般修长紧致的美腿。整体散发野性
   而又危险的魅力。

■ 决定性特征——羊角
   珊蒂头部两侧长有乳白色（creamy white）的卷曲犄角，呈螺旋漩涡状，
   类似山羊/绵羊的角。平时被左右蓬松散开的银白色短发遮掩，不易被发现。
   当发动超能力时，头发会因周围力场而轻轻飘浮，露出底下的犄角。

■ 瞳孔变化
   通常时为深色瞳孔。使用念力时双眼发出如电热线般逐渐变红的绯红色光芒，
   随输出功率提高而亮度增强，给人以直视非人魔物的恐怖感。

■ 姿态习惯
   - 说话时习惯双手插腰、挺胸的威吓性站姿
   - 摆出与姊姊左右对称的姿势（如以手托胸、手贴脸颊等）
   - 俯视对手时带有睥睨的轻蔑感

■ 核心印象：恶魔双子中的腹黑天然呆妹妹

   珊蒂·贝茨与诺玛·贝茨作为双胞胎，其精神活动的异常同步令人毛骨悚然。
   她们像共享一个意识中枢般，经常将台词拆开轮流讲、同时歪头、同时笑、
   做出完美的左右对称动作。但在同步中仍可看出珊蒂的个性特征：

┃ 对姊姊的依赖 ┃
│  — 尊称诺玛为「姊姊大人」（姊姊様）                             ┃
│  — 发言时常需要姊姊纠正（如"珊蒂，这些事情不需要说明"）        ┃
│  — 相较于诺玛更显天然呆，有时会不自觉地泄露情报                 ┃
│  — 战略上听从姊姊指示，但关键时刻也会主动提出判断（如发现狙击手）┃

┃ 非人感与冷酷 ┃
│  — 笑的时候缺乏人类发自内心的感情，给人空洞的异质感             ┃
│  — 对"人类"抱有彻底的蔑视，称呼人类为"区区人类"               ┃
│  — 将杀戮视为理所当然，声称"造成伤亡本部也不会负担责任"       ┃
│  — 享受将强者逼入绝境的过程，带有施虐倾向                       ┃

┃ 天然呆属性 ┃
│  — 会不经意泄露FBI内部情报（如承认制服是为了更容易得到协助）    ┃
│  — 对GⅢ提及「Ｆ」这样的机密代号（事后被金次注意）              ┃
│  — 两人一起唱歌玩耍般的战斗风格，展现从容不迫的态度             ┃

┃ 战斗美学 ┃
│  — 把战斗当作游戏：说"先从百分之五十开始"、"提升到百分之六十"  ┃
│  — 喜欢同步合唱（"啦啦啦、啦啦啦～♪"）边战斗边唱歌             ┃
│  — 在摧毁对手时发出嘻笑般的合声，享受力量带来的快感             ┃

■ 对远山金次 / GⅢ的态度
   - 将金次和GⅢ视为"危害美利坚合众国安全的恐怖分子"
   - 对金次展现的"HSS爆发模式"感兴趣，将其视为"很有趣"的观察对象
   - 对GⅢ的人工天才身份和接触"F"的行为抱有警戒和敌意
   - 内心对远山金叉的存在抱有极大的敬畏与忌惮

■ 信念
   - 绝对忠诚于美国政府/国家公安部的命令（作为兵器）
   - 相信自己的行动是在"维护神之国度美国的安全保障"
   - 视阻止"地狱之门"开启为自己存在的根本理由

                 【能力体系 / Ability System】
================================================================================

■ 核心能力：超绝念动力（Psycho Kinesis / 念力 / PK）

   贝茨姊妹拥有的核心超能力是一种极其强大的念力——通过意念直接对物体
   施加物理性影响。这种力量的特性、强度与限制如下：

┃ 强度等级 ┃
│  强度等级以百分比表示（从金次的对话中判断可能无上限）          ┃
│  — 50%：初始战斗状态，已足以扭曲钢铁、崩塌混凝土结构            ┃
│  — 60%：提升战力，增强速度和干扰精度                            ┃
│  — 全力发动：需数周恢复，足以引发天候/重力级别的大规模干涉      ┃

┃ 应用方式 ┃
│  ★ 物体操纵：扭曲钢架、弯折铁板、崩塌墙壁，如揉碎软糖般轻松   ┃
│  ★ 飞行能力：身体漂浮并高速飞行（可追上120km/h的汽车）        ┃
│  ★ 自身加速：利用念力拉动自己的身体，做出违反物理法则的机动   ┃
│  ★ 重力干扰：改变局部重力场，使物体加速/减速不按自由落体规律 ┃
│  ★ 子弹偏转：通过力场干扰弹道（对实弹有限制，对Cs气体难以干涉）┃
│  ★ 力场护盾：身体周围产生看不见的力场（使头发飘浮）           ┃
│  ★ 远程拉拽：对远距离目标施加念力拉扯/拖拽                     ┃
│  ★ 精密操控：接住飞来的铁板并回掷、将钥匙牌钥匙孔精准插入      ┃

┃ 限制与弱点 ┃
│  — 对微小粒子难以作用（CS毒气团无法吹散/排开）                 ┃
│  — 无法抵销重力（只能操控，不能消除重力影响）                  ┃
│  — 对无质量攻击有弱点（如冲击波「炸霸」有效）                 ┃
│  — 需要视线确认目标（否则难以精准施加力量）                    ┃
│  — 念力的"磁力线"可被特殊体术干扰                             ┃

■ 双子协同能力

   珊蒂与诺玛的念力可以通过双子的精神链接进行叠加和协同，发挥出
   几何级数的增强效果。典型协同战术包括：

┃ 同步操控 ┃ 两人联手扭曲大型建筑结构（如整座发射井内壁）        ┃
┃ 桶滚闪避 ┃ 珊蒂把手伸向诺玛，诺玛像游泳般挥臂，实现空中桶滚机动┃
┃ 交替防御 ┃ 互相伸手向对方，如副翼滚般左右散开躲避攻击          ┃
┃ 联合拉拽 ┃ 同时施加念力拖拽车辆（使凯迪拉克无法达到最高速）    ┃
┃ 协同飞行 ┃ 像被看不见的绳索连接般，同步加速减速，编队飞行      ┃

■ 恶魔羊角（种族特征）

   额头两侧的乳白色螺旋状羊角不仅仅是身份的象征，更是其超能力的增幅器：
   - 聚集大气中的"粒子"提升念动力的精度与范围
   - 在全力发动时，角本身会散发微弱的红光/能量波动
   - 羊角的露出通常代表认真状态（平时用头发遮掩以隐藏非人身份）

■ 莱克忒亚侵蚀（种族被动）

   由于体内流淌着异世界的气息，珊蒂与诺玛在战斗中会散发出一种生理性
   的压迫感，使普通人/低魔度生物产生本能的恐惧与厌恶。金次将其认知
   为"站在恶魔面前"的感觉，这种精神压迫足以干扰弱意志对手的HSS状态。

================================================================================
                【战斗记录 / Combat History】
================================================================================

■ 初战——莫哈韦沙漠 ICBM地下发射井（Vol.30）

   为阻止金次和GⅢ调查远山金叉下落而将其引入废弃飞弹发射井。
   展现压倒性念力：将井内多根钢架铁板如软糖般扭曲，瞬间崩塌
   数十吨重的废铁瀑布。逼得金次使用"廊回降"绝技逃生，将GⅢ
   压入废铁堆下。双方在井下展开"铁风"VS"铁浪"的对决，金次
   的弹幕被念力掀起的钢铁漩涡压制。金次用"炸霸"冲击波击退两人后
   逃脱，贝茨姊妹以超高速飞行追车至高速公路上，最终因距离超出
   念力范围而被甩脱。

■ 再战——尼加拉河上（Vol.31）

   在尼加拉瀑布附近的水上追击战中再度拦截金次一行。利用念力
   从警艇跳上金次等人的船，与众人展开混战。击败风魔阳菜（使其
   落水），令GⅢ和伊藤茉斩陷入苦战。最终被金次一行人以团队
   协作击败。

■ 战斗结果——暂时退场（Vol.32）

   贝茨姊妹被击败后，因全力战斗消耗过大，需要数周时间恢复。
   FBI的王牌暂时失去战力，美国的超自然贩卖通路随之复活。
   拉斯普丁纳感谢金次"收拾掉了贝茨姊妹"，称其管制下的贩卖通路
   因此重新开放。

■ 第30卷《追逐茉莉花》——初登场 / 沙漠拦截

   在洛杉矶莫哈韦沙漠的废弃洲际弹道导弹发射井，珊蒂与诺玛首次
   登场。以FBI国家公安部超能力侦查员身份拦截金次和GⅢ。展现了
   完全超越人类常识的念动力，一度将金次三人逼入绝境。战斗中揭示
   了她们的非人本质：
   - 自称不是人类（承认金次对她们"不是人类"的判断）
   - 提到"地狱之门"的存在
   - 提到"F"（未知代号，与GⅢ的隐藏目标相关）
   - 称金次为"Enable"（SDA排名第92）

■ 第31卷《寂静之鬼》——水上追击 / 尼加拉决战

   在尼加拉河上再度与金次一行交战。从警艇跳帮至金次船上，在
   瀑布轰鸣中展开激战。最终被金次一行击败。战后金次一行由
   日本外务省官僚钱形乃莉接应，进入加拿大日本大使馆避难。

■ 战后影响（Vol.32）

   - FBI秘密王牌暂时丧失战力，"需要好几个礼拜才能复原"
   - 原先被贝茨姊妹压制的超自然生物贩卖通路重新活跃
   - 日本政府通过FBI内线获悉金次一行击败贝茨姊妹，派遣钱形乃莉接应
   - 金次对"绝闩"（新开发的恐惧症）产生心理阴影

珊蒂·贝茨（与姊姊诺玛）在《绯弹的亚里亚》第30-31卷中作为
"北美寻父篇"的主要敌对势力登场。她们的角色定位和叙事功能如下：

┃ 叙事功能 ┃
│  — 作为远山金叉的"守护者"与金次之间的路障                    ┃
│  — 展现"魔度"概念并具体化：推动金次对超自然存在等级体系的认识  ┃
│  — 作为来自"地狱之门"的存在，铺垫后续"莱克忒亚（列库忒亚）"    ┃

│  — 使金次开发新招式（如更熟练的炸霸）和战术应变                ┃

┃ 主题意义 ┃
│  — 非人存在的"守护秩序"悖论：身为恶魔却在维护"神的国度"的安全  ┃
│  — 展现"人类"与"超常存在"之间的绝对力量差距                    ┃
│  — 作为金次"放弃做人"与"坚持以人类身份战斗"之间的对照          ┃
│  — 双胞胎恶魔象征不可分割的"双面性"——人类的两个对立面：        ┃

│  FBI国家公安部隐藏有更多的超自然力量。                          ┃

               【档案附注 / Notes】
================================================================================

1. 关于译名：本书使用「珊蒂·贝茨」（Sandy Bates）。日文原名为
   サンディ・ベイツ。另有「珊蒂·贝兹」等异译。

2. 关于姊妹辨识：珊蒂与诺玛容貌完全相同，仅靠单耳佩戴的马蹄形
   塑胶耳环的左右位置区分。小说中由GⅢ说明称呼和辨识方式。

3. 关于种族：原文中将珊蒂与诺玛归类为「非人类」、「恶魔」、
   「此岸之外的存在」。其魔度等级（98-99）在系列中属于最高梯度，
   与墨丘利（Mercury）和色金三姊妹处于同一层面。

4. 关于角：原文明确描述为"乳白色"的卷曲犄角，类似羊角/山羊角。
   部分二次创作中将其描述为"黑色"，但以原作第30-31卷中文官方
   翻译为准，应为乳白色。

5. 关于金属回避：贝茨姊妹在装扮上刻意避免金属物品（使用塑料扣环、
   木制钮扣），原因被推测为类似忍者的行动静音需求——避免金属碰撞
   声暴露位置，或与念力的某些使用特性有关。

6. 关于"F"：珊蒂在Vol.30中提到GⅢ试图接触的"F"是一个未知的
   关键号。金次对此产生疑问，但GⅢ回避了回答。该悬念在后续
   剧情中可能有进一步展开。

7. 在系列魔度体系中，珊蒂与诺玛是金次迄今为止遇到的最浓（最接近
   "魔物"）的存在之一。金次对她们的直觉判断是"恶魔"，而不是
   一般的魔女、妖怪或超能力者。
