                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 前日本公安零课（前公安零課）成员
   - 国际恐怖分子伊藤茉斩之弟
   - 美滨外语高中学生（潜入身份）
   - 伊藤家族次子

■ 家族
   - 伊藤家：世代产出"多重脑连结"（Multi-Brain Access）超能力者的特异家族
   - 姐姐：伊藤茉斩（伊藤茉斬 / 前公安零课四式 / N组织铂金指环成员）
   - "可鹉韦"之名的含义："神（カムイ / Kamui）"
     —— 族人以"可鹉韦"（含"神"之意的阿伊努语/古语）为弟弟命名，
        使弟弟成为"神"的替身/诱饵，以保护真正的"神"（姐姐茉斩）
   - 别名"伊藤剑"（伊藤劍）：
     —— 在部分卷目中以此名出现，暗示其作为"剑"即武器的定位

■ 年龄: 推测16-18岁（初登场时，与金次同年代）
■ 身高: 约170-175cm（苗条的美少年体型）
■ 外貌特征:
   - 美少年（美少年）—— 被多份档案如此描述
   - 五官端正清秀，给人中性化的美丽印象
   - 身材苗条优雅，不似力量型战士
   - 穿着标志性的便于行动的战斗服
■ 发色: 深色/黑色短发
■ 瞳色: 深色
■ 服装: 公安零课战斗装束 → 美滨外语高中学生制服
■ 擅长: 六层脑能力、"诺取"指技、公安零课格斗术、潜伏与追踪
■ 厌恶: 姐姐伊藤茉斩的恐怖行为、家族给予的命运

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 沉静寡言，一般不主动表露感情
   - 对任务极度认真，冷酷执行
   - 在美滨外语高中表面上与普通学生无异
   - 对姐姐茉斩怀有复杂的憎恨与亲情纠葛

■ 本质内核
   - 内心对角色的命运抱有抵触——作为"神"的替身而活
   - 加入公安零课的目的之一正是为了追捕/讨伐姐姐伊藤茉斩
   - 虽作为敌人与金次交手，但本质非恶，只是立场使然
   - 在金次面前展现出战士的骄傲与自尊

■ 矛盾点
   - 作为"神之替身"的宿命 vs 试图挣脱命运的自我意志
   - 对姐姐的亲情 vs 作为公安零课的职责
   - 美少年外表 vs 六层脑能力带来的强大战斗力

================================================================================
                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、六层大脑新皮质（六層大脳新皮質）              │
│          —— 伊藤家遗传的超常能力                   │
└─────────────────────────────────────────────────────┘

■ 原理
   - 伊藤家族世代遗传的超能力体系，名为"多重脑连结"
   - 可鹉韦的大脑新皮质拥有六层结构（普通人为六层但在进化中整合）
   - 每一层对应一种特定的能力档位（一档至六档）
   - 档次越高，能力越强大，但身体负荷也越大

■ 已确认的档位

   [1] 一档（第一档）
       基础档位，强化感知与反应速度
       相当于身体进入轻度战斗状态

   [2] 二档（第二档）
       进一步提升身体能力和神经传导速度
       可在战斗中做出超越常人的快速判断

   [3] 三档（第三档）
       大幅度提升战斗力
       在此档位下可施展"诺取"等高阶技巧

   [4] 四档至六档
       更高档位，具体能力在作中未完全展开
       每提升一档，战斗能力呈指数级增长
       代价：高档位对身体和精神的负荷巨大

┌─────────────────────────────────────────────────────┐
│  二、诺取（ノ取 / Noku）                          │
│          —— 北斗七星经穴指技                       │
└─────────────────────────────────────────────────────┘

■ 原理
   - "诺取"意为"北斗七星经穴指技"
   - 通过精准的指尖攻击命中人体经络穴位
   - 阻断或干扰对手的神经信号传导
   - 技术原型可能源自伊藤家族或公安零课的秘传武术

■ 实战表现
   - Vol.22 废弃组合屋道场之战：
     可鹉韦以"诺取"刺伤金次的四肢
     —— 使金次四肢暂时麻痹、丧失战斗力
   - 此技被金次的"樱花头槌"（超近距离头槌反击）击败

■ 对比：与伊藤茉斩的"不可知子弹"（矢指/空気弾）
   - 姐姐茉斩的必杀技为"不可知子弹"（空气箭矢 / 矢指），
     以右手食指射出空气子弹
   - 可鹉韦的"诺取"同属指技体系，但更偏向近战经穴攻击
   - 两者均源出伊藤家族/公安零课的"指"之武术系统

┌─────────────────────────────────────────────────────┐
│  三、公安零课格斗术                               │
└─────────────────────────────────────────────────────┘

■ 基础战斗能力
   - 作为前公安零课成员，接受过精英级的格斗训练
   - 枪械操作熟练（零课标准）
   - 潜行、追踪、审讯等公安战术精通
   - 能与其他零课成员（狮堂、滩、大门坊等）配合作战

■ 与同级战斗力的对比
   - 战斗力约等于或略低于远山金次（无爆发模式时）
   - 与金次的战斗：初期以"诺取"占优 → 被金次的樱花头槌击败
   - 综合实力：B+ ~ A- 级（武侦高中评级基准）

■ 名称考据
   - "可鹉韦"（カモウイ / Kawuwei / Kaomukai）
     —— 与阿伊努语"卡姆伊"（kamuy / 神）同源
     —— 伊藤家族将弟弟命名为"神"，
        意在使弟弟成为吸引仇恨的替身/诱饵，
        以保护真正的"神"——姐姐伊藤茉斩
   - "伊藤剑"（伊藤劍 / Itō Ken）
     —— 剑即武器，暗示可鹉韦作为"工具/武器"的定位
     —— 在部分卷目中以此别名出现（h15-chars: 可鹉韦/伊藤剑）

■ 与伊藤茉斩的关系补充
   - 茉斩被族人奉为"活神明"，从小被供奉在类似神社的设施中
   - 可鹉韦是家族为保护"真神"而设的替身
   - 因此可鹉韦对家族命运极为反感
   - 加入公安零课既是追捕姐姐，也是试图挣脱家族掌控

■ 关于"诺取"的补充
   - "诺"（ノ / No）可能指"能"（Nō）或"野"（No）
   - "取"为夺取/控制之意
   - 全名"诺取"（ノ取）可能意为"夺能"或"经穴夺取"
   - 与姐姐茉斩的"矢指"（空気弾 / 不可知子弹）同属伊藤家指技体系
   - 茉斩的"矢指"为远程攻击，可鹉韦的"诺取"为近战经穴攻击
   - 两者形成互补的战斗风格
