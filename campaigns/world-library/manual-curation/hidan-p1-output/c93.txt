                        【基础情报 / Basic Info】
================================================================================

■ 总览
   眧眧四姊妹是由四胞胎姐妹构成的战斗团体。
   对外用共享身份"万武昭昭"（万能武人）活动，
   实质上由四位各自专精不同领域的少女轮换出战，
   制造"一人精通格斗·射击·狙击·科技"的假象。
   
   四姐妹是蓝帮直属的中层执行部队，
   在作品中扮演"亚莉亚的黑暗镜像"这一象征性角色，
   同时是巴斯克维尔小队成立的直接催化剂。

■ 基本资料（以猛妹为对外标准形态）
   年龄: 14岁（初登场宣称"昨天满14岁"）
   身高: 约140cm（四姐妹身高一致）
   发色: 黑色
   发型: 双马尾（左右以缎带束起）
   瞳色: 茶褐色
   特征: 眼角涂红色胭脂，使上翘的双眼更加锐利
   着装: 清朝民俗服装改良版（各姐妹细节略有差异）
   国籍: 中国（自称大魏后裔）
   身份: 香港武侦高中留学生（表面）→ 蓝帮战斗员（实质）

■ 外貌特征
   - 娇小体型（约140cm），在作品主要战斗角色中最矮群体之一
   - 全员黑色双马尾 + 改良中国服
   - 眼角红色胭脂是四姐妹的统一标志性化妆
   - 外形与神崎·H·亚莉亚高度相似
     → 是作者有意设计的"亚莉亚黑暗镜像"

■ 四姐妹的总体性格谱系
   猛妹（狂·外向）←——— 炮娘（刚·均衡）———→ 狙姐（冷·内向）
                             ↓
                         机娘（智·技术）
   
   - 四位一体形成完整的战斗人格光谱
   - 对外以猛妹的"外向狂气"为印象代表
   - 内部的理性担当由炮娘和机娘分担
   - 冷酷执行面由狙姐承担

■ 核心信条（四姐妹共通）
   - "乱世是商机"——将世界的混乱局势视为赚钱机会
   - 力量即正义——认同蓝帮的丛林法则
   - "中华公主"自豪感——自视为中华文明继承者
     → 对金次等人的"东夷""北狄"蔑称源于此
   - 棋子主义——将人分为"有价值的棋子"和"无价值的废物"
   - 利益至上——立场随利润流动，非纯粹恶役

■ "打分系统"
   四姐妹共享一套对人的价值评估体系：
   0分 = 废物 · 不值得关注
   30-60分 = 可用棋子
   70-89分 = 优质资产
   90分以上 = 必须获得的稀有品
   
   典型案例：
   ├─ 金次 = 0分（但评语"战绩优良的棋子"——矛盾的评价）
   ├─ 蕾姬 = 90分（企图捕获出售作为暗杀资产）
   └─ 亚莉亚 = 未明确打分，但视为"对手"

■ 四姐妹之间的内部关系
   - 因四胞胎特质，拥有天生的默契和心灵相通
   - 任务配合流畅到仿佛共享意识（角色的无缝替换）
   - 分工明确，各司其职，鲜见内讧
   - 作为一个整体行动的"分裂人格"式战斗团体
   - 对大姊猛妹的领导有天然的服从
   - 蓝帮城政变中也展现了四人的政治协调能力

■ 作为"商业恶役"的特殊性
   - 与作品中其他反派不同，四姐妹的动机纯粹是商业利益
   - 不执着于绯绯色金、色金武术、复仇等宏大主题
   - 绑架新干线索要300亿人民币——纯粹的商业犯罪
   - 因此她们的态度随利益浮动，后期不再是纯粹敌人
   - 这种"务实"在作品中独树一帜

■ 运作原理
   四胞胎外形一致（140cm · 双马尾 · 中国服 · 红胭脂）
   → 敌人所见始终以为是同一个"万武昭昭"
   → 实际每次战斗由不同姐妹轮换出场
   → 制造"一人精通全领域战斗"的恐怖印象

■ 切换时机
   ├─ 格斗战必经 → 猛妹出场
   ├─ 枪战发生 → 炮娘接手
   ├─ 狙击/远程 → 狙姐接管
   ├─ 技术/陷阱 → 机娘布局
   └─ 撤退/逃跑 → 四姐妹同时行动，制造"对手追不上分身"的效果

■ 破绽与揭示
   此骗术被识破的四大线索（Vol.6-7）：
   1. 亚莉亚证言：泼水祭的昭昭（炮娘）和京都的昭昭（猛妹）
      说话方式和性格明显不同
   2. 亚莉亚回避"折平"耻辱：输给低年级生的丢脸感使她没有深入调查
   3. 新干线上两位昭昭同时现身：猛妹在前门，炮娘在后门
   4. 车顶上第三位昭昭（狙姐）从直升机伞降加入战场

■ 评估
   - 伪装效果：A+（成功欺骗主角团一段时间）
   - 被识破后的作战力：仍然极强（即使身份暴露，个体战力不变）
   - 长期效果：身份暴露后改为团体作战，威力反而增加

■ 四姐妹的总体轨迹
   四姐妹在故事中呈现"反派 → 竞争对手 → 混沌中立"的角色演变

   【Phase 1：纯粹反派期（Vol.6-7）】
   ├─ 以恐怖袭击和绑架为主要行动模式
   ├─ 作为新干线劫持事件的实施者登场
   ├─ 性格表现方面是最纯粹的恶役
   └─ 目的是金钱（300亿赎金）

   【Phase 2：组织内部期（Vol.13-14 蓝帮城）】
   ├─ 蓝帮内部权力斗争的参与者
   ├─ 发动政变囚禁诸葛静幻
   ├─ 作为蓝帮中层而非纯粹犯罪者行动
   ├─ 与金次等人的关系从"敌人"变为"竞争对手组织成员"
   └─ 机娘在此阶段正式加入成为第四人

   【Phase 3：混沌中立期（Vol.37 印度篇～后期）】
   ├─ 在伊·U残党中以观望态度参与
   ├─ 与主角团不再处于明确敌对立场的对抗
   ├─ 表达出"我们是来赚钱的，不是来送命的"态度
   ├─ 整体已不再是主线剧情的核心敌人
   └─ 角色定位从"反派"转化为"世界观填充要素"

■ 角色深度评估
   - 功能性反派：四姐妹的角色深度属于中等偏下
   - 个人动机单纯（利益驱动），缺乏复杂的情感冲突
   - 无明显的个人成长或思想变化
   - 角色魅力主要来自"形象的符号性"（亚莉亚的黑暗镜像）
    以及独特的"四胞胎伪装"战斗机制
   - 在作品中的最大贡献是作为巴斯克维尔小队成立的催化剂

■ 角色核心概念
   四胞胎伪装成单人的"万能武人"诡计
   —— 以"多"伪装成"一"，以团队之力制造个人传奇

■ 主题映射：亚莉亚的黑暗镜像
   四姐妹与亚莉亚的外形高度一致，但价值观完全相反：
   
   "如果亚莉亚没有遇到金次，没有加入巴斯克维尔——"
   "如果亚莉亚选择了商业犯罪的道路——"
   "她会变成什么样子？"
   
   四姐妹就是对这个问题的回答。
   她们是亚莉亚在平行世界中的另一条可能性：
   同样的娇小、双马尾、好战、射击天才——
   但驱动她们的动机是金钱和利益，而非正义与羁绊。

■ 其他主题标签
   【中国故事线】作品对中国势力的设定延伸
   —— 蓝帮 · 诸葛亮后裔 · 孙悟空 · 曹操后裔
   —— 四姐妹是这一世界观的重要组成部分
   
   【团队的诞生催化剂】
   新干线劫持事件直接催生了巴斯克维尔小队
   如果没有四姐妹的袭击，五位主角可能永远不会以
   "巴斯克维尔"之名正式组队作战
   
   【商业恶役的纯化形态】
   四姐妹的恶，是最纯粹、最没有负担的恶
   不执着于仇恨·复仇·宿命·大义
   只为了钱——这是一种"清爽"的反派定位
   
   【反差萌的暴力版】
   140cm · 双马尾 · 中国服 · 14岁少女
   → 但掌握致死绞技·青龙刀·超远程狙击·隐形炸弹
   视觉可爱与实用暴力的残酷反差

■ 命名考据
   "万武"（Wan Wu / 万能武人）
   ├─ "万" = 万能 · 多重
   ├─ "武" = 武术 · 战斗
   └─ 暗示由多人构成的"多领域战斗特性"
   
   "昭昭" / "眧眧" / "兆兆" / "Cao Cao"
   ├─ 全部为曹操（Cao Cao）的拼音变体
   ├─ 眧眧 = 威妥玛拼音（Tsao Tsao）
   ├─ 兆兆 = 拼写混淆变体
   ├─ 昭昭 = 汉字谐音
   └─ 与峰·理子（鲁平/Lupin）属同类命名梗

                【创作分析 / Literary Analysis】
================================================================================

■ 作者的设计意图
   赤松中学在设计四姐妹时的几个关键创作意图：

   1. 【战斗机制的创新】
      以多胞胎伪装成单人，是一个新颖的战斗诡计设计
      比单纯的"四胞胎姐妹"更有故事趣味性
      将推理元素（身份识别）融入动作战斗

   2. 【亚莉亚的性格反照】
      通过四姐妹的外形镜像揭示亚莉亚性格的另一面
      ——如果亚莉亚没有福尔摩斯血脉的责任感，
      她可能会变成什么样的人
      为亚莉亚的角色深度增添层次

   3. 【中国势力设定的实体化】
      在蓝帮组织架构下铺设具体角色
      为"中国线"（诸葛亮·孙悟空·曹操）提供具体战力展示
      四姐妹是被包装在"传统中华文化"外壳下的现代战斗团体

   4. 【巴斯克维尔诞生的必要条件】
      七卷新干线劫持战需要一个足够强大的对手
      迫使五位主角首次真正联合作战
      四姐妹的"四人各专一项"恰好需要五人各自的专长来破解

■ 角色局限性
   - 作为功能性反派，四姐妹缺乏深层心理描写
   - 后期退场时没有给她们的"落幕"安排
   - 始终作为"组织成员"而非有独立剧情的角色
   - 没有个人名字（仅以"猛妹""炮娘"等代号称呼）
   - 机娘加入后笔墨反而减少

■ 在系列中的定位总结
   眧眧四姊妹是绯弹系列中
   ——最色彩鲜明的中早期反派之一
   ——亚莉亚最直接的"暗面"对照体
   ——巴斯克维尔小队诞生的直接推手
   ——蓝帮/中国势力线的重要执行层角色
   ——兼具"战斗诡计趣味"和"主题象征价值"的角色设计

■ 本档案编制说明
   本档案重点聚焦四姐妹的个体身份及其作为"战斗团体"的特质，
   与档案c75（万武昭昭）形成互补视角：
   - c75 侧重"万武昭昭"这一假面身份的具象与诡计机制
   - c93 侧重"四个独立个体"的姐妹关系、个体特质与团体动力学

■ 姐妹本名未揭示
   四姐妹在作品中始终以"猛妹""炮娘""狙姐""机娘"的代号被称呼，
   其真实姓名从未在作品中被揭示。这是一种"无个性中的个性"设定。

■ 神秘的外在年龄
   虽然猛妹自称14岁，但面对她的战斗技巧和冷酷程度，
   角色们的内心独白常质疑这一年龄的真实性。
   也可能是蓝帮从幼年即培养的战斗人才。

■ 关于"曹操后裔"
   四姐妹自称大魏曹操的子孙后代，但这一身份未获其他角色验证。
   考虑到峰·理子·罗苹4世的命名方式（基于怪盗卢平），
   "曹操后裔"称号可能同样是名字玩梗的一部分，
   不一定是作品设定的真实血脉。

■ 与珂珂四姐妹（c41）的区别
   诸葛静幻麾下还有"珂珂四姐妹"（猛妹·炮娘·狙姐·机娘）：
   - 珂珂四姐妹是诸葛静态的直属战斗部队
   - 但根据文本交叉引用，珂珂四姐妹与眧眧四姊妹
     实为同一批角色，中文翻译中名称混用
   - 本档案以"眧眧四姊妹"为主名称

■ 与万武昭昭（c75）的关系
   眧眧四姊妹 = 实质存在（四人）
   万武昭昭    = 伪装身份（捏造的"单人"身份）
   二者是"本体与面具"的关系
