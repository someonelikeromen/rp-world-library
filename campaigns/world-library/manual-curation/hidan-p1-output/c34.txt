   - 国际武侦联盟关联人员

   ┌─────────────────────────────────────────────────────┐
   │ 伊·幽时期 → 被逮捕/司法交易 → 武侦高留学生      │
   │ → 星座小队队长 → 师团正式成员                     │
   └─────────────────────────────────────────────────────┘
   - 伊·幽（伊·U）攻击少女队成员（与峰理子、夹竹桃组队）

   - 星座小队（C队）队长——指挥欧洲补考行动
   - 师团（国际超自然组织联盟）正式成员

■ 种族: 人类（圣女贞德血脉传承者）
■ 性别: 女性
■ 年龄: 16-17岁（就读武侦高中二年级）
■ 国籍: 法国（法国出身）
■ 信仰: 天主教（圣女血脉与信仰密切相关）
■ 发色: 银白/银发（Sister Silver / 银冰魔女的标志）
■ 瞳色: 蓝色系（与冰能力呼应的寒色系瞳色）
■ 三围: 未公开（苗条匀称的法式少女体型）
■ 外貌特征:
   - 银色长发，通常束成马尾或自然披散
   - 典型的法国少女面容，五官精致立体
   - 身材纤细修长，站姿优雅如骑士
   - 常穿武侦高中制服、女仆装（变装时）、
     或带有法式风格的便服/礼服
   - 变装时擅长切换发型、声线与服装风格
     （理子传授的伪装术）

■ 性格特征:
   - 【表面】严肃认真、骑士道精神、责任感强、纪律严明
   - 【内面】有着不为人知的少女心和柔弱的另一面
   - 【成长】从伊·幽的冷酷执行者转变为信念坚定的伙伴
   - 对认定的人（金次）展现出极大的包容与理解
   - 完美主义倾向，对自己要求严格
   - 在理子的引导下开始接受萌系文化，但不坦率

■ 喜欢:

   - 与金次相处的安静时刻
   - 完成使命的成就感
   - 变装/伪装的乐趣（理子影响）

■ 厌恶:
   - 无辜者受害
   - 使命背叛者
   - 不公正的战斗

                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 骑士姬风范：言谈举止带有法式贵族修养与骑士精神
   - 冷静理智：作为情报科精英和星座队长，
     擅长分析局势、制定策略
   - 使命感强：继承圣女贞德的"守护"意志，
     对师团的使命极为认真
   - 外冷内热：表面严肃矜持，实则内心柔软

■ 本质内核
   - "被击败的魔剑"——救赎的起点：
     最初以伊·幽成员"魔剑"身份绑架白雪，被金次
     以空手夺白刃制伏逮捕。这次失败反而成为
     她从黑暗走向光明的转折点
   - 双重身份的矛盾体：
     体内流着圣女贞德的血液，却曾是犯罪组织的成员。
     这种身份矛盾驱使她不断寻求自我救赎与证明
   - 隐藏的少女心：
     在严肃的骑士外表下，贞德和普通少女一样
     渴望浪漫、渴望被理解。在金次面前尤其明显——
     她会邀请金次共寝、在巴黎化装舞会上展现柔情
   - "理解者"的定位：
     她是少数真正理解金次身心负荷的人之一。
     作为情报官式的伙伴，她能看到金次战斗背后的代价

■ 精神成长曲线
   ┌─────────────────────────────────────────────────────┐
   │ 伊·幽执行者 → 被逮捕 → 留学生 → 星座队长        │
   │ → 师团战士 → 金次的"另一个理解者"                │
   └─────────────────────────────────────────────────────┘
   - Vol.2（魔剑）：以伊·幽成员身份伪装白雪绑架真白雪，
     与白雪的火焰"色香菖蒲"激战，被金次逮捕
   - Vol.3（留学生）：以武侦高留学生身份再次登场，
     向金次提供弗拉德的致命情报
   - Vol.4（师团参战）：在宣战会议上作为师团方参战，
     正式从犯罪者转为正义方
   - Vol.6（冰火联手）：与白雪合作以温差战术击败金女
   - Vol.15（星座小队）：担任星座小队队长，带领金次
     前往欧洲补考，在巴黎展现前所未有的柔软一面
   - Vol.16-17（被俘与救援）：被眷属俘虏作为怪兽祭品，
     后被金次与丽莎救出
   - Vol.40（埃及远征）：与金次、金女、梅梅特组队
     前往埃及追查莎拉·汉

                 【能力全析 / Ability Analysis】

┌─────────────────────────────────────────────────────┐
│  一、冰系魔法·钻石冰尘（Diamond Dust）            │
└─────────────────────────────────────────────────────┘

■ 概述
   - 贞德的核心战斗能力，继承自圣女贞德血脉的魔法力量
   - 可以操控寒气与冰晶进行攻防
   - 威力足以与星伽白雪的火焰"色香菖蒲"正面抗衡
   - 被评价为"钻石冰尘"——因冰晶在光线折射下如钻石闪耀

■ 攻击性应用
   - 冰弹/冰枪：凝聚空气中的水分为冰弹射出
   - 冰墙/冰盾：瞬间构筑冰壁防御
   - 钻石冰尘风暴：大范围的冰晶暴风，兼具视觉效果与杀伤力
   - 低温束缚：将目标冻结在地面或墙壁上
   - 冰之陷阱：预设在特定区域的冰冻触发装置

■ 防御性应用
   - 寒冰护甲：在体表构筑薄冰层增强防御
   - 冰盾阵列：多层冰盾叠加防御
   - 低温结界：制造小范围的低温领域削弱敌人活动能力

■ 协同战术
   - 冰火联动（与白雪合作）：
     利用火焰的高温与寒冰的低温造成急剧温差，
     使敌方金属武器脆化断裂。
     曾在"木工包围战"中使用此战术击碎金女的单分子震动刀
   - 温差脆化：急速冷热交替使金属/装备产生疲劳裂纹

┌─────────────────────────────────────────────────────┐
│  二、伪装·变装术                                 │
└─────────────────────────────────────────────────────┘

■ 来源
   - 由峰理子（怪盗罗苹四世）亲自传授
   - 贞德在这方面展现出惊人的天赋
   - 理子评价其为"天生的演员"

■ 能力范围
   - 声线模仿：可以完美模仿目标的声音和语调
   - 外貌伪装：通过化妆、假发、服装进行高度逼真的变装
   - 气质切换：不仅能改变外表，连举止气质都能彻底转换
   - 快速换装：在极短时间内完成多套伪装切换

■ 经典伪装案例
   - 伪装成星伽白雪（Vol.2）：完美复制白雪的外貌与声音，
     成功绑架真白雪，连金次和亚莉亚都被骗过
   - 在巴黎的各类变装：执行星座小队任务时的战术伪装

┌─────────────────────────────────────────────────────┐
│  三、情报分析/指挥能力                           │
└─────────────────────────────────────────────────────┘

■ 情报科精英
   - 专精于情报收集、分析、战术规划
   - 作为星座小队队长展现出色的指挥调度能力
   - 擅长从零散信息中构建完整的态势图景

■ 战术规划
   - 在多国协作环境中具备跨文化沟通与协调能力
   - 制定作战计划时考虑全面，善用队员特长
   - 情报官式的思维方式使她能预测敌人的下一步行动

┌─────────────────────────────────────────────────────┐
│  四、近战格斗                                    │
└─────────────────────────────────────────────────────┘

■ 剑术基础
   - 继承圣女贞德的战斗传统，具备骑士规格的剑术训练
   - 可使用圣剑杜兰朵（Durandal）——传说中不灭之剑
   - 与星伽白雪的火焰之刀"色香菖蒲"进行过正面交锋

■ 空手格斗
   - 体能和格斗基础在武侦高中水平以上
   - 但主要依赖魔法/情报/伪装能力，非纯格斗型角色
   - 曾被金次以空手夺白刃制伏（Vol.2），
     表明在近身擒拿方面存在短板

                  【经典场面 / Key Scenes】
================================================================================

■ 魔剑初亮相（Vol.2）
   贞德以伪装成白雪的模样出现在金次和亚莉亚面前，
   完美复制了白雪的容貌、声音与气质，
   连金次都被骗过，成功绑架了真的白雪。
   ——展现出伊·幽成员的高超变装技术。

■ 真面目揭露（Vol.2）
   "你就是真正的魔剑吗……"
   当贞德挟持亚莉亚时，被金次识破伪装。
   贞德的银发在月光下闪耀，魔剑的真面目终于揭开。
   站在她面前的是解开星伽封印的白雪，
   手持火焰之刀"色香菖蒲"。

■ 冰火激战（Vol.2）
   钻石冰尘 vs 色香菖蒲
   寒冰与烈焰在武侦高中地下激烈碰撞。
   冰晶在高温中蒸发成雾，又被新的寒气重新凝结。
   这是《绯弹的亚里亚》中东西方能力者首次正面交锋的名场面。

■ 空手夺白刃（Vol.2）
   在贞德与白雪激战的最后关头，
   金次以亚莉亚教的空手夺白刃制伏贞德。
   这位强大的魔剑就这样被赤手空拳地逮捕了。
   ——奠定了金次在贞德心中特殊地位的瞬间。

■ "弗拉德是怪物"（Vol.3）
   以留学生身份再次登场的贞德，严肃地警告金次：
   "弗拉德是存活超过120年的非人怪物……"
   她以曾为伊·幽内部人员的视角提供了关键情报。

■ 冰火联手（Vol.6 木工包围战）
   曾经互为宿敌的白雪与贞德——
   火焰与寒冰的搭档竟然联手了！
   利用温差脆化战术，使金女的单分子震动刀在
   急冷急热中脆化断裂。
   这是两人关系转折的标志性场面。

■ 巴黎的雪夜（Vol.15 哿与银冰）
   在巴黎香榭丽舍大道的雪夜中，
   贞德展现出从未有过的少女姿态——
   与金次打雪仗、在公寓中共度时光、
   邀请他共寝。
   这一刻，"银冰魔女"剥去了冰冷的外壳，
   露出了里面那个渴望被爱的普通少女。

■ 化装舞会上的公主（Vol.15）
   在加尼叶宫的化装舞会上，
   贞德以优雅的礼服出现在金次面前。
   这一刻她不再是战士或情报官，
   而是一位真正的法国少女。

■ "请救出贞德"（Vol.16）
   贞德被眷属俘虏，成为怪兽祭品。
   面对V-2导弹死刑和贞德被困的绝境，
   金次发誓要救出她。
   当丽莎觉醒为热沃当之兽时，贞德的命运悬于一线。

■ 龙之港救援成功（Vol.17）
   金次与丽莎潜入龙之港，
   成功救出被囚禁的贞德。
   三人在荷兰海岸线重逢，
   贞德终于获得自由。

■ 埃及远征入队（Vol.40）
   "我需要你，贞德。"
   金次亲自招募贞德加入埃及远征队。
   贞德毫不犹豫地答应了——
   这是她作为金次信任的伙伴再次站在同一战线。

■ 与理子、夹竹桃观战AA（AA外传）
   在武侦高屋顶上，曾经的"攻击少女队"三名成员
   ——理子、夹竹桃、贞德——聚在一起观战
   间宫姐妹的鹰卷对决。
   贞德以骑士般的比喻解说战况，
   展现出与冷酷魔剑时期截然不同的温和一面。

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 圣女血脉 vs 犯罪者过往 / 骑士使命 vs 少女心意
成长弧光: 伊·幽的执行者 → 被逮捕者 → 赎罪的留学生
           → 值得信赖的队长 → 金次的理解者
象征意象: 「银冰」—— 寒冷外表下封存着炽热的心
          「魔剑」—— 曾被用作黑暗的工具，终被光明之手握持
          「雪夜的巴黎」—— 坚硬心灵融化的浪漫瞬间

■ 角色在作品中的功能定位
   - 伊·幽→师团转折的代表人物：从犯罪组织到正义方的
     成功转型案例
   - 欧洲战线的核心指挥官：负责金次在欧洲补考期间的
     任务统筹与战术指挥
   - 金次的"第二个理解者"：与亚里亚的炽热感不同，
     贞德以冷静的视角理解并接纳金次的一切
   - "圣女"主题的现代演绎：继承圣女贞德之名，
     在现代武侦世界中的救赎与奋斗
   - 法国文化元素担当：为作品增添法式风情与骑士气质

■ 在整体剧情中的位置
   - 作为前期反派→后期同伴的角色转型实例
   - 连接伊·幽篇与欧洲篇的重要桥梁人物
   - 师团情报体系的关键节点
   - 后期远征埃及的重要战力

■ 与同作品的"圣女"对比
   相对于历史上第一代圣女贞德的殉教悲剧，
   第三十代贞德·达鲁克在命运的转角遇到了
   愿意接纳她的伙伴——这是对"圣女"主题的
   现代化改写：不再独自背负十字架，而是
   在同伴中找到前进的力量。

              【档案备注 / Archive Notes】
══════════════════════════════════════════════════════

■ 关于别称的演变
   - 魔剑（Maken）：伊·幽时期的代号
   - 银冰魔女（Silver Ice Witch）：因其冰系魔法与银发
   - 第三十代圣女贞德：正式的血脉称谓
   - 贞德·达鲁克30世：系列作品中的标准中文译名

■ 关于"魔剑"与"艾丽斯贝尔"的区别
   - 注意：作品中另有一位被称为"魔剑"的角色
     艾丽斯贝尔（Alicel），与贞德·达鲁克30世不同
   - 贞德的"魔剑"是其伊·幽时代的代号/任务代号
   - 艾丽斯贝尔是后期登场的另一角色，同样被称为"魔剑"
   - 两者不可混淆

■ 关于"星座小队"（Constellation Squad）
   - 简称C队
   - 由绿松校长为金次欧洲补考而特别组建
   - 成员包含金次、贞德（队长）等
   - 管辖范围覆盖欧洲地区
   - 任务包含补考监视、欧洲情报收集等

■ 关于变身/能力的来源
   - 冰系魔法"钻石冰尘"是血脉传承能力
   - 她的母亲（前一代圣女）传授了基础能力
   - 与星伽白雪的火系能力形成对比的"冰"之传承
   - 绯弹世界中的超自然能力设定体系内的血脉魔法

■ 与历史上的圣女贞德的关系
   - 她是圣女贞德的直系血脉传承者（第三十代）
   - 保留了圣剑杜兰朵的传承
   - 继承了"守护法兰西"的使命精神
   - 但故事背景是现代日本/国际武侦世界
   - 她的角色定位从"宗教圣女"转变为"现代武侦"

■ 关于感情线的定位
   - 贞德对金次的感情是作品中的重要副线之一
   - 在巴黎篇中发展到接近明确表达的程度
   - 与亚里亚的"正宫"地位、白雪的"青梅竹马"定位、
     理子的"损友/暧昧"定位形成对比
   - 贞德更偏向"理解者"和"灵魂伴侣"的定位
   - 后期因剧情篇幅分配而逐渐转为支持角色

■ 关于AA外传中的表现
   - AA外传中贞德以法国武侦留学生身份登场
   - 与理子、夹竹桃保持了友好的同僚关系
   - 用骑士比喻解说间宫姐妹的战斗
   - 展现了本篇中较少见到的"学姐"风范

■ 关于变装术的师承细节
   - 变装术由峰理子（怪盗罗苹四世）亲自传授
   - 理子称贞德是"天生的演员"
   - 贞德的变装连白雪本人都难以分辨
   - 这不仅是一项技能，也象征了理子与贞德之间
     深厚的友谊——理子将自己的核心技术毫无保留地
     传授给了贞德

■ 关于贞德后期出场频率
   - Vol.15-16（欧洲篇）是贞德戏份最密集的时期
   - Vol.40（埃及远征篇）有重要再登场
   - 在其余卷数中多作为support角色或客串登场
   - AA外传中有少量但关键的客串
