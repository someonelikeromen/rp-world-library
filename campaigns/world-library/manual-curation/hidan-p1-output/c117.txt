================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格（对主人/指示者）
   - 绝对服从：以"奴隶"身份自居，对主人命令无条件执行
   - 忠诚至上：对恩蒂米菈的忠贞不二，即使豁出性命也要守护
   - 指令依赖：一旦命令被下达，执行精准无误；一旦超出指令范围，陷入panic
   - 勤勉认真：在指定任务范围内极为可靠，甚至不惜自牺牲

■ 底层性格（种族天性）
   - 兽性本能：保留强烈的野兽直觉——依靠嗅觉、听觉等原始感官
   - 嗅闻识人：用气味辨别身份（可通过气味识别变小的拉斯普奇娜）
   - 警戒性强：对陌生气味和潜在威胁保持高度警觉
   - 团结行动：双胞胎之间有高度默契，行动如同一个有机体

■ 核心心理——指令依赖症（Command Dependency）
   - 长期作为森林贤女恩蒂米菈的奴隶生活，使她们丧失独立判断能力
   - 金次评价："如同当代日本职场中没了上司就什么都不会做的社畜"
   - 当遇到新的局面（如拉斯普奇娜变成幼儿），她们的程序出现"bug"—— 
     既有的复仇指令与当前现实无法匹配，导致行动冻结
   - 当获得新的指示者（如安洁丽卡）时，能迅速转入新的指令系统
   - 这一特征既是弱点也是忠诚度的体现

■ 双胞胎间的互动
   - 高度同步：行动、说话常有镜像式的默契
   - 顺序对话：萜萜蒂→列萜蒂的顺序发言模式
   - 互相确认：遇到不确定的情况时会面面相觑交换意见
   - 共用态度：对事物保持相同的警戒或畏惧
   - 连体行动：几乎所有场合都是两人一体

■ 精神成长曲线
   - Vol.32：作为N护卫 + 恩蒂米菈的奴隶，机械式执行守护任务
   - Vol.32（后半）：成为金次的"战利品"后开始适应特拉（人类世界）规则
   - Vol.41：独立追踪拉斯普奇娜→遭遇"复仇对象变成幼儿"的认知危机
     → 在安洁丽卡指引下获得临时指令系统 → 
     最终回归莱克忒亚协助奇娜（原仇人）的治疗，完成从"复仇工具"到
     "能选择宽恕路径"的进化

■ 短刀战
   - 武器：后腰佩带类似尖头菜刀的利刃
   - 风格：近战突袭型，配合兽性直觉的敏捷动作

   - 威慑：曾让远山金次在战斗中产生警惕

■ 投石索（Bolas）
   - 武器：原始人/草原部族捕获动物的投掷武器
   - 构造：两根绳索+两端系有石球
   - 用途：缠住敌方的脚踝使其摔倒
   - 实战表现：金次被此招式瞬间绊倒，显示精准度极高
   - 备注：反映了萜蒂库恩族源自原始部落的狩猎文化

■ 追踪能力
   - 嗅觉追踪：依靠野兽般的嗅觉进行追踪
   - 气味辨识：能在复杂环境下通过气味锁定目标
   - 个体区分：连双胞胎之间的气味都能被金次辨识，
     证明她们拥有强烈的个体气味特征
   - 实战应用：尾随金次并从气味中识别出拉斯普奇娜的存在

■ 游泳能力
   - 独特泳姿：狗爬式加尾巴打水的独有游泳方式
   - 抗寒性：在冬季的尼亚加拉河水中也能坚持

■ 格斗基础
   - 协同作战：双胞胎的连携攻击
   - 压制技巧：曾同时锁喉和固定金次的身体

■ 指令依赖症
   - 无明确指示时行动停滞，无法独立决策
   - 对方决策者的依赖性极高，易被第三方操控
   - 案例：安洁丽卡轻易收编了她们作为临时部下

■ 战力上限
   - 远山的金次评价："光靠那三人根本无法阻止老爸，顶多只能争取几秒" 
     —— 他们的战斗力在顶级武侦面前有限
   - 战斗力倾向于辅助/牵制型，而非主要战力

■ 心理脆弱性
   - 遇到超出"命令范围"的事态时会恐慌
   - 过度依赖外部指示，精神独立性接近于零

                  【人际关系 / Relationship Map】

■ 恩蒂米菈·蒂（Endimira）
   关系：主人 → 前主人 → 永远的效忠对象
   评价："恩蒂米菈大人"
   关键节点：在莱克忒亚的森林中作为精灵恩蒂米菈的奴隶生活多年 →
              在加拿大的日本大使馆中跟随恩蒂米菈成为金次的"战利品" →
              恩蒂米菈返回莱克忒亚后留下双胞胎在特拉继续追踪拉斯普奇娜
   备注：她们对恩蒂米菈的忠诚接近宗教性的奉献，
          一切行动的终极动因都与恩蒂米菈的意志相关

■ 远山金次（Tohyama Kinji）
   关系：战利品主人（名义上）→ 临时同居对象 → 合作关系
   评价："金次"（直呼其名，非敬称）
   关键节点：
     Vol.32：在尼亚加拉大瀑布被金次一方救起→跟随恩蒂米菈一起成为金次奴隶
       → 住在金次公寓期间 → 被安置在京都伏见处
     Vol.41：尾随金次，为追查拉斯普奇娜而敌视金次 → 被金次的正义感说服 →
       （虽仍跟随安洁丽卡，但最终前往莱克忒亚时感谢了金次一方）
   备注：金次从不认为她们是"奴隶"，但双胞胎自身对此身份认同坚定

■ 远山金叉（远山金次的父亲 / GⅡ）
   关系：敌人（曾经的防卫对象）
   评价："那个可怕的男人"
   关键节点：Vol.32尼亚加拉大瀑布对峙——她们作为尼莫的护卫，
              试图用短刀阻止金叉，但自知完全不是对手
   备注：对远山父子都保持警惕和恐惧

■ 尼莫（N之提督 / Nemo）
   关系：主人（N时代）/ 保护对象
   评价："尼莫大人"
   关键节点：Vol.32作为尼莫在加拿大的护卫，为尼莫的跳跃（瞬间移动）断后
   备注：替尼莫挡下危险，自愿留在加拿大面对SWAT部队

■ 拉斯普奇娜（Rasputina）/ 奇娜（China）
   关系：仇人 → 复仇目标 → 和解→协助治疗
   评价："龙之魔女拉斯普奇娜" → "奇娜"
   关键节点：
     故乡被拉斯普奇娜的龙烧毁 ← 极深的仇恨渊源
     Vol.41：追踪到变成幼儿的奇娜 → 因指令崩溃而困惑 → 
       最终听从安排，带奇娜回莱克忒亚治疗
   备注：这是双胞胎角色弧中最关键的转折——从复仇工具变成了
           通往治疗之路的护送者

■ 安洁丽卡·斯塔尔（Angelica Starr）
   关系：临时指示者/合作者
   评价："安洁丽卡"
   关键节点：Vol.41由安洁丽卡"接管"指示 → 双胞胎迅速投入新指令系统
   备注：展现了双胞胎"指令依赖"特性的可预测性——

■ 利维娅（Levia / 海洋女神）
   关系：同胞世界的上级存在 → 合作者
   评价：对利维娅保持敬意（利维娅在莱克忒亚是地位极高的大人物）
   关键节点：Vol.41 利维娅以莱克忒亚机制劝说双胞胎→促成了和解

■ 伏见（Fushimi / 狐女）
   关系：庇护者

■ 风魔阳菜（风魔阳菜）

                  【档案备注 / Archive Notes】

■ 名字释义
   "萜萜蒂"（Tettei）和"列萜蒂"（Retsutei）这一命名方式在绯弹系列
   中属于莱克忒亚风格的拟音命名，带有原始部落语言的特征。
   在金次的内心中，两人被合并称为"萜萜蒂·列萜蒂"作为一个整体单位。

■ 关于"奴隶"身份
   虽然恩蒂米菈本人和双胞胎都自称"奴隶"（在莱克忒亚"战利品文化"
   的语境下），但远山金次始终拒绝承认这一身份，以现代价值观
   平等对待她们。作品中"奴隶"一词更多是文化差异的描写，
   而非作者对奴隶制度的提倡。

■ 同体但非同名
   虽然出自同一个双胞胎组合，姐妹两人各自有独立的名字和人格。
   在本档案中"列萜蒂"作为代表名，但姐妹都被完整收录。
   在主线战力评定中，双胞胎通常被视为一个战术单位。

■ 已确认事实
   - 两人返回莱克忒亚后生活安宁，并协助恩蒂米菈种植"很像荞麦"
     的蓼科植物（受金次送的日本荞麦面启发）
   - 奇娜在薇泽丽芙的疗养所接受治疗后情况良好
   - 恩蒂米菈和萜萜蒂·列萜蒂最终放弃了复仇（因为原来的拉斯普奇娜
     已经不存在了）

■ 日语中出现的异体表记
   简体中文译本中统一表记为"萜萜蒂·列萜蒂"或简写"萜萜蒂/列萜蒂"；
   日文原版中为"テッテイ・レツテイ"（音译）
