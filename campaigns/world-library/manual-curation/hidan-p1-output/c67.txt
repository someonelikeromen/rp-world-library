================================================================================
                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - N组织铂金指环成员（戒指阶级：金>铂>银>铁）
   - 莱克忒亚（列库忒亚 / Leutecia）异世界派遣至地球的战斗人员
   - N三人攻击队的主将（尖兵：哈比鸟 / 主将：瓦尔基丽雅 / 辅佐：伊藤茉斩）
   - 可在人形态与飞龙形态之间切换的异界女武神

■ 外貌特征
   - 人形态：高䠷金发女性，身高约170cm以上，身材修长健美
   - 发型：金色长发编成麻花辫至发尾
   - 装备：黄绿色镶银铠甲——护胸、护肩、胫甲，着高跟鞋
   - 特征：头部侧方有一对小翅膀（非装饰，为生物器官）
   - 武器：银枪（通称"女武神之枪"）+ 盾牌
   - 飞龙形态：巨大飞龙，覆盖鳞甲，翼展广阔，力量与耐久远超人类形态

■ 种族/出身
   - 莱克忒亚（列库忒亚）原住民——与人类不同的异界生物种族
   - 在生物学分类上与哈比鸟（Harpy）相近，同属莱克忒亚飞行种
   - 具有莱克忒亚女武神（Valkyrie）的种族特性——荣耀准则、文化禁忌
   - N组织中已知的异界成员之一（同属：墨丘利/水银女、海卓拉、恩蒂米菈）

■ 性别: 女性（人形态）
■ 发色: 金色
■ 瞳色: 金色/琥珀色（推测）
■ 惯用手: 右（枪术使用）

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 寡言少语，极少表露感情
   - 严格执行命令，以N组织的目标为行动准则
   - 在战斗场景中展现高度的专业性和战术纪律
   - 对敌人不留情面，但对特定对象（如金次）在特定条件下可进行情报交涉

■ 内核特质
   - 拥有莱克忒亚女武神特有的荣誉感与禁忌准则
   - 表面服从N组织，实则保留自身种族的独立判断
   - 具有异界生物对地球人类社会的疏离感与好奇
   - 严格遵循"女武神"的传统文化规范（头盔禁忌即是明证）

■ 文化禁忌——女武神头盔
   - 莱克忒亚女武神种族特有规范
   - 若女武神的头盔被男性脱下，该女武神须在"被杀"（处决对方或自我了断）
     与"被爱"（认对方为主人或配偶）中二选一
   - 此禁忌暗示瓦尔基丽雅在莱克忒亚社会中具有某种婚配/忠诚传承制度
   - 在故事中尚未触发（头盔未曾被脱下）

■ 与N组织的关系
   - 作为N铂金指环成员，忠诚度可靠但非盲目
   - 与茉斩（辅佐）和哈比鸟（尖兵）组成固定战术三人组
   - 与尼莫（提督）有直接的上下级关系
   - 与其他异界成员（墨丘利、海卓拉）可能有莱克忒亚同乡的默契

================================================================================
                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、基础战斗能力 —— 人形态（女武神模式）      │
└─────────────────────────────────────────────────────┘

■ 银枪术
   - 使用银枪（女武神之枪）为武器，配合盾牌使用
   - 枪术不属于地球已知的任何流派，为莱克忒亚异界武术
   - 战斗风格可切换（已确认有样式Ⅰ/Ⅱ/Ⅲ三种模式）
   - 完成度极高，在枪术技巧上不逊于地球顶尖武侦
   - 配合暗黑领域使用，可从任何方向发动致命穿刺

■ 防御能力
   - 持盾防御，盾牌的材质与结构疑似莱克忒亚锻造
   - 铠甲（黄绿色镶银甲）提供良好的物理防护
   - 在铠甲防御下，近距离手枪弹可能难以造成决定性伤害

■ 冲击波攻击
   - 可从枪或盾牌发出冲击波
   - 例：在明治神宫之战中以冲击波割伤金次右耳、震伤其右臂
   - 中距离攻击手段，填补暗黑领域无法覆盖的间隙

┌─────────────────────────────────────────────────────┐
│  二、超自然能力                                      │
└─────────────────────────────────────────────────────┘

■ 暗黑领域（Dark Field / 暗黑領域）
   - 瓦尔基丽雅最具代表性的异界能力
   - 可制造光线吸收率99.95%以上的领域
   - 领域内完全黑暗，视觉/光学瞄准完全失效
   - 领域范围可扩展，最大覆盖面积≥数十米范围
   - 仅瓦尔基丽雅本人可在其中自由行动（种族适应性）
   - 战术应用：封锁敌方视野 → 以枪术在黑暗中精确刺击

■ 飞龙化（Dragon Morph / 飛龍化）
   - 从人形态转变为巨大飞龙形态
   - 飞龙形态：
     · 体长数米，翼展广阔
     · 覆盖鳞甲，物理抗性极高
     · 拥有强大的咬合力与飞行机动性
     · 可承载骑乘者（被尼莫等操控者骑乘）
   - 在人形态中头部的小翅膀可能是飞龙化器官的残留
   - 飞龙形态的维持时间与消耗未知

┌─────────────────────────────────────────────────────┐
│  三、亚种存在 —— 操舵手（Helmsman）               │
└─────────────────────────────────────────────────────┘

■ 操舵手（瓦尔基丽雅亚种）
   - 确认存在瓦尔基丽雅的亚种/派生型
   - 操舵手为诺契勒斯号（诺契勒斯核子潜艇）的船员
   - 职能：潜艇操舵/航行控制
   - 保留部分女武神特征但非完全战斗型
   - 推测N组织从莱克忒亚引进了多位瓦尔基丽雅族成员，
     分别承担不同的舰艇职务

■ 种族多样性推测
   - 瓦尔基丽雅族在莱克忒亚可能有多种职业分化
   - 战斗型：瓦尔基丽雅（主将）
   - 舰艇型：操舵手
   - 可能存在其他未披露的亚种

┌─────────────────────────────────────────────────────┐
│  四、战术定位与协同                                 │
└─────────────────────────────────────────────────────┘

■ N三人攻击队战术架构
   ┌─────────────┐
   │  哈比鸟     │ ← 尖兵：空中侦察、突袭、捕获
   │  (Harpy)    │     无臂但有巨翼，速度极快
   └──────┬──────┘
          ▼
   ┌─────────────┐
   │  瓦尔基丽雅  │ ← 主将：正面战斗、火力核心、领域控场
   │  (Valkyrie) │     人形态三风格切换+暗黑领域
   └──────┬──────┘
          ▼
   ┌─────────────┐
   │  伊藤茉斩   │ ← 辅佐：不可知子弹、游走牵制、撤退掩护
   │  (Makoto)   │     为前公安零课，战术经验丰富
   └─────────────┘
   
   战术原则：当对方展现接近己方战力时，无论胜败都即时撤退。
   这意味着N三人队的核心战术是"优势速攻、胜负不留"，
   以最小风险获取最大战果。

■ 飞龙化战线角色
   - 在大型战役（如羽田机场上空拦截远山五兄妹）中作为空中作战单位
   - 配合尼莫的云雾隧道与墨丘利的圆盘形态形成立体防御网
   - 飞龙形态时可能失去人形态的战术精度，转为力量与体型压制

     · 飞龙化 → 投入全力/最高危险等级
   - 情报提供 → 愿意配合（可能受N上层命令）

                 【主题关键词 / Thematic Keywords】
================================================================================

核心主题: 异界女武神 · 莱克忒亚的战士
角色原型: 北欧女武神（Valkyrie）+ 西方龙（Dragon）
双重形态: 人形态（战术精密型）↔ 飞龙形态（力量压制型）

■ 在作品中的定位
   - N组织的实战中坚力量——作为N三人攻击队的主将
   - 莱克忒亚异界存在"渗透地球"的代表性角色之一
   - N组织战斗系统的"重火力核心"
   - 与恩蒂米菈（精灵）、墨丘利（水银）共同构成
     N的异界战力三角

■ 莱克忒亚关联
   - 是"接轨"设定的重要一环——异世界生物进入地球
   - 与操舵手等亚种共同揭示莱克忒亚存在成体系的军事组织
   - N组织通过异界召唤/派遣获得跨次元战力优势

■ 发展前景（推测）
   - 飞龙形态曾被击杀 → 但种族中存在多个个体/亚种
   - 若莱克忒亚篇进一步展开，瓦尔基丽雅族可能具有更大戏份
   - 其种族的文化禁忌（头盔规则）尚未在剧情中被触发，
     可能为未来剧情埋下的伏笔
   - 随N组织分裂（尼莫脱N），瓦尔基丽雅族所属成为悬案

■ 命名考据
   - "瓦尔基丽雅"音译自北欧神话的 Valkyrie（女武神）
   - 其全名"库维莉亚斯，伊立夏那，菲力嘎娜娜斯，罗罗"
     为疑似莱克忒亚语/异界语的音译，词源不明
   - 北欧女武神神话中：
     · Valkyrie是奥丁的侍女，负责在战场上挑选英勇战死者
     · 引导英灵前往瓦尔哈拉（英灵殿）
     · 以长枪、铠甲、战马或飞行为经典形象
   - 绯弹版本将"女武神"与"飞龙"元素融合，
     创造出独特的双形态异界战士

■ 关于"死亡"与"亚种"的重要说明
   - 在Vol.27中飞龙形态被金一（加奈）以"罗剎"击杀
   - 但在Vol.36中"操舵手（瓦尔基丽雅亚种）"登场
   - 这意味着：
     A) 瓦尔基丽雅族有多个个体，被击杀的只是其一
     B) 被击杀的是飞龙形态，瓦尔基丽雅核心可能不死
     C) N组织持续从莱克忒亚招募/召唤瓦尔基丽雅族成员
   - 目前尚无定论，但(A)+(C)的可能性最高

■ 人形态头部的小翅膀
   - 极可能是退化/半显化的飞龙化器官
   - 类似某些奇幻设定中"龙族可在人形保留部分特征"
   - 小翅膀在生物学上与哈比鸟的巨翼同源（均为飞行器官），
     但瓦尔基丽雅的飞行能力主要在飞龙形态下发挥

■ 女性至上的N组织环境
   - N组织成员以女性（及类人女性生物）为主
   - 瓦尔基丽雅作为非人女性，完全适应此环境
   - 其种族似乎也是母系/女性主导的社会结构

■ 与北欧神话原型的差异
   - 传统Valkyrie：
     · 引导灵魂，服务神明
     · 多为团体行动，戴盔披甲骑飞马
     · 有选择生死的神格
   - 绯弹版瓦尔基丽雅：
     · 战斗先驱，而非灵魂引导者
     · 双形态（人+飞龙），非骑马
     · 无神格，为异界的高级战斗种族
     · 归顺于N组织而非神明

■ 已知的相关角色索引
   - 恩蒂米菈（c00?）—— 同为莱克忒亚派遣者，精灵族
   - 墨丘利/水银女（c60?）—— 同为莱克忒亚存在
   - 海卓拉（c61?）—— 莱克忒亚共生体
   - 操舵手 —— 瓦尔基丽雅亚种
   - 哈比鸟（c?）—— 莱克忒亚飞行种，战斗搭档
   - 伊藤茉斩（c64）—— N三人队辅佐
