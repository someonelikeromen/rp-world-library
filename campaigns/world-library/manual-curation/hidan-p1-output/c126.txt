                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 龙的魔女（Dragon Witch）
   - 往来于莱克忒亚（列库忒亚）与现世的人口贩卖商
   - 奴隶贸易商 · 半人半妖狩猎者
   - 俄罗斯东正教古仪式派信徒（名义上）

■ 种族/血脉
   - 龙与人类混血（祖母是龙）
   - 半人半龙种
   - 拥有龙族血统的魔女

■ 年龄
   - 自称"打出生以来二十年"（Vol.32），但实际可追溯至1898年
   - 有1898年、1947年、2008年三代照片，容貌完全未变
   - 推测实际年龄超过百年（借助魔术/异世界时间差）

■ 外貌特征
   初期状态（Vol.32 地下品川初登场）：
   ├─ 金发：一头纤细的金发，两侧长有如同水墨画中龙的分支犄角
   ├─ 瞳色：蓝色
   ├─ 体格：北方裔白人女性特有的丰满身材
   ├─ 服装：几乎裸露全部白皙肌肤的"比基尼铠甲"+披风
   │        搭配高跟靴、深红色指甲油
   ├─ 饰品：脖子上挂有镶宝石的十字架项链
   ├─ 尾巴：前端长有刺针般长毛的长尾，可自由操控
   └─ 坐骑：大红色 YAMAHA YZ1 FAZER 大型运动机车

   重伤后状态（Vol.40 埃及再登场）：
   ├─ 右臂：肘部以下缺失，安装五指钩爪假肢（弹簧锁紧机关）
   ├─ 右眼：失明，戴眼罩
   ├─ 面部：被龙咬伤的傷痕横跨一大块，但因其美貌形同纹身
   ├─ 左肩-左胸间：被恩蒂米菈箭矢射穿的大面积烧伤疤痕
   │        （使用烧灼止血留下的原始治疗痕迹）
   ├─ 铠甲：莱克忒亚制的防弹铠甲（可偏转子弹）
   └─ 鳞片：龙化时背部、肩膀、左前臂、小腿长出炮铜色鳞片

■ 惯用语言
   - 俄语（母语）：блядь(混蛋)、сукаблядь(畜生)、
     собака(去死)、чёрт(该死)、Ураааа(乌拉)
   - 英语（对外交涉用）
   - 莱克忒亚语（魔术咏唱用）："佩尔贝，贝尔佩，来杰！"
     "Ангельский круг" 等

                  【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   ├─ 贪婪的商人：视一切为商品，金钱至上主义
   ├─ "人生就是用金钱买卖的东西"——极端资本主义世界观
   ├─ 享乐主义："趁活着的时候赚大钱，尽情享乐，才算赢家"
   ├─ 自信从容：面对金次也始终保持玩弄猎物的态度
   └─ 残虐：以牙还牙，加倍奉还（Vol.40座右铭）

■ 本质内核
   ├─ 实用主义者：只做对生意有利的事，不浪费时间和感情
   ├─ 孤独的个体：虽是独行商，但与各方势力保持中立关系
   ├─ 有意外纯情的一面：被金次强吻后表现出"
   ├─   巨大的羞耻反应→"这、这是我的初吻……！"
   ├─   且是"北方裔白人女子特有的大红脸"（满脸通红）
   ├─ 战斗狂潜质：面对强敌时展现出兴奋和享受的态度
   └─ 守财奴本质：连纯金粉都随身携带作为财产

■ 核心信念
   "人是金钱的奴隶，人生是用金钱买卖的东西"
   "我只是个商人，目的就只有钱"
   "时间就是金钱"

■ 心理弱点
   ├─ 过于自信：多次低估对手（金次、猿田、恩蒂米菈）
   ├─ 金钱至上主义的盲点：在最后关头被金钱反噬
   ├─ 对魔术过于依赖：魔之全集被夺后战斗力大幅下降
   ├─ 感情经验缺失：被强吻后出现明显的动摇和混乱
   └─ 报复心强：仇恨驱动下采取冲动行动

■ 经典台词
   "赐予罪孽深重之人，慈悲的死亡——斩断，剖开，作为龙的饲料。"
     —— 俄罗斯正教古仪式派的画十字后接抹脖子的开场白

   "我的座右铭是以牙还牙，加倍奉还。我要砍下你的两条胳膊，挖出两只眼睛。"
     —— Vol.40 对金次的复仇宣言

   "你、你、你这家伙！竟、竟然夺走了少女的……嘴唇……！
    这、这可是我的初吻……！明明年纪比我小……！我要你以死谢罪！"
     —— Vol.40 被金次强吻后

   "我卖的可不是像那种随处可见的廉价女人。"
     —— 对恩蒂米菈的标价

   "我打出生以来二十年，都尽可能赚钱不浪费时间。"
     —— 自我介绍

┌─────────────────────────────────────────────────────┐
│  一、魔之全集（Complete Demon Book Collection）    │
│          —— 十三册古代魔书的合订本               │
└─────────────────────────────────────────────────────┘

■ 来历
   - 抢夺半人半妖"古代人民"持有的十三册魔书
   - 以不同颜色纸张区分各卷，合订后侧面呈彩虹色
   - 书中记载了各半妖种族秘传的战斗魔术
   - 并非所有魔术对使用者都有良好"适合度"
   - 拉斯普丁纳最擅长的是最初抢得的龙召唤/归还魔术

■ 已确认的使用章节

   [1] 白色页面 — 视野外瞬间移动（Teleportation）
       用途：往来于现世与莱克忒亚之间
       机制：以时间与重量的平衡进行跳跃
       施展方式：在地面画魔法阵，辅以披风内侧图样
       备注：可从莱克忒亚将隐形龙传输到此世界
       辅助构造：胎痕 + 火焰环结合为魔法阵结构

   [2] 红色页面 — 火焰吐息（Flame Breath）
       用途：从口中喷出火焰喷射器级别的烈焰
       机制：龙族血统产生的消化器官可燃性气体+分泌液
       应用：曾用此招焚烧恩蒂米菈的森林及各种村庄

   [3] 黄色页面 — 闪电魔术（Lightning Magic）
       用途：远程电击，可麻痹生物
       实例：Vol.32 以剪刀手势放闪电击中萜萜蒂与列萜蒂

   [4] 绿色页面 — 龙卷风魔术（Tornado / Wind Magic）
       用途：产生横向龙卷风，用于拖动目标
       实例：Vol.32 卷入火花后将萜萜蒂与列萜蒂拖向自己

   [5] 不明颜色 — 火焰舞蝶·爆炎弹
       用途：制造发光蝴蝶→狮子→凤凰状火焰弹
       效果：可烧死隐形龙，具备照明+高杀伤力

┌─────────────────────────────────────────────────────┐
│  二、龙之使役（Dragon Taming）                    │
│          —— 拉斯普丁纳最核心的战斗能力           │
└─────────────────────────────────────────────────────┘

■ 隐形龙（Invisible Dragons / 不可视龙）
   种类A — 大型隐形龙
   ├─ 体型：暴龙型双足步行，高约3米，头部异常大
   ├─ 视觉：无眼睛，依靠听觉（枪声/爆炸声）定位
   ├─ 皮肤：坚硬如橡胶，反器材步枪（12.7mm）仍打不穿
   ├─ 特性：体表具备光线曲折迷彩，在光学上完全隐形
   ├─ 颜色：色素极薄，血管清晰可见的白龙（被烧后显现）
   ├─ 智商：低下，分不清敌人和主人（曾误咬拉斯普丁纳）
   └─ 攻击：锯齿獠牙的咬合力如老虎钳，可撕裂人体

   种类B — 小型隐形龙（佩尔贝、贝尔佩、来杰）
   ├─ 体型：狗大小，会飞
   ├─ 智商：较高，能理解拉斯普丁纳的英语命令
   ├─ 特性：同样隐形，但比大型龙温顺且听驯
   └─ 用途：束缚对手、侦察、监视、运输物品

■ 龙群协同战术
   - 利用爆炸声或枪声诱导龙群攻击特定目标
   - 用龙封住对手行动后，自己以火焰爪斩杀
   - 在敌人体表擦上气味，使龙群追踪
   - 魔法阵中召唤龙群进行围攻

┌─────────────────────────────────────────────────────┐
│  三、龙族体质与战斗能力                           │
└─────────────────────────────────────────────────────┘

■ 龙化第二形态（Second Form）
   触发条件：极度愤怒或危机时
   外观变化：
   ├─ 背部、肩膀、左前臂、小腿长出炮铜色龙鳞
   ├─ 犬齿变长
   ├─ 表情更接近龙，语言能力可能衰退
   └─ 整体防御力进一步提升

■ 火焰钩爪（Flame Claws）
   - 假肢钩爪上涂有可燃性油
   - 用钩爪摩擦铠甲边缘产生火花点燃
   - 可造成灼烧伤口，防止缝合
   - 目标：专门瞄准对手的眼睛和手臂（执拗攻击模式）

■ 近战格斗体系
   1. 机车格斗术 — 源自魔女扫帚格斗术的摩托车战斗
      ┃ 翘前轮冲撞、后轮战锤扫击、圆规式回旋扫腿等
   2. 钩爪格斗 — 五指均为锋利刀具的假肢武器
      ┃ 可锁住对手刀身使其无法抽回
      ┃ 可抓取、破坏、穿刺
   3. 尾巴攻击 — 灵活的长尾可缠住对手腰部使其无法逃脱
   4. 空爆移动 — 以空气爆破改变空中轨迹（锯齿状下落）

■ 铠甲防御
   - 莱克忒亚制的魔法铠甲
   - 铠甲护肩可偏转子弹（通过弧面+角度）
   - 可用于格挡和弹开手枪级别的火力

■ 弱点
   ├─ 魔之全集被破坏/夺取后，可使用魔术大幅受限
   ├─ 龙群智商低，易被诱导误伤自己人
   ├─ 枪声和爆炸声吸引龙群不分敌我的攻击
   └─ 对弓箭武器有特别的恐惧（即恩蒂米菈的复合弓）

                  【经历年表 / Timeline】

■ 莱克忒亚时代（正篇开始前）
├─ 祖母是龙的诞生的龙人混血魔女
├─ 在莱克忒亚抢夺古代人民（半人半妖）的魔书
├─ 烧毁恩蒂米菈居住的精灵森林
├─ 烧毁萜萜蒂与列萜蒂的故乡（导致她们失去语言能力）
├─ 将半人半妖当作奴隶贩卖至全世界
├─ 收集全十三册魔书，合订为"魔之全集"
├─ 1898年、1947年、2008年被拍到相同容貌的照片
│  （推测跨越三个时代，但外表毫无变化）
├─ 与莫里亚蒂教授及尼莫有关联（知晓N的计划）
└─ 被日本某组织从明治时代起代代监视

■ Vol.32 — 地下品川 · 初战与"死亡"
├─ 追踪恩蒂米菈至日本东京
├─ 与猿田武检补（中川老师）联手设计圈套
├─ 以芹奈和林檎的发饰为诱饵引出金次和恩蒂米菈
├─ 召唤隐形龙群包围废工厂
├─ 与金次进行机车格斗战+火焰魔术战
├─ 释放"Ангельский круг"（天使之环）包围战场
├─ 试图用视野外瞬移带恩蒂米菈前往莱克忒亚贩卖
├─ 金次以"扇贯"开道，恩蒂米菈以复合弓射穿魔之全集
├─ 箭尾的爆竹声吸引龙群围攻拉斯普丁纳
├─ 被自己的龙咬噬，连同魔法阵和FAZER一起消失
└─ 被外界认为已死亡（金次向猿田报告"被龙吃掉了"）

■ Vol.33-34 — 战后余波
├─ 亚莉亚、白雪、贞德等人研究其留下的纯金粉
├─ 确认纯金粉上施有未知魔术（"跳金"——穿越时空媒介）
├─ 金次被路西菲莉亚提及"就连拉斯普丁纳都被你讨伐"
├─ 蕾芬洁提到拉斯普丁纳曾说过世界各地的魔女正因
│  色金粒子空白化而搬来日本
└─ 金的残金被用于研究穿越时空的"跳金"术式

■ Vol.40 — 埃及 · 复活与再战
├─ 被龙群咬噬后未死，在莱克忒亚接受低水平缝合治疗
├─ 右臂肘以下丧失，装钩爪假肢
├─ 右眼失明，面部留下横跨伤痕
├─ 左肩至左胸间留下大面积烧伤疤
├─ 回到现世后开始在埃及活动
├─ 在吉萨市场袭击金次和梅梅特藏身的店铺
├─ 骑着Majesty撞倒市民逃跑
├─ 在金字塔前观察金次与莎拉的战斗
├─ 在苏伊士炮台挟持穆斯塔法和拉拉做人质
├─ 与金次、金女、梅梅特展开第二次对决
├─ 用透明龙封锁金次行动，试图火焰爪击杀
├─ 被金次以"人类震爆弹"战术强吻（吸出肺内可燃气体）
├─ 被吻后表现出巨大羞耻反应（初吻被夺）
├─ 释放第二形态（龙鳞化），展现更强战斗力
├─ 金女以"姐对"爆发模式+光影刀对战
├─ 被梅梅特的沙人质术欺骗，失去筹码
├─ 星星（远山雪花）逼近，战斗结局不明
└─ 拉斯普丁纳已展现更强的复仇心与战斗能力

   关系：复仇对象 · 商品目标 · 击败她的仇人

   备注：恩蒂米菈是拉斯普丁纳从莱克忒亚一直追踪到此世界

   备注：尼莫的诺契勒斯号上有一名与拉斯普丁纳长得

■ 魔之全集（The Complete Collection of Demon Books / 魔之全集）
   - 十三册古代人民魔书的合订本
   - 侧面呈彩虹色（各卷不同颜色纸张）
   - 包含：龙召唤/归还、火焰吐息、闪电、龙卷风、瞬移等
   - 是拉斯普丁纳战斗力的核心
   - Vol.32中被恩蒂米菈的箭矢射穿，导致书中魔术失控

■ YAMAHA YZ1 FAZER（大红色大型运动机车）
   - 拉斯普丁纳的常规移动手段
   - 用于施展机车格斗术
   - Vol.32中与魔法阵一起消失于瞬移中

■ 钩爪假肢（Claw Prosthetic / 五指钩爪假手）
   - Vol.40后右臂的替代品
   - 五指均为锋利刀具
   - 内有弹簧锁紧机关，可锁住对手武器
   - 涂有可燃性油，摩擦铠甲即点燃为火焰钩爪

■ 纯金粉 / 砂金
   - 拉斯普丁纳随身携带的财产
   - 施有未知魔术（"跳金"术式——穿越时空的媒介）
   - 被白雪/亚莉亚/贞德/玉藻研究确认
   - 用于魔法阵的辅助构造材料

■ 俄罗斯正教十字架
   - 镶嵌宝石的项链十字架
   - 象征其俄罗斯正教古仪式派的信仰背景

■ 莱克忒亚制比基尼铠甲
   - 可偏转子弹（通过弧面设计）
   - 以防莱克忒亚的各种魔术攻击为前提制作

                 【世界地位与主题 / Thematic Position】
================================================================================

■ 在世界观中的定位
   - 莱克忒亚侧魔女的中坚力量
   - 半人半妖贩卖网络的节点人物
   - 金次"莱克忒亚篇"的初期重要敌军
   - 证明色金粒子空白化后世界魔女持续流入日本的证据

■ 主题内涵
   ┃ "金钱 vs 人性" ┃ 拉斯普丁纳将一切视为商品的极端资本主义，
   ┃                ┃ 与金次"人不是东西"的信念形成鲜明对立

   ┃ "复仇的循环"   ┃ 从猎人到猎物、再从猎物重生为复仇者的过程，
   ┃                ┃ 展现了莱克忒亚侧弱肉强食的世界观

   ┃ "龙与火"       ┃ 龙象征毁灭与不可控制的自然力量，
   ┃                ┃ 火焰象征她的愤怒与复仇心——最终被火焰反噬

   ┃ "铁处女的反差" ┃ 残虐无道的奴隶商人在被夺初吻后流露出
   ┃                ┃ 少女般的纯情反应，是系列经典的"恶役萌"设计

■ 平行参照
   - 俄罗斯背景 + 使役龙的能力 → 影射格里高利·拉斯普京
     （拉斯普丁纳 = 拉斯普京的女性化变体）
   - 与瓦尔基丽雅、海卓拉、路西菲莉亚同为莱克忒亚魔女
   - 不同于瓦尔基丽雅的军事感和海卓拉的学者气质，
     拉斯普丁纳是纯粹的"商人型"魔女

■ 关键事实确认
   - 初登场：Vol.32《魔剑的妖精》地下品川篇
   - 再登场：Vol.40《……》埃及篇
   - 虽在Vol.32被龙噬而"死亡"，但Vol.40确认生还
   - 年龄谜团：1898-1947-2008三次照片容貌不变
     （推测与莱克忒亚和现世的时间流速差有关）
   - 祖母是龙 → 半人半龙的混血魔女
   - 初吻被金次在战斗中强行夺取（Vol.40）
   - 名字"拉斯普丁纳"是格里高利·拉斯普京的女性化衍生

■ 关于"魔之全集"的补充
   - 十三册魔书对应"十三种古代人民"
   - 拉斯普丁纳最擅长龙魔术（因与自身龙血统契合）
   - 魔书被射穿后是否完全失去所有魔术能力——待确认
     （Vol.40中她仍能召唤小型龙+使用火焰，但未再现
      瞬移和火焰环等高阶魔术）

■ 关于"跳金"术式
   - 拉斯普丁纳使用的纯金粉是穿越时空/世界的关键介质
   - 确认与恩蒂米菈使用的魔法阵金丝为同一种未知魔术
   - 证明"金"在莱克忒亚魔术体系中具有特殊的超空间性质

■ 故事功能
   - 连接莱克忒亚与现世的人口贩卖网络的重要一环
   - 促使金次领悟"扇贯"（冲击波雷射）的契机
   - 推动恩蒂米菈从"奴隶"心理向自由战士蜕变的关键角色
   - 展现色金粒子空白化后世界魔女涌入日本的现实

■ 未解之谜
   - 拉斯普丁纳的真正年龄和长寿之谜
   - 与列诺艾尔（诺契勒斯号龙女船员）的亲缘关系
   - Vol.40最终战的结局（雪花逼近后）
   - 是否会成为第三次接轨时的相关人物
   - 魔之全集是否已完全修复
