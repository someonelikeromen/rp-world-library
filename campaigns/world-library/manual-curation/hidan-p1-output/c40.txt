                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 德古拉女伯爵（Countess Dracula）—— 欧洲传说中的吸血鬼贵族
   - 紫电魔女 —— 使用紫色雷电和催眠术的欧洲系魔女
   - 眷属（伊·U 关联势力）成员 → 后期转为"非敌非友"的独立协力者
   - "同窗会联盟"（Reunion）夺还小队正式成员（Vol.37 印度篇）
   - 伊·第二届同学会参与者（夏洛克·福尔摩斯召集）

■ 家族
   - 德古拉一族 —— 传说中的吸血鬼家族后裔
   - 关联人物：
     · 弗拉德·德古拉（Vlad Dracula / "无限之罪弗拉德"）
       伊·U第二号人物，阶级在夏洛克·福尔摩斯之上
       与希尔达同属德古拉家系，共享吸血鬼体质
       但有明确血缘关系否未记载
     · 德古拉家族特征：
       魔力驱动的吸血鬼体质、超强再生能力、
       多形态变身（第三形态等）、魔脏（Magic Organs）系统、
       银制武器特效弱点

■ 特征分类
   - 魔度：20-50 范围（"浓"的类别），
     与九九藻、绯鬼、古兰督卡同级
     → 绯弹世界的魔力体系中属于中上级别
   - 魔女类型：纯粹的"紫电魔女"型，雷电系专精
   - 对比同级魔女：
     · 希尔达（紫电）vs 卡羯·葛菈塞（厄水）：
       希尔达更纯粹、更非人性；卡羯保留更多人类情感
     · 希尔达（紫电）vs 贞德·达鲁克30世（银冰）：
       元素对立（雷 vs 冰），立场上常对立

■ 外貌
   - 年轻女性外表，肤色苍白（德古拉家系特征）
   - 金色卷曲的螺旋状双马尾（Vol.37描述："卷曲的金色双马尾"）
   - 锐利的瞥视眼神
   - 身着哥特式暗色礼服——黑色荷叶边装饰（Vol.37描述）
   - 常携鸵鸟羽毛扇（装饰/武器兼用）
   - 黑色蝙蝠状翅膀（可展开飞行）
   - 战斗时全身缠绕紫色电光，散发妖异光芒
   - 瞳色未明确记载，推测为红色或紫色（吸血鬼系特征）
   - 涂有鲜红指甲油的手（Vol.37描述）

■ 标志装束
   - 日常/社交：哥特萝莉式黑色礼服 + 荷叶边阳伞 + 鸵鸟羽毛扇
   - 战斗装：同礼服，可展开翅膀；雷电缠绕
   - 学生装（Vol.37描写）："像是在角色扮演什么美少女游戏的人物般、
     造型有点类似礼服的女学生制服"

■ 年龄
   - 明确年龄未公开
   - 作为德古拉家族成员（吸血鬼系），实际年龄可能远超外表
   - 推测外表年龄为16-22岁左右（与武侦高学生相仿）

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 冷酷无情的执行者 —— 对任务以外的一切漠不关心
   - 傲慢 —— 对自己的能力有绝对自信，视普通人类为蝼蚁
   - 残忍 —— 战斗中不吝使用极端手段（操纵、下毒、劫持）
   - 高贵 —— 符合女伯爵身份的优雅与威严

■ 行为模式
   - 以强大魔力压制对手，先展示压倒性力量再逐步击溃
   - 善于利用暗示术（催眠术）操控他人心理
   - 战术上倾向于设局埋伏而非正面硬碰
     （晴空塔的玫瑰丛陷阱 + 双重陷阱：毒耳环+假亚莉亚）
   - 不轻视敌人 —— 在晴空塔对理子设下精密的双重陷阱
   - 会使用诡计和伪装（躲在他人影子里搭免费飞机，Vol.37描述）

■ 本质内核
   - 纯粹的"魔女" —— 缺乏普通人的同理心和道德感
   - 将自身定位为高于人类的超凡存在
   - 对自己的吸血鬼/魔女身份有强烈的自豪感
   - 但被理子输血救活后并非完全无动于衷：
     后期转为支援角色（Vol.15香港、Vol.22前零课事件、Vol.37印度篇）
   - 显示出"亦敌亦友"的灰色立场 —— 从未完全被"洗白"，
     但也不再是纯粹的敌对存在

■ 角色弧光：纯粹的敌人 → 受恩者 → 灰色协力者
   - Phase 1（Vol.4-5）：纯粹的敌对者，眷属的尖兵
   - Phase 2（Vol.8-15）：偶发性的支援者，立场变化的过渡期
   - Phase 3（Vol.22-37）：正式协力者（Reunion夺还小队成员）
   - 最大转折点：Vol.5被理子输血救活 —— 以德报怨改变了她的立场

■ 与其他魔女的差异化
   - 紫电魔女（希尔达）vs 厄水魔女（卡羯·葛菈塞）：
     卡羯有人类感情和脆弱面（白朗峰冰河共生的感动）
     希尔达几乎没有同理性驱动，行动基于利害计算
   - 紫电魔女（希尔达）vs 银冰魔女（贞德·达鲁克30世）：
     贞德虽为魔女但保留骑士道精神；希尔达更不择手段
   - 紫电魔女（希尔达）vs 热沃当之兽（丽莎）：
     丽莎本质是被诅咒的人类少女；希尔达本质是吸血鬼贵族

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、核心能力——紫电操纵（Purple Lightning）       │
└─────────────────────────────────────────────────────┘

■ 原理
   - 利用自身魔力（魔度20-50）生成并操控紫色雷电
   - 雷电既可以作为远程攻击武器，也可以强化自身
   - 可通过外部电源增幅威力
     （Vol.5晴空塔之战：通过棺材状变压器连接城市电网）

■ 已知招式/形态

   [1] 雷球（Thunder Ball / 雷球 / Tiara）
       凝结雷电形成球状能量体
       远程攻击技能
       电流密度极大，电压下降极小——极其危险的气体放电技能
       金次评价："如果被击中，就会像希尔达说的那样，烧成焦炭"
       金次认为再战时有大概率会失手的对手之一

   [2] 雷星（Lightning Star / 雷星 / Stellar）
       雷球的上位技·大型版
       星形雷电投射物，攻击范围和威力均大于雷球
       需更高的魔力输出

   [3] 第三形态（Third Form）
       德古拉一族的进阶变身形态
       发动条件：白热化战斗时使用
       效果：召唤大规模雷电覆盖战场，全身被紫色电光笼罩
       特征：攻击范围广域化，威力大幅提升
       弱点：第三形态下全身带电，
              若四颗魔脏被银弹同时破坏，
              电流会失去控制反噬自身
              （Vol.5被理子的银弹霰弹击中后，电流反噬导致坠落）

   [4] 雷球·雷星弱点
       需要外部电源供给才能达到必杀技水准
       如果不做外部准备就无法使用最大威力版
       金次对策："把输电线和希尔达隔开"

■ 关于能力等级的确认
   - 金次（Vol.40）评价希尔达为"再战时有大概率会失手的对手"
   - 与亚莉亚同样承认其威胁度极高
   - 属于危险度极高的能力者，被金次列入"需要持续监视"名单

┌─────────────────────────────────────────────────────┐
│  二、德古拉一族体质——吸血鬼系能力               │
└─────────────────────────────────────────────────────┘

■ 魔脏系统（Magic Organs / 魔臓）
   - 德古拉家族成员体内的魔力核心器官
   - 希尔达共有四颗魔脏
   - 普通吸血鬼的魔脏位置固定且对称（如左右胸各一）
   - 希尔达经过手术移位移置魔脏位置，使其不对称分布
     → 普通攻击无法同时击中全部魔脏
     → 这是她最关键的防御策略
   - 只要四颗魔脏不同时被破坏，就不会死亡
   - 银制武器对魔脏有特效（神话系克制关系）
   - 决胜手法（Vol.5）：
     理子用温切斯特M1887霰弹枪装填银弹霰弹，
     藏在向日葵花束中近距发射，同时覆盖四颗魔脏

■ 超再生能力（Regeneration）
   - 德古拉家族的吸血鬼再生能力
   - 普通伤害可快速恢复（被斩断的翅膀可以再生）
   - 严重伤害（魔脏被破坏）后会濒死/暂时丧失战力
   - 需要输血/外部能量辅助恢复

■ 蝙蝠翅膀飞行
   - 展开蝙蝠状巨大翅膀进行飞行
   - 飞行速度高，适合空战
   - 翅膀本身是可被攻击的脆弱部位
     （Vol.5被理子用刀斩断双翼，但可再生）

■ 穿墙能力
   - 可穿过固体墙壁（Vol.37：只把头钻出车顶铁板）
   - 被金次吐槽"在车内看起来身体吊在天花板上很惊悚"
   - 推测为德古拉家族的灵体化/穿透能力

■ 影化·附体术
   - 可藏身于他人的影子中进行移动
     （Vol.37 描述："躲在别人的影子里搭免费飞机"）
   - 可用于潜行、暗杀、跟踪
   - 金次区分是否是希尔达的术式的依据
     （Vol.45：判断"影化加附体的手法跟希尔达的术式一样，不过火候差远了"）

┌─────────────────────────────────────────────────────┐
│  三、其他能力                                      │
└─────────────────────────────────────────────────────┘

■ 暗示术 / 催眠术（Hypnosis / Suggestion）
   - 强力的精神操纵能力
   - 可以控制他人的行为和意识
   - Vol.5：通过毒耳环控制峰理子假扮亚莉亚
   - 金次在晴空塔被催眠动弹不得
   - 具体发动条件不明（可能需要媒介或对视）

■ 魔法阵·魔术知识
   - Vol.37提及：希尔达为卡邦克鲁的魔法阵准备了"能够停止的魔术"
     ——类似于对魔法阵程式进行破坏的电脑病毒
   - 说明她不仅依赖魔力，也拥有深度的魔术理论知识

■ 战斗风格
   - 以压倒性的雷电攻击为主
   - 配合催眠术和精神操控达成战术目标
   - 使用吸血鬼体质的再生能力打持久战
   - 战术灵活，善用环境（城市电力、影子移动）

┌─────────────────────────────────────────────────────┐
│  四、弱点与限制                                  │
└─────────────────────────────────────────────────────┘

■ 银制武器特效 —— 最致命的弱点
   - 银弹/银制武器对德古拉一族有特殊杀伤效果
   - Vol.5 决定性一击是银弹霰弹

■ 魔脏暴露即致命
   - 虽经手术移位增加防御难度，
     但四颗魔脏同时被破坏即濒死

■ 电流反噬风险
   - 第三形态全身带电状态下，
     若魔脏被破坏，电流会失控反噬自身
   - Vol.5 被银弹命中后电流失控导致坠落

■ 外部电源依赖
   - 必杀技（雷球/雷星）的全力版需外部电源
   - 切断输电线和隔离电源可阻止最大威力攻击

■ 魔度限制
   - 魔度20-50，属中上级别但非最顶级
   - 持续战斗能力受魔力量限制

                 【主题关键词 / Thematic Keywords】
================================================================================

核心定位: 欧洲吸血鬼系魔女 · 伊·U关联者 → 灰色协力者
角色弧光: 纯粹敌人 → 败北·受恩 → 非敌非友的灰色协力者
象征意象: 紫色闪电、蝙蝠翅膀、哥特阳伞、血与雷

■ 作品定位
   - 绯弹世界中"欧洲魔女势力"的代表之一
   - 德古拉家族在伊·U体系中的战力展示
   - 作为理子的对手衬托了理子的成长（从叛徒到英雄）
   - 推动"被救赎的敌人"这一叙事模式
     （理子献血救希尔达 → 反映理子内心的善良）
   - 构成欧洲魔女三极体系：紫电·希尔达 / 银冰·贞德 / 厄水·卡羯

■ "被救赎的敌人"叙事
   - 希尔达的转变并非主动悔改，而是被动接受了他人的善意
   - 这种转变模式不同于传统"洗白"，保留了角色的神秘感和威胁度
   - 从被理子输血救活到后期协助金次，暗示她并非完全冷漠
   - 但从未成为完全的"友方"——始终保持灰色地带

■ 战斗哲学的体现
   - 希尔达的战斗方式是"以绝对的魔力优势碾压"
   - 缺乏卡羯那种在冰河中共生交换体温的人类情感
   - 但在被理子输血救活后，展现了微妙的"欠人情"意识
   - 体现了绯弹世界中"恩怨分明的能力者伦理"
