                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 前公安零课（旧公安零课）编号第三号强者 · 三式 (Type-3)
   - 东京地检特搜部 执行部队队长
   - 狮堂班（以其为队长的四人精锐小队）队长
   - 金刚力士（仁王/那罗延天力士）的子孙——遗传性超常肌力血统

■ 家族
   - 狮堂家：代代相传的"先天性肌质多重症"血统
     ——肌丝经过多次折叠，力量输出为常人的256倍
   - 女儿：狮堂美香（Shidō Mika）——同样继承金刚力士怪力体质
   - 家系渊源：金刚力士子孙——佛教护法神"仁王"的现代后裔

■ 年龄: 40-50岁代（估计，昭和时代出生）
■ 身高: 约185cm（因极宽肩膀与魁梧体格，视觉上更为庞大）
■ 体重: 远超外表所见（肌肉纤维密度为常人数倍，骨骼极硬）
■ 发色: 如狮子鬃毛般的卷曲长发
■ 瞳色: 深邃双眸
■ 体型: 轮廓深邃，五官立体；魁梧如铁塔，肌肉型巨躯
■ 国籍: 日本
■ 惯用手: 右

■ 所属组织
   - 旧公安零课（已解散）→ 东京地方检察厅特别搜查部（执行部队）
   - 狮堂班：其组建并指挥的四人精锐小队
     · 滩（Nada）—— 武侦，SDA排行第十九，速度型
     · 可鹉韦（Kamugai）—— 美少年格斗家，诺取使用者
     · 妖刕／原田静刃（Yakiri）—— 佣兵忍者，暗杀系
     · 大门坊（Daimonbou）—— 僧兵，灵异对策专员

                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格 —— 玩世不恭的暴力大叔

   ┃ 诙谐幽默 ┃ 喜欢说笑话、用刑警剧台词开玩笑
   │           ┃ 常以"～呢"、"～吧"的慵懒语调说话
   │           ┃ 被金次评价"讲话方式莫名诙谐"
   ┃ 粗犷豪放 ┃ 喜欢喝酒，一口气干完整瓶一升装日本酒
   │           ┃ 酒品豪爽，在聚会上带头营造热闹氛围
   ┃ 玩世不恭 ┃ 对任务抱着"天真的男人"的态度
   │           ┃ 即使面对强敌也笑着说"别逗我笑"
   ┃ 爱护部下 ┃ 邀请部属聚会并亲自下厨（做咖哩）
   │           ┃ 为部下买单请客、帮可鹉韦解围
   ┃ 成熟老练 ┃ 一眼看穿金次的爆发模式控制原理
   │           ┃ 善于诱导对手说话、获取情报

■ 深层性格 —— 铁血的国家暴力执行者

   ┃ 国家意志 ┃ 以暴力守护日本为己任
   │           ┃ 零课时代被允许不经审判直接击毙恶徒
   ┃ 绝对自信 ┃ 对自己的力量有绝对的自负
   │           ┃ 面对爆发模式金次仍游刃有余
   ┃ 学习能力 ┃ 从美国败仗中吸取教训
   │           ┃ 将大门坊"像保镳一样带在身边"弥补短板
   ┃ 残酷面   ┃ 能够毫不犹豫对目标使用致命暴力
   │           ┃ 拥有实质上的杀人许可证
   ┃ 老谋深算 ┃ 安排可鹉韦与金次在外语高中"偶遇"刺探情报
   │           ┃ 一切言行背后皆有计算
   ┃ 昭和遗风 ┃ 以昭和时代出生者特有的举例方式
   │           ┃ 用古老的机器人动画命名自己的招式

■ 精神内核——"天真的男人"哲学

   狮堂虎严的人生哲学可以用"天真的男人"（甘い男）来概括。
   这并非指幼稚或无知，而是在绝对力量支撑下的从容不迫——
   
   1. 对自己的力量有绝对的自信，所以不需要紧张或戒备
   2. 即使面对危机也能保持笑容，因为相信拳头能解决一切
   3. 在铁血任务中不失去人性的幽默感
   4. 在暴力执行的同时保持昭和式的"男气概"

   这种"天真的男人"哲学，既是他作为绝对强者的骄傲宣言，
   也是他在国家暗部的黑暗中保持人性的精神支柱。

■ 核心反差——铁汉柔情

   狮堂最大的魅力点在于强烈的反差感：
   ┃ 一拳碎楼的怪力 ↔ 系上小兔子围裙做咖哩
   ┃ 冷酷的逮捕者 ↔ 请部下吃饭的慷慨大叔
   ┃ 国家暴力机器 ↔ 开黄腔时被部下调侃的老爸
   ┃ 威胁金次的铁腕 ↔ 看金次被捉弄时笑得最大声

   这些反差使他从一个扁平的"敌人"角色升华为有血有肉的角色，
   也是他在读者中拥有高人气的核心原因。

┌─────────────────────────────────────────────────────┐
│  一、金刚力士血脉 · 先天性肌质多重症              │
│         —— 256倍肌力的绝对力量体系                │
└─────────────────────────────────────────────────────┘

■ 原理
   - 狮堂家世代遗传的罕见体质
   - 通常人的肌肉纤维只经过一次折叠
   - 狮堂家的肌丝经过多次折叠（具体折叠数未公开）
   - 输出力量为常人的256倍
   - 代价：需要大量糖原补充能量；体重远超外表可见

■ 已确认的能力参数

   [1] 基准力量输出
       常人基准：1
       狮堂基准：256
       评价：远超人类认知范畴的绝对物理力量

   [2] 樱花对比值
       八倍樱花（vs金次 vol-22）：
       ┃ 狮堂以左手单手接住 ┃ "几乎到极限"但仍有余力
       │                     ┃ 金次评价："他毫发无伤"
       ┃ 全力拳击 ≈ 樱花×10倍 ┃ 可鹉韦评估（vol-38）
       ┃ 握力异常 ┃ 能捏碎金属，以握力限制对手无法动弹
       ┃ 投掷力 ┃ 能将金次水平投掷出数米远

   [3] 身体特性
       体重异常：因肌肉密度极大，体重远超外观
       骨骼极硬：超越常人范畴的骨密度
       脚步声重：木质地板会发出"轧轧"的沉重声响
       汽车悬架：因他的重量而下沉

┌─────────────────────────────────────────────────────┐
│  二、铁拳战技 · 超重击格斗体系                   │
└─────────────────────────────────────────────────────┘

■ 战斗风格
   狮堂并非速度型——他的拳速与体型相称的"慢"，
   但力量太过庞大，以至于产生"空间扭曲的错觉"。
   即使被预判也无法防御——因为力量过强。
   作品描述其全力一击如"坠落地球的小行星"。

■ 已确认的招式命名（源自昭和机器人动画）

   [1] 伊迪安之剑（Ideon Sword）
       源自《传说巨神伊迪安》
       用于形容其全力打击
       别称"太阳射线"或"伊甸王神剑"
       可鹉韦和滩对其招式的戏称

   [2] 指节箭（Knuckle Arrow）
       "现代复活的仁王使出全力的指节箭"
       握紧拳头后如拉弓般蓄力，然后释放
       特征：先吹一口气在拳头上，然后深吸一口气

   [3] 超慢拳（Extremely Slow but Overwhelming Punch）
       从正上方砸下的"绝对打击"
       力量过大导致速度感知异常
       金次评价："狮堂全力使出的拳击，估计具有樱花十倍左右的威力"

│  三、战术指挥与战斗经验                           │
└─────────────────────────────────────────────────────┘

■ 狮堂班战术体系
   - Delta队形 · 攻击性阵列（初现vol-21）

   - 知道金次与父亲远山金叉是同一类型

■ 经验积累
   - 从美国败仗中学习到"需要灵异对策专员同行"的教训
   - 将大门坊如同保镳般带在身边成为定番模式
   - 数十年的国家暗部工作经验

                  【人际关系 / Relationship Map】
================================================================================

■ 远山金次（远山金次）
   关系：追捕者→亦敌亦友 / 长辈对后辈
   评价：狮堂是金次在作品中遇到的最强纯力量型对手之一。
         虽然奉命多次追捕金次，但狮堂对金次的态度含有
         "长辈对后辈的考验"与"同为武侦世家的默契"。
         狮堂认识金次的父亲远山金叉，曾亲自赴美试图救回他——
         这使得他对金次抱有超越任务层面的个人兴趣。
         在妖刕家宴会上请金次吃饭，在被逼穿女装时笑得最开心
         ——关系介于对手与损友之间。
   金次的评价："那混账……虽然强得离谱，但至少不是什么不由分说的家伙。"

■ 远山金叉（远山金叉）— 金次之父
   关系：营救者 / 知晓者
   评价：狮堂是少数知道远山金叉生存真相的人物之一。
         他曾受日本政府派遣，潜入美国试图救回金叉。
         虽然任务失败，但他成功确认了金叉的存活。
         这层背景使他对远山家的秘密比常人有更深的了解。

■ 远山金一／加奈（远山金一/加奈）
   关系：合作者 / 同世代战友
   评价：与加奈之间有超越组织的合作关系。
         两人经常联手行动——如闯入金次房间逼其穿女装。
         加奈对狮堂的态度亲密中带有熟稔的"损友"感。
         两人在任务中配合默契，互相理解对方的行事逻辑。

■ 狮堂班成员
   [1] 大门坊（大门坊）
       性质：部下 / 保镳 / 灵异对策专员
       评价：从美国败仗后，狮堂学会了将大门坊"像保镳一样带在身边"
             ——用以弥补自身对超能力者的应对短板。
             两人的组合是"绝对力量 × 灵异对策"的完美搭配。

   [2] 滩（滩）
       性质：部下 / 速度型搭档
       评价：滩是狮堂班中速度最快的成员，与狮堂的力量型互补。
             滩经常调侃狮堂的招式命名，两人关系轻松。

   [3] 可鹉韦（可鹉韦）
       性质：部下 / 年轻后辈
       评价：可鹉韦是狮堂班中最年轻的一员。狮堂安排其与金次
             在外语高中"偶遇"以刺探情报。称呼狮堂为"狮堂先生"。

   [4] 妖刕／原田静刃（妖刕）
       性质：部下 / 联络员
       评价：妖刕是狮堂与金次之间的主要联络人。
             妖刕家的聚会由妖刕充当"主人"而狮堂充当"家长"。

■ 狮堂美香（狮堂美香）— 女儿
   关系：亲族
   评价：继承了金刚力士血统的怪力，与父亲属于同系统的"乘能力者"。
         从女儿的存在可知狮堂家的怪力血统是通过遗传延续的。

■ 星伽白雪（星伽白雪）
   关系：同行关系
   评价：在vol-29曾与白雪一起行动。作为国家特务与武侦名家，
         两人在克罗梅德尔事件中有所交集。

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: 国家守序暴力 vs 个人意志自由
           —— 作为国家机器的一员执行任务 vs 作为"天真的男人"的人性保留
成长弧光: （已完成的强者）→ 从失败中学习 → 建立完善战斗体系
          —— 狮堂并非成长型角色，而是"已完成型"的绝对强者
          其弧光更多体现在"从美国败仗中学习后自我完善"的成熟过程

象征意象: 狮子（勇猛与守护）、仁王（金刚力士的护法神形象）、
          铁拳（绝对暴力的具象化）

世代主题: 昭和硬派 vs 平成理性
          —— 狮堂代表的是昭和时代出生的"传统的男人"美学
          与金次所代表的平成"理性武侦"形成鲜明对照

■ 作品定位
   - 前公安零课第三号强者的身份，使其成为国家暗部势力的代表
   - 金次的"战力标尺"——提醒读者和金次本人：天外有天
   - 远山家主线的关键知情者——唯一试图营救远山金叉的行动者
   - 反差萌角色的典范——刚铁巨汉的日常温馨面
   - 金刚力士神话的现代版——传统神话要素在现代战斗中的再现

■ 叙事功能
   [1] 战力标尺：以"300+ vs 100"的压倒性数值差，
      始终提醒读者和金次本人：即使进入爆发模式，离最强还远得很
   [2] 金叉知情者：连接"远山家族主线"与"国家阴谋线"的关键节点
   [3] 零课门面：展示了零课解散后国家特工的生存状态
   [4] 昭和/平成对比：通过狮堂与金次的互动展示世代差异与传承
   [5] 搞笑调剂：大叔式幽默、黄段子、喝酒场面为故事提供调剂

■ 名字考据
   "狮堂"（しどう / Shidō）
   ┃ "狮" = 狮子 —— 对应其狮子般的卷发与勇猛
   ┃ "堂" = 殿堂/大堂 —— 有如寺庙仁王般的守护者形象
   ┃ 全名直喻"狮子殿堂的虎威之人"
   ┃ 作品中评价："名字让人搞不清楚是狮子还是老虎"
   ┃ "虎严"与"虎岩"两种表记并存，音同义近

■ "三式"的含义
   狮堂虎严在公安零课中被称作"三式"（Type-3），
   暗示零课内部存在类似"编号"的等级制度。
   他是第三号强者——前零课中只有两人排名在其之上。

■ 金刚力士与现实的关联
   金刚力士是佛教中的护法神，通常以仁王像的形式
   立于寺庙山门两侧，以超人的怪力守护佛法。
   狮堂虎严的"金刚力士子孙"设定，正是将这一神话概念
   现代化为"遗传性怪力血统"。

■ 256倍的力量意义
   对比樱花：狮堂全力拳击 ≈ 樱花×10倍
   接八倍樱花："几乎到极限"但仍有余力
   全力一击的威力：足以震荡大气、震碎大楼玻璃
   在纯力量领域，狮堂被认为是作品中最强级别的存在

■ 粉丝通称
   ┃ 狮堂 / 狮堂先生 / 狮堂大叔
   ┃ 真·狮子 / 金刚力士 / 昭和巨人

■ 声优信息
   动画改编中，狮堂虎严主要出现在小说后期卷次（vol-21以后），
   截至当前动画化部分尚未推进至该卷次，故无已公开声优信息。

■ 关键事实确认
   - 与金次的关系从"追捕者"逐步发展为"亦敌亦友的长辈"
   - 唯一试图从美国营救远山金叉的行动者（虽然失败）
   - 与远山加奈有超越组织层面的合作与默契
   - 金刚力士血脉确认会遗传（女儿狮堂美香继承）
   - 战斗数值在零课中排名第三（三式），但纯力量被认为最强

■ 与其他角色的战力比较
   ┃ 对比大门坊  ┃ 狮堂: 纯力量型 · 物理顶点         ┃
   │              ┃ 大门坊: 灵异专精型 · 技术型       ┃
   ┃ 对比滩      ┃ 狮堂: 超重击型 · 一击决定          ┃
   │              ┃ 滩: 高速型 · 连续攻击              ┃
   ┃ 对比金次    ┃ 狮堂: 无需爆发的天生怪力            ┃
   │              ┃ 金次: HSS依赖型 · 爆发有限时        ┃
   ┃ 对比犀牛糖果┃ 同为"先天肌质多重症"系能力者        ┃
   │              ┃ 狮堂的强度被认为高于犀牛糖果        ┃
