                  【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 姐(诺玛)妹(珊蒂)同步双人相声式对话——一人一句构成完整句子
   - 爱唱歌，经常哼唱旋律放松或以示从容
   - 对猎物展现嗜虐笑容——舌尖舔舐嘴唇的挑衅姿态
   - 自信过剩，常以居高临下的态度对待敌人
   - 喜欢玩弄猎物——例如用铁板玩"杀人飞盘"游戏

■ 本质内核
   - 极端爱国主义（Proud Patriot / 爱国者）
     · 自称"神之国度美利坚"的守护者
     · 认为超能力者是"被神选中"的特权存在
   - "砦派"意识形态的坚定信奉者
     · 反对第三次接轨（莱克忒亚与现世的融合）
     · 希望维持超能力者既得利益阶层的现状
     · 对其他超自然存在的涌入持排斥态度
   - 对自身非人身份有清醒认知且完全接纳
     · 不否认自己是"恶魔"
     · 享受作为超常存在的力量与地位
   - 对FBI/美国政府高度忠诚
     · 接受任务追杀远山家族（妨碍与远山金叉接触者）
     · 把阻止"门派"（接轨赞成派）行动视为使命

■ 双人同步人格
   - 诺玛与珊蒂在行动、语言、战术上高度同步
     · 摆出完全相同的姿势（如以左前臂捧胸的招牌动作）
     · 对话以近乎完美的镜像节奏交替
     · 战斗时心意相通——无需言语即可完成配合
   - 诺玛为发号施令的姐姐角色
     · 通常是先开口的一方
     · 决定超能力输出功率等级
     · 珊蒂则遵命行事，以"姐姐大人"称呼
   - 同步模式被外人描述为"像照镜子一样"

■ 嗜虐性与幽默感
   - 将战斗视为游戏
     · 以"百分之五十"、"百分之六十"分级对待敌人
     · 发射"杀人飞盘"戏弄金次
   - 中弹/受创时会用少女般夸张的"唉呦呦"语气
   - 击败敌人时会比出V字胜利手势

■ 对远山金次的评价
   - 称呼金次为"狗子"、"Enable"（政府文档中的代号）
   - 认可金次和GⅢ的战斗力，但不认为能战胜自己
   - 视其为"门派"势力的干将，必须排除的障碍

                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、核心能力：磁力操纵 (Magnetic Manipulation)    │
│          —— 曾被误认为念力/精神感应的真正力量     │
└─────────────────────────────────────────────────────┘

■ 真相揭秘
   - 金次最初在飞弹发射井中误以为贝茨姐妹的能力是"念力(PK/Psycho Kinesis)"
   - 后经ZⅡ(远山金天)和星伽白雪的分析确认——实际为"磁力操纵"
   - 能力原理：自身产生强力磁场，操纵铁磁性物质

■ 基础应用

   [1] 远距离铁磁物操控 (Ferromagnetic Telekinesis)
       范围：可达数百公尺
       对象：铁、钢、镍等铁磁性物质
       极致：可扭曲整座飞弹发射井的钢架铁板
       局限：对非磁性物质（塑料、木、铜、铝）无效
             对微小气溶胶/气体粒子无法有效操作
       案例：
        - 亚利桑那导弹井：扭曲钢架铁板如软糖，制造"钢铁地狱"
        - 尼亚加拉外轮：远程吸附整艘铁壳船，强制改变航向
        - 精微操作：操控GⅢ义肢上的钢丝捆缚风魔阳菜

   [2] 磁力飞行 (Magnetic Flight)
       原理：将自身磁力投射到大型铁磁体上，通过吸引力/排斥力移动身体
       特征：飞行轨迹呈不自然加速/减速
             看起来像"电影的吊钢丝特技"——不符合物理法则
       案例：
        - 从飞弹发射井底部垂直升上井口（无阶梯可用）
        - 在废铁堆间以锯齿状路径高速移动
        - 互相吸引式突进：诺玛与珊蒂一边N极一边S极互相吸引，高速夹击敌人

   [3] 磁力干扰 (Magnetic Interference)
       原理：通过磁力拉动敌方武器中的金属部件
       效果：使手枪准度大幅下降，导致射击失误
       细节：对枪械的影响并非弯曲弹道，而是拉动射手自身动作
             令敌人即使近距离也难以击中
       局限：对非金属武器无效（如拳脚、尼龙制品）
       备注：这是贝茨姐妹最隐蔽的防御手段——让敌人以为是自己的失误

   [4] 磁性感知 (Magnetic Perception)
       工具辅助：蹄铁形耳环通过摆动检测磁力线方向
       被动能力：可感知周围铁磁体的分布与状态
       应用：即使在暗处也能感知铁质障碍物/敌人持有武器的位置

   [5] 磁力炮 (Magnetic Cannon / 磁力砲)
       原理：以自身磁力加速发射铁磁体炮弹
       弹药类型：磁铁矿球形弹、船锚、铁板（任意铁磁性物体）
       威力：足以贯穿铁制船体、破坏外轮船轮
       弹道特征：呈现不规则"乱飘球"轨迹——因磁力不断扰动
       联合应用：姐妹交替发射，形成连续攻击

┌─────────────────────────────────────────────────────┐
│  二、第二形态 (Second Form / 第二型態)             │
└─────────────────────────────────────────────────────┘

■ 概述
   - 贝茨姐妹与蕾芬洁、路西菲莉亚、卡邦克鲁等同为具有"第二形态"的存在
   - 第二形态下全能力值上升，外观伴随变化
   - 在系列作品中是莱克忒亚系高等级存在的共通特征

■ 已知特征
   - 变身时外观发生变化（与丽莎、路西菲莉亚同类型——伴随外形变化）
   - 与希尔达的不变外形·内压提升型变身为不同类别
   - 第二形态装甲化：褐色肌肤上浮现宝石/甲壳般的保护层
     （参考同期出场的卡邦克鲁的第二形态——浮起宝石形成铠甲）

■ 推测能力提升
   - 磁力输出功率大幅增强
   - 防御力上升（外骨骼/能量铠甲）
   - 体能与格斗能力同步提升

┌─────────────────────────────────────────────────────┐
│  三、格斗能力 (Close Combat)                       │
└─────────────────────────────────────────────────────┘

■ 综合评价
   - 不仅仅依赖磁力——自身具备高水平的格斗技
   - 金次评价："她们会格斗战，而且还是并用磁力的未知格斗技"
   - 熟练完成度极高，堪比使用"未知长枪术的瓦尔基丽雅"

■ 战斗风格
   - 并用磁力进行不规则的加速/减速/变向
   - 姐妹联手形成左右夹击的完美包夹阵型
   - 利用磁力锁定/控制敌人肢体
   - 擅长"抱住对手并用磁力互相排斥"的摔掷技法
   - 可用磁力远程取回武器/弹药/道具

■ 感官能力
   - 战斗时眼睛发出红光，可强化暗处视觉
   - 对周围金属物体有"第六感"般的感知
   - 可在激烈战斗中维持冷静判断（除被反制时露出惊讶外）

┌─────────────────────────────────────────────────────┐
│  四、已知弱点与限制                              │
└─────────────────────────────────────────────────────┘

   [1] 对微小粒子/气体无效
       - CS催泪瓦斯无法驱散
       - 沙尘/烟雾等气溶胶状态物质无法操控

   [2] 重力抗性有限
       - 使物体坠落、横向移动很强
       - 使物体上浮/对抗重力则较弱
       - 飞行依赖外部铁磁体（被吸引/排斥），不能完全独立浮空

   [3] 非磁性武器免疫磁力
       - 木、塑料、陶瓷、生物组织等不受直接影响
       - 拳脚、冲击波（如炸霸）无法以磁力偏折

   [4] 有/无视角依赖
       - 没有目视目标时，磁力操作的精准度下降
       - 对拥有隐身/藏身能力的敌人（如风魔阳菜）优先排除

   [5] 物理伤害有效
       - 没有如同弗拉德或希尔达的无限回复能力
       - 只要物理攻击能够击中，就能击败

├─ 遭遇：在废弃的核弹发射井中被贝茨姐妹拦截

│  ├─ 诺玛和珊蒂先以磁力扭曲钢架铁板包围金次一行
│  ├─ 以"从百分之五十开始"的功率输出战斗
│  ├─ 风魔阳菜被铁架埋没，后GⅢ奇袭失败
│  ├─ 金次以八岐大蛇+铁风弹幕应战，贝茨姐妹以铁浪反击
│  ├─ 铁风暴·子弹牢笼展开，但仍无法击中——因磁力干扰
│  ├─ 诺玛以铁板玩"杀人飞盘"，金次以橘花接盘失败被埋
│  ├─ 金次右肩脱臼，GⅢ利用绞盘绳索救出金次
│  ├─ 贝茨姐妹从无梯的发射井中飞出追击
│  └─ 金次炸毁贝茨姐妹的吉普车后乘凯迪拉克撤离
└─ 结果：金次方撤退，初战未分胜负

再战（Vol.31 · 尼亚加拉瀑布 — 美国/加拿大国界之战）
├─ 背景：金次一行乘外轮船沿尼亚加拉河前进
├─ 遭遇：贝茨姐妹驾驶警艇在国界处拦截
├─ 战斗：
│  ├─ 磁力炮首击：磁铁矿炮弹击中外轮，重创茉斩
│  ├─ 金次推理出磁力真相，决定弃用金属武器
│  ├─ 诺玛以磁力操控GⅢ义肢的钢丝捆缚风魔阳菜
│  ├─ 风魔主动跳入尼亚加拉河避险
│  ├─ 船只搁浅于国界岩石上（半属美国半属加拿大）
│  ├─ 贝茨姐妹登船，与远山兄弟进行近身战
│  ├─ 姐妹联手施展磁力同步格斗术
│  ├─ 船锚磁力炮连续十二发——金次以绝闩全部反弹
│  ├─ 金次以炸霸铁砂感知磁力线，猜中磁力走向
│  └─ 最终金次以徒手+赤脚（无磁性）实施近战突破

后续行动（Vol.39 · 铁岚初披露）

│  ├─ 依然保持同步的双人相声式吐槽

                 【主题关键词 / Thematic Keywords】
================================================================================

核心冲突: "砦派" vs "门派" —— 拒变 vs 接纳的意识形态对立
角色象征: 磁力（两极相生）、恶魔角（非人身份）、镜像双生
伏笔线索: 与莱克忒亚界的关联出身、与希尔达的形态相似性

■ 作品定位
   - 绯弹亚里亚后期（Vol.31以后）的重要敌对角色
   - 远山金叉搜索篇的主要障碍之一
   - 代表美国政府/砦派势力的超能力执法者
   - 与雷米艾莉雅篇（Vol.43）中角色功能转为向导
   - 双胞胎角色的高度同步性是本系列中独一无二的战斗单位

■ 双胞胎命名象征
   - 诺玛 (Norma) = N (北极/North)
   - 珊蒂 (Sandy) = S (南极/South)
   - 姐妹联手的磁力如同地球磁场——两极对生

■ 系列意义
   - 磁力型对手填补了金次战斗经验的空白
   - 金次因此开发出"铁岚"等对磁力战术
   - 揭示了莱克忒亚系存在的"第二形态"普遍性
   - 展示了FBI在超自然领域的组织架构与人员配置

              【档案备注 / Archive Notes】
================================================================================

■ 关键事实确认
   - 诺玛·贝茨的身份为"双胞胎之姐"，妹妹为珊蒂·贝茨
   - 非人类存在——具有类羊的卷曲犄角和红色发光眼瞳
   - 超能力为磁力操纵（非念力），常被外人误读
   - 属于FBI国家公安部超自然犯罪部门的精英单位
   - "砦派"意识形态的坚定信奉者——反对第三次接轨
   - 初次登场为Vol.31的亚利桑那导弹井之战
   - 最后一次已知出现为Vol.43的成田机场

■ 能力补充说明
   - 磁力操作的精密程度因距离和可视性变化
   - 无法通过磁力"弯曲子弹弹道"——而是拉动射手身体造成偏移
   - 飞行能力依赖外部铁磁体作为锚点
   - 木/塑料/陶瓷等非磁性物质是有效对策
   - 蹄铁形耳环既是装饰也是能力辅助工具

■ 关于"第二形态"
   - 贝茨姐妹确实具有第二形态（参照vol-37中对路西菲莉亚、蕾芬洁及贝茨姐妹同为变身存在的描述）
   - 第二形态下的具体外观和能力增幅尚未在正文中充分描写
   - 从系列其他莱克忒亚系角色的第二形态推断：全能力大幅提升，出现装甲化/宝石化外观

■ 关于贝茨姐妹的出身
   - "忽然出现在美国南部"——暗示来自莱克忒亚界
   - 被FBI收养培养为超能力执法者
   - 对美国的忠诚建立在"被给予甜头的既得利益者"立场上
   - 对南美出身的过去几乎不提及

■ 非战斗特征
   - 诺玛和珊蒂的对话形式在系列中独一无二——无缝同步双人相声
   - 这种同步性被其他角色（如夏洛克和梅露爱特）模仿
   - 外观设计融合了恶魔元素（角）和美国执法者元素（制服）
   - 是系列中为数不多的明确非人类执法机关角色
