================================================================================
                        【基础情报 / Basic Info】
================================================================================

■ 身份
   - 德古拉女伯爵（Countess Dracula）
   - 伊·幽（伊·U / E.U.）关联者 → 后期的准盟友／协力者
   - 紫电魔女 —— 使用紫色雷电和催眠术的欧洲系魔女
   - "同窗会联盟"（Reunion）夺还小队成员（第19卷印度篇）

■ 家族
   - 德古拉一族——传说中的吸血鬼家族后裔
   - 关联：弗拉德·德古拉（Vlad Dracula，"无限之罪弗拉德"）
     · 伊·幽第二号人物，阶级在夏洛克·福尔摩斯之上
     · 希尔达与弗拉德之间有无血亲关系没有明确记载，
       但同属德古拉家系，共享吸血鬼体质
   - 德古拉家族特征：魔力驱动的吸血鬼体质、再生能力、
     多形态变身、魔脏（Magic Organs）系统

■ 特征
   - 魔度：20-50范围（"浓"的类别），与九九藻、绯鬼、古兰督卡同级
     → 说明希尔达在绯弹世界的魔力体系中属于中上级别
   - 魔女分类：纯粹的"紫电魔女"型，擅长雷电系攻击
     → 相比同样身为魔女的卡羯·葛菈塞（厄水魔女）拥有更多人性面，
       希尔达更接近纯粹的、非人性的魔女存在

■ 外貌
   - 典型的德古拉家系吸血鬼气质——苍白皮肤、深色长发
   - 战斗姿态下可展开巨大蝙蝠状双翼
   - 紫色雷电缠绕身体时散发妖异光芒
   - 身着哥特式暗色礼服/战斗装，符合欧洲贵族吸血鬼形象
   - 瞳色文献未明确记载，推测为红色或紫色（符合德古拉家系特征）

■ 年龄
   - 明确年龄未公开，推测为外表20-30岁左右
   - 作为德古拉家族成员，实际年龄可能远超外表

================================================================================
                   【人物特质 / Personality Profile】
================================================================================

■ 表层性格
   - 冷酷无情的执行者——对任务以外的一切漠不关心
   - 傲慢——对自己的能力有绝对自信，视普通人类为蝼蚁
   - 残忍——战斗中不吝使用极端手段（操纵、下毒、劫持）

■ 行为模式
   - 以强大魔力压制对手，先展示压倒性力量再逐步击溃
   - 善于利用暗示术（催眠术）操控他人心理
   - 战术上倾向于设局埋伏而非正面硬碰（晴空塔的玫瑰丛陷阱）
   - 不轻视敌人——在晴空塔对理子设下双重陷阱（毒耳环+假亚莉亚）

■ 本质
   - 纯粹的"魔女"——缺乏普通人的同理心和道德感
   - 将自身定位为高于人类的超凡存在
   - 对自己的吸血鬼/魔女身份有强烈的自豪感
   - 但被救后并非完全无动于衷——接受了理子的输血存活，
     后期转为支援角色，显示其并非绝对邪恶

■ 与其他魔女的对比
   - 紫电魔女（希尔达）vs 厄水魔女（卡羯·葛菈塞）：
     希尔达更纯粹、更非人性；卡羯保留更多人类情感和脆弱
   - 紫电魔女（希尔达）vs 银冰魔女（贞德·达鲁克30世）：
     两人都使用元素系攻击，立场上常对立，能力类型互补

■ 精神定位
   - 典型的"反派变为非完全敌对"角色
   - 从主要反派（Vol.4-5）→ 偶尔支援的"亦敌亦友"（Vol.8, 11）
     → 正式的协力者（Vol.19 印度篇夺还小队）
   - 但从未完全被"洗白"——始终保持魔女的本色和距离感

================================================================================
                 【能力全析 / Ability Analysis】
================================================================================

┌─────────────────────────────────────────────────────┐
│  一、核心能力——紫电操纵（Purple Lightning）       │
│          —— 德古拉女伯爵的标志性超自然力量        │
└─────────────────────────────────────────────────────┘

■ 原理
   - 利用自身魔力（魔度20-50）生成并操控紫色雷电
   - 雷电既可以作为远程攻击武器，也可以强化自身
   - 可通过棺材状变压器吸收城市电力增幅威力
     （Vol.5 晴空塔之战，通过棺材连接城市电网）

■ 已知招式/形态
   [1] 雷球（Thunder Ball）
       凝结雷电形成球状，发射攻击
   
   [2] 雷星（Lightning Star）
       星形雷电投射物，可能为雷球的变体或进阶版

   [3] 第三形态（Third Form）
       德古拉一族的进阶变身形态
       发动条件：进入白热化战斗时使用
       效果：召唤大规模雷电覆盖战场，威力大幅提升
       特征：全身被紫色电光笼罩，攻击范围广域化
       弱点：第三形态下自身也被强电流包裹，
              若被银弹击中魔脏可能引发电流反噬
               （Vol.5 被理子的银弹霰弹击中后，电流反噬自身，
                 从晴空塔坠落）

┌─────────────────────────────────────────────────────┐
│  二、德古拉一族体质——吸血鬼系能力               │
└─────────────────────────────────────────────────────┘

■ 魔脏系统（Magic Organs / 魔臓）
   - 德古拉家族成员体内存在多个"魔脏"（魔力核心器官）
   - 希尔达共有四颗魔脏
   - 一般吸血鬼的魔脏位置固定且对称（如左右胸各一）
   - 希尔达经过手术移位移置魔脏位置，使其不对称分布
     → 普通攻击无法同时击中全部魔脏
   - 只要四颗魔脏不同时被破坏，就不会死亡
   - 银制武器对魔脏有特效（神话系克制关系）
   - 破坏手法（Vol.5）：理子用温切斯特M1887霰弹枪
     装填银弹霰弹，近距同时覆盖四颗魔脏

■ 再生能力（Regeneration）
   - 德古拉家族的吸血鬼再生能力
   - 普通伤害可快速恢复
   - 被切断的翅膀可以再生（Vol.5理子斩断双翼后未见致命影响）

■ 飞行能力
   - 展开蝙蝠状的巨大翅膀进行飞行
   - 推测飞行速度高，适合空战
   - 翅膀本身也是可被攻击的目标（Vol.5 被理子斩断）

■ 暗示术 / 催眠术（Hypnosis / Suggestion）
   - 强力的精神操纵能力
   - 可以控制他人的行为和意识
   - Vol.5：通过毒耳环控制峰理子，使其假扮亚里亚
   - 暗示术的具体发动条件不明（可能需要媒介或对视）

┌─────────────────────────────────────────────────────┐
│  三、弱点与限制                                  │
└─────────────────────────────────────────────────────┘

■ 银制武器特效
   - 银弹对德古拉一族有特殊杀伤效果
   - Vol.5决定性一撃即是银弹霰弹

■ 魔脏暴露即致命
   - 虽然通过手术移位增加防御难度，
     但一旦四颗魔脏同时被破坏即濒死

■ 电流反噬风险
   - 第三形态全身带电的状态下，
     若魔脏被破坏，电流会失去控制反噬自身
   - Vol.5 被银弹命中后电流失控导致坠落

■ 魔度依赖
   - 作为魔力驱动型存在，魔度水平直接影响战斗持续力
   - 20-50的魔度在作品中属于中上，但非最顶级

                  【经历年表 / Timeline】
================================================================================

Vol.4 宣战会议（首次登场｜袭击者）
├─ 在宣战会议召开期间，希尔达袭击亚里亚
├─ 破解"壳金七星"

├─ 亚里亚的母亲神崎香苗在高等法院被判有罪（有期徒刑536年）
├─ 希尔达袭击押送香苗的戒护车
│     → 华生乘ICBM改造飞行器及时出现击退希尔达
└─ 此时希尔达的动机与背景尚未深入展开

Vol.5 苍蓝闪光（主要反派｜晴空塔决战）
├─ 晴空塔设局：
│     ├─ 控制峰理子（戴毒耳环）
│     ├─ 将真亚里亚藏于玫瑰丛中
│     └─ 让理子假扮亚里亚诱骗金次
├─ 远山金次追华生至晴空塔顶层观景台
├─ 希尔达正式现身——揭示为真正的敌人
├─ 以暗示术将金次催眠动弹不得
├─ 理子为保护亚里亚出头反抗
│     ├─ 主动引爆毒耳环（中毒，十分钟致死）
│     └─ 独自迎战希尔达
├─ 战斗过程：
│     ├─ 理子斩断希尔达双翼
│     ├─ 但希尔达四颗魔脏已被手术移位至不对称位置
│     ├─ 希尔达进入第三形态，召唤大规模雷电
│     └─ 理子将温切斯特M1887霰弹枪藏在向日葵花束中
├─ 决胜一击：
│     └─ 近距发射银弹霰弹——同时命中四颗魔脏
│     → 希尔达被自身电流反噬，从晴空塔坠落
├─ 结局：
│     ├─ 金次与亚里亚救回中毒的理子
│     ├─ 华生与矢常吕依琳老师完成解毒
│     └─ 理子捐献血液给濒死的希尔达使之存活
│     → 以德报怨——这是希尔达角色弧的转折点
└─ 希尔达存活，但尚未完全转为友方

Vol.8 香港・真空炸弹事件（支援角色）
├─ 圣诞节之夜，香港维多利亚港油轮事件
├─ 卡羯·葛菈塞（厄水魔女）企图倾倒原油制造真空炸弹
├─ 星伽白雪与希尔达赶来支援金次与亚里亚
└─ 此时希尔达已从敌人转为某种程度上的同行协力者

Vol.10（背景提及）
└─ 作为支持性角色存在

Vol.11（前零课逮捕事件｜直接支援）
├─ 远山金次被前公安零课（狮堂、滩、可鹉韦、妖刕、大门坊）
    以"无名氏之死"杀人嫌疑逮捕
├─ 狮堂以256倍力量挡下金次的八倍樱花
├─ 金次首次使用"幻梦爆发"但效果有限
├─ 希尔达出现支援金次
│     └─ 被妖刕用霰弹枪击伤
├─ 武装检察官介入宣布金次留级，前零课撤退
└─ 希尔达受伤后撤退——证实其已站在金次一方

Vol.19 印度篇（夺还小队正式成员）
├─ 夏洛克·福尔摩斯召集"同窗会联盟"（Reunion）
├─ 金次担任夺还小队队长
├─ 小队成员：猴（孙悟空）、路西菲莉亚·莫里亚蒂四世、
                希尔达、埃莉萨·浮士德、华生（四世）、梅露爱特
├─ 目标：从卡邦克鲁（大地女神）处夺回神秘器皿
├─ 在印度赞达剌遭遇卡邦克鲁夜袭
├─ 希尔达与梅露爱特被卡邦克鲁俘虏
│     → 最终获救
└─ 希尔达在此作为正式协力者而非单纯"前敌人"行动

                  【人际关系 / Relationship Map】
================================================================================

■ 弗拉德·德古拉（Vlad Dracula）
   关系：同族长辈·伊·幽上级
   评价：德古拉家族的前辈，伊·幽第二号人物
   备注：两人是否直系血亲虽未明确记载，但同属德古拉家系。
         弗拉德在伊·幽中阶级超越夏洛克·福尔摩斯。

■ 峰·理子·罗苹四世（Mine Riko Lupin 4th）
   关系：曾经的死敌 → 续命恩人
   关键节点：Vol.5 晴空塔决战（理子斩翼→银弹击杀→输血救活）
   评价："那个女人……明明应该杀了我，反而救了我"
   备注：理子的以德报怨是希尔达角色转变的关键。
         从纯粹的敌人变成后来的支援者，理子的输血是转折点。

■ 远山金次（Tohyama Kinji）
   关系：曾经的敌对目标 → 后期的协力对象
   关键节点：Vol.5 晴空塔（金次被催眠）→ Vol.11 前零课事件（希尔达支援）
             → Vol.19 印度篇（同为夺还小队成员）
   备注：希尔达对金次没有理子那种个人恩怨的联系，
         更多是基于立场变化产生的合作关系。

■ 神崎·H·亚里亚（Kanzaki Holmes Aria）
   关系：曾经的目标 → 关系不明朗的同盟
   关键节点：Vol.4 破解壳金七星 → Vol.5 被囚禁于玫瑰丛
   备注：希尔达曾对亚里亚造成重大伤害（破解壳金七星，
         导致绯绯色金失控）。后期虽转为协力者，
         两人之间是否有和解并未直接描写。

■ 卡羯·葛菈塞（厄水魔女）
   关系：同为欧洲魔女系的同行
   备注：两人能力类型不同（紫电 vs 厄水），
         但在作品中常在同一时间线出现。
         相比卡羯有人性面，希尔达更"纯粹的魔女"。

■ 星伽白雪（Hoshiga Shirayuki）
   关系：Vol.8 香港事件中的协同战斗者
   备注：与白雪一同在金次支援时出现，合作战斗。

                  【关键物品 / Key Items】
================================================================================

■ 棺材变压器（Coffin Transformer）
   - 晴空塔之战中使用
   - 外观为棺材形状的装置
   - 用于连接城市电力系统，将电能转化为紫电魔力
   - 大幅增强希尔达的电力输出

■ 毒耳环（Poison Earrings）
   - Vol.5用于控制峰理子
   - 理子戴上后受到暗示术影响，被迫假扮亚里亚
   - 摘除时会引爆，释放致死毒药（约十分钟致死）
   - 后由华生和矢常吕老师成功解毒

■ 玫瑰丛（Rose Thicket）
   - 晴空塔观景台上设置的玫瑰丛陷阱
   - 真亚里亚被藏在其中，难以被发现
   - 兼具隐藏与攻击性的陷阱装置

■ 温切斯特M1887霰弹枪（对手所持）
   - 并非希尔达本人的武器，而是被理子使用的决胜武器
   - 装填银弹霰弹，近距同时粉碎四颗魔脏
   - 银弹对德古拉一族有特效
