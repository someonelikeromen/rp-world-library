## 1. 伊·U（伊·幽 / Eiyū / I-U）
==============================================================================

---WORLD_ITEM---
NAME: 伊·U（伊·幽）
TYPE: factions
DESCRIPTION: 伊·U是绯弹的亚里亚世界观中最核心的国际秘密结社，全称为"伊·幽"，由世界顶级历史伟人的后代组成。组织本质上是一个拥有核子潜艇（东方号）的武装战斗集团，以潜艇为移动基地在全球活动。首领"教授"即夏洛克·福尔摩斯一世（亚莉亚的曾祖父），他双目早已失明，但凭借超人的推理能力和听觉感知世界。伊·U的核心目标围绕"色金"（绯绯色金、琉琉色金、璃璃色金等宇宙金属）展开研究和争夺，夏洛克曾利用"历镜"（时空透镜）将绯绯色金射入三年前的亚莉亚体内，制造出"绯弹的亚莉亚"。组织的二号人物包括"无限之罪弗拉德"（德古拉伯爵，存活超过120年的非人怪物）和"鬼"（实力远在弗拉德之上）。伊·U内部有"超秂师团"这一精锐战斗部门，帕基诺老大曾是其中成员。佩特拉曾试图夺取伊·U首领宝座。在极东战役（FEW）开启后，伊·U与N组织、师团、眷属等多方势力形成错综复杂的对抗格局。夏洛克在第二十四卷召开"伊·U同学会"后，又于第三十七卷组建"同窗会联盟"（Reunion），联合各路强者对抗莫里亚蒂教授。截至第四十五卷，伊·U核潜艇与N组织的诺契勒斯号曾一度被击沉，但夏洛克与华生一世重新搭档后恢复活跃。
SIGNIFICANCE: 核心反派/中立势力，亚莉亚的出身组织，色金战争的源头之一，贯穿全系列的暗线势力

## 2. 东京武侦高中（东京武侦高 / Tokyo Butei High School）
==============================================================================

---WORLD_ITEM---
NAME: 东京武侦高中
TYPE: factions
DESCRIPTION: 故事的主要舞台，位于东京湾学园岛上的特殊高中，专门培养"武侦"（武装侦探）——持有国家认证的武侦执照、可携带枪械执行任务的准军事化执法人员。学校设有多个专业学科：侦探科（搜查与推理）、强袭科（正面突击战斗）、狙击科（远程狙击）、装备科（武器开发与改造）、超能力搜查研究科（SSR/CVR，针对超能力者）、救护科（医疗与急救）、谍报科（情报收集与潜入）、车辆科（驾驶与车械）、普通科（非战斗学生）。武侦等级从S到E逐级排列，S级为最高。学校由绿松武尊担任校长，教务科主任高天原佑彩负责实务管理。学校拥有完整的武侦法体系（十条宪章）和严格的校规，同时设有强袭科竞技场、地下仓库、HPC服务器室等设施。学生宿舍分为男生宿舍和女生宿舍。校园内还有机动科、武侦医院等附属设施。AA外传中详细描写了学校的"战姊妹制度"——高年级学姐一对一指导低年级学妹为期一年的师徙制。学校的师生关系较为开放，许多教师本身就是现役武侦（如缀梅子、兰豹、小夜鸣等）。该校在国际武侦联盟中享有盛誉，常与罗马武侦高中、香港武侦高中等国际武侦机构交流。
SIGNIFICANCE: 主要舞台，主角团队的出身学校，培养大部分登场角色的体制机构

## 3. 巴斯克维尔小队（Baskerville / 巴斯克维尔）

---WORLD_ITEM---
NAME: 巴斯克维尔小队
TYPE: factions
DESCRIPTION: 本作主角团队，以远山金次为队长、神崎·H·亚莉亚为副队长的五人精英武侦小队。正式成立于第七卷末尾——在新干线劫持事件结束后，金次、亚莉亚、白雪、理子、蕾姬五人形成的固定搭档关系。小队名称源自"巴斯克维尔的猎犬"（福尔摩斯经典案件），暗示这是一支专门猎杀"怪物"（超自然威胁）的队伍。小队在极东战役（FEw）中作为师团阵营的第一线战斗单位，先后经历了与佩特拉、眧眧三姐妹、希尔达·德古拉、蓝帮、孙/猴、魔女连队、GⅢ/GⅣ、N组织等多次高强度战斗。第十四卷后因英/美/中多国外交压力，金次被绿松校长撤销巴斯克维尔小队队长资格，转入贞德领衔的"星座小队"，但巴斯克维尔的成员依然维持密切关系。第二十九卷巴斯克维尔全员以"转装生"身份潜入阿尼亚斯学院执行对抗N组织的任务。小队内部关系复杂：亚莉亚与金次为恋人关系，白雪暗恋金次，理子与金次有暧昧，蕾姬曾向金次求婚并与之订婚。小队后来加入了丽莎·艾薇·杜·安克（热沃当之兽）等新成员。在AA外传中，间宫明里作为亚莉亚的战妹也被视为巴斯克维尔的关联成员。
SIGNIFICANCE: 主角核心小队，贯穿全系列的主要战斗单位

## 4. 师团（Shidan / Corps）
==============================================================================

---WORLD_ITEM---
NAME: 师团（Corps）
TYPE: factions
DESCRIPTION: 极东战役（Far East War / FEw）中的两大超自然阵营之一，由众多希望维护世界现有秩序的组织和个人组成。师团在第七卷末尾的"宣战会议"上正式确立，由贞德·达鲁克30世在空地岛召开多国超自然组织大使会议后划分而成。师团方包括但不限于：星伽神社（以白雪和风雪为代表的武装巫女）、武侦高中（以巴斯克维尔小队为代表）、伊·U的温和派、自由石匠（凯撒与华生所属）、部分欧洲教会势力。师团的核心策略是通过外交与武力相结合的方式，阻止"第三次接轨"（异世界列库忒亚与地球的融合）或至少将其控制在可控范围内。玉藻（天狐）作为师团的重要智囊参与了多次策略制定，包括拉拢GⅢ和GⅣ加入师团的"罗密欧任务"。师团在第十卷的会议中讨论了对GⅢ/GⅣ的拉拢策略，在第十六卷中遭"眷属"大军围剿——师团驻地遭炸弹袭击，金次被误认为内奸。师团与眷属在欧洲战区（比利时、荷兰、龙之港等）发生过大规模冲突。后来当N组织崛起成为共同威胁时，师团与部分眷属成员（如卡羯、佩特拉）实现了有限合作。
SIGNIFICANCE: 极东战役两大阵营之一，代表秩序维护方
