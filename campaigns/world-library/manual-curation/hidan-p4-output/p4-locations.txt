# 绯弹的亚里亚 — 主要地点清单

## 总览

本清单覆盖绯弹的亚里亚正传vol-01~45及AA外传vol-01~04范围内出现的核心地点。每项标注首次登场卷号（SOURCE_REF）、详细描述、意义及关联势力/角色。

---

---WORLD_ITEM---
NAME: 东京武侦高中（Tokyo Butei High School / 東京武偵高校）
TYPE: locations
DESCRIPTION: 位于东京湾彩虹桥南方的人工浮岛"学园岛"上，南北长约两公里、东西宽五百公尺的长方形人工岛屿。这所学校是培训"武侦"（武装侦探）的综合教育机构，学生除了一般科目外，还能学习侦探科、强袭科、情报科、通信科、车辆科、鉴识科、生物科、超能力搜查研究科（S研）、特殊搜查研究科（CVR）等专业科目。校内设有强袭科训练设施、侦探科专业大楼、学生食堂、男生宿舍（多栋）、女生宿舍（多栋）、地下仓库（七大危险区域之一）、教务科（三大危险区域之一）、武道馆、图书馆、温室等设施。校规要求学生在校内必须携带枪械与刀剑。学园岛上还有面向学生的商店街、美容院、公园等设施。岛屿北端有单轨电车的浮岛北车站可通往台场方向。由于学校性质特殊，教师多为各国特殊部队出身或前佣兵。岛上还停有车辆科的直升机和各类特殊车辆。
SIGNIFICANCE: 全系列核心舞台，远山金次、神崎·H·亚莉亚、星伽白雪、峰·理子·罗苹四世、蕾姬、贞德·达尔克三十二年等主要角色就读的学校。故事的起点和大本营，巴斯克维尔小队的组建地，也是极东战役开始前宣战会议的会场所在地之一。
SOURCE_REF: vol-01
AFFILIATED: 远山金次|神崎·H·亚莉亚|星伽白雪|峰·理子·罗苹四世|蕾姬|贞德|华生|巴斯克维尔小队|绿松武校长|强袭科|侦探科

---WORLD_ITEM---
NAME: 学园岛（学園島 / Gakuenjima）
TYPE: locations
DESCRIPTION: 东京武侦高中所在的人工浮岛，位于东京湾彩虹桥南侧。岛屿为长方形，南北长约两公里、东西宽约五百公尺。此岛原本是东京湾岸再开发计划的一环，计划失败后被贱价出售，由武侦相关机构购入改建为教育设施。岛上除武侦高中的校舍、宿舍外，还有以学生为对象的商店、美容院、公园等各类设施。岛屿北方有一座同样形状但未开发的空地岛（别名"空地岛"），上面只有一台风力发电机。学园岛与台场之间由青海南桥连接，岛北端设有单轨电车的浮岛北车站。由于岛屿原本设计是作为羽田机场的增设跑道，地形细长，适合用作迫降场地——第一卷终盘ANA600号班机迫降事件中，空地岛被用作紧急迫降跑道。
SIGNIFICANCE: 武侦高中所在地，东京武侦这一概念在物理上的载体。作为人工浮岛，既是剧中日常生活的舞台，也因其特殊地理条件多次在战斗场景中发挥关键作用（迫降、狙击、追击等）。
SOURCE_REF: vol-01
AFFILIATED: 东京武侦高中|远山金次|神崎·H·亚莉亚

---WORLD_ITEM---
NAME: 空地岛（空地島 / Akichi-shima）
TYPE: locations
DESCRIPTION: 位于学园岛北方、与学园岛隔着彩虹桥相望的另一座同样形状的人工浮岛。这座岛屿因为开发计划失败而一直闲置，上面只有一座风力发电机孤零零地矗立在岛屿南端。岛上没有诱导灯或任何机场设施，但在第一卷的高潮事件中，被用作ANA600号班机的紧急迫降场地——武侦高中的学生们从学园岛搭乘汽艇来到空地岛，用手电筒充当诱导灯，成功帮助金次和亚莉亚驾驶的客机在暴风雨夜安全迫降。此后该岛也在第八卷的"宣战会议"中作为师团与眷属双方势力的会面场所使用。
SIGNIFICANCE: 学园岛的姐妹岛，在第一卷迫降事件中扮演关键角色，同时也是第八卷极东战役宣战会议的会场，师团与眷属在此正式宣战。
SOURCE_REF: vol-01

---WORLD_ITEM---
NAME: 男生宿舍（武侦高中男生寮）
TYPE: locations
DESCRIPTION: 学园岛上的武侦高中男生宿舍，有多栋建筑物。第一男主远山金次住在南端的某一栋的四人房（因转科到侦探科后没有室友，实际独自居住一室）。宿舍为标准的公寓式建筑，房间约六叠大小，配有阳台。金次的房间在第二卷中曾被白雪用M60机枪扫射、被伪装成亚莉亚的理子潜入，成为各种混乱事件的舞台。宿舍附近有温室和公园等设施。第三男生宿舍在第六卷中曾受到蕾姬的监视。宿舍是武侦高中学生日常生活的重要据点，因为校规要求携带武器，因此宿舍内枪械管理也是日常的一部分。
SIGNIFICANCE: 远山金次的居住地，系列中大量日常与非日常剧情的发生地，也是多位女性角色"闯入"和"袭击"的目标地点。
SOURCE_REF: vol-01

---WORLD_ITEM---
NAME: 女生宿舍（武侦高中女生寮）
TYPE: locations
DESCRIPTION: 学园岛上的武侦高中女生宿舍，有多栋建筑物，位于学园岛北端。第一女生宿舍的屋顶设有直升机停机坪。宿舍顶层是亚莉亚在第二卷中从屋顶跳伞逃走的起点。白雪住在某栋女生宿舍中。第二女生宿舍是理子居住的地方，第十一卷中金次曾因学园祭的混乱而误入。女生宿舍的高度和屋顶位置使其成为多次剧情中的制高点和逃脱起点。宿舍楼下有温室塑胶屋，曾作为金次和亚莉亚从屋顶坠落时的缓冲。
SIGNIFICANCE: 主要女性角色的居住地，多次剧情的关键起点/终点，屋顶停机坪是交通工具的重要补给点。

---WORLD_ITEM---
NAME: 强袭科（強襲科 / Assault Division）
TYPE: locations
DESCRIPTION: 东京武侦高中的专业科目之一，俗称"没有明天科"。该科毕业时的生存率仅为97.1%，意味着每100人中约有3人无法活着毕业——他们会在任务或训练中死亡。强袭科的专用训练设施内枪声和刀剑碰撞声不绝于耳，装备检整和战斗训练是日常。该学科的学生通常以小隊行動为主，评等从E级到S级不等。远山金次在一年级的第一、二学期曾就读于强袭科（评等E级），后因讨厌强袭科的暴力氛围而转到最"正常"的侦探科。亚莉亚是强袭科的S级学生，以双剑双枪的武技闻名。强袭科被列为东京武侦高中"三大危险区域"之一。
SIGNIFICANCE: 武侦高中最危险的学科，体现了武侦世界残酷的一面。作为金次的转科前所属地，也是与亚莉亚结缘的开端——亚莉亚正是为了让金次回归强袭科而不断追捕他。
SOURCE_REF: vol-01
AFFILIATED: 神崎·H·亚莉亚|远山金次|强袭科教师|不知火亮|武藤刚气

---WORLD_ITEM---
NAME: 侦探科（探偵科 / Detective Division）
TYPE: locations
DESCRIPTION: 东京武侦高中的专业科目之一，被金次评价为"这间学校中最正常的学科"。侦探科的专业大楼古色古香，教授推理学以及各种侦探术。金次在高一第三学期从强袭科转科至此，理由是侦探科比强袭科安全得多。侦探科的学生可以在科内布告栏上接受委托（如找走失的猫等），赚取报酬和学分。侦探科也负责调查校内的各种事件。峰·理子·罗苹四世虽然才华横溢但被金次称为"侦探科天字第一号的笨蛋女"，穿着充满荷叶边的甜美萝莉塔风格服装。高天原老师是侦探科的良心教师。
SIGNIFICANCE: 金次在系列中的正式所属学科，代表了相对"正常"的武侦生活。但即使是最正常的学科，在武侦高中这个大环境下也充满危险。
SOURCE_REF: vol-01

---WORLD_ITEM---
NAME: 教务科（教务科 / Academic Affairs Office）
TYPE: locations
DESCRIPTION: 东京武侦高中"三大危险区域"之一。虽然表面上是教师聚集的教务办公室，但实际上这里由一群战斗力超群的教师掌控，对学生极度严格。教务科的教师们大多曾是各国特种部队成员或佣兵，战斗力远超一般学生。潜入教务科被视为极其危险的任务。亚莉亚曾命令金次协助她潜入教务科，从天花板通风口进入以盗取文件。教务科拥有对学生进行停学、退学等处分的大权，曾命令白雪找保镖、将金次和蕾姬退学等等。第十一卷中金次被传唤到教务科时，内心极度抗拒这个"危险区域"。
SIGNIFICANCE: 武侦高中权力中枢之一，象征着学校体制的暴力性和不合理的权威。多次作为剧情冲突的触发点和转折点。
SOURCE_REF: vol-02
AFFILIATED: 绿松武校长|神崎·H·亚莉亚|远山金次|星伽白雪

---WORLD_ITEM---
NAME: 地下仓库（地下倉庫 / Underground Warehouse）
TYPE: locations
DESCRIPTION: 东京武侦高中"三大危险区域"之一，位于地下七楼，是武侦高中最深处的区域。对外委婉地称为"仓库"，实际上储存了大量弹药、武器和危险物品。内部有大仓库，集中堆放校内最危险的弹药。地下仓库深处还有已经废弃不用的资料室。这里也是学校面临外部入侵时最不设防的区域之一。在第二卷中，白雪被陷害后逃入地下仓库，亚莉亚和金次深入追击却被锁在密封的资料室中，面临窒息危机。地下仓库的构造复杂，通路众多，包含宴会厅大小的空间和排水沟等设施。
SIGNIFICANCE: 武侦高中最危险的地下区域，存储全校致命武器的弹药库。作为战斗和逃亡的舞台，在第二卷和第十六卷等关键剧情中出现。
SOURCE_REF: vol-02

---WORLD_ITEM---
NAME: 超能力搜查研究科 / S研（SSR - Superpower Search and Research Division）
TYPE: locations
DESCRIPTION: 东京武侦高中的专业科目之一，通称"S研"（SSR）。该学科致力于研究和发展超能力，拥有预言能力。星伽白雪是该科的优等生，拥有以念力操纵火焰的能力。S研的预言曾多次发出关于魔剑袭击白雪的警告。该学科在日本其他学校和机构中也有类似组织，如罗马武侦高中的"歼魔科"。S研的学生经常参加合宿修行（如伊势神宫合宿），并与星伽神社等传统超自然势力保持着联系。S研所处的专业大楼相较于强袭科而言安静得多，但同样充满神秘色彩。
SIGNIFICANCE: 绯弹世界超自然侧的代表学科，连接武侦世界与超能力/灵力世界的关键枢纽。白雪的所属学科，也是星伽神社巫女能力在武侦教育体系内的延伸。
SOURCE_REF: vol-01
AFFILIATED: 星伽白雪|星伽神社|玉藻|歼魔科

---WORLD_ITEM---
NAME: 特殊搜查研究科 / CVR（CVR - Criminal Profiling & Special Research Division）
TYPE: locations
DESCRIPTION: 东京武侦高中的专业科目之一，通称"CVR"。岛麒麟就读于此学科。该学科的大楼后方有篮球场等设施，拥有独立的训练区域。CVR有两种类型，其中CVRⅡ种的学生偶尔会被选拔到宝冢音乐学校进行短期留学，接受以"清纯、正直、美丽"为校训的女性教育训练。CVR大楼区域比较安静，附近有公园和小池塘等景观设施。CVR在AA外传中有更详细的描写，一年级女主角间宫明里也与CVR的学生多有互动。
SIGNIFICANCE: 武侦高中的特殊调查研究部门，在AA外传中占据重要地位。代表武侦教育体系中心理/行为分析方向的分支。

---WORLD_ITEM---
NAME: 星伽神社（星伽神社 / Shishimi Shrine）
TYPE: locations
DESCRIPTION: 位于青森县郊外的古老神社，星伽一族的根据地。星伽家族代代是此神社的巫女，以"武装巫女"闻名，使用武装手段守护神体（剑、镜、玉、矛等）。星伽神社在漫长的历史中以"武装"方式守护神体，拥有独特的战斗力。白雪从小在神社中长大，被严格限制外出，甚至在她懂事以来第一次离开神社是金次带她去烟火大会。神社供奉有铭刀"绯金菖蒲"等神宝，在第四卷中被加奈盗走。白雪从神社来到东京武侦高中读书时，受到了诸多制约和反对。粉雪是白雪在星伽神社的妹妹之一。
SIGNIFICANCE: 星伽白雪的家族根据地，武装巫女传统的发源地。在超自然/灵能力量层面的重要据点，拥有多件神器级物品。

---WORLD_ITEM---
NAME: 伊势神宫
TYPE: locations
DESCRIPTION: 位于日本三重县的著名神社，是日本神道信仰的最高圣地。在绯弹世界中，白雪曾在此进行合宿修行（超能力搜查研究科的合宿活动）。白雪从伊势神宫合宿回来后给金次送了豪华便当，成为系列的开篇场景之一。伊势神宫作为武侦高中S研学生的修行地点之一，体现了超能力训练与传统神道修行的结合。
SIGNIFICANCE: S研学生的修行场所之一，将武侦教育与传统神道修行结合的例证。

---WORLD_ITEM---
NAME: 伦敦武侦局（ロンドン武偵局 / London Butei Bureau）
TYPE: locations
DESCRIPTION: 位于英国伦敦的武侦官方机构，是神崎·H·亚莉亚在十四岁开始从事武侦工作时活跃的场所。亚莉亚在那里被誉为S级武侦，使用双剑双枪的武技在欧洲各地活跃。然而她的功劳曾被伦敦武侦局的官僚写成自己的业绩。伦敦武侦局属于英国武侦厅体系，与日本武侦厅、外务省等机构有复杂的政治关系。在系列中，伦敦武侦局多次试图把亚莉亚调回伦敦，并曾派出直升机在学园岛女生宿舍楼顶试图带走亚莉亚。英国武侦厅在第十五卷中更通过政治手段迫使东京武侦高中对金次做出停学处分。
SIGNIFICANCE: 亚莉亚的母港和职业起点，英国武侦体系的核心机构。作为福尔摩斯家族的势力范围，在政治和外交层面多次影响故事发展。
SOURCE_REF: vol-01

---WORLD_ITEM---
NAME: 伊·U（伊·U / IU - 超人师团 / 潜水航母）
TYPE: locations
DESCRIPTION: 全称为"伊·U超级潜艇"（又称"超人师团"），是一艘由大日本帝国海军与纳粹德国在二战期间合作建造的巨大核动力潜水航母。舰内空间极为广阔，拥有教室、金库、无齿翼龙化石标本、游泳池等设施，用LED照明装饰得如同海上宫殿。舰内通用语言为日文和德文。伊·U最初是让超人们互相教导技能的学习研究组织，后演变为横跨全球的超自然军事力量。夏洛克·福尔摩斯二世在某一时期掌管了伊·U，将其改造成自己的势力基地。该舰航速可达47节，可长期潜航，能经由北极海航行至全球各地。在第九卷中，金次与亚莉亚攻入伊·U并击败夏洛克，导致伊·U崩坏。但在第二十卷中，伊·U再次出航，载着金次一行人前往鬼之国。
SIGNIFICANCE: 全球超自然世界三大势力之一的核心载体，师团与眷属争夺的焦点。绯弹系列超自然军事力量的最直观体现，夏洛克·福尔摩斯二世的基地，也是"绯弹的亚莉亚"原点事件的发生地。
