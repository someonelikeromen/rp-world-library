# 绯弹的亚里亚里（绯弹的亚莉亚）—— 重要术语·科技·武器数据库
## 覆盖范围：main vol-01~45 / AA vol-01~04
## 生成日期：2026-07-03

=============================================================================
## 一、核心术语
=============================================================================

---WORLD_ITEM---
NAME: 武侦（Butei / Armed Detective）
TYPE: terms
DESCRIPTION: 武侦是绯弹世界中为对抗凶恶化犯罪而新设立的一种国际资格。领有武侦执照者可比照警察，可携带武器并享有逮捕权。但武侦是为钱所动的"便利屋"，不同于警察——只要在武侦法允许范围内，不论多粗暴、多无聊的工作都能处理。培养武侦的"东京武侦高中"位于彩虹桥南方的人工岛屿"学园岛"上，学生入学需携带枪械与刀剑。武侦行业下分多个专门学科：强袭科（通称"没有明天科"）、侦探科、车辆科、通信科、鉴识科、情报科、救护科、警务科、超能力搜查研究科（SSR）、化学科、生活科等。
SIGNIFICANCE: 武侦是整部作品世界观的基础设定，所有角色皆围绕此制度展开故事，是区分绯弹世界与现实世界的核心概念。
SOURCE_REF: vol-01
---WORLD_ITEM---
NAME: 武侦宪章（Butei Charter）
TYPE: terms
DESCRIPTION: 武侦行业的道德和行为准则。第一条："同伴之间要互信互助"，是整部作品中反复出现的重要信条，也是亚莉亚最常挂在嘴边的准则，用来团结队友或要求配合。第二条："与委托人订下的契约，必须确实遵守"。宪章在武侦社会中具有高度约束力，违反宪章会受到同行和社会的排斥。
SIGNIFICANCE: 贯穿全作的行为准则，是角色之间建立信任关系的基础，也是剧情推进中多次被引用和考验的核心价值观。
SOURCE_REF: vol-01~02
---WORLD_ITEM---
NAME: 武侦法第九条
TYPE: terms
DESCRIPTION: 武侦法规定，"武侦不论在任何情况下，都不得在武侦活动中杀害任何人。"这是武侦行业的铁律，也是区分武侦与普通武装力量的关键约束。金次和亚莉亚在多次事件中都面临着突破此条款的诱惑与挑战，这一约束塑造了武侦独特的"活捉"战斗风格。
SIGNIFICANCE: 定义了武侦的道德底线，使武侦区别于杀手或军队，极大影响了战斗方式和剧情冲突的解决方向。
SOURCE_REF: vol-01
---WORLD_ITEM---
NAME: 伊·U（I·U / 伊·幽）
TYPE: terms
DESCRIPTION: 全作最大的秘密结社，是由历史上著名伟人后代组成的国际犯罪组织。名字来自英语"Eureka"（我发现了）的音译。成员包括夏洛克·福尔摩斯4世（亚莉亚）、莫里亚蒂教授的后裔、罗苹的后裔峰理子、贞德的后裔、弗拉德的后裔等各色历史名人的子孙。伊·U拥有远超时代的高科技水平，包括超空蚀鱼雷改造的奥尔库斯潜航艇、M134改单人加特林、雷射武器如意棒等。该组织在vol-08的"极东战役"后分裂为"师团"和"眷属"两大阵营展开内战。
SIGNIFICANCE: 核心反派组织，是串联全作所有冲突的枢纽，几乎每个主要角色都有伊·U的背景。伊·U的科技水平代表了世界中最高端的黑科技来源。
SOURCE_REF: vol-01~45
---WORLD_ITEM---
NAME: 师团与眷属（Shidan vs. Kenzoku）
TYPE: terms
DESCRIPTION: 伊·U在极东战役前夕分裂为两大联盟。"师团"由伊·U钻研派余党、梵蒂冈圣女梅雅、玉藻、星伽巫女等组成，以维持世界均衡为目标；"眷属"由魔女卡羯·葛菈塞、吸血鬼希尔达、蓝帮、哈比、佩特拉等组成，追求力量与混沌。双方在vol-08的宣战会议上正式划分阵营，围绕亚莉亚体内的壳金展开争夺。此后全作的势力格局以此二元对立为基础展开。
SIGNIFICANCE: 全作后期的核心势力格局，定义了"极东战役"后的世界博弈版图，几乎所有组织和个人都必须选边站。
SOURCE_REF: vol-08
---WORLD_ITEM---
NAME: 极东战役（Kyokuto Sen'eki / Far East Campaign）
TYPE: terms
DESCRIPTION: 发生在作品时间线中的大规模超自然战争，是伊·U分裂为"师团"与"眷属"后的首次全面冲突。战役以东京和学园岛为主要舞台，牵扯了来自全球的各方势力。亚莉亚的"壳金七星"在战役中被希尔达破坏，壳金散落并被眷属成员夺走。此战奠定了之后各卷的追寻壳金主线，也是许多角色命运转折的关键事件。
SIGNIFICANCE: 全作最重要的转折性战役事件，直接导致亚莉亚体内绯弹封印被破，壳金散落，此后各卷主线围绕回收壳金展开。
SOURCE_REF: vol-08~09
---WORLD_ITEM---
NAME: 武侦杀手（Butei Killer）
TYPE: terms
DESCRIPTION: 第一卷开篇出现的连环犯罪者，专门针对武侦发动袭击。手法特点是在武侦的交通工具上安装"一减速就会爆炸"的炸弹，夺走受害者自由后，用远距离操控武装直升机追击，最终将目标逼入死路。初期被误以为是个体犯罪，后逐渐揭露实际上与伊·U和更大的阴谋有关。这一事件是金次和亚莉亚相遇并结为搭档的契机。
SIGNIFICANCE: 开篇事件，是推动男女主角相遇、金次重返强袭科的导火索。
SOURCE_REF: vol-01

## 二、特殊能力与体质
=============================================================================

---WORLD_ITEM---
NAME: 爆发模式 / HSS（Hysteria Savant Syndrome）
TYPE: terms
DESCRIPTION: 远山家男性代代相传的特殊体质——"情绪爆发学者症候群"。当进入性亢奋状态时，脑中会分泌出约正常人三十倍的β脑内啡（β-endorphin），戏剧性地亢进大脑、小脑、脊髓等中枢神经系统的活动。在爆发模式下，逻辑思考能力、判断力、反射神经都会飞跃性提升，达到超人级别。但进入模式后，面对女性会陷入一种"保护女性""表现魅力"的本能心理状态，行为变得像温柔的牛郎。持久时间通常只有几十分钟，解除后会有极端疲劳，需要长时间睡眠恢复。此外还有"半进爆发"（半爆发）的中间状态。
SIGNIFICANCE: 金次的核心能力设定，远山家代代的"正义使者"体质。是战斗能力的主要来源，也是许多喜剧桥段的源头。金次的大哥远山金一能通过变装成美女加奈来长期维持爆发模式。
SOURCE_REF: vol-01, vol-04, vol-15后记
---WORLD_ITEM---
NAME: 加奈（Kana）—— 金一的爆发模式化身
TYPE: terms
DESCRIPTION: 远山金次的大哥远山金一（即夏洛克·福尔摩斯4世的哥哥）通过变装成绝世美女来长期维持爆发模式的化身。金一在母亲死后，为了哄哭泣的弟弟而变装成母亲的模样，意外发现通过变装成女性可以避免"伤害女性"的心理障碍，从而持续维持爆发模式状态。加奈之名即是这种状态的代号，战斗力极强，是远山家对爆发模式控制最纯熟的人物。
SIGNIFICANCE: 展示了远山家爆发模式控制的最高境界，也是vol-04中金次与大哥对决的关键对手。
SOURCE_REF: vol-04
---WORLD_ITEM---
NAME: 壳金七星（Kakkin Shichisei / Seven Shell-Golds）
TYPE: terms
DESCRIPTION: 由古代星伽巫女创造的特殊镀金外壳，用来封印和阻绝人类与"绯绯色金"之间的"心系"（心灵连接）。壳金共有七枚，呈七星配置安置在亚莉亚的心脏附近（即体内的绯弹周围）。只要七枚壳金全部完好，人类只能与绯绯色金进行"法系"（法术性连接），保持安全状态，需持续三年才能完全阻绝心系。在极东战役中，希尔达用法术破解了壳金七星，导致壳金散落并被"眷属"成员夺走。亚莉亚体内只剩两枚，若不及时回收，将会"绯绯神化"成为破坏神。
SIGNIFICANCE: 后期主线核心道具，全作vol-08之后的主要剧情驱动力——回收七枚壳金以阻止亚莉亚变成破坏神。
SOURCE_REF: vol-08, vol-09
---WORLD_ITEM---
NAME: 绯绯色金（Hibiki Irogane / Scarlet Mystic Gold）
TYPE: terms
DESCRIPTION: 绯弹世界中最神秘的超自然金属/物质，具有超越现代科学理解的力量。据玉藻（九尾狐）的解释，绯绯色金是一种可以赋予宿主巨大力量的神性物质，但若与人类"心系"（心灵过度连接），宿主会成为破坏神"绯绯神"。古代巫女研制出"壳金"来封印其力量。夏洛克·福尔摩斯4世曾在伊·U事件中将绯弹射入亚莉亚体内，使其成为"绯弹的亚莉亚"。亚莉亚的粉色头发和红紫色眼眸就是绯弹带来的变化。
SIGNIFICANCE: 世界观最底层的神秘核心，亚莉亚力量的来源与诅咒的根源，整个故事围绕此展开。
SOURCE_REF: vol-04, vol-08
---WORLD_ITEM---
NAME: 超能力搜查研究科 / SSR（Supernatural Search-and-Research）
TYPE: terms
DESCRIPTION: 武侦高中内最神秘的专门学科之一，专门研究和培养超能力者（超侦）。星伽白雪是该科的学生。该科研究感应能力、探测术、预言等超自然搜查手法，在武侦业界的存在感日益增加。然而该科的预言与情报常被其他科视为可疑，学生被视为"诡异可疑"的存在。相关超能力包括：白雪的巫女灵力、火炎操控、式神操控；蕾姬的超感觉（狙击能力与念话）；以及各色"色金"相关能力。
SIGNIFICANCE: 为世界观引入超自然元素，区分了普通武侦与"超侦"的战斗力层级，为后期涉及神话与超自然的战斗奠基。
SOURCE_REF: vol-02
---WORLD_ITEM---
NAME: 色金（Irogami / Colored Golds）
TYPE: terms
DESCRIPTION: 与绯绯色金同系列的多种色金，每种色金对应不同的颜色和神力。包括：白雪使用的"色香菖蒲"（属于色金系列武器）、绯金菖蒲（佩特拉持有）、以及各种色金衍生的武器和法术。色金构成了绯弹世界超自然力量体系的基础，不同色金的持有者拥有不同的超自然能力。后期故事中，"反色金"技术也被开发出来用于对抗色金力量。
SIGNIFICANCE: 绯弹世界超自然力量的物质基础，几乎所有超能力和特异武器的来源。
SOURCE_REF: vol-02, vol-04, vol-08, vol-27

## 三、重要武器与装备
=============================================================================

---WORLD_ITEM---
NAME: 绯弹（Hidan / Scarlet Bullet）
TYPE: terms
DESCRIPTION: 由绯绯色金制成的特殊子弹，夏洛克·福尔摩斯4世在伊·U事件中将其射入年幼的亚莉亚心脏附近，由此亚莉亚被称为"绯弹的亚莉亚"。绯弹赋予了亚莉亚超常的战斗能力和绯色的外表（粉红色头发、红紫色眼眸），但也带来了被绯绯神吞噬的危险。绯弹被七枚壳金包裹以限制其力量。当壳金被破坏后，绯弹的力量开始失控，亚莉亚面临变为破坏神"绯绯神"的危机。
SIGNIFICANCE: 作品标题的由来，亚莉亚的力量之源与命运核心，整部作品围绕绯弹的影响展开。
SOURCE_REF: vol-04, vol-13
---WORLD_ITEM---
NAME: 科尔特·和平制造者（Colt Single Action Army / Peacemaker）
TYPE: terms
DESCRIPTION: 远山金一（加奈）使用的左轮手枪，是19世纪开发的古董级名枪。虽然装弹数和连射能力不及现代自动手枪，但在"速射"这一杂技领域具有构造优势——因为左轮手枪的扳机行程短，连续扣动扳机（Fanning/速射技术）可以达到极快的射速。配合爆发模式下的超人反射神经，金一能够用这把枪使出"不可视子弹"。金次在vol-04的对决中从大哥手中获得了这把枪。
SIGNIFICANCE: 加奈/金一的标志性武器，"不可视子弹"的物质载体。后期传承给金次，成为他后期的重要武器。
SOURCE_REF: vol-04
---WORLD_ITEM---
NAME: 不可视子弹（Invisible Bullet）
TYPE: terms
DESCRIPTION: 远山金一（加奈）的究极枪技，使用者以"无形架式"拔枪——让对手完全看不到手枪的存在、拔枪的动作、瞄准的瞬间和被击中的过程。其原理是利用和平制造者左轮手枪在爆发模式下超高速扣扳机（速射/Fanning），使枪的移动速度快到超越人眼视觉极限。只有同样在爆发模式下的金次，凭借高度集中的感知力才看穿了这一招。金次后期也学会了此招。
SIGNIFICANCE: 代表绯弹世界中人类枪技的最高境界，仅在爆发模式下可施展，是vol-04兄妹/兄弟对决的核心。
SOURCE_REF: vol-04
---WORLD_ITEM---
NAME: M60 通用机枪（M60 General Purpose Machine Gun）
TYPE: terms
DESCRIPTION: 星伽白雪的标志性武器，美军开发的7.62mm NATO弹通用机枪，重量约10公斤，火力强大到被描述为"战争用的枪"。白雪经常在宿舍、阳台、甚至百货公司内不择场合地使用M60扫射，成为作品的标志性搞笑/恐怖元素。白雪在后来的故事中使用了可折叠改造版M60，能从裙子中抽出子弹链并快速组装。这把枪的过度使用也成为白雪"狂战士"性格的符号。
SIGNIFICANCE: 白雪的角色标志，将"大和抚子"与"重机枪"的反差推向极致，是作品中辨识度最高的热兵器之一。
SOURCE_REF: vol-04, vol-10, vol-13
---WORLD_ITEM---
NAME: 德拉古诺夫狙击枪（Dragunov SVD）
TYPE: terms
DESCRIPTION: 狙击手蕾姬使用的轻型半自动狙击步枪。蕾姬是被称为"狙击手的天才"的武侦，能在恶劣条件下进行精密射击，甚至曾用此枪在运动会中射击运动员手中的棍棒来进行"诱导射击"。德拉古诺夫的速射能力使蕾姬可以连续射击进行弹幕压制或地面标记。蕾姬的狙击能力常被称为"超感觉"，能在目视范围外精确命中目标。
SIGNIFICANCE: 蕾姬的角色标志武器，代表作品中狙击技术的顶峰，配合蕾姬的机械人般性格形成鲜明对比。
SOURCE_REF: vol-02, vol-04
---WORLD_ITEM---
NAME: 圣剑杜兰朵（Durandal）
TYPE: terms
DESCRIPTION: 贞德持有的传说圣剑，号称"没有砍不断的东西"。在作品中与白雪的色香菖蒲交锋时，两把神剑互相都无法损伤对方。贞德的祖先——真正的圣女贞德曾用此剑击败弗拉德（虽然未能杀死不死之身的弗拉德）。杜兰朵在vol-04中被白雪的色香菖蒲砍断，后被改造成拐杖中的宽刃穿甲剑，由贞德继续使用。
SIGNIFICANCE: 欧洲传说中的圣剑，贞德的身份象征，与白雪的色香菖蒲形成东西方名剑对决。
SOURCE_REF: vol-02, vol-03, vol-04
---WORLD_ITEM---
NAME: 色香菖蒲 / 绯金菖蒲（Shikishoubu / Hikin Shoubu）
TYPE: terms
DESCRIPTION: 星伽白雪使用的两把名刀。色香菖蒲是白雪的佩刀，号称"没有斩不断的东西"，与贞德的杜兰朵在交锋中不分胜负。绯金菖蒲则是星伽神社供奉的御神体刀，被佩特拉盗走，后在金字塔决战中被白雪夺回。这两把刀都是用色金/绯金锻造的神剑级武器，具有远超普通刀剑的锋利度和硬度。
SIGNIFICANCE: 代表星伽巫女的传承武力，东西方名剑对决的关键一方。
SOURCE_REF: vol-02, vol-04
---WORLD_ITEM---
NAME: 奥尔库斯（Orcus）—— 超空蚀鱼雷潜航艇
TYPE: terms
DESCRIPTION: 由伊·U利用超空蚀效应鱼雷（如苏联Shkval火箭鱼雷技术）改造而成的小型载人潜水艇。利用超空蚀效应——在水中的物体前方产生足以包覆整艘船舰的大气泡，使船舰在气泡中航行，如同在空气中前进——可以达到时速300公里以上的超高速，且几乎无声。原本是军用的鱼雷技术，被伊·U改造成可以乘坐2-3人的交通工具。武藤刚气曾在短时间内复制改造了一艘。
SIGNIFICANCE: 代表伊·U远超时代的科技水平，是作品中辨识度最高的交通工具类科技产物。
SOURCE_REF: vol-04, vol-05, vol-15, AA vol-02
---WORLD_ITEM---
NAME: 如意棒（Nyoi Bo / Laser Staff）—— 孙的雷射武器
TYPE: terms
DESCRIPTION: 来自香港的"猴"——孙使用的必杀武器，真相并非西游记中的红色棒子，而是从孙的眼睛发射的强力雷射光线（光学武器），拥有肉眼无法跟上的速度。如意棒能够融化金属，曾在香港将Excalibur（王者之剑）熔化延展成伞状。孙是伊·U出身的高手，也是金次在香港篇（vol-13~14）的主要对手之一。
SIGNIFICANCE: 展示了绯弹世界中的高科技光學武器，中国武术与科技的融合，香港篇的核心战力。
SOURCE_REF: vol-13, vol-14
---WORLD_ITEM---
NAME: Excalibur / Ragnarok —— 大英帝国的至宝
TYPE: terms
DESCRIPTION: 夏洛克·福尔摩斯4世在伊·U时代使用的萨克逊剑（Saxon sword），剑铭为"Ragnarok"（并非Excalibur——Excalibur另有其剑，由一位羽毛头盔女持有）。金次从夏洛克手中夺取了这把剑，后被孙的如意棒熔化，残骸经意大利马尼亚戈的名工匠重新锻造为"马尼亚戈短刀"回到金次手中。夏洛克故意散播"丢失了Excalibur"的假情报给MI6以混淆视听。

SOURCE_REF: vol-15, vol-20, vol-25
---WORLD_ITEM---
NAME: 镜击（Mirror Shot）
TYPE: terms

SIGNIFICANCE: 金次独创的标志性技能，象征他不再只是模仿大哥，而是走出自己的路。
SOURCE_REF: vol-04
---WORLD_ITEM---
NAME: 空中装弹（Aerial Reloading）

SIGNIFICANCE: 爆发模式下的顶级操作技巧，代表了绯弹世界中枪械操作技术的巅峰。
SOURCE_REF: vol-04

SIGNIFICANCE: 伊·U科技改造能力的代表产物，AA篇中的重要反派武器，展现了伊·U的小型化武器技术水平。

## 四、战斗技能与战术概念
=============================================================================

---WORLD_ITEM---
NAME: 双剑双枪（Soken Soujuu / Dual Swords Dual Guns）
TYPE: terms
DESCRIPTION: 亚莉亚的标志性战斗风格——同时使用两把手枪和两把刀进行战斗，左右开弓型。亚莉亚是能够在双手分别使用不同武器，同时进行射击和斩击的天才。这一技术在强袭科中也是顶尖水平。金次的哥哥金一（夏洛克）也使用同样的双剑双枪战斗方式。此技巧需要高度的左右脑协同和空间认知能力。
SIGNIFICANCE: 亚莉亚的战斗标志，展现其作为"鬼武侦"的战斗天赋和福尔摩斯家族的天才血统。
SOURCE_REF: vol-01, vol-03
---WORLD_ITEM---
NAME: 无形架式（Mukei Kama'e / Invisible Stance）
TYPE: terms
DESCRIPTION: "不可视子弹"的前置技巧，通过特殊的身体姿势和枪械掌握方式，让对手无法察觉到手枪的存在和位置。解除对手的"枪警戒"——一种在武侦训练中习得的对枪械的本能感知。使用无形架式时，对手即使面对面也无法判断何时会被枪口瞄准，彻底瓦解对方的防御预判。
SIGNIFICANCE: "不可视子弹"的核心前置技术，代表了爆发模式下超越常规战斗认知的战斗技巧。
SOURCE_REF: vol-04
---WORLD_ITEM---
NAME: 半进爆发 / 半爆发（Han-shin Bakuhatsu / Semi-HSS）
TYPE: terms
DESCRIPTION: 金次在性亢奋过程中受到干扰时发生的中间状态。与完全爆发模式不同，半进爆发的能力提升幅度较小但副作用也较轻，持续时间更灵活。金次在vol-04中被白雪用M60扫射时，因为受到干扰而进入了这种状态，成功躲过了机枪连射。这一状态在后来的故事中也多次出现，为金次提供了更多元的能力选择。
SIGNIFICANCE: 爆发模式的亚种状态，为金次的战斗提供了[灵活的能力调控手段，减少了完全爆发模式带来的尴尬社交后果。
SOURCE_REF: vol-04
