# 绯弹的亚里亚AA 角色清单（vol-01~02）
## 格式：角色名(日文名/英文名) — 身份／学科 — 备注

## 主要角色（AA主角团）

间宫明里(間宮あかり / Mamiya Akari) — 主角，强袭科一年级，E级武侦 → 获D级考试资格 — 身高139cm幼儿体型，崇拜亚莉亚，她的第一个战妹。使用微型乌兹冲锋枪。家传"鸢穿"招式（改造版非杀伤性偷盗技）。真实身份：间宫一族后裔，掌握秘毒"鹰卷"。两年前家乡被伊·U毁灭，妹妹乃乃香被夹竹桃下毒。射击时隐藏真正实力（隐藏杀人招式"十弩"）。

神崎·H·亚莉亚(神崎・H・亜莉亜 / Kanzaki Holmes Aria) — 强袭科二年级，S级武侦 — 福尔摩斯第四代（欧尔梅斯），粉红双马尾。黑白双枪Government。从伦敦武侦高中留学东京。明里的战姐。绰号"双剑双枪的亚莉亚"。性格严格但温柔，不擅长理解别人感情但在努力学习。

佐佐木志乃(佐々木志乃 / Sasaki Shino) — 侦探科一年级 — 武装检察官之女，岩流剑术传承者（燕返），对明里有过度的占有欲和跟踪狂行为。使用日本军刀"晒衣竿"（刀长150cm以上）。战姐是星伽白雪。与明里因叶子派相识。

火野莱卡(火野ライカ / Hino Raika) — 强袭科一年级，美日混血 — 165cm高挑身材，金发马尾。被称为"男人婆"，内心渴望可爱。使用Magpul Masada突击步枪。秘密爱好：玩Dollfie Dream人偶。战妹是岛麒麟。

岛麒麟(島麒麟 / Shima Kirin) — 国中部三年级研习生，特殊搜查研究科(CVR) — 135cm，萝莉风打扮，非常可爱。使用掌心雷手枪，随身携带长颈鹿布偶"乔纳森"（内部垫脚台/藏枪）。前任战姐妹是峰理子，现任战姐是火野莱卡。

## 重要配角

高千穗丽(高千穂麗 / Takachiho Rei) — 强袭科一年级A级武侦，C班班长 — 武装律师家庭出身，鸟取方言会不小心跑出来。高傲但内心重视朋友。使用斯特姆会格·超级红鹰左轮手枪（454Casull）。四对四战中输给明里后对明里产生莫名执着。曾申请成为亚莉亚的战妹但失败。

峰理子(峰理子 / Mine Riko) — 侦探科二年级 — 麒麟的前任战姐，甜美萝莉风格改造制服。实为伊·U成员，怪盗罗苹四世。远程操控公车劫持并重伤亚莉亚。擅长远距离操控和战术策划。

夹竹桃(夾竹桃 / Nerium) — 伊·U成员，毒药专家，24岁 — 东大药学系毕业。被称为"魔宫之蝎"。两年前袭击间宫一族小镇，对乃乃香下"符丁毒"。使用TNK丝线陷阱，左手白手套内有危险毒素。想要夺取间宫家秘传"鹰卷"。

星伽白雪(星伽白雪 / Hoshiga Shirayuki) — 超能力搜查研究科(SSR)二年级，学生会长，星伽神社巫女 — 超能力者（读心/预知），对志乃的真心一目了然。性格天然但恐怖（对情敌毫不留情）。爱慕远山金次，因此敌视粉红双马尾的亚莉亚。战妹是佐佐木志乃。

间宫乃乃香(間宮乃乃香 / Mamiya Nonoka) — 明里的妹妹，一般中学学生 — 性格温柔坚强，照顾明里日常生活。两年前被夹竹桃注射"符丁毒"，视力开始丧失，8天内将死亡。

风魔阳菜(風魔陽菜 / Fūma Yōna) — 谍报科一年级，风魔忍者后裔 — 远山金次的战妹。擅长隐藏气息、苦无格斗、烟雾弹。使用"鼓膜破"等风魔忍术。与间宫家有历史恩怨。

远山金次(遠山キンジ / Tohyama Kinji) — 二年级，侦探科E级（原强袭科S级） — 爆发模式（性亢奋学者症候群）使用者。有女性恐惧症。性格阴沉但关键时刻可靠。风魔阳菜是他的战妹。与亚莉亚有联系。

## 配角

贞德·达鲁克(ジャンヌ・ダルク30世 / Jeanne d'Arc 30th) — 伊·U成员，法国人，银发，"银冰魔女" — 30代圣女贞德，使用魔法/冰能力（本篇设定），与理子、夹竹桃组成攻击少女队。

爱泽汤汤(愛沢トウトウ / Aizawa Tōtō) — 高千穗的双胞胎随从之一，妹妹头 — 擅长二人默契配合。在四对四战中伪装成普通女学生偷袭明里。

爱泽夜夜(愛沢ヤヤ / Aizawa Yaya) — 高千穗的双胞胎随从之二，妹妹头 — 与汤汤一同行动，使用"笑箱"拘捕法（把明里扔进垃圾桶）。

兰豹(蘭豹 / Lan Bao) — 强袭科教师 — 香港黑手党首领的女儿，美女但凶暴。性格豪爽，偏爱类似自己的莱卡。

小夜鸣(小夜鳴 / Sayonaki) — 救护科约聘讲师 — 帅哥男教师，负责监督四对四战。

高天原佑彩(高天原ゆたか / Takamagahara Yutaka) — 侦探科教师 — 武侦高中最温柔的老师，与兰豹共租房间。

中空知(中空知 / Nakasora) — 通信科二年级 — 胆小口吃的学姐，负责传达教务科通知。

宫本诗织(宮本詩織 / Miyamoto Shiori) — 佐佐木家双胞胎女仆姐姐 — 在特训中扮演爱泽姐妹陪志乃训练。

宫本伊织(宮本伊織 / Miyamoto Iori) — 佐佐木家双胞胎女仆妹妹 — 同上。

星伽粉雪(星伽粉雪 / Hoshiga Kayuki) — 白雪的妹妹 — 巫女，崇拜白雪。

星伽华雪(星伽華雪 / Hoshiga Hanayuki) — 白雪的妹妹 — 巫女，语尾带"的说"。

## 组织

伊·U(伊・U / E.U.) — 国际犯罪组织，由历史上著名犯罪者后代组成。正在搜集优秀人才，绑架/杀害武侦高中学生。

攻击少女隊 — 伊·U下属三人小队：峰理子（罗苹四世）、贞德（圣女贞德30代）、夹竹桃。

间宫一族 — 掌握秘传毒术"鹰卷"的忍者/毒术家族。两年前被伊·U袭击，族人四散隐居。
