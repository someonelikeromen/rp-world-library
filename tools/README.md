# 腾讯文档爬取 & 增量更新工具

## 概述

本工具集用于从腾讯文档在线表格爬取数据，并支持基于「更新日志」sheet 的增量更新。

### 支持的两个表格

| 表名 | 文档ID | 更新日志 Tab |
|------|--------|------------|
| 曙光表 | `DVXdHdXNzZWdkQ01Z` | `gj0akn` (规则书更新表) |
| 无限口述规则云端版 | `DZFZQcGhmdWtXdHlK` | `soorea` (更新日志) |

## 工具文件

```
tools/
├── README.md              # 本文件
├── config.json            # 表格配置
├── scrape_sheet.py        # 爬取脚本（Python 编排）
├── diff_updates.py        # 更新差异检测
├── apply_updates.py       # 增量合并
└── updates/               # 本地更新日志缓存
    ├── 曙光表_更新日志.json
    └── 无限口述_更新日志.json
```

## 快速使用

### 1. 全量爬取
```
在 Pi 中执行：
"使用 tools/scrape_sheet.py 爬取 曙光表"
"使用 tools/scrape_sheet.py 爬取 无限口述"
```

### 2. 增量更新
```
在 Pi 中执行：
"检查 曙光表 是否有更新"
"检查 无限口述 是否有更新"
"同步更新 曙光表"
```

## 更新日志结构

### 曙光表 - 规则书更新表
| 列 | 字段 | 说明 |
|----|------|------|
| C64 | 编号 | 唯一编号 |
| C65 | 名称 | 兑换项名称 |
| C66 | 支线剧情 | 支线等级 |
| C67 | 分类 | 所属 sheet（科技类/魔法传说类/辅助类/娱乐类） |
| C68 | 更新内容 | 添加/调整/删除 |
| C69 | 修改提议者/作者 | 贡献者 |
| C70 | 更新时间 | 日期 |
| C71 | 调整/删除原因 | 备注 |

### 无限口述 - 更新日志
| 列 | 字段 | 说明 |
|----|------|------|
| C64 | 名称 | 兑换项名称 |
| C65 | 类别 | 所属 sheet |
| C66 | 支线等级 | 支线等级 |
| C67 | 日期 | 更新日期 |
| C68 | 更改内容 | 添加/调整/删除 |
| C69 | 负责人 | 贡献者 |
| C70 | 备注 | 备注 |

## 增量更新流程

```
1. 打开目标表格的更新日志 tab
2. 提取更新日志所有数据
3. 与本地缓存 diff_updates.py 比对
4. 识别新增/修改的条目
5. 对于需要更新的条目：
   a. 定位所属 sheet
   b. 打开对应 tab 获取该条目的完整数据
   c. 合并到本地 JSON 文件
6. 更新本地缓存
```
