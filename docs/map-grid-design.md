# 多边形网格地图设计

地图功能用于多世界 RP 的地点、探索、战斗、势力范围和事件展示。

核心思想：地图由多边形网格组成，通过格子内容、颜色、图标、边界和图层表达地形、单位、势力、危险、状态与 GM 隐藏信息。

## 1. 地图类型

支持：

```text
square-grid      方格地图
hex-grid         六边形地图
triangle-grid    三角网格
polygon-grid     自定义多边形网格
node-map         节点地图/关系式地点图
```

第一版建议优先实现 `square-grid` 或 `hex-grid`，自定义多边形作为扩展。

## 2. 地图层级

```text
Map
  ├── Layers
  ├── Cells
  ├── Edges
  ├── Entities
  ├── Overlays
  └── GM Hidden Data
```

## 3. 格子内容

每个格子记录：

- 坐标或多边形顶点。
- 地形。
- 颜色。
- 图标。
- 标签文字。
- 进入成本。
- 视野阻挡。
- 掩体。
- 高度。
- 所属势力。
- 当前单位。
- 事件/陷阱/资源。
- 玩家可见信息。
- GM 隐藏信息。

## 4. 颜色规则

颜色用于快速表达状态，但不能只靠颜色，必须同时有文字/标签，方便前端展示和避免歧义。

建议：

```text
绿色：安全/友方/可通行
黄色：注意/中立/低风险
橙色：危险/警戒/高成本
红色：敌对/战斗/高危
紫色：异常/污染/神秘
蓝色：水域/能量/防护
灰色：未知/封锁/不可见
黑色：禁区/死亡/不可通行
```

## 5. 图层

```text
terrain-layer      地形层
faction-layer      势力控制层
danger-layer       危险层
entity-layer       单位层
event-layer        事件/线索层
resource-layer     资源层
vision-layer       视野/迷雾层
gm-layer           GM 隐藏层
combat-layer       战斗范围/技能范围层
```

前端可切换图层；GM 层默认折叠或隐藏。

## 6. 多边形格子

自定义多边形格子需要记录顶点：

```json
{
  "cellId": "cell-001",
  "shape": "polygon",
  "vertices": [
    { "x": 0, "y": 0 },
    { "x": 1, "y": 0 },
    { "x": 1, "y": 1 },
    { "x": 0, "y": 1 }
  ]
}
```

方格/六边形可以只记录轴坐标，再由前端计算顶点。

## 7. 战斗结合

地图格子影响：

- 移动距离。
- 视野和遮蔽。
- 射程。
- 范围技能。
- 高低差。
- 地形词条。
- 环境资源。
- 势力介入。
- 逃跑路线。

战斗日志应记录位置变化与地图状态变化。

## 8. 前端实现建议

前端只读：

- 左侧选择 Campaign / Card / Session / Map。
- 中间显示地图或正文历史。
- 右侧显示当前格子信息、单位、地形、GM 隐藏层。

地图数据来源于 JSON，前端不直接修改状态。

## 9. 地图更新原则

- 地图初始数据写入 map 文件。
- 会话中的破坏、占领、污染、火灾、封锁写入 map delta。
- 玩家探索后更新 visibility。
- GM 隐藏陷阱和事件留在 gm-layer。
