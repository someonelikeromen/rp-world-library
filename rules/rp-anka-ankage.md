# RP Anka / Ankage · 安科 / 安价规则

安科与安价是可选玩法层，可嵌入 Actor / Director 模式。它们提供随机性和用户候选，但不替代角色内生推演。

## 安科

安科使用随机表决定当前条件下的合理分支。

适用：

- NPC 反应。
- 随机遭遇。
- 暗线推进。
- 事件强度。
- 调查线索出现。
- 势力反应。

规则：

- 安科表中的每个结果必须符合世界规则和当前局势。
- 极端结果需要低权重和因果入口。
- 骰出结果后仍需通过知识、能力、心理、动机、关系、感知和 OOC 校验。
- 不合理结果应降级、转译或解释为误判/局部发生，而不是硬圆。

## 安价

安价接收用户候选、投稿、台词大意或行动方案。

处理流程：

1. 收集候选。
2. 合法性筛选：知识、能力、感知、心理、动机、资源、关系、世界规则。
3. 状态标记：合格 / 部分合格 / 高风险 / 重大不可逆 / 不合格。
4. 转译：把部分合格候选改写成角色可能做出的相近行为。
5. 选择：可按角色动机排序，也可用安科表或骰池选择。
6. 落地：执行并结算后果。

## 禁止

- 安价直接让 NPC 无铺垫爱上、投降、背叛或送神器。
- 安科骰出神迹跳过能力、资源、感知、因果链。
- 随机结果覆盖已建立的人物心理、势力利益和世界规则。
- 用骰子逃避 OOC 检查。
