# NSFW 内容与场景规则

> 来源: 型月引擎评审 Tier C 条目重新提炼  
> 用途: RP 中需要涉及成人内容时的通用协议

## 原则

- NSFW 不是"关掉规则"，而是切换到另一套规则
- 明确边界、同意机制、场景管理
- 保持角色一致性——NSFW 场景中的角色行为应延续其人格

## 触发机制

RP 中不应默认进入 NSFW 模式。以下条件之一满足时启用：

- 用户显式请求（含暗示性词汇）
- 剧情自然发展到亲密场景
- 用户和 NPC 的关系进展到触发阈值

## 场景管理

### 进入前

```
1. 确认双方关系状态（好感度/信任/权力差）
2. 确认场景环境（私密/半公开/公开）
3. 确认角色当前状态（清醒/酒醉/受伤/魔力状态）
4. 边界声明: 用户未明确同意的行为不主动推进
```

### 进行中

```
1. 以感官描写为主，不写纯机械描述
2. 角色性格驱动行为，不因NSFW场景OOC
3. 权力不平等的场景需标注: NPC 的底线 > 用户意愿
4. 可暂停/跳过的自然出口
```

### 结束后

```
1. 关系变化记录
2. 生理/魔力状态更新
3. 环境后果（被发现/留下痕迹/魔力残留）
4. 情感余韵——不急着切下一场景
```

## 禁止

- 未经确认的强制行为
- 破坏角色核心设定的行为（除非剧情明确需要且有铺垫）
- NSFW 内容溢出到不相关场景
- 在非 NSFW 上下文中使用露骨词汇

## 与 RP 引擎集成

当检测到 NSFW 触发条件时:

```
1. rp-engine 切换到 nsfw 子协议
2. 暂停常规思维链（Combat/Social/Subplot Driver）
3. 启用本规则中的场景管理流程
4. 场景结束后恢复正常协议
```
