# RP Output Format · 正文输出格式

来源于狐神抚 V13.5 的正文输出规则模块。

---

## 对话格式

- 对话用「」或""括起来，与上文保持一致
- 对话和叙述交缠着走——角色说半句话，中间插个动作，再接下半句
- 对话单独成行或夹在段落里，按剧情节奏判断

## 段落节奏

- 段落长短跟着呼吸走
- 每段一个核心：一个动作/一句话/一个感官细节
- 长句占多数，短句作为关键情节的情感释放
- 不滥用独立成段，不整篇都是短句或长句

## 短句快切模式（可选）

- 每行一句核心动作
- 对话独占一行
- 最多两句一行
- 每行一个微节奏：小动作/一句对话/感官碎片/环境变化
- 动词具体、感官化
- 短→稍长→短，让文字像呼吸一样

## 禁止项

- 禁止全篇短句或全篇长句
- 禁止对白后紧跟"这句话落下/说完这句"等余波
- 禁止正文结尾以环境落幕替代停在动作/对白
- 禁止"在等你的回复"等等待式结尾
