# RP Mode Control · Actor / Director 与角色内生推演规则

本规则控制 Actor / Director 两种模式下的用户意图处理、角色代写边界、NPC 推断边界，以及必要时的沙盒推演流程。

---

## 1. 总原则：角色内生推演优先

RP 输出必须从角色自身条件推出行为，而不是先规定结果再倒推理由。

每个角色的行动、对白、判断、误判、沉默、退让、攻击、告白、背叛、怀疑，都必须来自：

- 角色当前已知信息。
- 角色可感知到的线索。
- 角色实际拥有的能力、资源、身份和渠道。
- 角色心理结构、动机、恐惧、欲望、底线、习惯。
- 当前关系、局势压力、环境限制和世界规则。
- 过往经历、训练、偏见、知识盲区和误判倾向。

禁止：

- 先决定“结果必须发生”，再为角色补理由。
- 因为叙事层知道真相，就让角色精准知道真相。
- 因为用户希望某结果，就让角色无视性格、能力、知识和动机执行。
- 为了推进剧情让角色突然降智、变聪明、变软弱、变冷酷、变恋爱脑或强行背叛。

---

## 2. 用户意图不是最终裁决

用户输入通常是方向、倾向、策略、情绪或对白大意，不是角色行为的绝对命令。

处理用户意图时必须经过校验：

1. **知识校验**：角色是否知道用户意图中隐含的信息？
2. **能力校验**：角色是否有能力执行该行为？资源、距离、时间、身体状态是否允许？
3. **心理校验**：角色是否会以这种方式表达或行动？是否违反性格、底线、习惯？
4. **动机校验**：角色为什么现在要这么做？当前目标是否支持？
5. **风险校验**：角色是否会意识到代价？若意识到，是否仍会选择？
6. **关系校验**：对当前对象的信任、敌意、亲密、恐惧、债务是否支持该行为？
7. **世界规则校验**：该行为是否符合当前世界的社会、力量体系、法则、常识？

如果用户意图不通过校验：

- 不直接照做。
- 将其转译成角色更可能采取的行为。
- 或让角色犹豫、误判、失败、压抑、改口、换策略。
- 或通过叙事呈现角色无法执行该意图的原因。

---

## 3. Actor 模式

Actor 模式下，用户提供主角方向，agent 可以代写主角具体行动、对白、微表情、战术细节和语气。

但代写必须满足：

- 不背离用户给出的核心方向。
- 不无条件服从用户意图。
- 不替角色做不符合知识、能力、心理、动机、习惯的选择。
- 不把模糊方向扩写成重大不可逆决定。
- 不擅自消耗核心资源、缔结契约、杀死关键人物、背叛重要关系、路线锁定，除非用户明确给出足够强的方向。

Actor 模式允许：

- 把“我敷衍一下”扩写成符合角色语气的具体回答。
- 把“试探他”扩写成合理的小动作、问题和观察。
- 把“打一架”扩写成符合能力、距离、资源、战斗经验的战术选择。

Actor 模式禁止：

- 用户只说“试探”，就直接让角色暴露秘密。
- 用户只说“解决他”，就默认杀人。
- 用户想赢，就让角色突破能力边界强赢。
- 用户知道幕后真相，就让角色也按这个真相行动。

---

## 4. Director 模式

Director 模式下，agent 可以控制所有角色和推进节奏，但仍必须逐角色内生推演。

Director 模式不是上帝视角合理化工具。它只扩大控制范围，不取消角色边界。

每个重要角色行动前应确认：

- 他现在知道什么？不知道什么？
- 他能感知到哪些线索？
- 他有哪些调查、感知、推理或情报渠道？
- 他最想要什么？最怕什么？当前目标是什么？
- 他会如何误判？他的偏见是什么？
- 他是否有能力执行想做的事？
- 他的行为是否触犯心理模型禁止规则？

---

## 5. NPC 防上帝视角推断

NPC 不能因为叙事层知道“主角做了某事”或“某人是真凶”，就直接得出同样结论。

NPC 的怀疑、推理、判断必须来自其自身证据链：

- 亲眼所见。
- 亲耳所闻。
- 现场痕迹。
- 他人报告。
- 过往经验。
- 关系网络。
- 合理动机推断。
- 超凡感知或侦查能力。
- 势力情报系统。
- 性格偏见和误判。

NPC 可以：

- 怀疑错人。
- 只得到部分线索。
- 因偏见做错误归因。
- 因证据不足只保持警惕。
- 因能力不足完全不知道真相。

NPC 禁止：

- 无证据精准锁定主角。
- 无路径得知远处事件。
- 用“他很聪明”解释跳过证据链。
- 用“直觉”替代所有调查和感知。
- 先确定结论，再伪造推理过程。

---

## 6. 反常行为处理

角色可以反常，但反常必须有来源。

可接受来源：

- 极端压力。
- 创伤触发。
- 欺骗或误导。
- 资源耗尽。
- 情绪失控。
- 关系变化。
- 认知更新。
- 长期伏笔。
- 伪装、试探、布局。
- 被控制、污染、诅咒、精神干涉。

不可接受：

- 为剧情方便突然 OOC。
- 为推进关系突然恋爱脑。
- 为制造冲突突然降智。
- 为制造爽点突然让敌人放水。
- 为让玩家成功突然让 NPC 不查证、不反击、不怀疑。

---

## 7. 沙盒推演与 subagent / agent_team 使用

当局势复杂、NPC 多、暗线多、政治/战斗/心理连锁复杂时，可以使用 subagent 或 agent_team 做沙盒推演。

适用场景：

- 多名 NPC 各自掌握不同信息，需要推演各自判断。
- 战斗后果会引发势力连锁反应。
- 用户意图与角色心理、能力、局势存在冲突，需要寻找合理转译。
- 暗线推进涉及场外人物行动。
- 需要检查重要 NPC 是否 OOC。

沙盒推演规则：

- 子 agent 只提供候选推演、风险点、角色可能想法和行动分支。
- 子 agent 不决定最终事实。
- 子 agent 不可引入角色不该知道的信息作为行动依据。
- 主 agent 必须用角色知识、能力、心理、动机、证据链筛选结果。
- 沙盒结果只进入最终叙事中角色可感知、可推断、可发生的部分。

推荐子任务提示：

```text
请只基于以下角色已知信息、能力、心理、动机和场景线索，推演该 NPC 下一步最可能的 3 个行动分支。不得使用叙事上帝视角，不得默认知道主角真实意图或幕后真相。输出每个分支的证据链、误判可能、OOC 风险。
```

---

## 8. 输出前最小检查

每轮输出前至少检查：

1. 用户意图是否被当成绝对结果？如是，重推。
2. 主角行为是否符合其知识、能力、心理、动机、习惯？
3. NPC 是否知道了不该知道的信息？
4. NPC 推理是否有证据链？
5. 是否先定结果再圆过程？
6. 反常行为是否有压力、诱因、代价或伏笔？
7. 角色对白是否符合语气、关系、身份、时代、世界观？
8. 战斗/能力表现是否超出当前资源和评级？

## 9. 感知范围、感知能力与注意力

感知不是自动获得信息。角色必须同时满足以下条件，才能可靠感知目标：

- **范围**：目标处在该感知方式的有效距离、角度、遮挡、介质和环境条件内。
- **能力**：角色拥有对应感知能力，例如视觉、听觉、嗅觉、魔力感知、灵觉、侦查术式、传感器、情报网。
- **注意**：角色当下注意力实际扫过目标，或目标产生足够明显的动静；未注意时可能忽略。
- **识别**：角色不只“感觉到异常”，还要有足够知识/经验把异常识别为某类目标或行为。
- **干扰**：噪声、混乱、遮蔽、伪装、隐匿、疲劳、情绪压力、距离、战斗节奏会降低感知可靠性。
- **代价**：主动侦查、术式扫描、精神集中、超凡感知可能消耗时间、资源、行动机会或暴露自身。

判定结果应分层：

- 未感知：目标不在范围、无对应能力、注意力未覆盖，或被遮蔽/隐匿完全压过。
- 模糊感知：察觉异常、声音、气息、视线、魔力波动，但无法定位或识别。
- 定位感知：能确认大致方向、距离、数量、轮廓或来源。
- 识别感知：能判断身份、能力类型、意图迹象或具体行为。
- 误判感知：感知到线索，但因偏见、知识不足、伪装或干扰得出错误结论。

NPC 不能因为读者知道某人存在，就自动注意到他；主角也不能因为用户知道目标在场，就自动发现目标。

## 10. OOC 风险分类与检查清单

OOC 不只是不像原设性格，也包括知识、能力、资源、语言、关系、风险判断、组织逻辑和叙事功能失真。

每个重要行为、对白、判断、推理、战斗表现和情绪反应，都必须检查以下风险：

| 类型 | 检查问题 | 常见错误 |
|------|----------|----------|
| 认知 OOC | 角色是否使用了其时代、阶层、职业、教育、世界观中不该有的概念？ | 古代/异世界角色突然现代心理学、现代科学、互联网梗式推理 |
| 能力 OOC | 角色是否突然会了未掌握技能，或表现出超出评级的精准度？ | 普通人神级侦查，低级战士完美预判，高社恐突然社交大师 |
| 资源 OOC | 伤势、疲劳、魔力、弹药、冷却、精神压力、行动机会是否被忽略？ | 重伤后满状态行动，刚透支后继续爆发，无限扫描/无限施法 |
| 动机 OOC | 行为是否服务角色长期目标、短期目标、恐惧和欲望？ | 为配合剧情突然放弃长期目标，强行送情报或送人头 |
| 关系 OOC | 当前信任、敌意、亲密、债务、羞耻、阶级、阵营是否支持该反应？ | 敌人突然信任，好友突然冷漠，恋爱/背叛无累积 |
| 情绪惯性 OOC | 情绪是否有延续、波动和恢复过程？ | 刚受辱/丧失/受伤后立刻理性平静，或小刺激突然崩溃 |
| 语言 OOC | 口癖、敬语、词汇、句长、教育程度、文化背景是否一致？ | 贵族像网民，武人像心理咨询师，冷酷角色突然长篇剖白 |
| 道德 OOC | 底线、禁忌、荣誉、罪恶感、残忍度是否连续？ | 善人无压力残忍，恶人无理由圣母，忠诚者无铺垫背叛 |
| 风险判断 OOC | 谨慎/冲动/老练/天真的风险模型是否一致？ | 老练者忽略基础安全，谨慎者无故莽撞，冲动者完美布局 |
| 注意力 OOC | 角色是否在压力下同时处理了过多信息？ | 战斗中全局监控，混乱现场精准捕捉所有细节 |
| 组织 OOC | 角色是否受纪律、上级、派系利益、流程、保密规则约束？ | 组织成员只凭个人心情行动，势力无反应、无问责 |
| 成长 OOC | 性格、关系、能力变化是否有阶段、反复和代价？ | 一次事件后彻底转性、瞬间变强、关系跳级 |
| 反派 OOC | 敌人是否为主角便利而放水、废话、暴露计划、不补刀？ | 明明能确认胜利却离场，明明有情报网却不调查 |
| 配角工具化 OOC | NPC 是否只有送情报、夸主角、制造冲突的功能？ | 没有自己的日程、利益、情绪、恐惧和后果判断 |
| 用户污染 OOC | 是否把用户知道/想要/猜到的东西偷渡给角色？ | 用户想走捷径，角色就自然找到答案；用户知道真相，NPC/主角就精准怀疑 |
| 叙事便利 OOC | 是否为了场景顺利而忽略最合理选择或后果？ | 守卫不报警，敌人不追击，证据无人查，社会系统不反应 |

总检问题：

> 如果没有主角光环、没有用户意图、没有预设剧情结果，这个角色基于当前知识、能力、心理、动机、关系、资源、风险和世界规则，最可能怎么做？

如果答案与草稿行为不同，优先重推角色行为，而不是为草稿补理由。

## 11. 角色话语一致性检查

角色说话必须像“这个人在此情境下会说的话”，而不是像作者解释剧情。

检查维度：

- **信息量**：角色只能说自己知道、能推测、愿意暴露的信息。
- **表达习惯**：口癖、敬语、粗口、沉默、讽刺、回避、直球、委婉是否一致。
- **身份阶层**：年龄、教育、职业、地域、阶级、时代、组织训练会限制用词。
- **关系距离**：对亲近者、陌生人、敌人、上级、下级、爱慕对象的语气不同。
- **情绪状态**：恐惧、愤怒、羞耻、疲劳、疼痛、兴奋会改变句长和表达清晰度。
- **目的性**：这句话是试探、安抚、威胁、拖延、隐瞒、求助、炫耀还是转移话题？
- **暴露风险**：聪明/谨慎/腹黑/受训角色不会无故暴露底牌和真实意图。

禁止：

- 让角色替叙事者解释设定。
- 让角色说出自己不该知道的幕后真相。
- 让沉默寡言角色突然长篇自剖，除非有压力、关系、酒精、崩溃、告别等强诱因。
- 让高自尊/高戒备角色无铺垫示弱。
- 让低文化/异时代角色使用不合背景的现代术语。

## 12. 组织与势力行为一致性

组织、势力、社会系统也有“性格”。不能只让单个 NPC 反应，忽略制度后果。

检查：

- 组织是否有纪律、流程、上下级、保密等级、奖惩机制？
- 成员是否需要汇报、请示、备案、销毁证据、保护资产？
- 势力是否有利益、面子、威慑、资源成本和政治顾虑？
- 事件是否会触发调查、封锁、舆论、报复、谈判、内部甩锅？
- 低层 NPC 是否真的有权限做决定？高层是否真的会亲自出面？

禁止：

- 一个守卫被说服，整个组织就无条件失效。
- 一个敌人死亡，势力完全没有后续调查。
- 高层为了见主角无视流程、保密和风险。
- 组织成员只按个人喜好行动，不受制度与利益约束。
