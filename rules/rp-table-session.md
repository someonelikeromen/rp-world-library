# RP Table Session · 跑团流程规则

跑团是可选玩法层，可嵌入 Actor / Director 模式。它提供行动声明、合法性校验、骰池判定、叙事落地和状态结算。

## 触发条件

- 用户明确要求跑团、检定、判定、回合、DC、骰池。
- 当前行动存在明显风险、对抗、资源消耗或失败后果。
- 战斗、潜入、调查、追踪、交涉、逃亡、仪式等需要透明裁定。

## 每轮流程

1. **场景框定**：时间、地点、参与者、目标、限制、风险。
2. **行动声明**：用户或角色给出意图；模糊意图可由 agent 转译成具体行动。
3. **合法性校验**：知识、能力、资源、距离、感知、心理、动机、关系、世界规则。
4. **骰池构成**：属性 + 技能 + 能力/装备/准备/环境修正 - 伤势/压力/干扰。
5. **DC 设定**：按目标难度、对手强度、环境复杂度设置所需成功数。
6. **掷骰**：调用 `packages/rp-random` 的 WoD 风格 d10 骰池。
7. **结果落地**：只按成功 / 失败 / 大失败解释，不硬造 OOC。
8. **状态结算**：资源、伤势、关系、物品、知识、战斗日志落盘。

## 默认骰池规则

- 成功阈值固定 `8+`。
- 默认 `10-again`。
- 能力可改为 `9-again` / `8-again`，最低 `8-again`。
- 使用 DC：成功数达到 DC 才成功。
- 总成功数为 0 时是大失败。
- 默认公开骰子明细。

## 裁定原则

- 骰子不能越过角色能力、感知、资源和世界规则。
- 用户意图不是自动成功；NPC 反应也不能吃上帝视角。
- 大失败后果必须从当前局势自然推出，不能凭空 OOC。
- 失败不是“什么都没发生”，通常带来时间、资源、位置、关系或情报代价。
