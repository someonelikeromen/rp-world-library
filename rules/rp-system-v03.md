# RP System v0.3 — 原作完整奖励与成就规范

本文件是当前 RP 系统的优先规则。若与旧 memory、旧剧情摘要或旧奖励候选冲突，以本文件为准。

## 1. 基础定位

- 玩法：Actor 模式；用户只控制主角，AI 控制 NPC、环境、事件。
- 世界：漫威电影宇宙，开局为托尼·斯塔克阿富汗失踪前一个月。
- 主角基底：普通人穿越者，拥有本地合法身份、住所、资金和社会日程。
- 奖励与成长可以跨世界，但必须可验证、可运行、可记录。
- 用户修正优先级高于 agent 既往推导；一旦用户指出系统错误，应暂停 RP，先修正规则与状态。

## 2. 骰池判定

- 使用 d10 骰池。
- 每颗 d10 结果 >= 8 计 1 成功。
- 默认 10-again：掷出 10 时追加 1 颗骰。
- 掷骰前或掷骰同时必须公开：骰池构成、成功阈值、again 规则、目标、失败后果。
- 不伪造、不暗改、不因结果差而重掷；除非已有规则或能力明确允许。

### 成功等级

| 成功数 | 结果 |
|---|---|
| 0 | 失败 |
| 1 | 勉强成功 / 部分成功 |
| 2 | 标准成功 |
| 3-4 | 优秀成功 |
| 5+ | 卓越成功 |

## 3. 成就等级

成就使用多世界强度等级：F / E / D / C / B / A / S / SS / EX。

| 等级 | 定义 | 奖励倾向 |
|---|---|---|
| F | 很小的普通进展，通常只记录 | 通常无奖励 |
| E | 低风险但有明确第一次意义 | E-D |
| D | 有实际阶段意义但风险低 | D 为主，少量 C |
| C | 明确突破实用阶段，或中等风险行动成功 | C 为主，少量 D / B 种子 |
| B | 高风险或关键剧情节点 | B 为主，少量 A 种子 |
| A | 重大剧情改写或击败远强敌 | A 为主，少量 S 种子 |
| S/SS/EX | 世界级、宇宙级、命运级 | 特殊处理 |

### 成就触发条件

成就必须满足至少一项：

1. 第一次完成有意义闭环。
2. 突破明确阶段门槛。
3. 承担实际风险并成功。
4. 改变外部世界状态。
5. 连续积累达到阶段结果。

限制：

- 同一能力体系一天最多触发一个训练类成就。
- 同一训练方向短时间不能连续刷成就。
- 日常蒙太奇一次最多触发一个生活/长期维持类成就。
- 高风险剧情成就可以额外触发，但必须真有风险。

## 4. 奖励生成流程

每次成就奖励固定流程：

1. 判定成就等级。
2. 确定奖励等级范围。
3. 从合法奖励池中生成或抽取 10 个不重复候选。
4. 过滤不合规候选。
5. 从 10 个候选中随机展示 3 个。
6. 用户三选一，或要求重随/查看候选池。
7. 用户明确选择前，奖励不生效。
8. 用户选择后，写入角色卡与 memory。

## 5. 奖励合法性硬规则

奖励必须是原作中明确存在的完整对象。允许的奖励对象包括：

1. 完整流派。
2. 明确术式 / 招式 / 技能。
3. 明确物品 / 装备 / 消耗品。
4. 明确血统 / 体质 / 体系基础。
5. 明确角色能力传承。

禁止：

- 风格化原创奖励。
- “某某式直觉”“某某雏形”“某某感”之类 agent 自创标签。
- 普通技能换皮，如校园设备熟悉感、普通资料整理能力、普通时间管理能力。
- 作品调性错误的奖励。
- 原作没有明确出现的能力、物品、体系或训练法。
- 为了降低强度而把完整原作能力拆成自创弱化版。

重要：奖励等级决定“能不能进入候选池”，而不是把强能力捏成弱版。若完整奖励太强，就不进入低等级成就池。

## 6. 流派奖励规则

如果奖励是有流派的能力，则获得完整流派传承，而不是某一个招式。

例如：

- 水之呼吸：获得完整水之呼吸流派传承，而不是只获得一之型。
- 飞天御剑流：获得完整飞天御剑流传承，而不是只获得龙槌闪。
- 北斗神拳：若成就等级不足以承载完整流派，则不应进入候选池。

完整流派传承包括：

- 原作明确的基本理论。
- 步法、呼吸、发力、节奏或对应基础。
- 原作明确包含的招式体系。
- 对应熟练度传承。

限制：

- 技艺理解和熟练度到账。
- 输出上限、身体承受、安全性、武器条件、法律风险由当前角色现实条件决定。
- 如果当前身体不足以安全施展高阶招式，不能强行发挥原主级威力。

## 7. 单独术式 / 招式奖励规则

如果奖励是单独术式或技能，如替身术、影分身、强化魔术、缠、波纹疾走，则获得该术式/技能的完整施展方法。

不能写成“替身术雏形”“波纹疾走触碰版”这类原作未明确对象。若要限制威力，应通过施展条件、身体承受、能量储备、环境和风险来限制，而不是改造奖励本体。

## 8. 体系基础补足规则

若奖励需要某个力量体系基础，奖励必须自动补足施展该能力的最低标准。

例如：

- 获得替身术时，若主角没有查克拉，则同时获得能施展替身术的最低查克拉基础、基础提炼/控制、结印和术式知识。
- 获得强化魔术时，若主角没有魔术回路，则必须同时获得能施展该强化魔术的最低魔术回路、术式与基盘接入方式；否则该奖励不能进入候选池。
- 获得水之呼吸时，必须补足最低呼吸适性、基础体能与剑型肌肉记忆，但不等于柱级肉体。
- 获得飞天御剑流时，若成就等级不足以补足最低身体承载，则该奖励不进入候选池。

只补足“施展该奖励的最低标准”，不额外赠送更高体系强度。

## 9. 奖励条目模板

每个奖励候选必须包含：

- 名称
- 来源作品
- 等级
- 类型
- 原作依据
- 奖励内容
- 最低施展条件
- 本奖励补足的条件
- 当前可发挥效果
- 当前不能做到
- 消耗 / 风险
- 适用检定
- 成长路线

## 10. 技能成长与训练

训练不自动触发奖励。大多数训练只给进度、状态或熟练度。

技能升级需要同时满足：

1. 足够训练进度。
2. 明确阶段门槛。
3. 必要时完成环境/压力/实战测试。

同日重复训练同一方向时收益递减：

- 第 1 次：正常收益。
- 第 2 次：正常或 -1。
- 第 3 次：收益减半。
- 第 4 次以后：除非有明确条件，否则主要积累疲劳和风险。

## 11. 当前存档处理原则

用户已要求：

- 按 v0.3 规则处理。
- 剧情回滚。
- 能力回滚。
- 成就回滚。
- 开局能力也重置。
- 按当前用户偏好的处理方式、风格与人物性格重新生成和推演。
- 只有成就奖励由用户选择。
- 后续推演直到一个月结束、钢铁侠正式开始。

执行顺序：

1. 先沉淀 v0.3 系统规则。
2. 再备份旧角色卡和旧剧情状态。
3. 清空旧进度、旧能力、旧成就。
4. 重建开局角色卡。
5. 重新生成开局奖励候选，用户选择后才生效。
6. 按 v0.3 继续 RP。

## 12. 已判定为不合规的旧奖励

以下旧奖励是 agent 风格化原创，不符合 v0.3，后续不得继续使用：

- 修炼者的身体记忆。
- 一刀修罗式专注雏形。
- 自我演算雏形。
- 机械直觉·低阶。
- 校园设备熟悉感。
- 交叉索引书签。
- 任何类似“某某雏形 / 某某式感知 / 普通技能换皮”的奖励。

旧剧情与旧能力将按用户要求回滚；过去结算不作为新周目事实。
