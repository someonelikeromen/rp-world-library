# 分布式思维链 (Distributed Chain-of-Thought)

> 来源: 型月引擎评审 A2  
> 用途: RP 中战斗/社交/暗线等不同认知域使用独立思维链模块

## 原则

单一系统提示词处理所有场景 → 战斗检定敷衍、NPC 行为扁平、暗线被遗忘。

将不同"认知域"拆分为独立思维链，由主引擎按场景路由调用。

## 思维链类型

### 1. 战斗链 (Combat Driver)

触发: 任何形式的武力冲突

```
Step 1: 先手判定 — 双方反应 + 感知 + 环境因素
Step 2: 攻防检定 — (攻方出力 × 技能倍率) - (守方耐久 + 防护)
Step 3: 特殊机制判定 — 魔术/宝具/能力/词条对抗
Step 4: 结果与代价 — 伤害程度 + 资源消耗 + 环境破坏 + 公众暴露
```

### 2. NPC 社交链 (Social Driver)

触发: 与 NPC 发生有意义的对话/互动

```
3 级过滤:
  1. 性格层: NPC 的核心性格倾向决定反应基调
  2. 诉求层: NPC 当前想要什么？什么能打动TA？
  3. 底线层: 底线具有一票否决权，好感度≠服从

反好感度绑架:
  好感度只代表私人情感倾向，绝不等于行为上的绝对服从。
  当玩家要求违背 NPC 行为底线时，底线一票否决。
```

### 3. 暗线推演链 (Subplot Driver)

触发: 每轮 RP 结束时自动运行

```
空间隔离原则:
  只推演"场外正在发生但角色感知不到"的事件。
  严禁 NPC 以全知方式"视奸"玩家行动。

命运预告:
  暗线事件不直接干预当前场景，而是以环境信号间接呈现。
  例如: "你听到远方教堂的钟声多敲了一声" → 暗示教会方面有异动
```

### 4. 世界推演链 (World Driver)

触发: 时间跳跃/场景切换/重大事件后

```
滚动检查:
  - 势力动态: 各势力在做什么？势力关系是否变化？
  - 环境变化: 天气/魔力浓度/公众舆论
  - 连锁反应: 上一事件的涟漪效应
  - 新事件触发: 概率引擎判定是否有新事件涌现
```

## 与 rp-engine 集成

rp-engine 在每个回合按以下顺序路由：

```
1. 接收用户输入
   ↓
2. 判定场景类型 → 选择思维链
   ├─ 战斗 → Combat Driver
   ├─ 社交 → Social Driver
   └─ 探索/其他 → 直接叙事
   ↓
3. 运行对应思维链 → 产出叙事判定
   ↓
4. World Driver 检查全局变化
   ↓
5. Subplot Driver 推演暗线
   ↓
6. 输出叙事正文
```
