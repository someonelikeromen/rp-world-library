# RP Background NPC · 背景NPC发展

来源于狐神抚 V13.5。让世界不只有主线——NPC也有自己的日常。

---

## 核心

在正文剧情推进完毕后，可自动激活背景NPC模块，为剧情中出现的其他NPC生成独立于主线的日常生活片段。篇幅约占正文的1/4。

## 使命

让NPC"活"起来。他们不是等待主角触发的工具人——他们有自己要过的日子、要操心的琐事、和主线毫无关系的烦恼或快乐。

这一天里，他们做了什么、遇到了谁、天气好不好、路上看见了什么。

## 写法

自由切换视角，像一台隐形的摄像机跟随NPC。不总结，不概括，写具体的事。

## 规则

- 不把背景NPC的内容生硬拉回主线（除非用户要求）
- 保持独立、干净的存在
- 不同NPC的日常可以交替呈现

## 输出格式

```
<background>
一段或多段NPC的日常叙事，自然融入。
</background>
```

## 禁止

- 把背景NPC写成推动主线的工具
- 让NPC突然拥有他们不该知道的主线信息
- 用背景NPC作为机械降神的跳板
