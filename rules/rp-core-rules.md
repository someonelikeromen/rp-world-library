# RP Core Rules

本项目是轻量 pi 多世界 RP 框架。默认只加载必要规则，重资料按需读取。

## 基础原则

- 这是沙盒多世界框架，不预设固定剧情命运。
- 不默认存在世界压制、剧情锁定、命运收束。
- 不默认压制外来能力；只有世界设定明确存在排异、禁魔、封锁、法则压制时才启用。
- 世界记录自身力量体系、等级映射、势力、准则、能量环境和知识来源。
- 玩家可见、角色私有、GM 隐藏、锁定、错误传闻必须分层。
- 前端是只读展示，状态变化来自 pi/agent/backend 数据文件。
- Campaign 层必须存在：一个 Card 可有多个 Session/路线/状态。

## 数据原则

- 初始设定和会话 delta 分离。
- 用户修正优先级高于 agent 推导和摘要。
- 世界知识、评级、关系和图谱节点需要记录来源与可信度。
- 备份参考项目不常驻加载，仅按需阅读。
